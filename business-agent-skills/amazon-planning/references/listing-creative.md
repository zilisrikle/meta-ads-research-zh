# 商品页面创意：图片、视频、A+ 页面与品牌旗舰店

使用本参考规划 Amazon 商品详情页创意。创意要求因品类与站点而异，生产前验证当前的 Amazon 创意规范。

## 主图

主图是转化与点击资产。它必须满足 Amazon 政策，并在搜索结果中让商品一眼可辨。

常见要求：

- 多数品类要求纯白背景。
- 商品占据图片大部分面积。
- 除非品类规则允许，否则不加文字、徽章、边框、水印、道具或内嵌图形。
- 商品必须与买家收到的实物一致。
- 分辨率足够高，支持缩放（如有）。
- 实用的规划目标是长边至少 1,000 像素以获得缩放资格，高质量详情页素材常用 2,000 像素或更高。验证当前站点/品类规格。
- JPEG 通常是最稳妥的默认格式；TIFF、PNG 或 GIF 是否可用取决于上传路径与品类。

规划指引：

- 为手机搜索结果可见性优化。
- 用最清晰的展示角度，而不是最艺术的角度。
- 除非包装本身就是商品，否则避免只用包装图。
- 多件装或捆绑装，数量必须醒目且合规。
- 做缩略图冲击力检查：把图片缩小到手机/搜索尺寸看。如果轮廓、商品类型与差异化价值看不清，这张图还没准备好承接付费流量。

## 副图序列

用副图在消费者滑到评价区之前回答他们的疑问。

| 槽位 | 角色 | 目的 |
|---|---|---|
| 1 | 主图 | 干净的商品识别 |
| 2 | 利益点主视觉 | 展示购买的主要理由 |
| 3 | 功能证明 | 解释差异化功能或材质 |
| 4 | 使用场景 | 展示商品在真实场景中的样子 |
| 5 | 尺寸/适配 | 降低对尺寸或兼容性的不确定 |
| 6 | 对比 | 讲清变体、捆绑，或优于替代品的逻辑 |
| 7 | 说明/信任 | 展示安装、保养、质保、安全或内容物 |
| 8 | 备用/随展示面变化的素材 | 按站点渲染的槽位强化向往感或实用用法 |

不要把信息图塞太满。文字在手机上必须可读。

不要假设每个上传的图片槽位都会在 live 商品详情页渲染。很多站点最突出地展示前七个视觉槽位，视频还可能挤占图片槽位。优先排好前 6-7 个素材。

副图序列围绕消费者异议搭建，而不是内部功能优先级。最好的下一张图，是回答消费者点击之后犹豫的那张。

## 商品视频

当动态、安装、前后对比、质感、比例或使用场景能实质提升理解时，用视频。

商品详情页视频上传通常需要品牌注册或同等的品牌/供应商资格。在制定重视频的上线计划前先验证权限。常见规划规格包括短 16:9 视频、`.mp4` 或 `.mov`、高分辨率源，以及站点特定的文件大小/时长限制。

推荐结构：

1. 立刻展示商品与使用场景。
2. 演示主要利益点。
3. 用特写或真实使用证明差异化。
4. 回应一两个常见异议。
5. 以商品、品牌与变体清晰度收尾。

避免无依据的声明、医疗声明、夸张效果与评价式表述，除非被允许且有依据。

## A+ 页面

A+ 页面不应当是五点描述的漂亮复刻。用它来：

- 讲品牌与产品故事。
- 解释高端材质、工艺或技术。
- 在目录内做商品对比。
- 用图解、使用场景与保养说明降低异议。
- 交叉销售相邻商品。

只有品牌素材足够、商品经济学撑得起更丰富的模块时，才用高级 A+ 页面。

在品牌满足运营资格要求后，高级 A+ 页面在 Amazon 促销期可能免费。把资格（而不只是预算）当作门槛问题。

高级 A+ 页面优先给高客单价、高流量、重对比或重演示的商品。低流量 ASIN 先优化主图、标题、报价与基础 A+。

## 品牌旗舰店

Amazon 品牌旗舰店适合：

- 品牌推广落地页。
- 品牌故事讲述。
- 品类导航。
- 新品上线中心。
- 季节性或活动专属页面。

品牌旗舰店规划应包括页面层级、主视觉、品类磁贴、畅销品、对比模块与广告系列专属落地路由。

## 创意 QA

上线前检查：

- 手机可读性。
- 品类合规。
- 声明有依据。
- 商品/变体一致性。
- 本地化质量。
- 图片顺序逻辑。
- 关键商品信息不依赖小字也能获取。
- 广告承诺与商品详情页证明一致。

## 常见错误

- 为桌面设计，而多数消费者看的是手机。
- 副图做成通用生活场景填充物。
- 加法务或 Amazon 政策撑不住的声明。
- 忽略品类内的竞品图片惯例。
- 把品牌推广或 DSP 流量导向与广告承诺不匹配的品牌旗舰店。
- 确认品牌注册与账户权限之前，就规划视频、高级 A+ 页面或重品牌旗舰店的素材。
