# Amazon DSP

Amazon DSP 是 Amazon 的需求方平台（demand-side platform），用于在 Amazon 自有库存与第三方供应上做程序化展示、在线视频、流媒体电视、音频与商业受众激活。在 Amazon 销售的品牌与不在 Amazon 销售的品牌都可以使用。

## 角色

当计划需要以下能力时使用 Amazon DSP：

- 超出搜索驱动的商品推广广告的上层漏斗触达。
- 用 Amazon 购物、流媒体与受众信号做认知或种草。
- 覆盖较长考虑周期的再营销。
- 流媒体电视、在线视频、展示或音频展示位。
- 更高级的度量，如有权限时的亚马逊营销云（AMC）、触达/频次、购买路径或增量研究。
- 有权限时的 AI 辅助 DSP 广告系列类型，如 Performance+ 与 Brand+。

不要把 Amazon DSP 当作修补零售就绪不足的捷径。如果价格、可售性、评价、商品详情页质量或度量偏弱，DSP 会快速放大浪费。

## 权限与预算

权限模式与最低消费因站点、账户与合作方而异：

| 权限路径 | 最适合 |
|---|---|
| 代运营服务 | 希望由 Amazon 或代运营合作方操作投放的大型广告主 |
| 合作方或代理自助 | 需要 DSP 权限与专业能力、但不想自建内部团队的品牌 |
| 直接自助 | 有程序化运营、度量、创意与预算纪律的团队；权限可能受限 |

务必验证目标站点与权限路径当前的最低花费、平台费、服务费与创意要求。

不要把"自助"等同于"不需要合作方"。在很多市场，自助 DSP 权限仍通常通过认证合作方获得，而代运营的最低消费可能明显更高。Amazon 也在向统一的 Campaign Manager 工作流演进，商品推广广告与 DSP 的界面边界可能变化。

## 形式规划

| 形式 | 主要用途 | 规划说明 |
|---|---|---|
| 展示 | 种草、再营销、零售媒体规模 | 准备多种尺寸，确保商品/报价信息可读。 |
| 动态电商广告 | 商品级再营销与目录驱动广告 | 需要干净的商品 feed 与零售就绪。 |
| 在线视频 | 产品教育、品类切入点、种草 | 用短的、利益点驱动的创意，品牌与商品尽早可见。 |
| 流媒体电视 | 广泛触达与品牌提升 | 需要更大的预算，以及超越末次点击销量的度量计划。 |
| 音频 | 认知与信息强化 | 用简单的声明与易记的品牌信号。 |

流媒体电视也可能通过经典 DSP 设置之外的自助 Streaming TV / Sponsored TV 广告系列流程投放。在把小预算或中预算的电视需求导向 DSP 之前，先检查这个选项。

## Performance+ 与 Brand+

Performance+ 与 Brand+ 是 AI 驱动的 Amazon DSP 解决方案，在默认使用传统 DSP 订单项规划之前应当优先考虑。

| 方案 | 角色 | 规划说明 |
|---|---|---|
| Performance+ | 下层漏斗与结果导向的展示/视频/流媒体电视优化 | 在转化信号已配置时，可按 Amazon 销量的 ROAS 或站外事件的 CPA 优化。有权限时的战术可包括获客、再营销、留存与种草。 |
| Brand+ | 上层漏斗认知与触达/频次 | 目标是认知、详情页浏览或长期互动，而非即时末次点击 ROAS 时使用。 |

当账户有足够的转化、受众与创意输入让模型学习时，使用 Performance+ 或 Brand+。在排除项、品牌安全、频次、库存与度量上保持人工护栏。

## 受众策略

常见的 DSP 受众分组：

- 品类意向人群。
- 生活方式与兴趣受众。
- 上下文受众。
- 商品浏览或品类浏览人群。
- 品牌购买者或非购买者。
- 有权限时的竞品或互补品浏览人群。
- 符合资格的广告主第一方受众。
- 符合资格的 AMC 构建的规则型与相似受众。

按意向排序受众。如果探新与再营销需要不同的预算、出价、KPI 或频次控制，不要混在同一个订单项里。

## 度量

按漏斗角色选择度量：

| 角色 | 指标 |
|---|---|
| 认知 | 触达、频次、视频完播、品牌搜索提升、品牌提升 |
| 种草 | 详情页浏览、品牌旗舰店访问、加购、新客、浏览归因质量 |
| 转化 | 购买、ROAS、ACoS、获客成本、总销量影响 |
| 增量性 | 地理测试、保留组（holdout）、AMC 分析、可行时的匹配市场测试 |

注意浏览归因。对 DSP 而言，如果受众本身购买意向就很高，直接归因的 ROAS 会高估增量性。

## 运营节奏

- 上线时把探新、种草、再营销订单项明确分开。
- 按购买周期与创意量设置频次上限。
- 每周复盘创意疲劳、触达饱和、受众重叠与供应质量。
- 用 Sponsored Products 与 Sponsored Brands 的搜索查询数据指导 DSP 受众与创意主题。
- 用 DSP 洞察为商品推广广告与商品页面创意找到新的品类、竞品与生活方式角度。
- 在有权限时用 AMC 与统一报表，把直接归因、辅助路径、触达/频次与增量性问题分开回答。

## 常见坑

- 在商品推广广告与零售就绪稳定之前就启动 DSP。
- 只用末次点击 ROAS 评判流媒体电视。
- 把探新与再营销合并成混合 ROAS。
- 用与 Amazon 购物行为脱节的通用品牌创意。
- 投放期间忽略库存、价格与评价变化。
- 把 Performance+ 或 Brand+ 当作"设置即忘"，不检查信号质量、排除项、频次与创意疲劳。
