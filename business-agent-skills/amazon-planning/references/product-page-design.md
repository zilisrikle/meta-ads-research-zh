# 商品详情页设计

使用本参考设计 Amazon 商品详情页，包括标题、五点描述、产品描述、搜索词、A+ 页面、变体与 Amazon SEO。要求因品类与站点而异，在目标账户中验证当前风格指南。

## 必填与推荐字段

| 字段 | 角色 |
|---|---|
| 商品标识符 | GTIN，如 UPC、EAN、ISBN 或 JAN，除非豁免 |
| 标题 | 主要可搜索商品名与消费者扫读行 |
| 品牌 | 品牌/制造商名；相关时应与品牌注册对齐 |
| 主图 | 必填商品图；必须符合 Amazon 图片政策 |
| 价格 | 售价，含适用的本地含税展示规则 |
| 库存 | 可售数量或 FBA 入库计划 |
| 成色 | 全新、二手、Renewed、收藏品，或品类特定的成色 |
| 品类/浏览节点 | 决定可发现性、风格指南与资格 |
| 五点描述 | 核心利益点、功能、使用场景、兼容性与异议 |
| 产品描述 | 补充背景、故事、说明或技术细节 |
| 搜索词 | 在 Amazon 当前限制内的后台搜索关键词 |
| 尺寸/重量 | 关乎消费者信心与履约费 |
| 合规属性 | 材质、成分、安全、警告、认证、年龄分级、国家特定字段 |

## 标题策略

标题必须平衡搜索相关性、消费者清晰度与品类合规。

### 通用模式

```text
Brand + Product Type + Primary Differentiator + Key Attribute/Size/Quantity + Use Case or Compatibility
```

示例：

```text
ProWidget Stainless Steel Water Bottle, Insulated, 32 oz, Leakproof Lid, For Travel and Gym
ProWidget USB-C Laptop Stand, Adjustable Aluminum Riser, Foldable Desk Stand for 13-16 in Laptops
```

### 标题规则

- 最重要的查询与商品类型放前面。
- 避免关键词堆砌、重复词、促销声明、emoji 与无依据的最高级。
- 遵循品类特定的最大长度与格式规则。
- 用消费者语言，不只用内部产品名。
- 尺寸、数量、兼容性或材质影响购买适配时要包含。

Amazon 在 2025 年收紧了多个站点与品类的标题政策。写最终标题前，验证品类特定的字符上限、重复词上限与禁用特殊字符。很多品类仍允许约 200 个字符，但部分品类上限更短。

### 标题决策规则

- **品牌前置标题**：品牌需求、溢价定位、替换/复购，或品牌信任重要时用。
- **利益点前置标题**：品牌不知名、清晰差异化是主要点击理由时用。
- 手机首屏可见段不读全文也要能看懂。
- 不要把字符上限当目标；可读性与转化比关键词密度更重要。

## 五点描述

用五点描述转化，不只是描述。

推荐结构：

| 五点 | 角色 |
|---|---|
| 1 | 主要价值主张与核心使用场景 |
| 2 | 有依据的差异化功能 |
| 3 | 适配、尺寸、兼容性或包含内容 |
| 4 | 用法、保养、安全或异议处理 |
| 5 | 品牌信任、质保、可持续或支持 |

模式：

```text
Benefit-led heading: feature proof -> shopper outcome.
```

避免：

- 无依据的声明。
- 未经批准的医疗、健康或受监管声明。
- 攻击竞品。
- 重复标题。
- 每个五点都塞满关键词。

## 产品描述

产品描述用于：

- 产品故事与更深的解释。
- 安装、保养或使用说明。
- 兼容性细节。
- 材质与制造工艺。
- 没有 A+ 页面时的品牌语调。

有 A+ 页面时，让产品描述补充 A+ 没覆盖的细节。

除非目标站点明确支持，否则避免在产品描述里用 legacy HTML 格式。Amazon 多年前已移除产品描述对多数 HTML 标签的支持；纯文本加简单换行是更稳妥的默认。

## 后台搜索词

后台搜索词放自然文案里放不下的相关同义词与替代表述。

指引：

- 标题/五点已大量覆盖的词不要重复，除非必要。
- 包含同义词、拼写变体与场景语言。
- 竞品商标不要放，除非政策与当地法律允许。
- 不要放不相关的大流量词。
- 遵守目标站点当前的字节/字符上限。
- 美国站点保守的规划上限约为 249-250 字节；超过生效上限可能导致字段被忽略或去索引。上传前验证当前品类/schema 上限。

有权限时也检查其他被索引或驱动筛选的字段：

- Subject Matter。
- Target Audience。
- Intended Use。
- Other Attributes。
- 颜色、材质、尺寸、款式、图案与兼容性字段。

这些结构化属性可能比往搜索词字段堆词更重要，因为它们影响筛选、相关性与目录理解。

## A+ 页面

用 A+ 页面提升转化与品牌信任。

常见模块策略：

| 模块 | 角色 |
|---|---|
| 主视觉 | 品牌/商品承诺与视觉背景 |
| 功能区块 | 有依据的主要利益点 |
| 对比表 | 帮消费者选对 SKU |
| 生活场景 | 展示使用与情感回报 |
| 技术/规格 | 降低兼容性与适配不确定 |
| 品牌故事 | 品牌重要时建立信任 |

高级 A+ 页面通常是资格门槛而非纯预算门槛。验证当前资格，常见门槛包括品牌注册、已发布的品牌故事覆盖，以及近期回看窗口内最少获批 A+ 页面项目数。

## 变体

只有商品是 Amazon 品类规则下的真正变体时才用父子变体，如尺寸、颜色、口味、数量或款式。

不要合并无关商品来合并评价。变体滥用可能导致商品页面下架或账户风险。

按品类允许的变体主题规划变体，不要按内部陈列偏好。变体主题不匹配是商品页面被拒或后续下架的常见原因。

## Amazon SEO

Amazon 搜索表现受相关性与表现影响：

| 驱动 | 示例 |
|---|---|
| 相关性 | 标题、五点描述、搜索词、品类、属性、浏览节点 |
| 表现 | 销售速度、转化率、价格、可售性、评价、履约、广告流量质量 |
| 消费者信任 | 评分、评价、图片、A+ 页面、配送承诺、退货信心 |

把广告与 SEO 当作闭环。广告揭示转化查询；商品页面应当把学到的吸收进可见文案与后台词。

有权限时，用搜索查询效果、品牌分析、搜索词报告与消费者评价语言作为 Amazon SEO 的反馈闭环。搜索查询效果尤其适合看查询级的展示份额、点击份额、加购份额与购买份额，对比站点整体。

避免过度依赖 "A9" 或 "A10" 这类非官方算法标签。持久的做法是提升相关性、结构化商品数据、转化证据、价格、可售性、评价与客户满意度。Amazon 更新的语义购物体验让清晰的使用场景、属性与消费者语言比重复关键词堆砌更重要。

## 评价与信任计划

新品先规划信任建设，再放量广告：

- 符合资格且经济上合理时用 Amazon Vine。
- 合规索评。
- 清晰的客服、质保、退货与使用信息。
- 副图与 A+ 模块回答消费者本会带到评价区的异议。

把评价挖掘当作研究输入：

- 提取购买触发点与异议。
- 识别不清楚的尺寸、适配、兼容性、成分或质量问题。
- 把重复异议变成图片、五点描述、A+ 模块或产品改进。
- 用消费者原话优化标题、五点描述、搜索词、品牌推广文案与视频脚本。

## 商品详情页审计

投放广告前检查：

- 主图在搜索结果中赢得点击。
- 标题可读，包含核心商品查询。
- 前三条五点描述回应最大的购买驱动。
- 副图回答常见异议。
- 价格与配送有竞争力。
- 评价数与评分相对竞品不致命。
- 变体清晰合规。
- A+ 页面或产品描述支撑广告承诺。
- 库存撑得起预期需求。
