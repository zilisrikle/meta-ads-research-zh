# KPI、基准与运营规则

把基准当作规划区间，不要当承诺。Amazon 表现因站点、品类、价格、利润、评价数、竞争、季节性、展示位与零售就绪而异。

## 核心指标

| 指标 | 全称 | 公式 | 含义 |
|---|---|---|---|
| ACoS | 广告销售成本（Advertising Cost of Sales） | `ad spend / attributed ad sales` | 广告归因销量中花在广告上的占比。越低越高效。 |
| TACoS | 总广告销售成本（Total Advertising Cost of Sales） | `ad spend / total sales` | 业务层面的总广告压力，含自然销量。 |
| ROAS | 广告支出回报（Return on Ad Spend） | `attributed ad sales / ad spend` | 每单位广告花费带来的收入。 |
| CPC | 单次点击成本（Cost Per Click） | `ad spend / clicks` | 每次点击的竞价成本。 |
| CTR | 点击率（Click-Through Rate） | `clicks / impressions` | 广告相关性与创意/查询匹配度。 |
| CVR | 转化率（Conversion Rate） | `orders / clicks` | 商品详情页与报价的转化。 |
| NTB | 新客（New-to-Brand） | Amazon 的新客指标（如有权限） | 在 Amazon 回看窗口内品牌新客带来的购买占比或量；子指标因广告产品而异。 |
| DPV | 详情页浏览（Detail Page View） | 商品详情页访问 | 种草信号。 |

## 指标关系

```text
ACoS = CPC / (Average selling price x CVR)
ROAS = 1 / ACoS
TACoS = ad spend / total sales
```

ACoS 太高时，诊断问题在 CPC、CVR、平均售价、归因组合，还是自然拉动不足。

## ACoS 与 ROAS

| ACoS | ROAS | 解读 |
|---|---|---|
| 10% | 10.0x | 通常高效，但如果主要是被蚕食的品牌需求，也可能买贵了。 |
| 20% | 5.0x | 是否可行看品类、利润、价格与目标；不要当作普遍意义上的强。 |
| 30% | 3.3x | 对某些品类或上线可能是健康的，对另一些则太高。对照盈亏平衡 ACoS 与 TACoS。 |
| 40% | 2.5x | 除非利润率高，否则需要增长、新客、排名或上线层面的理由。 |
| 50%+ | 2.0x 或更低 | 通常需要明确的战略理由、预算上限与测试后决策规则。 |

## 盈亏平衡 ACoS（Break-Even ACoS）

```text
Break-even ACoS =
(selling price - product cost - referral fee - fulfillment cost - discount - variable cost)
/ selling price
```

目标 ACoS 应当基于边际贡献与业务目标：

| 目标 | ACoS 姿态 |
|---|---|
| 利润收割 | 盈亏平衡以下，留利润缓冲 |
| 增长 | 接近目标利润，同时监控 TACoS 与自然排名 |
| 上线 | 预算、库存与学习目标明确时，可暂时超过盈亏平衡 |
| 品牌防御 | 通常 ACoS 更低；确保没有为自然本就能拿到的需求多付钱 |
| 竞品拦截 | 通常 ACoS 更高；用新客与长期价值评判 |

## 基准区间

只作粗略的方向性区间：

| 广告产品 | 常见规律 |
|---|---|
| Sponsored Products | 转化意图最高；通常是第一个表现基准。 |
| Sponsored Brands | 很多账户的直接转化低于 Sponsored Products，但能带来品牌旗舰店访问、视频互动与新客需求。 |
| Sponsored Display | 表现因上下文、受众、再营销设置差异很大。把探新与再营销分开。 |
| Amazon DSP | 上层漏斗的直接 ROAS 可能更低；评估触达、增量性与辅助需求。 |
| Streaming TV / Sponsored TV | 直接 ROAS 通常不是主要的解读方式；评估触达、频次、品牌搜索、详情页浏览与下游辅助需求。 |

除非针对确切站点、品类与周期有来源，否则不要做通用的 CPC、CTR、CVR、ACoS 断言。

## 归因与度量变化

Amazon 的归因与报表方法会变。做同比或前后对比时，确认账户用的是更新后的浏览归因、购物信号增强的末次触达归因、多触点归因（Multi-Touch Attribution）beta，还是统一报表变体。

用这些检查：

- 在报表允许时，把点击归因销量与浏览归因、辅助销量分开。
- 只有在两者都可用且标注清晰时，才对比收紧与放宽的浏览指标。
- 有权限时用 AMC 回答购买路径、频次、受众重叠、新客与增量性问题。
- 不检查归因方法是否变化，就不要把 2026 年的 ROAS 直接对比更早的周期。

## 亚马逊营销云与受众度量

AMC 不再只是 DSP 重度的企业话题。Amazon 已把 AMC 权限扩展到商品推广广告的广告主，包括受支持账户的自助权限与其他账户的合作方代管权限。当计划需要以下能力时用 AMC：

- Sponsored Products 或 Sponsored Brands 受众出价加成。
- Sponsored Display 受众激活。
- DSP 购买路径与频次分析。
- 跨广告产品的新客分析。
- 增量性、重叠或长回看周期的群组问题。

验证权限、洁净室权限、回看窗口，以及用户是直接操作 AMC 还是通过合作方操作。

## 诊断规则

| 症状 | 可能诊断 | 首要行动 |
|---|---|---|
| 展示高、CTR 低 | 查询不匹配、主图/标题/价格弱、展示位不适配 | 收紧定向、优化主图/标题、复盘价格与评分差距 |
| CTR 高、CVR 低 | 商品页面或报价问题 | 优化图片、五点描述、A+ 页面、评价、价格、配送承诺 |
| CPC 高、CVR 可接受、ACoS 高 | 竞价对利润来说太贵 | 降出价、转长尾/商品定向、提客单价/捆绑 |
| 展示低 | 出价/预算太低、目标太窄、资格问题 | 查资格、谨慎加价、拓宽发现 |
| ACoS 好、TACoS 上升 | 付费蚕食自然，或总销量没增长 | 复盘自然排名、增量性、品牌防御、预算分配 |
| ROAS 强、断货 | 广告跑赢了库存 | 降预算、保护头部 ASIN、调整上线日历 |

## 按目标计分卡

| 目标 | 主要指标 | 护栏 |
|---|---|---|
| 利润 | 边际贡献、ACoS、TACoS、ROAS | 库存、退货、折扣、仓储与履约费 |
| 上线 | 销售速度、CTR、CVR、排名、评价、TACoS | 预算上限、断货风险、评价信任 |
| 新客 | 新客订单/销量、CAC、复购率 | 利润、留存、促销成本 |
| 认知 | 触达、频次、视频完播、品牌搜索、DPV | 下游承接与增量性 |
| 留存 | 复购、订阅省、BTP 兑换、LTV | 折扣依赖 |
| 商品页面改进 | 单位会话转化率、CTR、CVR、搜索查询效果漏斗份额 | 流量组合与归因变化 |

## 上线前检查表

- 商品详情页完整合规。
- 主图与副图在手机上够强。
- 价格、评分、评价数与配送承诺在目标竞价中有竞争力。
- 库存撑得起计划花费。
- 已算出盈亏平衡 ACoS 与目标 ACoS。
- 广告系列角色、预算、出价、否定词与度量已定义。
- 如需品牌推广、品牌旗舰店、A+ 页面、品牌分析或展示型推广功能，品牌注册状态已知。

## 每周检查表

- 预算节奏与花超预算的广告系列。
- 搜索词收割与否定词。
- 按目标、展示位、匹配类型调出价。
- 商品详情页转化与可购买性。
- ACoS、ROAS、TACoS、销量、边际贡献。
- 库存、价格、促销与评价变化。
- 有权限时的新客与自然排名。
