# 账户设置、品牌注册与品类资格

在检查 Amazon 卖家、供应商或品牌是否准备好上架商品并投放广告时使用本参考。要求因站点、账户类型、品类与日期而异。上线前务必在目标站点验证所有本地文件、费用与资格。

## 销售账户与资格

| 领域 | 规划指引 |
|---|---|
| 销售计划 | 认真的电商运营通常需要专业销售计划：批量上架工具、业务报告、品牌工具与多数广告工作流都依赖它。计划名称与费用因站点而异。 |
| 身份验证 | 预计需要验证企业身份、税务、银行、付款、地址与法人代表信息。本地文件名称因国家而异。 |
| 商品标识符 | 在要求的地方使用有效的 GTIN，如 UPC、EAN、ISBN 或 JAN。品牌所有者在部分品类可申请 GTIN 豁免。 |
| 品类审批 | 部分品类、品牌、商品与成色在上架或投放广告前需要审批。规划媒体花费前先确认。 |
| 特色推荐（Featured Offer）资格 | 商品通常需要特色推荐资格才能出现在商品推广广告中。品牌推广与展示广告即使当前特色推荐属于其他卖家也可能展示，但被推广商品本身仍需具备资格。定价、可售性、履约、卖家绩效与账户健康都会影响这一点。 |
| 账户健康 | 账户健康不佳可能压制商品页面、降低资格或中断广告。把健康检查当作媒体就绪的一部分。 |

## 账户健康检查表

监控目标站点的账户健康仪表盘与本地绩效政策。常见信号包括：

- 账户健康评分（Account Health Rating, AHR），如有展示，作为账户健康的汇总分数。
- 订单缺陷率。
- 取消率（发货前）。
- 延迟发货率。
- 有效追踪率。
- 准时送达率（卖家自配送与卖家自配送 Prime 运营）。
- 客服不满意率（如有展示）。
- 政策违规。
- 商品真实性与安全投诉。
- 知识产权投诉。
- 买家消息回复时间。

不要把某一个站点的阈值当作通用标准。如果某项指标接近政策红线，先修运营再放量广告。

## 品牌注册（Brand Registry）

Amazon 品牌注册对品牌所有者很重要，因为它解锁或增强了：

- 品牌保护工具。
- Project Zero 与透明计划（Transparency）（如符合资格）。
- 品牌推广与部分展示型推广功能。
- A+ 页面与高级 A+ 页面（如符合资格）。
- 品牌旗舰店。
- 实验管理。
- 品牌分析与搜索查询效果（如有权限）。
- Amazon Vine 资格（在支持的站点）。
- 品牌定制促销（在支持的站点）。
- 亚马逊归因权限（在支持的站点）。
- 客户互动管理（Manage Your Customer Engagement）、帖子（Posts）、客户评价洞察与 Amazon 创意工具（如有权限）。

典型要求包括注册或待审中的商标、匹配的品牌名，以及品牌永久固定在商品或包装上的证据。Amazon 通常接受受支持商标局的文字商标，或含文字的设计商标；无文字的纯图形商标在品牌注册中更难使用。商标状态、接受的商标局与审批规则因站点而异。

## 上线与品牌工具说明

- **Amazon Vine** 可帮助符合资格的新品牌注册商品，通过 Amazon 官方测评人计划获得早期评价。定价与报名名额因站点与日期而异；部分站点按件数采用分级报名，包含一个小的免费档。
- **品牌定制促销** 不是广告系列。它们是卖家中心内受品牌注册门槛限制的受众促销工具，常用人群包括关注者、复购客户、高消费客户、流失风险客户、近期客户、加购未购客户，以及有权限时的潜在新客户。
- **搜索查询效果** 是一份品牌分析报告，帮助把品牌或 ASIN 的表现与站点查询需求对比。在有权限时可用于关键词缺口、声量份额、转化份额，以及商品页面/广告反馈闭环。
- **Project Zero 与透明计划** 是高级品牌保护层。把它们当作防伪风险与执法工具，而不是通用增长功能。
- **实验管理** 在流量足够大、能一次测试一个有意义的商品页面元素时最有用。

## 品类与合规就绪

在上架或投放广告前，识别商品是否触及受监管或高风险领域：

| 风险领域 | 示例 |
|---|---|
| 安全与认证 | 电子产品、电池、无线设备、玩具、儿童产品、汽车配件 |
| 健康与功效声明 | 补剂、化妆品、医疗器械、药品、治疗性声明 |
| 食品饮料 | 成分标签、保质期、进口规则、酒类 |
| 受限商品 | 武器、成人用品、监控设备、危险品 |
| 品牌限制 | 受限品牌、授权经销商要求、发票要求 |
| 成色限制 | 全新、二手、翻新、收藏品、Renewed，或品类特定的成色规则 |

受监管商品请以 Amazon 官方品类指引与本地法律顾问为准。当要求取决于账户历史或 Amazon 审核时，不要承诺一定能获批。

## 上线就绪门禁

在以下事项可靠之前，不要建议激进的广告花费：

- 账户可以创建或编辑商品页面。
- 商品标识符与变体有效。
- 品类审批已通过，或风险已明确记录。
- 履约方式与库存覆盖可行。
- 主图与商品详情页符合 Amazon 政策。
- 定价有竞争力，足以赢得流量，并在相关时赢得特色推荐。
- 如果计划包含品牌推广、品牌旗舰店、A+ 页面或品牌分析，品牌注册状态已知。
- 评价与信任计划在该品类的评价护城河面前可靠。
- 变体家族合法，不是围绕评价合并搭建的。
