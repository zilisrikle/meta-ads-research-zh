# Amazon Planning

使用本 skill 制定 Amazon 电商平台与广告策略，路径覆盖从业务背景到商品页面规格、广告系列结构、创意需求与运营指引。因为广告表现高度依赖商品详情页质量、可售性、价格竞争力与评价信任度，所以它同时覆盖电商平台就绪与 Amazon Ads 规划。

## Practice-first 原则

Amazon 规划应当优先考虑让电商业务真正运转起来的实践，而不是只满足让商品页面或广告系列"合规"的设置。广告、出价与广告系列类型固然重要，但它们都建立在零售就绪（retail readiness）、边际贡献（contribution margin）、产品市场匹配、目录完整性、库存纪律、评价信任与报价竞争力之上。

在给出商品页面或广告系列设置建议之前，先核对以下事项：

| 领域 | 要验证的内容 | 为什么重要 |
|---|---|---|
| 产品市场匹配 | 搜索需求、竞争对手强度、评价护城河（review moat）、差异化、品类合规 | 很多 Amazon 上线失败是因为报价在搜索结果页（SERP）上根本没有经济性优势 |
| 单位经济学 | 扣除推荐费、履约、仓储、退货、促销与广告后的边际贡献 | 没有盈亏平衡经济学，ACoS 目标毫无意义 |
| 零售就绪 | 主图、标题、价格、评价、配送承诺、A+ 页面、变体、可购买性 | 广告放大的是现有报价；它修不好一个弱的商品详情页 |
| 库存 | 覆盖周数（weeks of cover）、入库提前期、FBA/FBM/SFP 适配、低库存与积压库存风险 | 断货会杀死排名动量；积压会毁掉现金与利润 |
| 信任与合规 | Vine/评价计划、宣传声明、安全/品类要求、变体合法性、账户健康 | 信任与政策问题打断增长的速度比媒体问题更快 |
| 查询情报 | 搜索查询效果（Search Query Performance）、搜索词报告、品牌分析（Brand Analytics）、评价语言 | Amazon SEO 与 PPC 应当是同一个反馈闭环 |
| 度量 | ACoS、TACoS、边际贡献、新客（NTB）、增量性（incrementality）、AMC（有权限时） | 平台归因销量只是导航信号，不是最终的财务真相 |
| 运营节奏 | 上线期的每日健康检查、每周搜索词挖掘、每月目录/费用复盘、季度策略重置 | 商品页面、库存与广告分开运营时，Amazon 表现会衰减 |

### 核心运营规则

- 从业务目标与单位经济学出发，而不是从 Amazon 的产品菜单出发。
- 把零售就绪当作上线的门禁。如果图片、价格、配送、评价、库存或合规偏弱，先收紧花费，直到修好为止。
- 把广告当作"发现—收割"闭环：发现查询/ASIN，把赢家毕业到受控广告系列，加否定词，再把学到的反馈回商品页面文案与创意。
- 用 TACoS、边际贡献、排名与新客质量来评判，不要只看 ACoS。
- 当品牌防御、品类增长、竞品拦截、发现、再营销与认知需要不同的出价、预算或 KPI 时，把它们拆开。
- 保持变体家族干净。不要用变体、合并或停产 ASIN 来转移评价权益。
- 把库存当作营销约束。断货前先降出价；不要因为糟糕的需求计划而产生积压库存或低库存费用。
- 把品牌注册（Brand Registry）工具当作运营基础设施：A+ 页面、品牌旗舰店、Vine、搜索查询效果、实验管理（Manage Your Experiments）、品牌定制促销（Brand Tailored Promotions）、AMC，以及品牌保护工具（如有权限）。
- 避免僵化的一刀切基准。同一个 ACoS，在不同的 Amazon 品类、站点、利润、评价、价格与配送条件下，可以是优秀也可以是不可接受。

## Workflow

```
Step 1: Gather context       -> Business, product, marketplace, objective, budget, and KPI inputs
Step 2: Choose planning path -> Listing plan, ads plan, or integrated marketplace plan
Step 3: Design the system    -> Listing, creative, fulfillment, campaign, targeting, bid, and measurement design
Step 4: Produce outputs      -> Marketplace brief, ad plan, creative brief, and operating checklist
```

## Step 1: Gather Context

先查看当前对话或工作区中用户已提供的 brief、产品资料、分析导出、品类研究、商品页面审计或广告报告。不要假设固定的本地目录结构。

### Required Inputs

| 输入 | 要采集的内容 |
|---|---|
| 业务背景 | 品类、模式、差异化、渠道组合、利润约束 |
| 产品信息 | 产品类型、价格带、利益点、变体、GTIN/UPC/EAN/JAN 状态、受监管品类风险 |
| 站点 | 目标 Amazon 站点、语言、货币、本地合规约束 |
| 目标 | 新品上架、商品页面改进、广告上线、广告改进、完整电商平台计划 |
| 预算 | 月度媒体预算、上线预算、创意预算、库存约束 |
| 受众 | 消费者人群、购买动机、异议、使用场景 |
| KPI | 目标 ACoS、ROAS、TACoS、销量、利润、新客、排名、评价或库存目标 |

### Useful Diagnostics

| 领域 | 要检查的内容 |
|---|---|
| 账户状态 | 销售计划、品牌注册、账户健康、品类审批、广告资格 |
| 当前表现 | 销量、会话数、单位会话转化率、ACoS、TACoS、CTR、CVR、评价、特色推荐（Featured Offer）资格 |
| 商品页面资产 | 图片、视频、A+ 页面、品牌旗舰店、标题、五点描述、产品描述、搜索词 |
| 履约 | 亚马逊物流（FBA）、卖家自配送（Fulfilled by Merchant）、卖家自配送 Prime（Seller Fulfilled Prime）、混合策略、库存覆盖 |
| 度量 | 亚马逊归因（Amazon Attribution）、品牌分析、搜索查询效果、亚马逊营销云（AMC）、MMP 或外部分析 |

## Step 2: Choose Planning Path

### A. 商品页面优化

当商品详情页、报价、创意、履约或自然发现是主要瓶颈时走这条路径。弱的商品页面会浪费广告花费，因为点击发生在页面还没准备好转化之前。

| 商品页面创意 | [listing-creative.md](references/listing-creative.md) | 规划图片、视频、品牌旗舰店素材与创意 QA 时 |
| 履约与定价 | [fulfillment-pricing.md](references/fulfillment-pricing.md) | 选择履约、价格、费用、库存与特色推荐策略时 |

以下场景使用商品页面优化：

- 新站点上线。
- 商品详情页转化改进。
- A+ 页面、高级 A+ 页面、品牌旗舰店或视频制作。
- Amazon SEO 与零售就绪改进。

### B. Amazon Ads 规划

当账户的零售就绪度足以承接流量，或者用户需要广告系列架构、定向计划、预算计划、创意 brief 或优化规则时走这条路径。

| 广告产品 | 角色 | 典型前置条件 | 参考 |
|---|---|---|---|
| **Sponsored Products** | 购物结果页、商品详情页及部分优质应用/网站上的商品级广告；通常是表现核心 | 合格商品与特色推荐资格；销售计划要求因站点/账户而异 | [sponsored-products.md](references/sponsored-products.md) |
| **Sponsored Brands** | 品牌级广告：商品集合、品牌旗舰店聚光灯或视频 | 品牌注册；品牌旗舰店聚光灯需要品牌旗舰店 | [sponsored-brands.md](references/sponsored-brands.md) |
| **Sponsored Display** | Amazon 站内外的上下文、受众、再营销与展示/视频展示位 | 资格因站点、卖家/供应商身份、品牌注册及非本土（non-endemic）beta 权限而异 | [sponsored-display.md](references/sponsored-display.md) |
| **Streaming TV / Sponsored TV** | 自助式流媒体电视路径，用 Amazon 信号做电视级触达 | 可用性、命名与资格因站点而异；在部分地区仍以 Sponsored TV 名称呈现 | [streaming-tv.md](references/streaming-tv.md) |
| **Amazon DSP** | 程序化展示、在线视频、流媒体电视、音频、Performance+、Brand+ 与受众激活 | 自助或代运营权限；需要更大的预算与度量纪律 | [amazon-dsp.md](references/amazon-dsp.md) |

| 策略领域 | 参考 | 何时阅读 |
|---|---|---|
| 广告系列架构 | [campaign-strategy.md](references/campaign-strategy.md) | 搭建漏斗策略、预算分配、关键词策略、季节性或上线阶段时 |
| KPI 与经济学 | [kpi-benchmarks.md](references/kpi-benchmarks.md) | 设定 ACoS/ROAS/TACoS 目标、盈亏平衡 ACoS、基准或每周运营规则时 |
| 诊断 | [diagnostic-decision-trees.md](references/diagnostic-decision-trees.md) | 在调整出价、商品页面、库存或广告系列结构之前诊断表现问题时 |

### Business Goal to Ad Product

| 目标 | 首选 | 次选 | 说明 |
|---|---|---|---|
| 捕获高意向需求 | Sponsored Products 精准/商品定向 | Sponsored Display 再营销 | 从离购买最近的查询与 ASIN 意向开始。 |
| 发现转化查询 | Sponsored Products 自动＋手动广泛/词组 | Sponsored Brands 品类词 | 用搜索词挖掘，把赢家毕业到手动控制。 |
| 新客获取 | Sponsored Products 品类关键词 | Sponsored Brands 商品集合或视频 | 有权限时跟踪新客，不要只看短期 ACoS 评判。 |
| 品牌认知 | Sponsored Brands 视频/品牌旗舰店聚光灯 | Streaming TV、Amazon DSP 在线视频、Brand+ | 用触达与品牌搜索提升来评判，不只看直接销量。 |
| 竞品拦截 | Sponsored Products 商品定向 | Sponsored Display 商品定向 | 激进出价前先对比价格、评分、配送承诺与评价。 |
| 新品上线 | Sponsored Products 发现＋精准核心词 | Sponsored Brands 视频、Vine、A+ 页面 | 零售就绪、库存与评价计划不可靠之前不要放量。 |
| 复购与忠诚 | Sponsored Display 受众 | 品牌定制促销、DSP 再营销 | 品牌定制促销是卖家中心的受众/优惠券工具，不是广告控制台的广告系列；受众窗口要匹配购买周期。 |

### Budget Posture

预算小时，先集中花费再扩展形式。Sponsored Products 通常提供最干净的搜索意图与学习闭环。只有当预算、创意与度量能力足够让每种角色都得到公平测试时，再加入 Sponsored Brands、Sponsored Display 或 DSP。

| 预算姿态 | 推荐结构 |
|---|---|
| 极小/测试 | 只做 Sponsored Products；自动发现与手动精准赢家分开 |
| 早期增长 | Sponsored Products 加 Sponsored Brands 或 Sponsored Brands 视频，做品类存在感 |
| 规模化 | Sponsored Products、Sponsored Brands、Sponsored Display，漏斗角色清晰 |
| 企业/全漏斗 | 商品推广广告加 Streaming TV 或 Amazon DSP、AMC，以及有权限时的增量测试 |

### C. 一体化电商平台计划

新 Amazon 上线、重大重启或账户重建时使用这条路径。先设计商品页面就绪，再设计广告。广告负责引流；商品详情页质量、可售性、价格、评价与配送承诺决定流量能否变成有利可图的需求。

规划新品、重启、Prime 会员日/黑五网一冲刺、国际上线或全漏斗上线序列时，阅读 [launch-playbook.md](references/launch-playbook.md)。

## Step 3: Design the System

### 商品页面计划序列

1. **账户与资格**：销售计划、品牌注册、品类审批、合规、履约选择。
2. **商品详情页**：标题、五点描述、产品描述、搜索词、变体、A+ 页面。
3. **创意体系**：主图、副图、信息图逻辑、生活场景、视频、品牌旗舰店。
4. **报价经济学**：价格、促销、费用、配送承诺、库存、特色推荐竞争力。

### 广告计划序列

1. **广告系列架构**：按品牌防御、品类增长、竞品拦截、发现、再营销、上线支持等角色拆分。
2. **定向设计**：关键词匹配类型、商品定向、品类定向、受众、再营销窗口。
3. **出价与预算设计**：出价策略、日预算、展示位调整、测试预算、放量规则。
4. **创意设计**：按广告产品定制的文案、视频、品牌旗舰店路由、自定义图片，以及零售就绪检查。
5. **度量设计**：ACoS、ROAS、TACoS、新客、自然排名、库存、边际贡献，有权限时加 AMC，可行时加增量性分析。

### Naming Convention

使用一致的命名，方便报表与批量操作：

```text
[BrandOrProduct]_[AdProduct]_[Targeting]_[MatchOrAudience]_[Role]_[YYYYMM]

Example:
ProWidget_SP_Manual_Exact_BrandDefense_202604
ProWidget_SP_Auto_Discovery_202604
ProWidget_SB_Video_Category_202604
ProWidget_SD_Retarget_Views30d_202604
```

## Step 4: Produce Outputs

### 电商平台规格

包括：

- 商品详情页结构：标题、五点描述、产品描述、搜索词、变体计划。
- 关键词逻辑：核心词、次级词、长尾词、竞品词与否定词主题。
- A+ 页面或高级 A+ 页面模块计划。
- 创意 brief：主图、副图序列、视频、品牌旗舰店模块。
- 履约与定价计划：FBA/卖家自配送/混合逻辑、费用风险、库存覆盖、促销计划。
- 评价与信任计划：Vine、合规索评、客服、退货摩擦。

### Amazon Ads 运营计划

包括：

- 目标、KPI、预算与经济红线。
- 每个广告产品的漏斗角色。
- 广告系列清单：定向、出价策略、日预算、匹配类型与否定策略。
- 按意向分层的关键词与 ASIN 定向清单。
- 按广告产品划分的创意规格。
- 每周运营检查表与优化规则。
- 季节性与促销日历。

## Platform Guidance

Amazon 的规则、费用、规格与资格因站点、账户类型、品类与日期而异。把所有数字规格都当作规划输入，在目标账户中验证后再上线。除非用户明确指定目标站点，否则不要硬编码某一国家、货币、卖家中心路径或本地法律要求。

Amazon Ads 界面变化很快。在定稿计划前，验证目标账户是否有新能力权限，例如 Sponsored Products 视频、Sponsored Products/Sponsored Brands 提示（prompts）、Streaming TV/Sponsored TV 命名、商品推广广告的 AMC、Sponsored Display 非本土 beta 权限、Performance+、Brand+ 与 Campaign Manager。
