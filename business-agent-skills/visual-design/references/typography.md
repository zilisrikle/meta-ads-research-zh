# 排印指南

有文字的地方，排印决定品质。字体、字号、字重、行高、字距——合在一起营造「易读」「美」「有品牌感」的印象。设计排印就是用字形表达优先级、调性和品牌个性。

---

## 选字体家族

### 字体类型和角色

- **无衬线（Sans-serif）**：现代、干净、UI 友好。网页和应用正文最常见的选择。
- **衬线（Serif）**：权威、可信、编辑感。想让标题或长文有分量时强。
- **等宽（Monospace）**：代码、数字数据、技术读数。等宽在功能上有要求时用。

### 字体数量越少越好

**一到两种**字体家族。三款以上，整体感开始散。

- **一款**：最干净的选择。只靠字重和字号建层级。
- **两款**：衬线配无衬线有编辑感。经典做法是标题衬线、正文无衬线。
- **加等宽**：只在处理代码或技术数据时——作为第三款加入。

### 定制字体 vs. 系统字体

能用**定制字体**（专有或付费）就用。它是品牌个性最强的杠杆之一。同样版式换个字体，印象完全不同。

但话说回来，**标准字体**（Inter、Noto Sans JP 等免费选项）把字重、字距、OpenType 特性调好，同样做出高质量排印。字体怎么用，比用哪款字体重要。

### 日文字体的注意事项

日文字形数量庞大，网页字体加载时文件体积是真问题。考虑子集化（只提取需要的字符）或用字体分发服务。

拉丁和日文字体混排时，检查基线和视觉字号是否对齐。日文字体视觉上通常比拉丁字体大，混排容易感觉别扭。

## 字号层级

排印的心脏是**字号层级**——用字号差异瞬间传达什么最重要、按什么顺序读。

### 建层级

大多数系统用 4–5 级：

| 级别 | 角色 | 大致字号 |
|-------|------|--------------|
| Display | Hero、落地页大标题 | 48px–96px |
| Heading | 节标题、卡片标题 | 24px–40px |
| Body | 段落、描述、主要内容 | 14px–18px |
| Caption / Label | 辅助文字、UI 标签、元数据 | 12px–14px |

字号随载体和设备变，关键是**相邻级别的字号差要清晰**。标题和正文差 2px 不算层级。

### 设计 display 字号

Display 文字是**建视觉冲击的地方**——hero 区或落地页的第一印象。

选的 display 字号反映品牌态度：

- **张扬（72px–110px）**：排印本身就是视觉主角。「字即冲击」的做法。
- **标准（48px–64px）**：自信但平衡。最常用的区间。
- **克制（40px 及以下）**：字往后退，让摄影或视频带头。

### 正文字号基线

正文字号，**易读第一**。选长文读得舒服的字号：

- **网页**：16px 基线；14px–18px 区间
- **移动端**：14px 是下限——再小难读
- **12px 及以下**：不要做正文。留给注脚和标签。

### 各载体的最小字号

观看距离和语境随载体变，下限也变。**尊重你所在载体的下限**：

| 载体 | 正文下限 | 辅助文字下限 | 备注 |
|--------|-----------|----------------------|-------|
| 网页（桌面） | 14px | 12px | 16px 基线 |
| 移动 UI | 14px | 12px | 点击区域另需 44px（[layout.md](layout.md)） |
| 幻灯片（1920×1080） | 24px | 18px | 投影的话正文建议 32px+ |
| 印刷（A4 / 文档） | 10–11pt | 8pt | 阅读正文 11–12pt 基线 |
| 海报 / 大幅面 | 看距离 | — | 远看的话正文等价 36px+ |
| HTML 邮件 | 14–16px | 12px | 给客户端缩放留余量 |

这些是**下限**。不要贴着下限设计——按密度和语境往上一档。更保险。

## 字重

字重建强调，但**过渡要细腻**。不要想加粗/细的二元——想小而有意的台阶。

### 字重怎么用

- **常规（Regular 400）**：正文基线。大多数文字用它。
- **中等（Medium 500）**：行内强调、UI 标签、导航。和常规的差别小，但有意用就有效。
- **半粗（Semibold 600）**：标题、节标题。明确的强调。
- **粗（Bold 700）**：最强的强调。省着用。

### 不要滥用 Bold

Bold (700) 是你最强的强调，但滥用读作噪声而不是强调。精致的排印倾向更轻——Light (300) 或 Medium (500) 当主力，Bold 留给真需要跳出来的时刻。整体构图更精致。

### 字重台阶数

最多用 **2–3 档字重**。超过四档，差别难分辨，强调变浑浊。

## 行高

行高是可读性最大的杠杆之一。同字体同字号——行高一变，印象大变。

### 按字号定行高

行高随字号调：**大字收紧，小字放宽**。

- **Display（48px+）**：1.0–1.15。紧字距给字块存在感。
- **Heading（24px–40px）**：1.15–1.3。没 display 紧，比正文紧。
- **Body（14px–18px）**：1.4–1.6。直接决定长文阅读的舒服度。
- **Caption（12px–14px）**：1.4–1.5。小字不显局促的余量。

### 正文行高决定品质

正文行高标准区间是 **1.4–1.6**，但这 0.2 的差别重要：

- **1.4–1.45**：紧而利。适合高密度、技术风 UI。
- **1.5–1.6**：松弛、有呼吸。适合长文和编辑内容。

文字感觉「隐隐难读」或「局促」，先查行高。常常 +0.1 就修好——动字号和字体之前先动它。行高加间距建的纵向节奏见 [layout.md](layout.md)。

## 字距（Tracking）

字距调密度和易读性。按字号和语境调好，排印精度大幅提升。

### 核心原则：大字收紧，小字放宽

字体通常在正文字号（14–18px 左右）最好看。偏离这个区间就要调：

- **Display（48px+）**：**负字距**（收紧）。大字容易显松；收紧加密度和力量。-1px 到 -3px 左右常见。
- **Body（14px–18px）**：**默认（normal）**通常就行。信字体的内置间距。
- **Caption / label（12px 及以下）**：**正字距**（放宽）。小字容易糊；+0.1px 到 +0.5px 有帮助。
- **全大写**：**正字距必须。** 大写字母挤在一起；+0.5px 到 +2px 常见。

### 深色模式的字距

深色背景上浅色文字看起来稍粗——光学光晕效应。稍加正字距（+0.1px 到 +0.3px）可改善易读性。不是必须；有些字体字号不需要。

## OpenType 特性

OpenType 特性解锁字体内置的替换字形和行为。用好，排印品质上一个台阶。

### 好用的特性

- **`liga`（连字）**：特定字母组合（fi、fl 等）换专用字形。文字流更顺。
- **`kern`（字距调整）**：优化字母对之间的间距。大多数浏览器默认开，但明确指定更保险。
- **`tnum`（等宽数字）**：数字等宽。表格和数据里的数字纵向对齐，更好比较。
- **`ss01`+（风格变体集，stylistic sets）**：字体专属的替换字形集。开了能榨出更多字体个性。

### 怎么用

不是每款字体支持每个特性。查你的字体实际有什么，只开贴合设计意图的。不要全开——有目的选。

## 文字易读性

美的排印从易读开始。读着费劲的设计，再漂亮也不成立。

### 每行字符数（measure）

每行字符太多，眼睛横移太远。太少，频繁换行打断节奏：

- **英文**：每行 45–75 字符最佳。60 左右理想。
- **日文**：每行 25–40 字符。报纸专栏是好参照。
- **用容器宽度控制**：给文字设 `max-width`，行长不随视口涨。容器宽度设计见 [layout.md](layout.md)。

### 对比度

文字和背景的对比度是可访问性问题：

- **正文**：最低 4.5:1（WCAG AA）
- **大字（18px+ 或 14px 加粗+）**：最低 3:1
- **占位符和提示文字**：对比度别压太低。看不清就等于没写。

调色板整体的对比度和可访问性见 [color.md](color.md)。

### 文字对齐

- **左对齐**最易读（拉丁和日文都一样）。一致的行首给眼睛稳定的回行点。
- **居中对齐**属于标题或短块。3 行以上居中难读。
- **右对齐**是特殊场景（数字右对齐、有意的设计效果）。
- **两端对齐**日文长文可用，拉丁文容易出现别扭的词间距。

## 不要

- **3 款以上字体家族**——整体感崩
- **4 档以上字重**——差别模糊，层级浑浊
- **正文低于 12px**——看不清。注脚 12px 也是下限。
- **display 字距保持默认**——大字显松显飘
- **正文行高低于 1.2**——行感觉叠在一起
- **展示字体做正文**——个性的展示字体小字号下失去易读性
- **长文居中对齐**——3 行以上转左对齐
- **不设容器宽度、行长失控**——大屏上每行超 100 字符，阅读受损

---

## 检查什么

- **层级一眼分明**：标题和正文瞬间分得清吗？
- **正文读得舒服**：读三段——眼睛累吗？
- **行高合适**：不局促、不松散——节奏自然吗？
- **字距合适**：大字不飘、小字不糊吗？
- **字重差别看得见**：用的字重之间分得清吗？
- **行长合适**：不太长、不太短——眼睛横移舒服吗？
- **字体搭配和谐**：两款字体是和谐还是打架？
- **小字号还读得清**：12–14px 文字清晰、不发虚吗？
