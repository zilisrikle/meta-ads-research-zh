# 受 Stripe 启发的设计系统

## 1. 视觉主题与氛围

Stripe 的网站是一座精确打磨的玻璃机器——每一像素都感觉经过测量。页面以深板岩蓝（`#0a2540`）的自信色块开场：全幅首屏区叠着抽象的 3D 渐变网格艺术（流动的紫色、蓝色与白色色带在深底上交织），白色文字宣告「为增长而生的金融基础设施」。这不是温暖——这是工程精度穿着营销外衣。品牌紫（`#635bff`）作为主行动信号穿插其间，按钮、链接与点缀元素带着安静的自信发光。

排印系统由 sohne-var（Stripe 定制可变字体）驱动，标题用紧凑的负字距（`-0.2px` 到 `-0.4px`），字重以 600 封顶——从不用粗黑体。OpenType 风格集 `ss01` 全局启用，财务数字用表格数字（`tnum`）保证对齐。层级完全靠字号阶梯（从 12px 说明到 64px 展示标题）与颜色（深板岩标题、灰蓝正文）实现，字重只在 400/500/600 三档间切换。

表面处理克制到近乎严苛：卡片用 8px 圆角 + `0 1px 3px rgba(50,50,93,0.1)` 的轻阴影；按钮 4px 圆角；输入框 6px。纵深（depth）只出现在三个地方——首屏的 3D 渐变艺术、卡片的轻阴影、深色区块（`#1c1e54`）与浅色主体之间的精密排布的色块对比。没有玻璃拟态，没有大圆角，没有装饰性渐变（首屏艺术除外）。连分隔线都用 `1px solid #e6ebf1` 的发丝灰，绝不抢戏。阴影轻到几乎不可见——纵深足而不生硬。

动效是隐形的：`0.15s ease` 的按钮悬停、`0.3s ease` 的卡片浮起、`0.5s cubic-bezier` 的首屏艺术漂移。页面滚动时内容块以 `translateY(16px) → 0` + 透明度淡入进入视口——克制、快速、从不炫技。这是给开发者的设计：每个细节都像 API 一样可预测。

**关键特征：**
- 深板岩（`#0a2540`）首屏 + 抽象 3D 渐变网格艺术——工程美学的宣言
- 品牌紫（`#635bff`）是唯一的彩色行动信号；其余全灰度 + 深蓝
- sohne-var 可变字体，`ss01` 风格集全局启用，财务数字用 `tnum`
- 字重封顶 600——层级靠字号与颜色，不靠粗黑体
- 8px 卡片圆角 / 4px 按钮圆角 / 6px 输入框——小圆角纪律
- 阴影只用一层轻阴影（`0 1px 3px rgba(50,50,93,0.1)`）——从不叠加重投影
- 深色区块用 `#1c1e54` 深品牌靛蓝——不是纯黑
- 动效隐形：0.15s 按钮、0.3s 卡片、滚动淡入 `translateY(16px)`

**色块页面节奏：**深板岩首屏（3D 渐变艺术 + 白字）→ 白色主体（产品网格、代码示例）→ 深靛蓝（`#1c1e54`）特性区块 → 白色客户证言 → 深板岩页脚——深色锚定首尾，中间白色呼吸。

## 2. 色彩体系与角色

### 主色
- **品牌紫**（`#635bff`）：主 CTA 按钮背景、关键链接、品牌点缀——Stripe 最具识别度的颜色（rgb 99, 91, 255）
- **深板岩**（`#0a2540`）：首屏背景、主标题文字、页脚背景——系统的「墨水」（rgb 10, 37, 64）
- **纯白**（`#ffffff`）：主页面画布、卡片表面

### 辅助色与点缀色
- **亮紫**（`#7a73ff`）：品牌紫的悬停/高光变体，用于按钮悬停态与渐变艺术中的紫色带
- **天蓝**（`#00d4ff`）：首屏 3D 渐变艺术中的青色带——仅出现在装饰艺术中，不进入 UI
- **薄荷**（`#00c48c`）：成功态点缀（极少用）
- **珊瑚红**（`#ff5c5c`）：错误态（表单验证）

### 表面与背景
- **白画布**（`#ffffff`）：默认页面背景
- **雾灰**（`#f6f9fc`）：替代表面——代码示例区、特性区块背景、表格条纹（rgb 246, 249, 252）
- **深靛蓝**（`#1c1e54`）：深色特性区块背景（rgb 28, 30, 84）——比深板岩更紫的深色
- **深板岩**（`#0a2540`）：首屏与页脚

### 中性色与文本
- **墨标题**（`#0a2540`）：所有标题——深板岩既是背景也是墨水
- **灰蓝正文**（`#425466`）：默认正文（rgb 66, 84, 102）——带蓝调的灰，长文不刺眼
- **浅灰蓝**（`#6b7c93`）：次级/说明文字（rgb 107, 124, 147）
- **发丝灰**（`#e6ebf1`）：边框与分隔线（rgb 230, 235, 241）
- **白柔**（`rgba(255,255,255,0.7)`）：深色表面上的次级文字

### 语义色与点缀色
- **成功**：`#00c48c`（薄荷绿）——极少出现，Stripe 刻意弱化成功态的色彩
- **错误**：`#ff5c5c`（珊瑚红）——表单验证错误
- **警告**：`#ff9f1c`（琥珀）——文档中的注意提示
- **信息**：`#635bff`（品牌紫兼任）

### 渐变系统
- **首屏 3D 渐变艺术**：深板岩底上的流动色带——紫（`#635bff`）→ 青（`#00d4ff`）→ 白，抽象网格形态。这是全站唯一的渐变，且只存在于首屏装饰艺术中
- **UI 表面禁用渐变**：按钮、卡片、输入框一律纯色——`linear-gradient` 在组件中绝不出现
- **深色区块过渡**：深板岩 → 深靛蓝（`#1c1e54`）的区块交替靠纯色块实现，无渐变过渡

- **主字体**：`sohne-var`，回退：`SF Pro Display`

### 原则
- **轻字重即签名**：展示字号的字重 300 是 Stripe 最独特的排印选择。别人用 600–700 抓注意力，Stripe 用轻盈当奢华——文字自信到不需要字重来立威。
- **处处 ss01**：`"ss01"` 风格集不可妥协。它改变特定字形（可能是替代的 `a`、`g`、`l` 形态），让所有 sohne-var 文字更几何、更当代。
- **两种 OpenType 模式**：`"ss01"` 给展示/正文，`"tnum"` 给财务数据的等宽数字。两者永不重叠——段落里的数字用 ss01，数据表里的数字用 tnum。
- **渐进字距**：字间距随字号按比例收紧：56px 下 -1.4px，48px 下 -0.96px，32px 下 -0.64px，26px 下 -0.26px，16px 及以下 normal。
- **双字重极简**：主要用 300（正文与标题）与 400（UI/按钮）。主字体无粗体（700）——SourceCodePro 用 500/700 形成代码对比。

## 5. 布局原则

### 间距系统
- 基准单位：8px
- 刻度：1px、2px、4px、6px、8px、10px、11px、12px、14px、16px、18px、20px
- 值得注意：小端刻度密集（4–12 每 2px 一档），反映 Stripe 为财务数据 UI 的精确导向

### 网格与容器
- 最大内容宽：约 1080px
- 首屏：居中单列，内边距慷慨，标题轻盈
- 特性区：特性卡片 2–3 列网格
- 全宽深色区块，`#1c1e54` 背景营造品牌沉浸
- 代码/仪表盘预览为带蓝调阴影的收纳卡片

### 留白哲学
- **精确间距**：不像极简系统的浩瀚留白，Stripe 的留白是度量过的、有意的。每个间隙都是刻意的排印选择。
- **数据密、铬宽**：财务数据显示（表格、图表）排得紧，但周围的 UI 铬间距慷慨。这营造受控的密度感——像装在漂亮画框里的整齐表格。
- **区块节奏**：白区块与深品牌区块（`#1c1e54`）交替，形成戏剧性的明暗节律，不靠随意用色打破单调。

### 圆角刻度
- 微（1px）：细粒度元素，微妙圆润
- 标准（4px）：按钮、输入框、徽章、卡片——主力
- 舒适（5px）：标准卡片容器
- 宽松（6px）：导航、较大可交互元素
- 大（8px）：特稿卡片、首屏元素
- 复合：`0px 0px 6px 6px` 给底部圆角容器（标签页、下来菜单底部）

## 6. 纵深与阴影层级

| 层级（Level） | 处理（Treatment） | 用途（Use） |
|-------|-----------|-----|
| 平（0 级） | 无阴影 | 页面背景、内联文字 |
| 环境（1 级） | `rgba(23,23,23,0.06) 0px 3px 6px` | 微妙卡片抬升、悬停提示 |
| 标准（2 级） | `rgba(23,23,23,0.08) 0px 15px 35px` | 标准卡片、内容面板 |
| 抬升（3 级） | `rgba(50,50,93,0.25) 0px 30px 45px -30px, rgba(0,0,0,0.1) 0px 18px 36px -18px` | 特稿卡片、下拉、浮层 |
| 深（4 级） | `rgba(3,3,39,0.25) 0px 14px 21px -14px, rgba(0,0,0,0.1) 0px 8px 17px -8px` | 弹窗、浮动面板 |
| 环（无障碍） | `2px solid #533afd` 轮廓 | 键盘焦点环 |

**阴影哲学**：Stripe 的阴影系统建立在色彩纵深原则上。多数设计系统用中性灰或黑阴影，Stripe 的主阴影色（`rgba(50,50,93,0.25)`）是呼应品牌海军蓝的深蓝灰。这让阴影不只加纵深——还加品牌氛围。多层手法把带蓝调的阴影与纯黑次级层（`rgba(0,0,0,0.1)`）以不同偏移配对，营造视差式纵深：品牌阴影离元素更远，中性阴影更近。负扩展值（-30px、-18px）确保阴影横向不超出元素占位，让阴影层级垂直而受控。

### 装饰性纵深
- 深品牌区块（`#1c1e54`）靠背景色对比营造沉浸纵深
- 首屏装饰用茜素红到品红过渡的渐变叠加
- 粘性元素顶部边缘阴影用 `rgba(0,55,112,0.08)`（`--hds-color-shadow-sm-top`）

## 7. 要做与不要做

### 要做
- 每个文本元素都用 sohne-var 并开 `"ss01"`——风格集**即**品牌
- 所有标题正文都用字重 300——轻盈是签名
- 所有抬升元素用带蓝调阴影（`rgba(50,50,93,0.25)`）
- 标题用 `#061b31`（深海军蓝）而非 `#000000`——暖度很重要
- 圆角保持 4px–8px——保守圆润是刻意的
- 任何表格/财务数字显示用 `"tnum"`
- 阴影分层：远处带蓝调 + 近处中性，形成纵深视差
- `#533afd` 紫作主交互/CTA 色

### 不要做
- sohne-var 标题不要用 600–700 字重——字重 300 是品牌声音
- 卡片按钮不要用大圆角（12px+、胶囊形）——Stripe 是保守的
- 不要用中性灰阴影——永远带蓝调（`rgba(50,50,93,...)`）
- 任何 sohne-var 文字不要跳过 `"ss01"`——替代字形定义个性
- 标题不要用纯黑（`#000000`）——永远 `#061b31` 深海军蓝
- 交互元素不要用暖点缀色（橙、黄）——紫是主色
- 展示字号不要用正字间距——Stripe 的字距收紧
- 品红/茜素红点缀不要用于按钮或链接——它们只作装饰/渐变
