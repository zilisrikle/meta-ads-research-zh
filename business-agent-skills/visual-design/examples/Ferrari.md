# Ferrari 灵感设计系统

## 1. 视觉主题与氛围

Ferrari 的网站是一部数字编辑刊物——一本精心策划的杂志，跃马（Prancing Horse）品牌以艺术机构的庄重与意大利车身工艺的精准呈现。页面开篇是一片极致黑的辽阔，唯有标志性的跃马徽标独自悬浮在自己的氛围中。下方，内容在墨黑电影感区块与清脆白色编辑面板之间戏剧性地交替展开。这种明暗对比（chiaroscuro）节奏——黑暗让位于光明、机械让位于人的故事——感觉更像在翻阅一本 Ferrari 年鉴，而非滚动商业网站。每个区块都是一帧精心策划的速写：从阴影中浮现的概念车、两位以雕塑般静止姿态站立的 F1 车手、一列宝石色调的量产车型巡游。

对一个以速度与激情立身的品牌而言，色彩语言如修道院般克制。法拉利红（Ferrari Red）(`#DA291C`) 以近乎手术刀般的稀疏度出现——保留给订阅（Subscribe）CTA 和需要立刻攫取注意力的点缀时刻。界面绝大多数生活在黑、白与精心校准的灰阶中（从 `#303030` 深色表面，经 `#8F8F8F` 中调，到 `#D2D2D2` 浅边框）。两种黄色——赛车黄（Racing Yellow）(`#FFF200`) 与更深的摩德纳黄（Modena Yellow）(`#F6E500`)——作为特殊场景的传承点缀存在于 token 体系中，致敬 Ferrari 的赛车血统。这种克制意味着，当红色出现时，它承载着整个品牌的重量。

排印依赖 FerrariSans——一款专有无衬线家族，标题为中等字重（font weight）（500–700）、比例紧凑。展示文字在章节标题上为 24–26px，而 UI 界面框架（chrome）生活在 12–16px，字重从常规到加粗。次级的 "Body-Font" 定制字体处理图注（caption）与功能文字，以大写加宽字间距（letter-spacing）（1px）渲染，营造标签般的编辑质感。这套双字体体系——FerrariSans 负责叙事权威，Body-Font 负责结构注释——赋予网站印刷杂志式的层级。没有一处文字装饰是多余的。标题字间距紧凑，标签字间距刻意放宽，形成在紧迫与从容之间交替的视觉节奏。

**关键特征：**
- 明暗对比式布局，深黑区块与干净白色编辑面板交替
- 法拉利红（`#DA291C`）极度稀疏地使用——是点缀，不是氛围
- 跃马徽标作为孤立的主视觉（hero）元素，立于虚空黑场
- FerrariSans 专有字体，比例紧凑、字重中等
- 新闻摄影风影像：概念渲染图、车手肖像、车型巡游——每个区块都是一个故事
- 大写 Body-Font 标签，宽字间距（1px），用于编辑注释
- 近乎零的圆角（border-radius）（默认 2px），映照精密工程美学
- 双框架架构（PrimeReact + Element Plus），驱动 32+ 交互组件
- 轮播（carousel）驱动的主视觉，编辑式幻灯片，箭头/圆点导航

## 2. 色板与角色

### 主色
- **法拉利红（Ferrari Red）**(`#DA291C`)：标志性的 Rosso Corsa——主点缀色与 CTA 色。用于订阅按钮、关键动作触发点，以及需要最大视觉权威的品牌时刻。系统中唯一最重要的颜色（--f-color-accent-100）
- **纯白（Pure White）**(`#FFFFFF`)：编辑内容面板的主表面、深色背景上的导航文字，以及按钮填充。为深色电影感区块之间提供呼吸空间的画布（--f-color-ui-0）

### 次级与点缀色
- **深红（Dark Red）**(`#B01E0A`)：法拉利红的更深变体，用于悬停（hover）/按下态与高对比场景——在不引入新色相的情况下为品牌色增加维度（--f-color-accent-90）
- **浓红（Deep Red）**(`#9D2211`)：饱和度最高的深红——用于激活态和连深红都需要更强分量的额外强调（--f-color-accent-80）
- **赛车黄（Racing Yellow）**(`#FFF200`)：源自 Ferrari 赛车涂装的传承点缀——保留给特殊高光与赛车相关场景（--f-color-yellow-hypersail）
- **摩德纳黄（Modena Yellow）**(`#F6E500`)：比赛车黄略暖、更金——用于次级传承点缀与品类标记（--f-color-yellow）

### 表面与背景
- **极致黑（Absolute Black）**(`#000000`)：主视觉区、电影感背景与主导性深色表面——让影像与跃马徽标悬浮的虚空
- **深色表面（Dark Surface）**(`#303030`)：页脚区、通讯订阅区块与层叠深色面板的次级深色表面——比纯黑略提亮以区分纵深（--f-color-ui-90）
- **浅灰表面（Light Gray Surface）**(`#D2D2D2`)：白色面板上分隔线与边框处理的微妙替代表面（--f-color-ui-20）
- **深色遮罩（Overlay Dark）**(`hsla(0, 0%, 7%, 0.8)`)：用于模态（modal）遮罩（overlay）与图片图注背景的半透明近黑（--f-color-overlay-darker）

### 中性色与文字
- **近黑（Near Black）**(`#181818`)：浅色表面上的主正文色——比极致黑略柔化以提升可读性（链接默认色）
- **深灰（Dark Gray）**(`#666666`)：次级文字与低调 UI 标签——用于文字需从主层级退后的场景（--f-color-black-60）
- **中灰（Mid Gray）**(`#8F8F8F`)：元数据、时间戳与辅助内容的三级文字（--f-color-black-50）
- **银灰（Silver Gray）**(`#969696`)：占位文字与禁用态指示（--f-color-black-55）

### 语义与点缀色
- **警示红（Warning Red）**(`#F13A2C`)：无障碍警示态——比法拉利红更亮、更偏橙，以区分语义警示与品牌表达（--f-color-accessible-warning）
- **成功绿（Success Green）**(`#03904A`)：确认与正向状态指示（--f-color-accessible-success）
- **信息蓝（Info Blue）**(`#4C98B9`)：信息提示、工具提示与中性状态消息（--f-color-accessible-info）
- **链接悬停蓝（Link Hover Blue）**(`#3860BE`)：文字链接的交互悬停态——庄重的藏青蓝，传递可交互性而不与法拉利红竞争

### 渐变体系
- token 体系中没有显式渐变
- 纵深通过摄影与黑白表面之间的二元对比实现
- 更深的遮罩色（`hsla(0, 0%, 7%, 0.8)`）通过在影像上叠加透明层营造纵深
- 偶发的摄影渐变（影棚拍摄中的光线衰减）在图片内容内提供氛围纵深

## 3. 排印规则

### 字体家族
- **FerrariSans**：标题、导航、按钮与编辑内容的主字体。一款专有无衬线体，默认中等字重（500）、紧凑 x 高、精准的字间距控制。Fallback：Arial、Helvetica、sans-serif
- **Body-Font**：图注、标签与功能文字的次级字体。常以大写加放宽字间距（1px）渲染，营造编辑标签美学。用于品类标签与小注释文字
- **Arial / Helvetica**：系统 fallback 字体，用于 Cookie 同意模态框（modal）、表单元素与第三方组件框架

| 卡片标题 | 24px (1.50rem) | 400 | normal | normal | FerrariSans，内容卡片标题 |

| UI 标题 | 16px (1.00rem) | 500 | 1.40 | 0.08px | FerrariSans，组件标题与导航项 |
| 加粗正文 | 16px (1.00rem) | 700 | 1.30（紧凑） | normal | FerrariSans，强调的内联文字 |
| 按钮标签 | 16px (1.00rem) | 400 | normal | 1.28px | FerrariSans，主按钮文字，宽字距 |

### 原则
- **专有身份**：FerrariSans 为 Ferrari 独有——替换它就会失去品牌识别度。该字体紧凑的比例与默认中等字重（500）传达工程精度
- **双语域体系**：FerrariSans 负责叙事嗓音（标题、内容、按钮），Body-Font 负责结构注释（标签、标记、微图注）——这映射了印刷杂志"编辑正文 vs 技术标签"的惯例
- **大写即强调工具**：Body-Font 图注用 `text-transform: uppercase` 加放宽字间距（1px），形成视觉上独立的标签层，读作"信息叠加层"而非主内容
- **紧凑行高**：标题用紧凑行高（1.00–1.30）形成密集有力的文本块，正文则放宽到 1.50 以舒适阅读——压缩标题与宽松正文的对比营造视觉张力
- **字重区间 400–700**：系统中有四个活跃字重（400、500、600、700）——比 Tesla 的区间大得多，但仍受控。500 是默认"嗓音"，700 用于强调，400 用于正文，600 用于导航

## 4. 组件样式

### 按钮
Ferrari 的按钮是极简白色矩形、近乎零圆角——CTA 哲学是"建筑，而非装饰"。

**主 CTA（白色）**——默认操作按钮：
- Default: bg `#FFFFFF`，text `#000000`，fontSize 16px（FerrariSans），letterSpacing 1.28px，padding 12px 10px，borderRadius 2px，border 1px solid `#000000`
- Hover: bg `#1EAEDB`（青色（Teal）），text `#FFFFFF`，opacity 0.9
- Focus: bg `#1EAEDB`，text `#FFFFFF`，border 1px solid `#FFFFFF`，outline 2px solid `#000000`，opacity 0.9
- 用于："Configure" 操作、浅色背景上的次级行动号召

**订阅 CTA（红色）**——高强调动作按钮：
- Default: bg `#DA291C`（法拉利红（Ferrari Red）），text `#FFFFFF`，borderRadius 2px，padding 12px 10px
- 用于：通讯订阅、深色背景上的主转化动作
- 唯一使用法拉利红的按钮——保留给最高视觉优先级

**幽灵按钮（白色边框）**——用于深色背景：
- Default: bg transparent，text `#FFFFFF`，border 1px solid `#FFFFFF`，borderRadius 2px，padding 12px 10px
- Hover: bg `#1EAEDB`（青色（Teal）），text `#FFFFFF`，opacity 0.9
- Focus：与主 CTA 焦点态相同
- 用于：叠加在深色影像与电影感区块上的动作

**文字链接**——内联导航：
- Default: text `#181818`（浅色表面）或 `#FFFFFF`（深色），no border，no background
- Hover：颜色切换为 `#3860BE`（链接悬停蓝（Link Hover Blue）），decoration 移除下划线
- 深色表面上的白色变体默认用下划线装饰
- 按场景用 FerrariSans 或 Body-Font（大写标签链接用 Body-Font）

### 卡片与容器

**编辑卡片**（内容区块）：
- Background: white
- Border: none
- Shadow: none
- Layout：图片在上，标题 + 图注在下
- 图片处理：卡片内通栏，图片无圆角
- Text：FerrariSans 标题（16–24px）+ Body-Font 图注（12–13px 大写）

**深色电影卡片**（主视觉/特写区块）：
- Background: `#000000`（极致黑（Absolute Black））
- 通栏（full-bleed）影像配文字叠加
- 无边框、无阴影——黑暗本身就是容器
- Text：白色，以精心安排的负空间定位

**车型阵容**（车型轮播）：
- 车辆缩略图的横向可滚动行
- 每辆车置于中性/白色背景
- 导航：箭头按钮 + 圆点指示器
- 背景切换以展示所选车型的配色语境

### 输入框与表单

**通讯订阅输入框**（页脚区块）：
- Background：深色表面上的 transparent
- Text: white
- Border: 1px solid `#CCCCCC`
- Placeholder: `#969696`（银灰（Silver Gray））
- Focus：边框颜色过渡（标准浏览器焦点环）
- Label：Body-Font 大写，12px，1px 字间距

**Cookie 同意**（模态框）：
- Background: white
- Border radius: 8px（对话框）
- Shadow: `rgb(153, 153, 153) 1px 1px 1px 0px`
- Buttons：超大（45px Arial），白底（bg）黑边框
- 使用标准 PrimeReact/Element Plus 模态框架

### 导航
- **桌面端**：跃马 Logo 居中置于页面顶部，主导航在下方——不是传统的横向导航栏，而是黑色背景上的通栏页眉块
- **Logo**：极致黑上的居中跃马徽标（44×42px）——最醒目的单个 UI 元素
- **链接**：FerrariSans，13px，字重 600，深色背景上的白色文字
- **移动端**：汉堡菜单（hamburger）收拢为纵向导航抽屉
- **页脚**：`#303030`（深色表面（Dark Surface））上的多列布局，品类链接为 Body-Font 大写
- 未观察到**粘性（sticky）导航**行为——页面自然滚动，页眉随之移出视野

### 图片处理
- **主视觉**：黑色背景上的通栏编辑摄影——氛围影棚灯光下的概念车、电影感构图的编辑肖像
- **长宽比（aspect ratio）**：混合——主视觉区横构图（16:9），肖像/车手影像近方形，车型阵容用宽幅全景
- **通栏 vs 内边距**：主视觉图片通栏出血到边缘；编辑内容图片在白色容器内带内边距
- **懒加载（lazy loading）**：首屏以下区块用渐进加载（PrimeReact 框架处理）
- **图片质量**：影棚灯光的高分辨率摄影——无用户生成或生活方式影像。每张图片都经过艺术指导（art-directed）

### 轮播组件
- 多幻灯片的编辑轮播
- 幻灯片位置的圆点指示器
- 幻灯片边缘的箭头导航（左/右）
- 自动播放，可手动接管
- 内容：混合编辑——活动回顾、车型发布、赛车高光

## 5. 布局原则

### 间距系统
- **基准单位**：8px（检测到的系统基准）
- **尺度**：1px、2px、4px、5px、6px、9px、10px、11.2px、12px、13px、15px、16px、19px、20px、25px
- **按钮内边距**：纵向 12px、横向 10px——紧凑精准
- **区块内边距**：主要内容块之间慷慨的纵向间距（估计 40–80px）
- **卡片间距**：网格项之间 16–20px
- **页脚内边距**：深色页脚块内横向 25px 的分区

### 网格与容器
- **最大宽度**：1920px（最大断点），较窄宽度下内容收缩
- **主视觉**：黑色上的通栏，内容居中
- **编辑区块**：2 列布局，图片 + 文字，左右交替
- **车型阵容**：横向滚动/轮播，桌面宽度可见 5–6 款车型
- **页脚**：链接品类的 4 列网格

### 留白哲学
Ferrari 把留白当作画廊墙面。每个区块——无论是黑虚空上的概念车渲染，还是中性灰上的一对 F1 车手——都被赋予自己"房间"般的呼吸空间。黑白交替的区块营造节奏韵律：深色 = 沉浸时刻，白色 = 编辑内容，深色 = 沉浸时刻。这种韵律让滚动如翻阅奢华出版物。编辑卡片之间的留白适中（不到 Tesla 那般极端），因为 Ferrari 在讲故事，而非展览单个物件。

### 圆角尺度
| 值 | 场景 |
|---|---|
| 1px | 小型内联元素（spans）的轻微柔化 |
| 2px | 按钮、输入框与交互元素的默认值——几乎不可察觉，剃刀般精准 |
| 8px | 模态对话框与遮罩容器——"最柔"的结构圆角 |
| 50% | 圆形元素：轮播圆点、头像缩略图、滑块手柄 |

## 6. 纵深与层级

| 层级 | 处理方式 | 用途 |
|---|---|---|
| Level 0（平面） | 无阴影、无边框 | 所有内容区块与卡片的默认态 |
| Level 1（微妙） | `rgb(153, 153, 153) 1px 1px 1px 0px` | 罕见——Cookie 同意对话框与下拉菜单 |
| Level 2（遮罩） | `hsla(0, 0%, 7%, 0.8)` 底层 | 模态遮罩与图片图注背景 |
| Level 3（边框） | `1px solid #CCCCCC` | 输入框、表单容器——以勾勒而非阴影营造纵深 |

### 阴影哲学
Ferrari 的层级手法几乎和 Tesla 一样扁平，但理由不同。Tesla 为极简而避阴影，Ferrari 避阴影是因为编辑摄影已提供所需的全部视觉纵深。唯一的阴影 token（`rgb(153, 153, 153) 1px 1px 1px 0px`）极其微妙——1 像素的耳语，只用在同意对话框这类实用场景。网站通过三种策略传达层级：
1. **表面色对比**：黑色区块 vs 白色区块形成不容置疑的层叠
2. **遮罩透明度**：80% 不透明度的 `--f-color-overlay-darker` 在无阴影下营造纵深
3. **摄影纵深**：影棚灯光的汽车影像，带反射、地面阴影与氛围雾，提供全部视觉维度

### 装饰性纵深
- 界面元素上无 UI 渐变、无辉光、无模糊效果
- 黑底上的跃马 Logo 以纯对比营造"悬浮于虚空"的效果——无需辉光或阴影
- 深到浅的区块过渡是硬切而非渐变融合——强化编辑翻页的隐喻

## 7. 建议与禁忌

### 建议
- 法拉利红（`#DA291C`）节制使用——只用于主 CTA 和品牌关键时刻。它的力量来自克制
- 在黑色电影感区块与白色编辑区块间交替，营造标志性的明暗对比节奏
- 用字重 500 的 FerrariSans 作默认标题嗓音——它是引擎声浪的排印等价物
- 所有标签、品类标记与结构注释用大写的 Body-Font，加 1px 字间距
- 所有交互元素的圆角保持 2px——剃刀般精准，而非圆润亲和
- 让摄影承载情感分量——每张图片都应是经艺术指导的影棚品质
- 把跃马徽标作黑色上独立的主视觉元素——绝不让相邻内容挤占它
- 保持按钮 12px/10px 的内边距比例——紧凑、有目的、无冗余
- 正文用 `#181818`（近黑（Near Black））而非纯 `#000000`——微妙的暖意提升可读性
- 黄色点缀（`#FFF200`、`#F6E500`）严格保留给赛车运动与赛车传承场景

### 禁忌
- 不要把法拉利红撒在界面上当装饰——它是 CTA 信号，不是主题色
- 不用圆角胶囊按钮或大圆角——2px 精准度不可谈判
- 不给卡片或内容容器加 box-shadow——纵深来自表面色对比与摄影
- 不在同一文本块内混用 FerrariSans 与 Body-Font——它们服务不同的层级功能
- 不给区块用彩色背景（蓝、绿等）——色板只有黑/白/灰加红黄点缀
- 不对 FerrariSans 标题做文本变换——大写只保留给 Body-Font 标签
- 不展示低质量或用户生成的影像——每张照片都必须达到编辑标准
- 链接悬停蓝（`#3860BE`）不用在交互悬停态之外——它不是品牌色
- 不做多个焦点互抢的繁忙布局——每个区块应只有一个清晰故事
- 不用品牌色覆盖语义色系统（警示、成功、信息）——`#F13A2C` 警示红刻意区别于 `#DA291C` 品牌红

## 8. 响应式（responsive）行为

### 断点
| 名称 | 宽度 | 主要变化 |
|---|---|---|
| 小手机 | ≤375px | 单列、最小内边距（12px）、堆叠导航、主视觉文字缩放到约 18px、通栏 CTA |
| 手机 | 376–600px | 单列、内边距略大（16px）、汉堡菜单导航、正文 13px |
| 小平板 | 601–768px | 2 列编辑网格开始、主视觉图片保持通栏、页脚切换为 2 列 |
| 平板 | 769–960px | 完整 2 列布局、轮播显示 3 辆车、内边距增至 20px |
| 桌面 | 961–1280px | 完整导航、2 列编辑配更大影像、车型阵容显示 5 款车型 |
| 大桌面 | 1281–1920px | 最大内容宽度、慷慨留白、主视觉摄影全电影尺度 |

### 触控目标（touch target）
- 主 CTA 按钮：最小高度 44px、纵向内边距 12px（满足 WCAG AAA 44×44px 目标）
- 导航链接：13px 文字、1.50 行高，项之间间距充足
- 轮播箭头：视口边缘 44px 以上的触控目标
- 页脚链接：分组，纵向间距充足（16–20px）以保证触控精度

### 收拢策略
- **导航**：完整横向导航在移动端收拢为居中跃马 Logo + 汉堡菜单
- **编辑区块**：2 列图文布局收拢为单列，图片堆叠在文字上方
- **车型阵容**：横向轮播保持滚动行为，可见车型从 5 款减至 2–3 款
- **页脚**：4 列链接网格在平板上收拢为 2 列，移动端为单列手风琴
- **主视觉轮播**：所有断点下通栏，圆点指示器与箭头按比例缩放
- **间距缩减**：区块内边距从 40–80px（桌面）减至 20–40px（移动端），保持成比例的呼吸空间

### 图片行为
- 主视觉图片：所有断点下通栏，用 `object-fit: cover` 保持电影感构图
- 编辑图片：在容器内响应式，保持长宽比
- 车型阵容：缩略图尺寸缩放，但保持一致的车框比例
- 艺术指导：移动端裁剪可能收紧车辆主体，减少环境语境
- 懒加载：PrimeReact 处理首屏以下内容的渐进图片加载

### 迭代指南
用本设计系统打磨已有界面时：
1. 一次只聚焦一个组件——Ferrari 的编辑节奏意味着每个区块都是自成一体的速写
2. 引用本文档中的具体颜色名与色值——色板虽小，每种颜色都有精准角色
3. 用自然语言描述而非 CSS 值——"剃刀般锋利的 2px 边角"比 "border-radius: 2px" 更能传达意图
4. 在具体数值旁描述想要的"感觉"——"区块间的编辑杂志翻页感"比 "margin-bottom: 80px" 更能传达布局哲学
5. 永远保持明暗对比——如果某区块感觉平，就检查它是该在黑色还是白色上以维持交替节奏
6. 每屏只把法拉利红保留给一个元素——如果红色出现在多处，它就失去了权威
