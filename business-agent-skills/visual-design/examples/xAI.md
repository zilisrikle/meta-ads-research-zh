# 源自 xAI 的设计系统

## 1. 视觉主题与氛围

xAI 的网站是深色优先、等宽驱动的粗野主义（brutalist）极简的大师课——一套像出自理解"克制是终极精致"的工程师之手的设计系统。整个体验锚定在近黑背景（`#1f2228`）配纯白文本（`#ffffff`）上，营造高对比、终端灵感的美学，传递深厚的技术可信度。没有渐变、没有装饰插画、没有争抢注意力的色彩点缀。这是一个通过缺席来沟通的网站。

排印（Typography）系统分属两种精心挑选的字体。`GeistMono`（Vercel 的等宽字体）以惊人的 320px 处理展示级标题，字重 300，同时作为按钮字体，大写加拉开的字间距（1.4px）。`universalSans` 以干净的几何无衬线语调处理所有正文和次级标题。等宽作展示字体的选择是定义性的美学决策——它把 xAI 定位成基础设施而非消费产品，是住在终端里的人建造的东西。

间距系统运行在 8px 基础网格上，值集中在小端（4px、8px、24px、48px），反映密集、信息聚焦的布局哲学。圆角极简——网站几乎不做圆角，保持锐利、建筑感的边缘。没有装饰阴影、没有渐变、没有分层抬升。深度纯粹通过对比和留白传达。

**关键特征：**
- 纯深色主题：`#1f2228` 背景配 `#ffffff` 文本——没有灰色中间地带
- 极端展示尺寸的 GeistMono（320px，字重 300）——等宽即奢华
- 大写等宽按钮，1.4px 字间距——技术感、命令感
- 正文用 universalSans 16px/1.5，标题 30px/1.2——干净对比
- 零装饰元素：无阴影、无渐变、无彩色点缀
- 8px 间距网格，稀疏而刻意的阶梯
- Heroicons SVG 图标系统——极简、功能化
- Tailwind CSS 加任意值——utility-first 的工程方法

## 2. 色彩体系与角色

### 主色
- **Pure White**（`#ffffff`）：唯一的文本色、链接色和所有前景元素。在 xAI 的系统中，白色不是背景——它是声音。
- **Dark Background**（`#1f2228`）：画布。带微妙蓝调的暖近黑（不是纯黑，不是中性灰）。这个特定色相避免 `#000000` 的刺眼，同时保持深邃的黑暗。

### 交互
- **White Default**（`#ffffff`）：默认态的链接和交互元素色。
- **White Muted**（`rgba(255, 255, 255, 0.5)`）：链接悬停态——刻意变暗而非变亮，不寻常且独特。
- **White Subtle**（`rgba(255, 255, 255, 0.2)`）：边框、分隔线和微妙表面处理。
- **Ring Blue**（`rgb(59, 130, 246) / 0.5`）：Tailwind 默认焦点环色（`--tw-ring-color`），用于键盘无障碍焦点态。

### 表面与边框
- **Surface Elevated**（`rgba(255, 255, 255, 0.05)`）：微妙卡片背景和悬停表面——几乎看不见的抬升。
- **Surface Hover**（`rgba(255, 255, 255, 0.08)`）：交互容器稍明显的悬停态。
- **Border Default**（`rgba(255, 255, 255, 0.1)`）：卡片、分隔线、容器的标准边框。
- **Border Strong**（`rgba(255, 255, 255, 0.2)`）：激活态和按钮轮廓的强调边框。

### 功能色
- **Text Primary**（`#ffffff`）：所有标题、正文文本、标签。
- **Text Secondary**（`rgba(255, 255, 255, 0.7)`）：描述、说明文字、支持文本。
- **Text Tertiary**（`rgba(255, 255, 255, 0.5)`）：弱化标签、占位文本、时间戳。
- **Text Quaternary**（`rgba(255, 255, 255, 0.3)`）：禁用文本、极微妙注释。

## 3. 排印规则

### 字体族
- **展示/按钮**：`GeistMono`，回退：`ui-monospace, SFMono-Regular, Roboto Mono, Menlo, Monaco, Liberation Mono, DejaVu Sans Mono, Courier New`
- **正文/标题**：`universalSans`，回退：`universalSans Fallback`

### 层级

| 角色 | 字体 | 字号 | 字重 | 行高 | 字间距 | 变换 | 备注 |
|------|------|------|--------|-------------|----------|-----------|-------|
| 展示首屏 | GeistMono | 320px (20rem) | 300 | 1.50 | normal | none | 极端尺寸、等宽奢华 |
| 章节标题 | universalSans | 30px (1.88rem) | 400 | 1.20（紧） | normal | none | 干净的无衬线对比 |
| 正文 | universalSans | 16px (1rem) | 400 | 1.50 | normal | none | 标准阅读文本 |
| 按钮 | GeistMono | 14px (0.88rem) | 400 | 1.43 | 1.4px | uppercase | 拉开的等宽、命令感 |
| 标签/说明 | universalSans | 14px (0.88rem) | 400 | 1.50 | normal | none | 支持文本 |
| 小字/元数据 | universalSans | 12px (0.75rem) | 400 | 1.50 | normal | none | 时间戳、脚注 |

### 原则
- **等宽作展示**：320px 的 GeistMono 不是噱头——它是品牌宣言。极端尺寸的定宽字符营造任何比例字体都无法实现的韵律、建筑感。
- **大尺寸轻字重**：320px 标题用字重 300，防止等宽在极端尺寸显得沉重或粗野。它读起来精确，而非压迫。
- **大写按钮**：所有按钮文本都是大写 GeistMono 加 1.4px 字间距。这为交互元素营造独特的、技术性的、近乎命令行的美学。
- **无衬线阅读**：16px/1.5 的 universalSans 为正文内容提供出色的可读性，与等宽展示元素形成干净对比。
- **双字体清晰**：系统只用两种字体，角色清晰——等宽负责冲击和交互，无衬线负责信息和阅读。不重叠、不含糊。

## 4. 组件样式

### 按钮

- 文本：`#1f2228`
- 内边距：12px 24px
- 圆角：0px（锐角）
- 字体：GeistMono 14px 字重 400，大写，字间距 1.4px
- 悬停：`rgba(255, 255, 255, 0.9)` 背景
- 用途：主 CTA（"TRY GROK"、"GET STARTED"）

**幽灵/描边**
- 背景：透明
- 文本：`#ffffff`
- 内边距：12px 24px
- 圆角：0px
- 边框：`1px solid rgba(255, 255, 255, 0.2)`
- 字体：GeistMono 14px 字重 400，大写，字间距 1.4px
- 悬停：`rgba(255, 255, 255, 0.05)` 背景
- 用途：次级操作（"LEARN MORE"、"VIEW API"）

**文本链接**
- 背景：无
- 文本：`#ffffff`
- 字体：universalSans 16px 字重 400
- 悬停：`rgba(255, 255, 255, 0.5)`——悬停变暗
- 用途：行内链接、导航项

### 卡片与容器
- 背景：`rgba(255, 255, 255, 0.03)` 或透明

- 品牌文字标志：白色文本，左对齐

- 悬停：`rgba(255, 255, 255, 0.5)` 文本色
- CTA：白色主按钮，右对齐
- 移动端：汉堡开关

### 徽章/标签
**等宽标签**
- 背景：透明
- 文本：`#ffffff`
- 内边距：4px 8px
- 边框：`1px solid rgba(255, 255, 255, 0.2)`
- 圆角：0px
- 字体：GeistMono 12px 大写，字间距 1px

### 输入框与表单
- 背景：透明或 `rgba(255, 255, 255, 0.05)`
- 边框：`1px solid rgba(255, 255, 255, 0.2)`
- 圆角：0px
- 焦点：`rgb(59, 130, 246) / 0.5` 的环
- 文本：`#ffffff`
- 占位符：`rgba(255, 255, 255, 0.3)`
- 标签：`rgba(255, 255, 255, 0.7)`，universalSans 14px

## 5. 布局原则

### 间距系统
- 基础单位：8px
- 阶梯：4px、8px、24px、48px
- 阶梯刻意稀疏——xAI 避开细碎的间距区分，偏好通过留白本身创造清晰视觉层级的大跨度

### 网格与容器
- 最大内容宽：约 1200px
- 首屏：全视口高度，巨大的居中等宽标题
- 功能区块：简单垂直堆叠，区块内边距慷慨（48px–96px）
- 桌面端功能描述用两列布局
- 全宽深色区块始终保持单一深色背景

### 留白（Whitespace）哲学
- **极端慷慨**：xAI 用海量留白。320px 标题配 48px+ 周围内边距，营造的空旷本身就是设计宣言——内容如此重要，需要呼吸的空间。
- **垂直节奏优先于横向密度**：内容垂直堆叠，区块间大间距，而非横向打包。这创造深思熟虑、电影感的滚动体验。
- **无视觉噪音**：没有装饰元素、区块间边框、色彩变化，留白是主要结构工具。

### 断点
- 2000px、1536px、1280px、1024px、1000px、768px、640px
- Tailwind 响应式修饰符驱动断点行为

### 圆角阶梯
- 锐角（0px）：按钮、卡片、输入框的主处理——默认
- 微妙（4px）：次级容器偶尔柔化
- 近零圆角哲学是品牌粗野主义身份的核心

## 6. 深度与层级

| 层级 | 处理 | 用途 |
|-------|-----------|-----|
| 扁平（0 级） | 无阴影、无边框 | 页面背景、正文内容 |
| 表面（1 级） | `rgba(255,255,255,0.03)` 背景 | 微妙卡片表面 |
| 边框（2 级） | `1px solid rgba(255,255,255,0.1)` 边框 | 卡片、容器、分隔线 |
| 激活（3 级） | `1px solid rgba(255,255,255,0.2)` 边框 | 悬停态、激活元素 |
| 焦点（无障碍） | `ring` 配 `rgb(59,130,246)/0.5` | 键盘焦点指示 |

**抬升哲学**：xAI 完全拒绝传统的基于阴影的抬升系统。网站上没有任何盒阴影。相反，深度通过三种机制传达：(1) 交互时变亮的不透明度边框，营造元素"激活"而非"抬起"的感觉；(2) 极微妙的背景不透明度变化（`0.03` 到 `0.08`），创造几乎察觉不到的表面区分；(3) 320px 展示字体与 16px 正文文本的巨大尺寸对比，创造排印深度。这是靠对比和不透明度的抬升，而非模拟光影。

## 7. 应该做与不应该做

### 应该做
- `#1f2228` 作通用背景——从不用纯黑 `#000000`
- 所有展示标题和按钮文本用 GeistMono——等宽就是品牌
- 所有按钮标签用大写 + 1.4px 字间距
- 巨型展示标题（320px）用字重 300
- 边框保持 `rgba(255, 255, 255, 0.1)`——几乎看不见，而非缺席
- 交互元素悬停变暗到 `rgba(255, 255, 255, 0.5)`——与惯例相反
- 锐角（0px 圆角）作默认——粗野主义精度
- 所有正文和阅读文本用 universalSans 16px/1.5

### 不应该做
- 不用盒阴影——xAI 零阴影抬升
- 白与深色背景之外不引入色彩点缀——单色色板神圣不可侵犯
- 不用大圆角（8px+、胶囊形）——锐边是刻意的
- 标题不用粗字重（600–700）——只用字重 300–400
- 悬停不变亮元素——xAI 变暗到 `0.5` 不透明度
- 不加装饰渐变、插画或色块
- 按钮不用比例字体——大写 GeistMono 是强制的
- 非绝对必要不用彩色状态指示——一切保持在白/深色谱系

## 8. 响应式行为

### 断点
| 名称 | 宽度 | 关键变化 |
|------|-------|-------------|
| 移动端 | <640px | 单列，首屏标题大幅缩小 |
| 小平板 | 640–768px | 内边距略增 |
| 平板 | 768–1024px | 两列布局开始，标题尺寸增大 |
| 桌面 | 1024–1280px | 完整布局，留白慷慨 |
| 大屏 | 1280–1536px | 更宽容器，更多呼吸空间 |
| 超大 | 1536–2000px | 最大内容宽，居中 |
| 极大 | >2000px | 内容保持居中，极端边距 |

### 触控目标
- 按钮用 12px 24px 内边距，触控舒适
- 导航链接用 24px 间距
- 最小点击目标：44px 高
- 移动端：全宽按钮方便拇指触达

### 折叠策略
- 首屏：320px 等宽标题大幅缩小（移动端约 48px–64px）
- 导航：横向链接折叠为汉堡菜单
- 功能区块：两列 → 单列堆叠
- 区块内边距：跨断点 96px → 48px → 24px
- 巨型展示字体最先调整尺寸——必须保持冲击力但不溢出

### 图片行为
- 极简图片——网站依赖排印和留白
- 任何产品截图保持锐角
- 全宽媒体随视口按比例缩放

### 迭代指南
1. 永远从 `#1f2228` 背景开始——从不用纯黑或灰背景
2. 展示和按钮用 GeistMono，其他一切用 universalSans——从不混用角色
3. 所有按钮必须大写 GeistMono 加 1.4px 字间距——不可妥协
4. 永无阴影——深度只来自边框不透明度和背景不透明度
5. 边框永远低不透明度的白（默认 0.1，强调 0.2）
6. 悬停变暗到 0.5 不透明度而非变亮——与大多数系统相反
7. 默认锐角（0px）——4px 只用于特定次级容器
8. 正文用 16px universalSans，1.5 行高，阅读舒适
9. 区块内边距慷慨（48px–96px）——让内容在黑暗中呼吸
10. 白底深色的单色色板是绝对的——除非功能关键，否则抵制加色
