# Linear 灵感设计系统

## 1. 视觉主题与氛围

Linear 的网站是深色优先产品设计的大师课——近黑画布（`#08090a`），内容像星光一样从黑暗中浮现。整体印象是极致的精密工程：每个元素都存在于精心校准的亮度层级中，从几乎不可见的边框（`rgba(255,255,255,0.05)`）到柔和发光的文字（`#f7f8f8`）。这不是把深色主题套在浅色设计上——黑暗是原生媒介，信息密度通过白色不透明度的微妙渐变而非颜色变化来管理。

排印系统完全建立在 Inter Variable 上，全局启用 OpenType 特性 `"cv01"` 与 `"ss03"`，赋予字体更干净、更几何的性格。Inter 的字重（font weight）范围惊人——从 300（轻正文）经 510（中等，Linear 的签名字重）到 590（半粗强调）。510 字重尤其独特：它介于常规与中等之间，形成不张扬的微妙强调。展示字号（72px、64px、48px）下，Inter 用激进的负字间距（letter-spacing）（-1.584px 到 -1.056px），标题被压缩、权威，感觉是被工程化而非被设计出来的。Berkeley Mono 是等宽伴侣，用于代码与技术标签，回退到 ui-monospace、SF Mono 与 Menlo。

色彩体系几乎完全无彩——深色背景配白/灰文字，只被一个品牌点缀打破：Linear 的签名靛紫（`#5e6ad2` 作背景，`#7170ff` 作交互点缀）。这个点缀色用得克制而有意，只出现在 CTA、当前态与品牌元素上。边框系统用超薄半透明白边框（`rgba(255,255,255,0.05)` 到 `rgba(255,255,255,0.08)`），无声地建立结构，像月光下画的线框。

**关键特征：**
- 深色原生：`#08090a` 营销背景、`#0f1011` 面板背景、`#191a1b` 抬升表面
- Inter Variable 全局 `"cv01", "ss03"`——几何替代形，更干净的美学
- 签名字重 510（介于常规与中等之间），多数 UI 文字用
- 展示字号的激进负字间距（72px 下 -1.584px，48px 下 -1.056px）
- 品牌靛紫：`#5e6ad2`（背景）/ `#7170ff`（点缀）/ `#828fff`（悬停）——系统中唯一的彩色
- 通篇半透明白边框：`rgba(255,255,255,0.05)` 到 `rgba(255,255,255,0.08)`
- 按钮背景近零不透明度：`rgba(255,255,255,0.02)` 到 `rgba(255,255,255,0.05)`
- 带内嵌变体的多层阴影，深色表面上的纵深
- Radix UI 原语（primitive）作组件基础（检测到 6 个原语）
- 成功绿（`#27a644`、`#10b981`）只用于状态指示

## 2. 色板与角色

### 背景表面
- **营销黑（Marketing Black）** (`#010102` / `#08090a`)：最深的背景——首屏区块与营销页的画布。近纯黑，带不可察觉的冷蓝底调。
- **面板深（Panel Dark）** (`#0f1011`)：侧栏与面板背景。比营销黑高一级。
- **三级表面（Level 3 Surface）** (`#191a1b`)：抬升表面区、卡片背景、下拉。
- **次级表面（Secondary Surface）** (`#28282c`)：最浅的深色表面——用于悬停态与略微抬升的组件。

### 文字与内容
- **主文字（Primary Text）** (`#f7f8f8`)：带微暖调的近白。默认文字色——不是纯白，避免深色背景上的视觉疲劳。
- **次文字（Secondary Text）** (`#d0d6e0`)：正文、描述、次级内容的冷银灰。
- **三级文字（Tertiary Text）** (`#8a8f98`)：占位符、元数据、弱化内容的弱化灰。
- **四级文字（Quaternary Text）** (`#62666d`)：最弱化的文字——时间戳、禁用态、微妙标签。

### 品牌与点缀
- **品牌靛蓝（Brand Indigo）** (`#5e6ad2`)：主品牌色——CTA 按钮背景、品牌标识、关键交互表面。
- **点缀紫（Accent Violet）** (`#7170ff`)：交互元素更亮的变体——链接、当前态、选中项。
- **点缀悬停（Accent Hover）** (`#828fff`)：点缀元素悬停态更浅、更饱和的变体。
- **安全薰衣草（Security Lavender）** (`#7a7fad`)：专门用于安全相关 UI 元素的弱化靛蓝。

### 状态色
- **绿（Green）** (`#27a644`)：主成功/当前状态。用于"进行中"指示。
- **翡翠（Emerald）** (`#10b981`)：次成功——胶囊徽章、完成态。

### 边框与分隔线
- **主边框（Border Primary）** (`#23252a`)：显著分隔的纯深色边框。
- **次边框（Border Secondary）** (`#34343a`)：略浅的纯色边框。
- **三级边框（Border Tertiary）** (`#3e3e44`)：最浅的纯色边框变体。
- **微边框（Border Subtle）** (`rgba(255,255,255,0.05)`)：超微妙半透明边框——默认。
- **标准边框（Border Standard）** (`rgba(255,255,255,0.08)`)：卡片、输入框、代码块的标准半透明边框。
- **线条色调（Line Tint）** (`#141516`)：最微妙分隔的近不可见线条。
- **三级线条（Line Tertiary）** (`#18191a`)：略可见的分隔线。

### 浅色模式中性色（浅色主题上下文用）
- **浅背景（Light Background）** (`#f7f8f8`)：浅色模式的页面背景。
- **浅表面（Light Surface）** (`#f3f4f5` / `#f5f6f7`)：微妙表面着色。
- **浅边框（Light Border）** (`#d0d6e0`)：浅色上下文中的可见边框。
- **浅边框替代（Light Border Alt）** (`#e6e6e6`)：替代的更浅边框。
- **纯白（Pure White）** (`#ffffff`)：卡片表面、高光。

### 遮罩
- **遮罩主（Overlay Primary）** (`rgba(0,0,0,0.85)`)：模态/对话框背景——极深，隔离焦点。

## 3. 排印规则

### 字体家族
- **主字体**：`Inter Variable`，回退：`SF Pro Display, -apple-system, system-ui, Segoe UI, Roboto, Oxygen, Ubuntu, Cantarell, Open Sans, Helvetica Neue`
- **等宽**：`Berkeley Mono`，回退：`ui-monospace, SF Mono, Menlo`

### 原则
- **510 是签名字重**：Linear 用 Inter Variable 的 510 字重（介于常规 400 与中等 500 之间）作默认强调字重。这形成微妙加粗感，没有传统中等或半粗的沉重。
- **大字号压缩**：展示字号的字间距渐进收紧——72px 下 -1.584px，64px 下 -1.408px，48px 下 -1.056px，32px 下 -0.704px。24px 以下，间距向 normal 放松。
- **OpenType 即身份**：`"cv01", "ss03"` 不是装饰——它们把 Inter 变成 Linear 独特的字体，赋予它更几何、更有目的感的性格。
- **三档字重体系**：400（阅读）、510（强调/UI）、590（强强调）。300 字重只出现在刻意弱化的上下文。

## 5. 布局原则

### 间距系统
- 基础单位：8px
- 刻度：1px、4px、7px、8px、11px、12px、16px、19px、20px、22px、24px、28px、32px、35px
- 7px 与 11px 值暗示光学对齐的微调
- 主节奏：8px、16px、24px、32px（标准 8px 网格）

### 网格与容器
- 最大内容宽度：约 1200px
- 首屏：居中单列，慷慨垂直内边距
- 特性区块：特性卡片的 2–3 列网格
- 全宽深色区块，内部最大宽度约束
- 更新日志：单列时间线布局

### 留白哲学
- **黑暗即空间**：在 Linear 的深色画布上，空位不是白色——是缺席。近黑背景就是留白，内容从中浮现。
- **标题压缩、周围展开**：72px -1.584px 字距的展示文字密集压缩，却坐在广阔的深色内边距中。排印密度与空间慷慨的对比制造张力。
- **区块隔离**：每个特性区块用慷慨的垂直内边距（80px+）分隔，无可见分隔线——深色背景提供天然分隔。

### 圆角刻度
- 微（2px）：内联徽章、工具栏按钮、微妙标签
- 标准（4px）：小容器、列表项
- 舒适（6px）：按钮、输入框、功能元素
- 卡片（8px）：卡片、下拉、弹出层
- 面板（12px）：面板、精选卡片、区块容器
- 大（22px）：大面板元素
- 全胶囊（9999px）：芯片、过滤胶囊、状态标签
- 圆形（50%）：图标按钮、头像、状态点

## 6. 纵深与阴影层级

| 层级（Level） | 处理（Treatment） | 用途（Use） |
|-------|-----------|-----|
| 扁平（0 级） | 无阴影，`#010102` 背景 | 页面背景，最深画布 |
| 微妙（1 级） | `rgba(0,0,0,0.03) 0px 1.2px 0px` | 工具栏按钮、微抬升 |
| 表面（2 级） | `rgba(255,255,255,0.05)` 背景 + `1px solid rgba(255,255,255,0.08)` 边框 | 卡片、输入框、容器 |
| 内嵌（2b 级） | `rgba(0,0,0,0.2) 0px 0px 12px 0px inset` | 下沉面板、内阴影 |
| 光环（3 级） | `rgba(0,0,0,0.2) 0px 0px 0px 1px` | 边框即阴影技法 |
| 抬升（4 级） | `rgba(0,0,0,0.4) 0px 2px 4px` | 浮动元素、下拉 |
| 对话框（5 级） | 多层栈：`rgba(0,0,0,0) 0px 8px 2px, rgba(0,0,0,0.01) 0px 5px 2px, rgba(0,0,0,0.04) 0px 3px 2px, rgba(0,0,0,0.07) 0px 1px 1px, rgba(0,0,0,0.08) 0px 0px 1px` | 弹出层、命令面板、模态 |
| 焦点 | `rgba(0,0,0,0.1) 0px 4px 12px` + 附加层 | 交互元素的键盘焦点 |

**阴影哲学**：在深色表面上，传统阴影（深上加深）几乎不可见。Linear 的解法是用半透明白边框作主要的纵深指示。抬升不通过阴影深浅传达，而通过背景亮度阶梯——每级略微提升表面背景的白色不透明度（`0.02` → `0.04` → `0.05`），形成微妙的堆叠效果。内嵌阴影技法（`rgba(0,0,0,0.2) 0px 0px 12px 0px inset`）为下沉面板制造独特的"凹陷"效果，增添传统深色主题缺乏的维度纵深。

## 7. 要做与不要做

### 要做
- 所有文字用 Inter Variable 配 `"cv01", "ss03"`——这些特性是 Linear 字体身份的根本
- 字重 510 作默认强调字重——它是 Linear 的标志性中间字重
- 展示字号用激进负字间距（72px 下 -1.584px，48px 下 -1.056px）
- 建在近黑背景上：营销用 `#08090a`，面板用 `#0f1011`，抬升表面用 `#191a1b`
- 用半透明白边框（`rgba(255,255,255,0.05)` 到 `rgba(255,255,255,0.08)`）而非纯深色边框
- 按钮背景保持近透明：`rgba(255,255,255,0.02)` 到 `rgba(255,255,255,0.05)`
- 品牌靛蓝（`#5e6ad2` / `#7170ff`）只留给主 CTA 与交互点缀
- 主文字用 `#f7f8f8`——不用纯 `#ffffff`，那会太刺眼
- 应用亮度堆叠模型：越深 = 背景越暗，抬升 = 背景略亮

### 不要做
- 主文字不要用纯白（`#ffffff`）——`#f7f8f8` 防止视觉疲劳
- 按钮不要用纯色背景——系统是透明的（白色 rgba 0.02–0.05）
- 品牌靛蓝不要作装饰——它只留给交互/CTA 元素
- 展示文字不要用正字间距——大字号的 Inter 永远是负的
- 深色背景上不要用可见/不透明边框——边框应该是耳语般纤细的半透明白
- 不要跳过 OpenType 特性（`"cv01", "ss03"`）——没有它们，就是普通 Inter，不是 Linear 的 Inter
- 不要用 700 字重（粗体）——Linear 的最大字重是 590，510 是主力
- UI 框架不要引入暖色——色板只有冷灰配蓝紫点缀
- 深色表面上不要用投影作抬升——用背景亮度阶梯代替

## 8. 响应式行为

### 断点
| 名称（Name） | 宽度（Width） | 关键变化（Key Changes） |
|------|-------|-------------|
| 小手机 | <600px | 单列，紧凑内边距 |
| 手机 | 600–640px | 标准移动布局 |
| 平板 | 640–768px | 2 列网格开始 |
| 小桌面 | 768–1024px | 完整卡片网格，展开内边距 |
| 桌面 | 1024–1280px | 标准桌面，完整导航 |
| 大桌面 | >1280px | 完整布局，慷慨边距 |

### 触控目标
- 按钮用舒适内边距，最小 6px 圆角
- 导航链接 13–14px，间距足够
- 胶囊标签 10px 横向内边距，触控友好
- 图标按钮 50% 圆角，保证圆形、易点的目标
- 搜索触发器位置显著，点击区慷慨

### 收起策略
- 首屏：72px → 48px → 32px 展示文字，字距按比例调整
- 导航：横排链接 + CTA → 768px 处收起为汉堡菜单
- 特性卡片：3 列 → 2 列 → 单列堆叠
- 产品截图：保持宽高比，可减小内边距
- 更新日志：全字号保持单列时间线
- 页脚：多列 → 堆叠单列
- 区块间距：80px+ → 移动端 48px

### 图片行为
- 仪表盘截图全字号保持边框处理
- 移动端首屏视觉简化（浮动 UI 元素减少）
- 产品截图响应式尺寸，圆角一致
- 深色背景保证截图在任何视口都自然融合

### 迭代指南
1. 所有 Inter 文字永远设 font-feature-settings `"cv01", "ss03"`——这是 Linear 观感不可妥协的部分
2. 字间距随字号缩放：72px 下 -1.584px，48px 下 -1.056px，32px 下 -0.704px，16px 以下 normal

7. 代码或技术内容用 Berkeley Mono，其他一律 Inter Variable
