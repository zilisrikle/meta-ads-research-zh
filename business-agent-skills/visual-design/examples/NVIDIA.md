# NVIDIA 风格设计系统

## 1. 视觉主题与氛围

NVIDIA 的网站是一个高对比度、技术导向的体验，通过设计的克制传达原始的算力。页面建立在纯黑（`#000000`）与纯白（`#ffffff`）的基础之上，以 NVIDIA 标志性的绿色（`#76b900`）点缀——这个颜色特殊到足以成为品牌指纹。这不是自然界的苍翠，而是 GPU 渲染光线般的电光感绿色，介于黄绿（chartreuse）与凯利绿（kelly green）之间，让任何科技行业的人一眼认出"NVIDIA"。

定制的 NVIDIA-EMEA 字体族（以 Arial 和 Helvetica 为回退）营造出干净、工业感的排印（Typography）语调。36px 加粗标题配 1.25 的紧行高，形成密集、权威的文本块。该字体没有硅谷无衬线字体的几何俏皮——它是欧洲的、务实的、工程导向的。正文为 15–16px，阅读舒适但不宽松，维持着屏幕空间如 GPU 显存般被优化的观感。

NVIDIA 的设计区别于其他深色背景科技网站之处，在于对绿色点缀的克制使用。`#76b900` 出现在边框（`2px solid #76b900`）、链接下划线（`underline 2px rgb(118, 185, 0)`）和 CTA 中——但在主内容中永不作为背景或大面积表面。绿色是信号，而非表面。配上深邃的阴影系统（`rgba(0, 0, 0, 0.3) 0px 0px 5px`）和极小的圆角（1–2px），整体效果如同一件精密工程硬件被渲染成像素。

**关键特征：**
- NVIDIA 绿（`#76b900`）作为纯点缀——仅用于边框、下划线与交互高光
- 以黑（`#000000`）为主导背景，深色版块配白（`#ffffff`）文字
- NVIDIA-EMEA 定制字体，Arial/Helvetica 回退——工业感、欧洲、干净
- 紧行高（标题 1.25），形成密集、权威的文本块
- 极小的圆角（1–2px）——全站锐利的工程化棱角
- 绿边框按钮（`2px solid #76b900`）作为主要交互模式
- Font Awesome 6 Pro/Sharp 图标系统，字重 900，图标锐利
- 多框架架构（PrimeReact、Fluent UI、Element Plus），支撑丰富的交互组件

- **聚焦环**（`#000000 solid 2px`）：键盘聚焦的黑色描边。

### 阴影与纵深
- **卡片阴影**（`rgba(0, 0, 0, 0.3) 0px 0px 5px 0px`）：抬高卡片的微妙环境阴影。

| 微文字 | NVIDIA-EMEA | 11px（0.69rem） | 700 | 1.00（紧） | normal | 最小 UI 文字 |

### 原则
- **加粗为默认语调**：NVIDIA 大量使用字重 700 于标题、按钮、链接与标签。400 字重保留给正文与描述——其余一律加粗，投射自信与权威。
- **标题紧、正文松**：标题行高统一 1.25（紧），正文则放宽到 1.50–1.67。这种对比在内容块顶部营造视觉密度，在段落中保证阅读舒适度。
- **导航全大写**：链接标签使用 `text-transform: uppercase` 配字重 700，导航语调如硬件规格标签。
- **无装饰性字距**：全文字距均为 normal，仅紧凑按钮例外（0.144px）。字体本身承载工业气质，无需修饰。

## 5. 布局原则

### 间距系统
- 基础单位：8px
- 尺度：1px、2px、3px、4px、5px、6px、7px、8px、9px、10px、11px、12px、13px、15px
- 主要内边距值：8px、11px、13px、16px、24px、32px
- 版块间距：48–80px 垂直内边距

### 网格与容器
- 最大内容宽度：约 1200px（收拢）
- 全宽主视觉版块配收拢文字
- 功能版块：产品卡片 2–3 列网格
- 文章/博客内容单列
- 文档侧边栏布局

### 留白（Whitespace）哲学
- **有目的的密度**：NVIDIA 的间距比典型 SaaS 网站更紧，呼应技术内容的密度。留白（Whitespace）用于分隔概念，而非营造奢侈的空旷感。
- **版块节奏**：深色版块与白色版块交替，以背景色（而不仅是间距）分隔内容块。
- **卡片密度**：产品卡片间距 16–20px 紧密排列，呈现目录感而非画廊感。

### 圆角（Border Radius）尺度
- 微型（1px）：内联 span、微小元素
- 标准（2px）：按钮、卡片、容器、输入框——几乎一切的默认
- 圆形（50%）：头像图片、圆形页签指示器

## 6. 纵深与层级

| 层级 | 处理 | 用途 |
|-------|-----------|-----|
| 平面（0 级） | 无阴影 | 页面背景、内联文字 |
| 微妙（1 级） | `rgba(0,0,0,0.3) 0px 0px 5px 0px` | 标准卡片、模态框 |
| 边框（1b 级） | `1px solid #5e5e5e` | 内容分割、版块边框 |
| 绿色点缀（2 级） | `2px solid #76b900` | 激活元素、CTA、选中项 |
| 聚焦（无障碍） | `2px solid #000000` 描边 | 键盘聚焦环 |

**阴影哲学**：NVIDIA 的纵深系统极简而实用。本质上只有一个阴影值——5px 环境模糊、不透明度 30%——谨慎地用于卡片与模态框。主要的纵深信号不是阴影而是*色彩对比*：白色版块旁的黑色背景、黑色表面上的绿色边框。这营造出硬件般的视觉分层：纵深来自材质差异，而非模拟光线。

### 装饰性纵深
- 主视觉内容后的绿色渐变渲染
- 版块过渡用深到更深的渐变（黑到近黑）
- 无玻璃拟态（glassmorphism）或模糊效果——清晰胜于氛围

## 7. 响应式行为

### 断点
| 名称 | 宽度 | 关键变化 |
|------|-------|-------------|
| 小手机 | <375px | 紧凑单列，内边距减小 |
| 手机 | 375–425px | 标准手机布局 |
| 大手机 | 425–600px | 更宽的手机布局，出现 2 列雏形 |
| 小平板 | 600–768px | 2 列网格开始 |
| 平板 | 768–1024px | 完整卡片网格，导航展开 |
| 桌面 | 1024–1350px | 标准桌面布局 |
| 大桌面 | >1350px | 最大内容宽度，充裕页边距 |

### 触控目标
- 按钮使用 11px 13px 内边距，保证舒适的点击目标
- 导航链接 14px 全大写，间距充足
- 深色背景上的绿边框按钮提供高对比点击目标
- 移动端：汉堡菜单折叠，全屏覆盖菜单

### 折叠策略
- 主视觉：36px 标题按比例缩小
- 导航：约 1024px 处完整横向导航折叠为汉堡菜单
- 产品卡片：3 列 → 2 列 → 单列堆叠
- 页脚：多列网格折叠为单列堆叠
- 版块间距：移动端 64–80px 缩至 32–48px
- 图片：保持宽高比，缩放到容器宽度

### 图片行为
- GPU/产品渲染图在所有尺寸保持高分辨率
- 主视觉图片按视口按比例缩放
- 卡片图片使用一致的宽高比
- 全幅深色版块保持边缘到边缘的处理

## 8. 响应式行为（扩展）

### 字体缩放
- 展示 36px 在移动端缩至约 24px
- 版块标题 24px 在移动端缩至约 20px
- 所有断点下正文保持 15–16px
- 按钮文字保持 16px，保证一致的点击目标

### 深浅版块策略
- 深色版块（黑底白字）与浅色版块（白底黑字）交替
- 两种表面上绿色点缀保持一致
- 深底：链接为白色，下划线为绿色
- 浅底：链接为黑色，下划线为绿色
- 这种交替营造自然的滚动节奏与内容分组
