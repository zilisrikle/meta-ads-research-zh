# Meta（商店）灵感设计系统

## 1. 视觉主题与氛围

Meta 商店是面向产品销售的零售体验，旨在销售硬件——Quest VR 头显、Ray-Ban Meta 智能眼镜及配件。设计在消费电子展厅与生活方式编辑感之间走钢丝：电影感的产品摄影铺陈在开阔的白色画布上，营造画廊般的向往感。每一个设计决策都服务于商品：慷慨的负空间把主视觉产品照框成博物馆藏品；深浅表面区块交替，创造视觉节奏，仿佛在实体零售店中穿行。

"Dolly" 设计系统（Meta 内部对商店层的命名）建立在更广泛的 FDS（Facebook 设计系统）基础之上，继承其灰阶与语义色板，同时叠加自有的产品导向色板。结果是一套鲜明的 Meta 风格系统——定制字体 Optimistic 为本可能冷峻的科技零售带来温暖与亲和——又足够灵活，能展示从 VR 头显到时尚眼镜的迥异产品线而不显割裂。表面策略是二元的：浏览与信息用纯白，沉浸式产品时刻用深邃暗色。

商店的视觉层级极度简洁。摄影承担重任，短促有力的标题用 Optimistic Medium 呈现，正文保持简短、可扫读。行动号召（CTA）为胶囊形，醒目无疑，永远是 Meta 蓝。没有视觉噪音，没有为装饰而装饰——每个元素要么卖货，要么导航。

**关键特征：**
- 摄影优先的零售设计：产品是视觉主角，而非 UI
- 二元表面策略：信息用纯白，沉浸式产品时刻用深暗
- 饱和蓝色的胶囊形 CTA，形成明确无误的行动点
- Optimistic VF 字体配 OpenType ss01/ss02 特性，带来几何暖意
- 慷慨的留白把产品框成画廊展品
- 8px 间距网格，纵向节奏严谨
- 深浅区块交替，形成"逛店式"的零售节奏

## 3. 排版规则

### 字体家族

**主字体：** Optimistic VF（Dalton Maag 为 Meta 定制的可变字体）
- 回退字体：Montserrat、Helvetica、Arial、Noto Sans
- OpenType 特性：`"ss01", "ss02"`——激活 Meta 专属替代字形的风格集
- 可变字体，连续字重轴（实测：300、400、500、700）

**次字体：** Helvetica
- 回退字体：Arial
- 用于小型工具文字（12px 页脚链接、法律文案）

### 层级

| 角色 | 字号 | 字重 | 行高 | 字间距 | 说明 |
|------|------|--------|-------------|----------|-------|
| 展示 1（Display 1） | 64px | 500（中等） | 1.16 | — | 桌面端主视觉标题，ss01+ss02 |
| 展示 2（Display 2） | 48px | 500（中等） | 1.17 | — | 区块主视觉、产品标题 |
| 标题 1（Heading 1） | 36px | 500（中等） | 1.28 | — | 主要区块标题 |
| 标题 2（Heading 2） | 28px | 300（细体） | 1.21 | — | 子标题，轻盈感 |
| 标题 3（Heading 3） | 18px | 700（粗体） | 1.44 | — | 卡片标题、粗体强调，ss01+ss02 |
| 正文（Body） | 18px | 400（常规） | 1.44 | — | 产品描述、正文 |
| 紧凑正文（Body Compact） | 16px | 500（中等） | 1.50 | -0.16px | 导航链接、UI 标签 |
| 粗体说明（Caption Bold） | 14px | 700（粗体） | 1.43 | — | 强调标签、价格文字 |
| 说明（Caption） | 14px | 400（常规） | 1.43 | -0.14px | 次级标签、元数据 |
| 小字（Small） | 12px | 400（常规） | 1.33 | — | 页脚链接、法律文字、时间戳 |
| 按钮（Button） | 14px | 400（常规） | 1.43 | -0.14px | 按钮标签文字 |

### 原则

Optimistic VF 是 Meta 排版身份的基石——一种人文主义无衬线字体，带着几何底蕴，在硅谷式的精密与消费级的温暖之间取得平衡。"ss01" 与 "ss02" 风格集引入替代字形，赋予标题独特的 Meta 气质。字重 500（中等）主导标题，营造不怒自威的存在感；而 28px 下出人意料地使用字重 300（细体），为子标题增添轻盈的编辑气质。小字号的负字间距（-0.14px 至 -0.16px）收紧 UI 元素的光学节奏，让阅读体验干脆高效。

## 4. 组件样式

### 按钮

**主按钮（胶囊）**
- 背景：Meta 蓝（`#0064E0`）
- 文字：白色（`#FFFFFF`）
- 边框：无
- 圆角：全胶囊（100px）
- 内边距：10px 22px
- 字体：Optimistic VF，14px，常规，-0.14px 字间距
- 悬停：加深至 `#0143B5`，scale(1.1) 变换
- 按下：`#004BB9`，scale(0.9)，不透明度 0.5
- 焦点：3px 强调色环形，outline auto 2px
- 过渡：背景 200ms ease，变换 150ms ease

**次按钮（描边胶囊）**
- 背景：透明
- 文字：深炭灰（`#1C2B33`），50% 不透明度
- 边框：2px solid `rgba(10, 19, 23, 0.12)`
- 圆角：全胶囊（100px）
- 内边距：10px 22px
- 悬停：背景变为 `rgba(70, 90, 105, 0.7)`，文字变白

**幽灵/链接按钮（Ghost/Link Button）**
- 背景：透明 / `rgba(255, 255, 255, 0)`
- 文字：链接蓝（`#385898`）
- 圆角：24px
- 内边距：4px 12px

**禁用态（Disabled）**
- 背景：`#DEE3E9`（--dolly-cta-disabled）
- 文字：`#8595A4`（--dolly-cta-disabled-text）
- 光标：not-allowed，无悬停效果

### 卡片与容器

- 背景：白色（`#FFFFFF`）或扁平灰（`#F7F8FA`）
- 圆角：标准卡片 20px（--card-corner-radius），产品特性卡片 24px
- 内边距：横向 10px，纵向 20px（--card-padding）
- 阴影：`0 12px 28px 0 rgba(0,0,0,0.2), 0 2px 4px 0 rgba(0,0,0,0.1)`（浮起卡片）
- 悬停：通过 translateY(-2px) 与阴影加深实现细微上浮
- 过渡：变换 300ms ease，盒阴影 300ms ease
- 产品卡片使用全出血图片，深色渐变上叠文字

### 输入框与表单

- 背景：白色（`#FFFFFF`）
- 边框：1px solid `#CED0D4`（--input-border-color）
- 圆角：8px
- 字体：Optimistic VF，16px
- 焦点：边框色变为强调蓝 `hsl(214, 89%, 52%)`，3px 外环
- 错误：边框与标签色 `hsl(350, 87%, 55%)`
- 占位符：`#65676B`（--secondary-text）
- 过渡：边框色 200ms ease，盒阴影 200ms ease

### 导航

- 背景：白色（`#FFFFFF`），顶部粘性定位
- 毛玻璃效果：`rgba(241, 244, 247, 0.8)` 配 backdrop-filter 模糊
- Logo：Meta 字标 SVG，左对齐
- 链接：Optimistic VF，16px/500，深炭灰（`#1C2B33`）
- 悬停：下划线装饰
- CTA：蓝色胶囊按钮，右对齐
- 移动端：汉堡折叠，全屏覆盖式导航
- 高度：桌面约 56px，移动端 48px
- 底部边框：细微的 `rgba(0,0,0,0.1)` 分隔线

### 图片处理

- 产品主视觉：全宽，电影感纵横比（桌面约 21:9，移动端约 4:3）
- 产品卡片：1:1 或 4:3，图片铺满至卡片圆角边缘
- 特性图片：圆角与卡片圆角一致（20-24px）
- 图片上深色文字：渐变遮罩 `linear-gradient(rgba(0,0,0,0), rgba(0,0,0,0.6))`
- 懒加载（Lazy Loading）：首屏以下图片使用原生 loading="lazy"
- WebP 格式，JPEG 回退

### 产品专属区块

- **Quest 区块**：深色背景（`#181A1B` 或 `#000000`），白色/浅色文字，紫色强调（`#A121CE`）
- **Ray-Ban 区块**：暖调生活方式摄影，红色强调（`#D6311F`），亚麻色调（`#F2F0E6`）
- **Portal 区块**：蓝绿色调（`#C8E4E8`、`#ADD4E0`），海军蓝强调（`#1B365D`）

### 网格与容器

- 容器最大宽度：约 1440px，居中，外边距 auto
- 产品网格：桌面 3 列，平板 2 列，手机 1 列
- 特性网格：2 列分栏（图片 + 内容），移动端堆叠
- 网格间隙：卡片之间 24px，移动端 16px
- 页面横向内边距：24-40px，视断点而定

### 留白哲学

留白是商店首要的奢侈信号。区块以 64-80px 的纵向内边距呼吸，营造从容的浏览感。产品图片悬浮在慷慨的负空间中，而非被挤到边缘。这种克制的间距传递高端定位——视觉上相当于高端零售店宽敞的过道。

### 圆角（border-radius）阶梯

| 值 | 场景 |
|-------|---------|
| 8px | 输入框、小 UI 元素、闪光占位符 |

| 24px | 特性卡片、产品高光区、幽灵按钮 |

## 6. 深度与层级

| 层级 | 处理 | 用途 |
|-------|-----------|-----|
| 扁平（Flat） | 无阴影，仅靠背景区分 | 默认卡片、区块 |
| 1 级（Level 1） | `0 2px 4px 0 rgba(0,0,0,0.1)` | 交互卡片的细微上浮 |
| 2 级（Level 2） | `0 12px 28px 0 rgba(0,0,0,0.2), 0 2px 4px 0 rgba(0,0,0,0.1)` | 浮起卡片、下拉菜单 |
| 遮罩（Overlay） | `rgba(0,0,0,0.6)` 全屏 | 弹窗/灯箱背景 |
| 内嵌（Inset） | `rgba(255,255,255,0.5)` 内阴影 | 玻璃效果表面的内发光 |

Meta 商店偏好以扁平为主的层级模型。表面区分大多来自背景色变化（白 → 柔灰 → 深色），而非阴影。阴影出现时柔和扩散，采用双阴影模式（大面积模糊阴影模拟环境光 + 小面积锐利阴影模拟直射光）。这营造出物理可信的深度感，又不增加视觉重量。

### 装饰性深度

- **毛玻璃导航**：`rgba(241, 244, 247, 0.8)` 背景配 backdrop-filter 模糊，形成半透明导航栏
- **深色区块渐变**：产品摄影上的 `linear-gradient(rgba(0,0,0,0), rgba(0,0,0,0.6))` 叠加，保证文字可读性
- **闪光加载态**：`#979A9F` 底色上的脉动不透明度动画（0.25 → 1.0），8px 圆角，1000ms steps 时序——产品图片加载时的骨架屏（skeleton）使用

## 7. 要做与不做

### 要做（Do）

- 所有主次 CTA 都用胶囊形（100px 圆角）按钮
- 让产品摄影主导——每块区域都把图片作为视觉主角
- 深浅表面区块交替，创造视觉节奏
- 所有展示文字用带 ss01 与 ss02 特性的 Optimistic VF
- 正文保持简短可扫读——这是零售，不是编辑
- 需要层级时使用双阴影模式（环境光 + 直射光）
- Meta 蓝（`#0064E0`）只用于可操作元素
- 用慷慨的留白（64-80px 区块内边距）传递高端感
- 图片上放文字时，在深色摄影上加渐变遮罩
- 语义色板（成功、错误、警示）用于状态传达时保持一致

### 不做（Don't）

- 不要用尖角（< 8px 圆角）——Meta 商店全是平滑曲线
- 不要混用产品专属强调色（同一区块不用雷朋红配 Quest 紫）
- 不要加装饰性边框或纹饰分隔线——分隔线只做功能性使用
- 图片上放重要文字时不要没有渐变罩
- 字重 300 不用于小于 28px 的文字——会细到看不清
- 不要用 Facebook 蓝（`#1877F2`）做主 CTA 颜色——用 Meta 蓝（`#0064E0`）
- 不要把产品图片挤得太满——所有摄影周围保持慷慨的内边距
- 单张卡片不要用超过 2 级文字层级
- 深色区块的卡片不要加投影——靠边框与颜色分离
- 不要用长段落——每块正文限制 2-3 行

## 8. 响应式行为

### 断点（Breakpoints）

| 名称 | 宽度 | 关键变化 |
|------|-------|-------------|
| 手机（Mobile） | <768px | 单列，汉堡导航，主视觉文字缩小至 36px，全宽产品卡片，48px 区块内边距 |
| 平板（Tablet） | 768-1024px | 2 列产品网格，紧凑导航，主视觉文字 48px |
| 桌面（Desktop） | 1024-1440px | 3 列产品网格，完整横向导航，主视觉文字 64px，80px 区块内边距 |
| 大桌面（Large Desktop） | >1440px | 最大宽度容器（1440px）居中，横向外边距加大 |

### 触控目标（Touch Targets）

- 最小触控目标：44x44px（符合 WCAG AAA）
- 移动端按钮高度：最小 44px，纵向内边距 10px
- 导航汉堡图标：48x48px 触控区
- 产品卡片可点区域：整张卡片表面

### 折叠策略

- **导航**：768px 以下横向链接折叠为汉堡菜单；CTA 按钮保持可见
- **产品网格**：1024px 处 3 列 → 2 列，768px 处 → 1 列
- **主视觉区块**：展示文字 64px → 48px → 36px 缩放；移动端 CTA 按钮纵向堆叠
- **特性区块**：2 列（图片 + 文字）→ 768px 以下全宽堆叠，图片在上
- **区块内边距**：视口收窄时 80px → 64px → 48px → 32px
- **卡片圆角**：所有断点保持 20-24px 一致

### 图片行为

- 响应式图片通过 srcset 提供多分辨率
- WebP 格式，渐进式 JPEG 回退
- 主视觉图片：移动端全出血，桌面端收纳
- 产品网格图片：保持纵横比，等比缩放
- 艺术指导：主视觉裁剪在桌面（宽电影感）与移动端（更紧的产品特写）之间变化
- 懒加载配闪光骨架屏（脉动灰色占位符）
