# 示例索引

每个文件都是一套以真实品牌为蓝本的详细设计系统——色板、排印（Typography）、组件、纵深、布局规则与可直接用于提示词的片段。三种用法：

1. **`DESIGN.md` 格式与深度的参考**——看一套完整设计系统如何成文。
2. **模式来源**——借用色彩策略、字体层级、阴影系统。
3. **起点**——如果下方某个品牌的调性接近目标，直接改编而非从零开始。

先扫一遍本索引，找到 1–2 个调性相符的示例，再读其完整文件。

## 按调性快速查找

### 极简、高端、产品即主角
- [Apple](Apple.md)——电影感黑/浅灰节奏、单一蓝色点缀、纯色底上的产品摄影。以极简致敬产品本体的减法美学。
- [Tesla](Tesla.md)——克制、全幅的汽车极简。以空旷表达自信。
- [Nike](Nike.md)——大胆的运动极简，超大字体，动感摄影。
- [Bugatti](Bugatti.md)——超豪华汽车，深色电影感，克制的镀铬点缀。
- [Ferrari](Ferrari.md)——意大利传承，标志性红，雕塑感产品处理。
- [BMW](BMW.md)——工程精度，结构化排印，干净几何网格。

### 温暖、编辑感、人文

- [Airbnb](Airbnb.md)——友好、摄影感、处处圆角。好客的温暖。
- [Starbucks](Starbucks.md)——咖啡馆温暖，深绿传承，生活方式影像。

- [Notion](Notion.md)——安静、文档感，充裕留白（Whitespace），色彩克制。
- [WIRED](WIRED.md)——杂志编辑感，强烈的衬线/无衬线对比，自信的科技新闻。

## 如何选择

- **先匹配媒介**——给企业受众的幻灯片从 Stripe / HashiCorp / Notion 取材，而非 PlayStation。
- **再匹配能量**——高端安静（Apple/Notion）、温暖编辑（Claude/WIRED）、开发者精准（Vercel/Linear）、大胆表现（PlayStation/Spotify）。
- **然后改编**——永不 1:1 复制。用 1–2 个示例做调性锚点，再合成。
