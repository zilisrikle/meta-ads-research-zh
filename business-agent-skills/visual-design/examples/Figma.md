# Figma 灵感设计系统

## 1. 视觉主题与氛围

Figma 的界面是设计了自己的设计工具——一堂排印精妙的大师课：定制可变字体（variable font）figmaSans 的字重（font weight）在极细的 320 与粗体 700 之间调节，中间还有大多数字体系统从未探索过的非常规字重档（330、340、450、480、540）。这种精细的字重控制让每个文本元素都拥有精确校准的视觉分量，通过微差而非"常规 vs 粗体"的钝器建立层级。

该页面呈现出一种迷人的二元性：界面框架（chrome）严格黑白（实际检测到的颜色只有 `#000000` 和 `#ffffff`），而首屏区块（hero section）与产品展示却爆发出活力多彩的渐变——电光绿、亮黄、深紫、热粉。这意味着设计系统本身是无色的，它把产品的彩色输出当作主角内容。Figma 的营销页本质上是一面白色画廊墙，上面挂着彩色艺术品。

让 Figma 与众不同的，除了可变字体，还有它的圆形与胶囊几何：按钮用 50px 圆角（胶囊）或 50%（图标按钮的正圆），营造出有机、工具调色板般的手感。虚线轮廓的焦点指示（`dashed 2px`）是刻意的设计选择，呼应 Figma 编辑器自身的选区手柄——网站的 UI 语言在引用产品的 UI 语言。

**关键特征：**
- 定制可变字体 figmaSans，字重档非常规：320、330、340、450、480、540、700
- 界面框架严格黑白——颜色只存在于产品内容中
- figmaMono 大写技术标签，字间距宽
- 胶囊（50px）与圆形（50%）按钮几何
- 虚线焦点轮廓，呼应 Figma 编辑器的选区手柄
- 活力多彩的首屏渐变（绿、黄、紫、粉）
- OpenType `"kern"` 特性全局启用
- 通篇负字间距——连正文都在 -0.14px 到 -0.26px

## 2. 色板与角色

### 主色
- **纯黑（Pure Black）** (`#000000`)：所有文字、所有纯色按钮、所有边框。界面唯一的"颜色"。
- **纯白（Pure White）** (`#ffffff`)：所有背景、白色按钮、深色表面上的文字。二元中的另一半。

*注：Figma 营销站点的界面层只使用这两种颜色。所有活力色彩只出现在产品截图、首屏渐变与嵌入内容中。*

### 表面与背景
- **纯白（Pure White）** (`#ffffff`)：主页面背景与卡片表面。
- **玻璃黑（Glass Black）** (`rgba(0, 0, 0, 0.08)`)：次级圆形按钮与玻璃效果的微妙深色叠加。
- **玻璃白（Glass White）** (`rgba(255, 255, 255, 0.16)`)：深色/彩色表面上按钮的磨砂玻璃叠加。

### 渐变体系
- **首屏渐变（Hero Gradient）**：电光绿、亮黄、深紫、热粉组成的多断点（multi-stop）活力渐变。这是首屏区块的视觉签名——代表该工具的创意可能性。
- **产品区块渐变（Product Section Gradients）**：各产品区（设计、开发模式、原型）在展示中可能使用各自的色彩主题。

## 3. 排印规则

### 字体家族
- **主字体**：`figmaSans`，回退：`figmaSans Fallback, SF Pro Display, system-ui, helvetica`
- **等宽 / 标签**：`figmaMono`，回退：`figmaMono Fallback, SF Mono, menlo`

### 层级

| 角色（Role） | 字体（Font） | 字号（Size） | 字重（Weight） | 行高（Line Height） | 字间距（Letter Spacing） | 说明（Notes） |
|------|------|------|--------|-------------|----------------|-------|
| 展示 / 首屏 | figmaSans | 86px (5.38rem) | 400 | 1.00（紧） | -1.72px | 最大冲击，极端字距（tracking） |
| 区块标题 | figmaSans | 64px (4rem) | 400 | 1.10（紧） | -0.96px | 特性区块标题 |
| 副标题 | figmaSans | 26px (1.63rem) | 540 | 1.35 | -0.26px | 强调的区块文字 |
| 轻副标题 | figmaSans | 26px (1.63rem) | 340 | 1.35 | -0.26px | 轻字重的区块文字 |
| 特性标题 | figmaSans | 24px (1.5rem) | 700 | 1.45 | normal | 粗体卡片标题 |
| 正文大 | figmaSans | 20px (1.25rem) | 330–450 | 1.30–1.40 | -0.1px 到 -0.14px | 描述、导语 |
| 正文 / 按钮 | figmaSans | 16px (1rem) | 330–400 | 1.40–1.45 | -0.14px 到 normal | 标准正文、导航、按钮 |
| 轻正文 | figmaSans | 18px (1.13rem) | 320 | 1.45 | -0.26px 到 normal | 轻字重正文 |
| 等宽标签 | figmaMono | 18px (1.13rem) | 400 | 1.30（紧） | 0.54px | 大写区块标签 |
| 等宽小 | figmaMono | 12px (0.75rem) | 400 | 1.00（紧） | 0.6px | 大写微标签 |

### 原则
- **可变字体的精度**：figmaSans 使用大多数系统从未触及的字重——320、330、340、450、480、540。这通过微妙的字重差异而非戏剧性跳跃建立层级。330 与 340 的差异几乎不可察觉，但结构意义重大。
- **轻即基础**：大多数正文用 320–340（比典型的 400"常规"更轻），营造空灵、透气的阅读体验，与设计工具的美学相配。
- **处处字距调整（kerning）**：每个文本元素都启用 OpenType `"kern"` 特性——字距调整不是可选项，而是结构性的。
- **默认负字距**：连正文都用 -0.1px 到 -0.26px 的字间距（letter-spacing），形成普遍紧凑的文字。展示文字进一步压缩到 -0.96px 与 -1.72px。
- **等宽字作结构**：figmaMono 大写、配合正字间距（0.54px–0.6px），形成技术路标式标签。

## 4. 组件样式

### 按钮

**黑实色胶囊（Black Solid (Pill)）**
- 背景：纯黑（`#000000`）
- 文字：纯白（`#ffffff`）
- 圆角：图标按钮用圆形（50%）
- 焦点：虚线 2px 轮廓
- 强调级别最高

**白胶囊（White Pill）**
- 背景：纯白（`#ffffff`）
- 文字：纯黑（`#000000`）
- 内边距（padding）：8px 18px 10px（垂直不对称）
- 圆角（border-radius）：胶囊（50px）
- 焦点：虚线 2px 轮廓
- 深色/彩色表面上的标准 CTA

**深玻璃（Glass Dark）**
- 背景：`rgba(0, 0, 0, 0.08)`（微妙深色叠加）
- 文字：纯黑
- 圆角：圆形（50%）
- 焦点：虚线 2px 轮廓
- 浅色表面上的次级操作

**浅玻璃（Glass Light）**
- 背景：`rgba(255, 255, 255, 0.16)`（磨砂玻璃）
- 文字：纯白
- 圆角：圆形（50%）
- 焦点：虚线 2px 轮廓
- 深色/彩色表面上的次级操作

### 卡片与容器
- 背景：纯白
- 边框：无或极简
- 圆角：6px（小容器）、8px（图片、卡片、对话框）
- 阴影：微妙到中等的抬升效果
- 卡片内容为产品截图

### 导航
- 白色上的干净横排导航
- 标志：黑色的 Figma 文字标识
- 产品标签页：胶囊形（50px）标签导航
- 链接：黑色文字，1px 下划线装饰
- CTA：黑色胶囊按钮
- 悬停：文字颜色经由 CSS 变量

### 特色组件

**产品标签栏（Product Tab Bar）**
- 横排胶囊形标签（50px 圆角）
- 每个标签代表一个 Figma 产品区（设计、开发模式、原型等）
- 当前标签高亮

**首屏渐变区块（Hero Gradient Section）**
- 全宽活力多彩渐变背景
- 白色文字叠加，86px 展示标题
- 产品截图漂浮在渐变中

**虚线焦点指示（Dashed Focus Indicators）**
- 所有交互元素在焦点状态用 `dashed 2px` 轮廓
- 引用 Figma 编辑器中的选区手柄
- 连接网站与产品的元设计（meta-design）选择

## 5. 布局原则

### 间距系统
- 基础单位：8px
- 刻度：1px、2px、4px、4.5px、8px、10px、12px、16px、18px、24px、32px、40px、46px、48px、50px

### 网格与容器
- 最大容器宽度：可达 1920px
- 首屏：全宽渐变，内容居中
- 产品区块：交替展示
- 页脚：深色全宽区块
- 响应式范围 559px 到 1920px

### 留白哲学
- **画廊式节奏**：慷慨的间距让每个产品区块像独立展品一样呼吸。
- **彩色区块作为视觉呼吸**：渐变首屏与产品展示在单色界面区块之间提供色彩上的舒缓。

### 圆角刻度
- 极小（2px）：小链接元素
- 微妙（6px）：小容器、分隔线
- 舒适（8px）：卡片、图片、对话框
- 胶囊（50px）：标签按钮、CTA
- 圆形（50%）：图标按钮、圆形元素

## 6. 纵深与阴影层级

| 层级（Level） | 处理（Treatment） | 用途（Use） |
|-------|-----------|-----|
| 扁平（0 级） | 无阴影 | 页面背景、多数文字 |
| 表面（1 级） | 渐变/深色区块上的白卡片 | 卡片、产品展示 |
| 抬升（2 级） | 微妙阴影 | 浮动卡片、悬停状态 |

**阴影哲学**：Figma 很少用阴影。主要的纵深机制是**背景对比**（彩色/深色区块上的白色内容）与产品截图本身固有的维度感。

## 7. 要做与不要做

### 要做
- 用 figmaSans 的精确可变字重（320–540）——精细的字重控制就是设计本身
- 界面严格黑白——颜色只来自产品内容
- 所有交互元素用胶囊（50px）与圆形（50%）几何
- 应用虚线 2px 焦点轮廓——标志性的无障碍模式
- 所有文字启用 `"kern"` 特性
- 标签用 figmaMono 大写、配合正字间距
- 通篇应用负字间距（-0.1px 到 -1.72px）

### 不要做
- 不要加界面颜色——单色色板是绝对的
- 不要用标准字重（400、500、600、700）——用可变字体的独特档位（320、330、340、450、480、540）
- 按钮不要用尖角——只用胶囊与圆形几何
- 不要用实线焦点轮廓——虚线是签名
- 正文不要加粗到 450 以上——轻字重美学是核心
- 正文不要用正字间距——永远是负的

## 8. 响应式行为

### 断点
| 名称（Name） | 宽度（Width） | 关键变化（Key Changes） |
|------|-------|-------------|
| 小手机 | <560px | 紧凑布局，堆叠 |
| 平板 | 560–768px | 微调 |
| 小桌面 | 768–960px | 2 列布局 |
| 桌面 | 960–1280px | 标准布局 |
| 大桌面 | 1280–1440px | 展开 |
| 超宽 | 1440–1920px | 最大宽度 |

### 收起策略
- 首屏文字：86px → 64px → 48px
- 产品标签页：移动端横向滚动
- 特性区块：堆叠单列
- 页脚：多列 → 堆叠

## 9. Agent 提示词指南

### 快速色彩参考
- 一切：纯黑（`#000000`）与纯白（`#ffffff`）
- 深玻璃：`rgba(0, 0, 0, 0.08)`
- 浅玻璃：`rgba(255, 255, 255, 0.16)`

### 示例组件提示词
- 「在活力多彩渐变（绿、黄、紫、粉）上创建首屏。标题 86px figmaSans 字重 400，行高（line-height）1.0，字间距 -1.72px，白色文字。白色胶囊 CTA 按钮（50px 圆角，8px 18px 内边距）。」
- 「设计产品标签栏，胶囊形按钮（50px 圆角）。当前态：黑底白字。非当前态：透明，黑字。20px figmaSans 字重 480。」
- 「构建区块标签：figmaMono 18px，大写，字间距 0.54px，黑色文字。字距调整启用。」
- 「正文 20px figmaSans 字重 330，行高 1.40，字间距 -0.14px。白底纯黑。」

### 迭代指南
1. 精确使用可变字重档位：320、330、340、450、480、540、700
2. 界面永远是黑 + 白——绝不给界面框架加颜色
3. 虚线焦点轮廓，不用实线
4. 正文字间距永远为负，等宽标签永远为正
5. 按钮/标签用胶囊（50px），图标按钮用圆形（50%）
