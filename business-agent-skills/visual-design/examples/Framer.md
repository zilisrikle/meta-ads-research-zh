# Framer 灵感设计系统

## 1. 视觉主题与氛围

Framer 的网站是一块电影感、工具至上的深色画布，散发着设计工具特有的自信——出自崇尚工艺的设计师之手。整个体验浸没在纯黑中——不是暖炭色或舒适的深灰，而是绝对虚空（`#000000`），让每个元素、每张截图、每个排印细节都像漂浮在深空中。这是一个把自家产品 UI 当作主角艺术的网站，将全保真截图与交互演示直接嵌入叙事流中。

排印是签名动作：GT Walsheim 配合极端的负字间距（letter-spacing）（110px 展示文字下达 -5.5px），标题感觉被压缩、动感、几乎像上了发条——像处于压力下随时可能膨胀的词语。过渡到正文的 Inter 无缝衔接，大量使用 OpenType 特性（`cv01`、`cv05`、`cv09`、`cv11`、`ss03`、`ss07`），连小字都有精致的定制感。Framer 蓝（Framer Blue）(`#0099ff`) 部署得克制而果断——作为链接色、边框点缀与微妙的光环阴影——在无暖调的黑上形成一条冰冷、电光的贯穿线。

整体效果是给网页设计师的夜总会：黑暗、精确、性感、毫不避讳地产品优先。每个区块都为展示工具能力而存在，网站本身就是概念验证。

**关键特征：**
- 纯黑（`#000000`）虚空画布——绝对的黑，不是暖黑也不是灰调黑
- GT Walsheim 展示字体，极端负字间距（110px 下 -5.5px）
- Framer 蓝（`#0099ff`）是唯一的点缀色——冰冷、电光、精确
- 胶囊形按钮（40px–100px 圆角（border-radius））——交互元素没有尖角
- 产品截图即主角艺术——工具本身就是营销
- 深色表面上的磨砂玻璃按钮变体，用 `rgba(255, 255, 255, 0.1)`
- Inter 全面使用丰富的 OpenType 特性，微排印精致

## 2. 色板与角色

### 主色
- **纯黑（Pure Black）** (`#000000`)：主背景，定义 Framer 深色优先身份的虚空画布
- **纯白（Pure White）** (`#ffffff`)：深色表面上的主文字色，点缀背景上的按钮文字
- **Framer 蓝（Framer Blue）** (`#0099ff`)：主点缀色——链接、边框、光环阴影、交互高亮

### 次级与点缀色
- **哑银（Muted Silver）** (`#a6a6a6`)：深色表面上的次级文字、柔和标签、弱化的描述
- **近黑（Near Black）** (`#090909`)：抬升的深色表面，微妙纵深分隔的阴影环颜色

### 表面与背景
- **空黑（Void Black）** (`#000000`)：页面背景，主画布
- **霜白（Frosted White）** (`rgba(255, 255, 255, 0.1)`)：深色上的半透明按钮背景、玻璃效果表面
- **微白（Subtle White）** (`rgba(255, 255, 255, 0.5)`)：悬停状态下稍不透明的磨砂元素

### 中性色与文字
- **纯白（Pure White）** (`#ffffff`)：标题文字、高强调正文
- **哑银（Muted Silver）** (`#a6a6a6`)：正文、描述、次级信息
- **幽白（Ghost White）** (`rgba(255, 255, 255, 0.6)`)：三级文字、深色表面上的占位符

### 语义与点缀色
- **Framer 蓝（Framer Blue）** (`#0099ff`)：链接、交互边框、焦点环
- **蓝辉光（Blue Glow）** (`rgba(0, 153, 255, 0.15)`)：焦点环阴影，交互元素周围的微妙蓝色光晕
- **默认链接蓝（Default Link Blue）** (`#0000ee`)：标准浏览器链接色（内容区偶尔使用）

### 渐变体系
- 没有显著的渐变使用——Framer 依赖纯平黑表面，偶尔用极低透明度的蓝调辉光营造纵深
- 产品截图背后有极低透明度的 Framer 蓝微妙径向辉光效果

## 3. 排印规则

### 字体家族
- **展示**：`GT Walsheim Framer Medium` / `GT Walsheim Medium`——定制几何无衬线，字重（font weight）500。回退：`GT Walsheim Framer Medium Placeholder`、系统无衬线
- **正文/UI**：`Inter Variable` / `Inter`——可变无衬线，大量使用 OpenType 特性。回退：`Inter Placeholder`、`-apple-system`、`system-ui`
- **点缀**：`Mona Sans`——GitHub 开源字体，用于部分元素的极细字重（100）
- **等宽**：`Azeret Mono`——代码与技术标签的等宽伴侣
- **圆体**：`Open Runde`——微标签的小圆体伴侣字体

### 原则
- **压缩即个性**：GT Walsheim 的极端负字间距（110px 下 -5.5px）是定义性的排印手势——标题像上了发条、紧迫、几乎屏住呼吸
- **OpenType 极繁主义**：Inter 同时部署 6+ 个 OpenType 特性（`cv01`、`cv05`、`cv09`、`cv11`、`ss03`、`ss07`），连正文字号都有微妙的定制感
- **展示字重的克制**：所有 GT Walsheim 用法都是字重 500（中等）——从不用粗体，也不用常规。这营造出自信但不咄咄逼人的展示语气
- **超紧行高（line-height）**：0.85 行高的展示文字意味着字母在垂直方向几乎重叠——刻意的密度，适合在臂展距离阅读

## 4. 组件样式

### 按钮
- **霜面胶囊（Frosted Pill）**：`rgba(255, 255, 255, 0.1)` 背景，黑字（`#000000`），胶囊形（40px 圆角）。生活在深色表面上的玻璃效果按钮——半透明、环境感、微妙
- **纯白实色胶囊（Solid White Pill）**：`rgb(255, 255, 255)` 背景，黑字（`#000000`），完整胶囊形（100px 圆角），内边距（padding）`10px 15px`。主 CTA——深色上干净、高对比、无法错过
- **幽灵（Ghost）**：无可见背景，白字，只靠文字造型。悬停时显现微妙的霜面背景
- **过渡（Transition）**：基于缩放的动画（矩阵变换，0.85 缩放系数），显现效果的不透明度过渡

### 卡片与容器
- **深表面卡片（Dark Surface Card）**：黑或近黑（`#090909`）背景，`rgba(0, 153, 255, 0.15) 0px 0px 0px 1px` 蓝色光环阴影边框，圆角（10px–15px 圆角）
- **抬升卡片（Elevated Card）**：多层阴影——`rgba(255, 255, 255, 0.1) 0px 0.5px 0px 0.5px`（微妙顶部高光）+ `rgba(0, 0, 0, 0.25) 0px 10px 30px`（深色环境阴影）
- **产品截图（Product Screenshots）**：深色容器内全宽或带内边距，软件 UI 预览用 8px–12px 圆角
- **悬停（Hover）**：Framer 蓝光环阴影的微妙辉光增强，或霜面表面的亮度变化

### 输入框与表单
- 营销站点的表单存在感极简
- 输入框遵循深色主题：深色背景、微妙边框、白色文字
- 焦点状态：Framer 蓝（`#0099ff`）光环边框，`1px solid #0099ff`
- 占位符文字用 `rgba(255, 255, 255, 0.4)`

### 导航
- **深色浮动导航栏**：黑色背景配磨砂玻璃效果，白色文字链接
- **导航链接**：15px Inter，字重 400，白色文字，悬停微妙透明度变化
- **CTA 按钮**：胶囊形，白色或霜面，位于导航右端
- **移动端**：收起为汉堡菜单，保持深色主题
- **吸顶行为**：滚动时导航固定在顶部

### 图片处理
- **产品截图即主角艺术**：全宽嵌入的 UI 截图，圆角（8px–12px）
- **深上加深的构图**：截图置于黑色背景上，用微妙阴影分隔纵深
- **16:9 与自定义宽高比**：产品演示填满容器
- **无装饰性图像**：所有图片都是功能性的——展示工具、输出或工作流

### 信任与社会证明
- 深色表面上的客户标志与评价用弱化灰
- 装饰极简——产品截图本身就是信任信号

## 5. 布局原则

### 间距系统
- **基础单位**：8px
- **刻度**：1px、2px、3px、4px、5px、6px、8px、10px、12px、15px、20px、30px、35px
- **区块内边距**：区块间大垂直间距（80px–120px）
- **卡片内边距**：15px–30px 内部内边距
- **组件间距**：相关元素间 8px–20px

### 网格与容器
- **最大宽度**：~1200px 容器，居中
- **列模式**：全宽首屏、2 列特性区块、单列产品展示
- **非对称布局**：特性区块常把文字（40%）与截图（60%）配对

### 留白哲学
- **在黑暗中呼吸**：区块间慷慨的垂直间距——黑色背景意味着留白表现为虚空，在内容块之间形成戏剧性的停顿
- **内部紧密、之间宽松**：单个组件构图紧凑（紧行高、压缩文字），但漂浮在慷慨的周围空间中
- **产品优先的密度**：截图区允许密集、信息丰富，与稀疏的营销文字形成对比

### 圆角刻度
- **1px**：微元素，近乎方形的精确边缘
- **5px–7px**：小 UI 元素、图片缩略图——微妙柔化
- **8px**：标准组件圆角——代码块、按钮、交互元素
- **10px–12px**：卡片、产品截图——舒适的圆角
- **15px–20px**：大容器、特性卡片——慷慨的圆角
- **30px–40px**：导航胶囊、分页——明显的圆角
- **100px**：完整胶囊形——主 CTA、标签元素

## 6. 纵深与阴影层级

| 层级（Level） | 处理（Treatment） | 用途（Use） |
|-------|-----------|-----|
| 0 级（扁平） | 无阴影，纯黑表面 | 页面背景、空区 |
| 1 级（光环） | `rgba(0, 153, 255, 0.15) 0px 0px 0px 1px` | 卡片边框、交互元素轮廓——Framer 蓝辉光环 |
| 2 级（收纳） | `rgb(9, 9, 9) 0px 0px 0px 2px` | 深色表面上微妙收纳的近黑环 |
| 3 级（浮动） | `rgba(255, 255, 255, 0.1) 0px 0.5px 0px 0.5px, rgba(0, 0, 0, 0.25) 0px 10px 30px` | 抬升卡片、浮动元素——微妙白色顶边高光 + 深色环境阴影 |

### 阴影哲学
Framer 的抬升体系与传统浅色主题设计相反。Framer 不用深色背景上的深阴影，而是：
- 极低透明度（0.15）的**蓝调光环阴影**作收纳——标志性手法，给每个带边框元素微妙地打上品牌
- 抬升元素顶边的**白色边缘高光**（0.5px）——模拟光线打在顶面
- 真正浮动元素的**深色环境阴影**——大扩散（30px）的 `rgba(0, 0, 0, 0.25)`

### 装饰性纵深
- **蓝辉光晕**：关键交互区背后微妙的 Framer 蓝（`#0099ff`）径向渐变
- **无背景模糊/玻璃拟态**：尽管有霜面按钮效果，但没有重度玻璃模糊——半透明通过简单的 rgba 不透明度实现

## 7. 要做与不要做

### 要做
- 主背景用纯黑（`#000000`）——不是深灰，不是炭色
- GT Walsheim 展示文字用极端负字间距（-3px 到 -5.5px）
- 所有按钮保持胶囊形（40px+ 圆角）——绝不用方形或微圆按钮
- Framer 蓝（`#0099ff`）只用于交互点缀——链接、边框、焦点状态
- 深色背景上的磨砂玻璃表面用 `rgba(255, 255, 255, 0.1)`
- GT Walsheim 只用字重 500——中等字重就是品牌
- Inter 文字用丰富的 OpenType 特性（cv01、cv05、cv09、cv11、ss03、ss07）
- 让产品截图成为视觉中心——工具自己营销自己
- 卡片收纳用蓝色光环阴影（`rgba(0, 153, 255, 0.15) 0px 0px 0px 1px`）

### 不要做
- 不要用暖调深背景（不用 `#1a1a1a`、`#2d2d2d` 或棕黑）
- GT Walsheim 展示文字不要加粗（700+）——只用中等 500
- Framer 蓝之外不要引入其他点缀色——这是单点缀色系统
- 非交互元素不要用大圆角（卡片用 10px–15px，只有按钮用 40px+）
- 不要加装饰性图像、插画或图标——产品就是插画
- 标题不要用正字间距——一切都被压缩、负字距
- 不要做重投影——纵深通过微妙的光环与极简环境阴影传达
- 内容区块背后不要放浅色/白色背景——虚空是神圣的
- 不要用衬线或展示字重字体——系统只用几何无衬线

## 8. 响应式行为

### 断点
| 名称（Name） | 宽度（Width） | 关键变化（Key Changes） |
|------|-------|-------------|
| 移动 | <809px | 单列，堆叠特性区块，首屏文字缩小（62px→40px），汉堡导航 |
| 平板 | 809px–1199px | 特性开始 2 列，导航链接部分可见，截图缩小 |
| 桌面 | >1199px | 完整布局，展开导航含所有链接 + CTA，110px 展示首屏，特性并排 |

### 触控目标
- 胶囊按钮：最小 40px 高，10px 垂直内边距——超过 44px WCAG 最小值
- 导航链接：15px 文字，内边距慷慨，触控友好
- 移动 CTA 按钮：移动端全宽胶囊，拇指易达

### 收起策略
- **导航**：全横排导航 → 移动断点收起为汉堡菜单
- **首屏文字**：110px 展示 → 85px → 62px → 跨断点约 40px，极端负字距按比例保持
- **特性区块**：并排（文字 + 截图）→ 移动端垂直堆叠
- **产品截图**：在容器内响应式缩放，保持宽高比
- **区块间距**：按比例减小——桌面 120px → 移动 60px

### 图片行为
- 产品截图响应式，在容器边界内缩放
- 无艺术指导变化——各断点同一裁剪
- 深色背景保证截图在任何尺寸都有视觉冲击
- 截图随用户滚动进入视口时懒加载

### 迭代指南
细化用本设计系统生成的现有界面时：
1. 一次只聚焦一个组件——深色画布让每个元素都珍贵
2. 始终核验 GT Walsheim 标题的字间距——极端负字距不可妥协
3. 检查 Framer 蓝只出现在交互元素上——绝不作装饰背景或非链接文字色
4. 确保所有按钮都是胶囊形——任何方形角都会立刻破坏 Framer 美学
5. 用 `rgba(255, 255, 255, 0.1)` 核验霜面玻璃表面——太不透明像 bug，太透明会消失
