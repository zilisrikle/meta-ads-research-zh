# 源自 Raycast 的设计系统

## 1. 视觉主题与氛围

Raycast 的营销网站就像一台精密仪器的深色内部——一个用黑曜石雕刻的瑞士手表表壳。背景不只是深色，而是一种近黑的蓝调（`#07080a`），营造出置身于 macOS 原生应用而非网站的感觉。每一个表面、每一条边框、每一层阴影都经过校准，唤起高性能桌面工具的感觉：快速、极简、可信。

标志性手法是借自 macOS 窗口镀铬（window chrome）的分层阴影系统：多层盒阴影加内嵌高光，模拟物理深度，仿佛卡片和按钮是黑暗桌面上真实被按下或凸起的玻璃元件。配合 Raycast Red（`#FF6363`）——几乎只部署在首屏标志性的斜纹条纹图案中——整个色板塑造出"强大且有个性"的品牌形象。红色不主导；它负责点睛。

Inter 无处不在——标题、正文、按钮、说明文字——启用丰富的 OpenType 特性（`calt`、`kern`、`liga`、`ss03`），形成一致、可读的排印语调。正字间距（正文 0.2px–0.4px）在深色 UI 中很不寻常，赋予文本通透、透气的质感，与密集的深色表面形成平衡。GeistMono 用于代码元素，强化了开发者工具的身份。

**关键特征：**
- 近黑蓝调背景（`#07080a`）——不是纯黑，微微偏蓝
- macOS 原生阴影系统，多层内嵌高光模拟物理深度
- Raycast Red（`#FF6363`）作为点睛色——首屏条纹，而非铺满
- Inter 配正字间距（0.2px），带来通透、可读的深色模式体验
- Radix UI 组件原语驱动交互层
- 微妙的 rgba 白色边框（0.06–0.1 不透明度），在深色表面上形成收纳感
- 键盘快捷键样式，带渐变键帽和厚重阴影

## 2. 色彩体系与角色

### 主色
- **Near-Black Blue**（`#07080a`）：主页面背景——带微妙蓝冷色调的基础虚空
- **Pure White**（`#ffffff`）：主标题文本、高强调元素
- **Raycast Red**（`#FF6363` / `hsl(0, 100%, 69%)`）：品牌点缀——首屏条纹、危险状态、关键高亮

### 次级与点缀
- **Raycast Blue**（`hsl(202, 100%, 67%)` / ~`#55b3ff`）：交互点缀——链接、焦点态、选中项
- **Raycast Green**（`hsl(151, 59%, 59%)` / ~`#5fc992`）：成功状态、积极指示
- **Raycast Yellow**（`hsl(43, 100%, 60%)` / ~`#ffbc33`）：警告点缀、高亮
- **Blue Transparent**（`hsla(202, 100%, 67%, 0.15)`）：交互表面的蓝色调叠加
- **Red Transparent**（`hsla(0, 100%, 69%, 0.15)`）：危险/错误表面的红色调叠加

### 表面与背景
- **Deep Background**（`#07080a`）：页面画布，最深的表面
- **Surface 100**（`#101111`）：抬升表面、卡片背景
- **Key Start**（`#121212`）：键盘按键渐变起点
- **Key End**（`#0d0d0d`）：键盘按键渐变终点
- **Card Surface**（`#1b1c1e`）：徽章背景、标签填充、抬升容器
- **Button Foreground**（`#18191a`）：浅色背景上按钮文本的深色表面

### 中性色与文本
- **Near White**（`#f9f9f9` / `hsl(240, 11%, 96%)`）：主正文文本、高强调内容
- **Light Gray**（`#cecece` / `#cdcdce`）：次级正文文本、描述
- **Silver**（`#c0c0c0`）：三级文本、弱化标签
- **Medium Gray**（`#9c9c9d`）：链接默认色、次级导航
- **Dim Gray**（`#6a6b6c`）：禁用文本、低强调标签
- **Dark Gray**（`#434345`）：弱化边框、非激活导航链接
- **Border**（`hsl(195, 5%, 15%)` / ~`#252829`）：卡片与分隔线的标准边框色
- **Dark Border**（`#2f3031`）：分隔线、表格边框

### 语义与点缀
- **Error Red**（`hsl(0, 100%, 69%)`）：错误状态、破坏性操作
- **Success Green**（`hsl(151, 59%, 59%)`）：成功确认、积极状态
- **Warning Yellow**（`hsl(43, 100%, 60%)`）：警告、需注意的状态
- **Info Blue**（`hsl(202, 100%, 67%)`）：信息高亮、链接

### 渐变系统
- **Keyboard Key Gradient**：从 `#121212`（顶部）到 `#0d0d0d`（底部）的线性渐变——模拟物理按键深度
- **Warm Glow**：`rgba(215, 201, 175, 0.05)` 径向扩散——精选元素背后的微妙暖色环境光

## 3. 排印规则

### 字体族
- **主要**：`Inter`——人文主义无衬线体，无处不在。回退：`Inter Fallback`、系统无衬线体
- **系统**：`SF Pro Text`——Apple 系统字体，用于精选 macOS 原生 UI 元素。回退：`SF Pro Icons`、`Inter`、`Inter Fallback`
- **等宽**：`GeistMono`——Vercel 的等宽字体，用于代码元素。回退：`ui-monospace`、`SFMono-Regular`、`Roboto Mono`、`Menlo`、`Monaco`
- **OpenType 特性**：全局启用 `calt`、`kern`、`liga`、`ss03`；展示文本加 `ss02`、`ss08`；首屏标题禁用连字（`"liga" 0`）

### 层级

| 角色 | 字号 | 字重 | 行高 | 字间距 | 备注 |
|------|------|--------|-------------|----------|-------|

| 区块展示 | 56px | 400 | 1.17 | 0.2px | OpenType：calt、kern、liga、ss03 |
| 章节标题 | 24px | 500 | normal | 0.2px | OpenType：calt、kern、liga、ss03 |
| 卡片标题 | 22px | 400 | 1.15 | 0px | OpenType：calt、kern、liga、ss03 |
| 副标题 | 20px | 500 | 1.60 | 0.2px | 放松行高以提高可读性 |
| 大正文 | 18px | 400 | 1.15 | 0.2px | OpenType：calt、kern、liga、ss03 |
| 正文 | 16px | 500 | 1.60 | 0.2px | 主正文文本，放松的节奏 |
| 紧凑正文 | 16px | 400 | 1.15 | 0.1px | UI 标签、紧凑场景 |
| 按钮 | 16px | 600 | 1.15 | 0.3px | 半粗，稍宽的字距 |

| 小代码 | 12px (GeistMono) | 400 | 1.60 | 0.2px | 行内代码、终端输出 |

### 原则
- **深色上的正字距**：与大多数用紧凑或中性字间距的深色 UI 不同，Raycast 用 +0.2px 到 +0.4px——营造通透、可读的感觉，补偿深色背景
- **字重 500 为基准**：大多数正文用中等字重（500）而非常规（400）——微妙的额外分量提升深色表面的易读性
- **展示克制**：64px/600 的首屏文本自信但不过分——Raycast 避开排印奇观，偏向功能优雅
- **处处 OpenType**：`ss03`（风格集 3）在 Inter 上全局启用，赋予字体略带几何感、工具般的气质

## 4. 组件样式

### 按钮
- **主胶囊按钮**：透明背景、白色文本、胶囊形（86px 圆角）、多层内嵌阴影（`rgba(255, 255, 255, 0.1) 0px 1px 0px 0px inset`）。悬停：不透明度 0.6
- **次级按钮**：透明背景、白色文本、6px 圆角、`1px solid rgba(255, 255, 255, 0.1)` 边框、微妙投影（`rgba(0, 0, 0, 0.03) 0px 7px 3px`）。悬停：不透明度 0.6
- **幽灵按钮**：无背景无边框，灰色文本（`#6a6b6c`），86px 圆角，同样的内嵌阴影。悬停：不透明度 0.6，文本变亮为白色
- **CTA（下载）**：半透明白色背景（`hsla(0, 0%, 100%, 0.815)`），深色文本（`#18191a`），胶囊形。悬停：全白背景（`hsl(0, 0%, 100%)`）
- **过渡**：所有按钮悬停用不透明度过渡，而非背景色变化——这是 Raycast 标志性的交互模式

### 卡片与容器
- **标准卡片**：`#101111` 表面，`1px solid rgba(255, 255, 255, 0.06)` 边框，12px–16px 圆角
- **抬升卡片**：环形阴影 `rgb(27, 28, 30) 0px 0px 0px 1px` 外层 + `rgb(7, 8, 10) 0px 0px 0px 1px inset` 内层——形成双环收纳
- **功能卡片**：16px–20px 圆角，首屏元素背后有微妙暖光（`rgba(215, 201, 175, 0.05) 0px 0px 20px 5px`）
- **悬停**：卡片通过边框不透明度提升或微妙阴影增强而变亮

### 输入框与表单
- 深色输入框，`#07080a` 背景，`1px solid rgba(255, 255, 255, 0.08)` 边框，8px 圆角
- 焦点态：边框变亮，出现蓝色光晕（`hsla(202, 100%, 67%, 0.15)`）环
- 文本：输入色 `#f9f9f9`，占位符 `#6a6b6c`
- 标签：`#9c9c9d`，14px，字重 500

### 导航
- **顶部导航**：深色背景与页面融合，白色文本链接，16px，字重 500
- **导航链接**：灰色文本（`#9c9c9d`）→ 悬停变白，悬停时下划线装饰
- **CTA 按钮**：导航末尾的半透明白色胶囊按钮
- **移动端**：折叠为汉堡菜单，保持深色主题
- **粘性**：导航固定顶部，带微妙边框分隔

### 图片处理
- **产品截图**：macOS 窗口镀铬风格——圆角（12px）、深阴影模拟悬浮窗口
- **全幅区块**：深色截图与深色背景无缝融合
- **首屏插画**：Raycast Red 斜纹条纹图案——抽象、几何、品牌定义性
- **应用 UI 嵌入**：展示真实的 Raycast 命令面板和扩展——产品即内容

### 键盘快捷键
- **键帽样式**：渐变背景（`#121212` → `#0d0d0d`）、厚重多层阴影（`rgba(0, 0, 0, 0.4) 0px 1.5px 0.5px 2.5px` + 内嵌阴影），营造逼真的物理按键外观
- 圆角：单个按键 4px–6px

### 徽章与标签
- **中性徽章**：`#1b1c1e` 背景、白色文本、6px 圆角、14px 字体字重 500、`0px 6px` 内边距
- 紧凑的胶囊式处理，用于分类

## 5. 布局原则

### 间距系统
- **基础单位**：8px
- **阶梯**：1px、2px、3px、4px、8px、10px、12px、16px、20px、24px、32px、40px
- **区块内边距**：主要区块间垂直 80px–120px
- **卡片内边距**：内部 16px–32px
- **组件间距**：相关元素间 8px–16px

### 网格与容器
- **最大宽度**：约 1200px 容器（断点在 1204px），居中
- **列模式**：单列首屏、2–3 列功能网格、全宽展示区块
- **应用展示**：产品 UI 以居中的窗口框呈现

### 留白（Whitespace）哲学
- **戏剧性负空间**：区块漂浮在浩瀚的黑暗虚空中，在功能之间形成电影般的节奏
- **产品密集，营销稀疏**：产品 UI 截图信息密集，但周围的营销文案用极简文本加大留白
- **垂直节奏**：区块内元素间一致的 24px–32px 间距

### 圆角阶梯
- **2px–3px**：微元素、代码片段、小指示器
- **4px–5px**：键盘按键、小交互元素
- **6px**：按钮、徽章、标签——主力圆角
- **8px**：输入框、行内组件
- **9px–11px**：图片、中型容器
- **12px**：标准卡片、产品截图
- **16px**：大卡片、功能区块
- **20px**：首屏卡片、突出容器
- **86px+**：胶囊按钮、导航 CTA——全胶囊形

## 6. 深度与层级

| 层级 | 处理 | 用途 |
|-------|-----------|-----|
| 0 级（虚空） | 无阴影，`#07080a` 表面 | 页面背景 |
| 1 级（微妙） | `rgba(0, 0, 0, 0.28) 0px 1.189px 2.377px` | 轻微抬升、行内元素 |
| 2 级（环） | `rgb(27, 28, 30) 0px 0px 0px 1px` 外层 + `rgb(7, 8, 10) 0px 0px 0px 1px inset` 内层 | 卡片收纳、双环技法 |
| 3 级（按钮） | `rgba(255, 255, 255, 0.05) 0px 1px 0px 0px inset` + `rgba(255, 255, 255, 0.25) 0px 0px 0px 1px` + `rgba(0, 0, 0, 0.2) 0px -1px 0px 0px inset` | macOS 原生按钮按压——顶部白色高光、底部深色内嵌 |
| 4 级（按键） | 5 层阴影栈，带内嵌按压效果 | 键盘快捷键键帽——物理 3D 外观 |
| 5 级（悬浮） | `rgba(0, 0, 0, 0.5) 0px 0px 0px 2px` + `rgba(255, 255, 255, 0.19) 0px 0px 14px` + 内嵌 | 命令面板、悬浮面板——厚重深度加光晕 |

### 阴影哲学
Raycast 的阴影系统是网页上最 macOS 原生的。多层阴影组合：
- **外环**用于收纳（替代传统边框）
- **内嵌顶部高光**（`rgba(255, 255, 255, 0.05–0.25)`）模拟来自上方的光源
- **内嵌底部深色**（`rgba(0, 0, 0, 0.2)`）模拟下方阴影
- 效果是物理的：元素像玻璃或拉丝金属，而非扁平矩形

### 装饰性深度
- **暖光**：精选元素背后 `rgba(215, 201, 175, 0.05) 0px 0px 20px 5px`——冷色深色画布上的微妙暖色光晕
- **蓝色信息光**：`rgba(0, 153, 255, 0.15)` 用于交互态强调
- **红色危险光**：`rgba(255, 99, 99, 0.15)` 用于错误/破坏性态强调

## 7. 应该做与不应该做

### 应该做
- 背景用 `#07080a`（不是纯黑）——蓝冷色调是 Raycast 感觉的关键
- 正文用正字间距（+0.2px）——这与大多数深色 UI 刻意不同
- 交互元素用带内嵌高光的多层阴影——macOS 原生深度是标志性的
- Raycast Red（`#FF6363`）作点睛，而非铺满——留给首屏时刻和错误状态
- 卡片收纳用 `rgba(255, 255, 255, 0.06)` 边框——几乎看不见，但结构上必不可少
- 正文基准字重用 500——中等字重提升深色模式易读性
- 主 CTA 用胶囊形（86px+ 圆角），次级操作用矩形（6px–8px）
- 所有 Inter 文本启用 OpenType 特性 `calt`、`kern`、`liga`、`ss03`
- 按钮交互用不透明度过渡（悬停：不透明度 0.6），而非颜色变化

### 不应该做
- 背景不用纯黑（`#000000`）——蓝色调把 Raycast 与通用深色主题区分开
- 正文不用负字间距——Raycast 刻意用正间距保证可读性
- 不把 Raycast Blue 当作万能主点缀——蓝色用于交互/信息，红色才是品牌色
- 不用单层扁平阴影——多层内嵌系统是 macOS 原生美学的核心
- 有 500 可用时正文不用常规字重（400）——额外字重防止深色模式文本显得单薄
- 不混用暖冷边框——坚持冷灰（`hsl(195, 5%, 15%)`）边框色板
- 不用没有内嵌伴侣的厚重投影——阴影永远成对出现（外层 + 内嵌）
- 不用装饰性元素、渐变或彩色背景——黑暗虚空是舞台，内容是演员

## 8. 响应式行为

### 断点
| 名称 | 宽度 | 关键变化 |
|------|-------|-------------|
| 移动端 | <600px | 单列、堆叠卡片、汉堡导航、首屏文本缩小到约 40px |
| 小平板 | 600px–768px | 2 列网格开始，导航部分可见 |
| 平板 | 768px–1024px | 2–3 列功能，导航展开，截图缩放 |
| 桌面 | 1024px–1200px | 完整布局，所有导航链接可见，64px 首屏展示 |
| 大桌面 | >1200px | 最大宽度容器居中，慷慨的侧边距 |

### 触控目标
- 胶囊按钮：86px 圆角配 20px 内边距——远超 44px 最小值
- 次级按钮：最小 8px 内边距，但边框提供视觉目标扩展
- 导航链接：16px 文本加周围内边距，保证可访问的触控目标

### 折叠策略
- **导航**：全横向导航 → 移动端汉堡加滑出菜单
- **首屏**：64px 展示 → 跨断点 48px → 36px
- **功能网格**：3 列 → 2 列 → 单列堆叠
- **产品截图**：在容器内缩放，保持 macOS 窗口镀铬比例
- **键盘快捷键展示**：移动端简化或隐藏（键盘快捷键无关）

### 图片行为
- 产品截图在固定比例容器内响应式缩放
- 首屏斜纹条纹图案按比例缩放
- macOS 窗口镀铬圆角在所有尺寸下保持
- 无懒加载伪影——图片对产品叙事至关重要

### 迭代指南
用此设计系统打磨已生成的界面时：
1. 检查背景是 `#07080a` 而非纯黑——蓝色调至关重要
2. 确认正文字间距为正（+0.2px）——负间距会破坏 Raycast 美学
3. 确保阴影同时有外层和内嵌层——单层阴影显得扁平且错误
4. 确认 Inter 启用了 OpenType 特性 `calt`、`kern`、`liga`、`ss03`
5. 测试悬停态用不透明度过渡（0.6）而非颜色替换——这是核心交互模式
