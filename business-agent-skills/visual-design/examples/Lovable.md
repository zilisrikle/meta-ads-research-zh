# Lovable 灵感设计系统

## 1. 视觉主题与氛围

Lovable 的网站通过克制散发出温暖感。整个页面坐落于奶油色、羊皮纸般的背景（`#f7f4ed`）之上，与大多数开发者工具网站的冷白惯例立刻划清界限。这不是为极简而极简——这是一种有意选择，让品牌显得平易近人、近乎模拟质感，如同一本做工精良的笔记本。近黑色的文字（`#1c1c1c`）与暖奶油底色形成对比，护眼的同时保持清晰的可读性。

自定义字体 Camera Plain Variable 是这套系统的秘密武器。与传递"科技公司"信号的几何无衬线字体不同，Camera Plain 带着一种人文主义的温暖——略微圆润的字尾、自然的曲线和舒适的阅读节奏。在展示级字号（48px–60px）下，字重（font weight）600 配合激进的负字间距（letter-spacing）（-0.9px 至 -1.5px），将标题压缩成自信的、编辑感强的宣言。该字体使用 `ui-sans-serif, system-ui` 作为回退字体（fallback），意味着定制字体承担着品牌个性的重任。

Lovable 视觉系统最独特之处在于它的不透明度（opacity）驱动的深度模型。它不使用传统的灰度色阶，而是以不同不透明度（0.03、0.04、0.4、0.82–0.83）调制 `#1c1c1c`，创造统一的色调范围。页面上每一层灰在技术上都是同一色相——只是透明度不同。这带来一种用任意十六进制色值几乎无法实现的视觉一致性。边框系统也遵循同一逻辑：浅分隔用 `1px solid #eceae4`，交互性更强的边界用 `1px solid rgba(28, 28, 28, 0.4)`。

**关键特征：**
- 暖奶油色背景（`#f7f4ed`）——不是白色也不是米色，是一种精心挑选、带着手工感的奶油色
- Camera Plain Variable 字体：人文主义温暖感，展示级字号配编辑感字间距
- 不透明度驱动的色彩系统：所有灰色均由 `#1c1c1c` 以不同透明度衍生
- 按钮上的内阴影（inset shadow）技法：`rgba(255,255,255,0.2) 0px 0.5px 0px 0px inset, rgba(0,0,0,0.2) 0px 0px 0px 0.5px inset`
- 暖中性边框色板：被动元素用 `#eceae4`，交互元素用 `rgba(28,28,28,0.4)`
- 全胶囊圆角（9999px）广泛用于动作按钮与图标容器
- 焦点状态使用 `rgba(0,0,0,0.1) 0px 4px 12px` 阴影，带来柔和的暖调强调
- shadcn/ui + Radix UI 组件原语，搭配 Tailwind CSS 工具类样式

## 2. 色彩体系与角色

### 主色
- **奶油色（Cream）**（`#f7f4ed`）：页面背景、卡片表面、按钮表面。整个体系的基石——温暖、纸质感、有人情味。
- **炭黑（Charcoal）**（`#1c1c1c`）：主要文字、标题、深色按钮背景。不是纯黑——带着自然的暖意。
- **米白色（Off-White）**（`#fcfbf8`）：深色背景上的按钮文字、细微高光。与纯白几乎难以区分。

### 中性阶梯（不透明度驱动）
- **炭黑 100%（Charcoal 100%）**（`#1c1c1c`）：主要文字、标题、深色表面。
- **炭黑 83%（Charcoal 83%）**（`rgba(28,28,28,0.83)`）：强次级文字。
- **炭黑 82%（Charcoal 82%）**（`rgba(28,28,28,0.82)`）：正文。
- **柔灰（Muted Gray）**（`#5f5f5d`）：次级文字、描述、说明文字。
- **炭黑 40%（Charcoal 40%）**（`rgba(28,28,28,0.4)`）：交互边框、按钮描边。
- **炭黑 4%（Charcoal 4%）**（`rgba(28,28,28,0.04)`）：细微的悬停背景、微染色。
- **炭黑 3%（Charcoal 3%）**（`rgba(28,28,28,0.03)`）：几乎不可见的叠加层、背景深度。

### 表面与边框
- **浅奶油（Light Cream）**（`#eceae4`）：卡片边框、分隔线、图片描边。那条暖调的分隔线。
- **奶油表面（Cream Surface）**（`#f7f4ed`）：卡片背景、区块填充——与页面背景同色，实现无缝融合。

### 交互
- **环形蓝（Ring Blue）**（`#3b82f6`，50% 不透明度）：`--tw-ring-color`，Tailwind 焦点环（focus ring）。
- **焦点阴影（Focus Shadow）**（`rgba(0,0,0,0.1) 0px 4px 12px`）：焦点与激活状态阴影——柔和、暖调、扩散。

### 内阴影
- **按钮内阴影（Button Inset）**（`rgba(255,255,255,0.2) 0px 0.5px 0px 0px inset, rgba(0,0,0,0.2) 0px 0px 0px 0.5px inset, rgba(0,0,0,0.05) 0px 1px 2px 0px`）：深色按钮标志性的多层内阴影。

## 3. 排版规则

### 字体家族
- **主字体**：`Camera Plain Variable`，回退字体：`ui-sans-serif, system-ui`
- **字重范围**：400（正文/阅读）、480（特殊展示）、600（标题/强调）
- **特性**：可变字体（variable font），带有连续的字重轴——支持 480 这类微调的中间字重。

### 层级

### 原则
- **温暖的人文主义语调**：Camera Plain Variable 赋予 Lovable 平易近人的个性。略微圆润的字尾和自然曲线，与大多数开发者工具使用的锐利几何无衬线形成对比。
- **把可变字重视为设计工具**：该字体支持连续字重值（如 480），让层级超越标准字重档位，实现细腻区分。60px 下 480 的字重呈现出一种展示风格——比半粗体更轻，又比常规更强。
- **大字号压缩**：标题使用负字间距（-0.9px 至 -1.5px）获得编辑感冲击力。正文保持常规字间距，保证舒适阅读。
- **两个字重，角色清晰**：400（正文/UI/链接/按钮）与 600（标题/强调）。窄字重范围让层级通过字号与间距、而非字重变化来建立。

## 5. 布局原则

### 间距系统
- 基准单位：8px
- 阶梯：8px、10px、12px、16px、24px、32px、40px、56px、80px、96px、128px、176px、192px、208px
- 阶梯在顶端慷慨展开——区块使用 80px–208px 的纵向间距，营造编辑级的呼吸感

### 网格与容器
- 内容最大宽度：约 1200px（居中）
- 主视觉区：居中单列，纵向内边距巨大（96px+）
- 功能区块：2–3 列网格
- 全宽页脚，多列链接布局
- 展示区块配居中卡片网格

### 留白哲学
- **编辑级的慷慨**：Lovable 在区块交界处的间距极为奢侈（80px–208px）。暖奶油背景让这些大面积留白显得温馨而非空洞。
- **内容驱动的节奏**：卡片内部紧凑间距（12–24px）与宽阔的区块间隙形成对比，营造出阅读节奏——在聚焦内容与视觉休息之间交替。
- **区块分隔**：页脚使用 `1px solid #eceae4` 边框和 16px 圆角容器。区块靠慷慨的间距界定，而非边框线。

### 圆角（border-radius）阶梯
- 微型（4px）：小按钮、交互元素
- 标准（6px）：按钮、输入框、导航菜单
- 舒适（8px）：紧凑卡片、div
- 卡片（12px）：标准卡片、图片容器、模板
- 容器（16px）：大容器、页脚区块
- 全胶囊（9999px）：动作胶囊、图标按钮、切换开关

## 6. 深度与层级

| 层级 | 处理 | 用途 |
|-------|-----------|-----|
| 扁平（Level 0） | 无阴影，奶油背景 | 页面表面、大部分内容 |
| 边框（Level 1） | `1px solid #eceae4` | 卡片、图片、分隔线 |
| 内嵌（Level 2） | `rgba(255,255,255,0.2) 0px 0.5px 0px inset, rgba(0,0,0,0.2) 0px 0px 0px 0.5px inset, rgba(0,0,0,0.05) 0px 1px 2px` | 深色按钮、主操作 |
| 焦点（Level 3） | `rgba(0,0,0,0.1) 0px 4px 12px` | 激活/焦点状态 |
| 环形（可访问性） | `rgba(59,130,246,0.5)` 2px 环形 | 输入框的键盘焦点 |

**阴影哲学**：Lovable 的深度系统有意保持浅层。系统不使用悬浮卡片配戏剧化投影，而是依靠奶油表面上的暖边框（`#eceae4`）实现温和的收纳。唯一值得注意的阴影模式是深色按钮上的内阴影——一种细微的多层技法：白色高光线压在顶部边缘，深色环与柔和投影处理底部。这营造出一种"压入表面"的触感，而非"悬浮于表面之上"。暖调焦点阴影（`rgba(0,0,0,0.1) 0px 4px 12px`）有意做得扩散而大，形成柔光而非锐利描边。

### 装饰性深度
- 主视觉区：主视觉后方柔和的暖调多色渐变晕染（粉、橙、蓝）——氛围感，几乎不可见
- 页脚：暖调渐变背景，向底部过渡
- 无生硬的区块分隔线——间距与背景暖调负责过渡

## 7. 要做与不做

### 要做（Do）
- 用暖奶油背景（`#f7f4ed`）作为页面基底——它是品牌标志性的温暖
- 展示级字号使用 Camera Plain Variable 配负字间距（-0.9px 至 -1.5px）
- 所有灰色由 `#1c1c1c` 以不同不透明度衍生，保证色调统一
- 在深色按钮上使用内阴影技法，营造触感深度
- 用 `#eceae4` 边框而非阴影做卡片收纳
- 保持窄字重系统：正文/UI 用 400，标题用 600
- 全胶囊圆角（9999px）只用于动作胶囊与图标按钮
- 激活态应用 0.8 不透明度，提供响应灵敏的触感反馈

### 不做（Don't）
- 不要用纯白（`#ffffff`）做页面背景——奶油色是有意为之
- 不要用厚重盒阴影做卡片——边框才是收纳机制
- 不要引入高饱和强调色——色板有意保持暖中性
- 不要用字重 700（粗体）——600 是系统中的最大字重
- 不要在矩形按钮上用 9999px 圆角——胶囊只给图标/动作切换
- 不要用锐利的焦点描边——系统使用柔和的阴影式焦点指示
- 不要混用边框样式——被动元素用 `#eceae4`，交互元素用 `rgba(28,28,28,0.4)`
- 不要放大标题字间距——Camera Plain 在大字号下本就设计为紧凑

## 8. 响应式行为

### 断点（Breakpoints）
| 名称 | 宽度 | 关键变化 |
|------|-------|-------------|
| 小屏手机（Mobile Small） | <600px | 紧凑单列，内边距减小 |
| 手机（Mobile） | 600–640px | 标准移动端布局 |
| 小平板（Tablet Small） | 640–700px | 2 列网格开始 |
| 平板（Tablet） | 700–768px | 卡片网格展开 |
| 小桌面（Desktop Small） | 768–1024px | 多列布局 |
| 桌面（Desktop） | 1024–1280px | 完整功能布局 |
| 大桌面（Large Desktop） | 1280–1536px | 最大内容宽度，外边距宽松 |

### 触控目标（Touch Targets）
- 按钮：8px 16px 内边距（舒适触控）
- 导航：条目之间间距充足
- 胶囊按钮：9999px 圆角形成大而易点的目标
- 菜单切换：6px 圆角按钮，尺寸充足

### 折叠策略
- 主视觉区：标题 60px → 48px → 36px 缩放，字间距按比例调整
- 导航：横向链接 → 768px 以下切换为汉堡菜单
- 功能卡片：3 列 → 2 列 → 单列堆叠
- 模板画廊：网格 → 堆叠纵向卡片
- 数据条：横向 → 纵向堆叠
- 页脚：多列 → 堆叠单列
- 区块间距：移动端从 128px+ 降至 64px

### 图片行为
- 模板截图在所有尺寸保持 `1px solid #eceae4` 边框
- 所有断点保留 12px 圆角
- 画廊图片响应式，纵横比一致
- 移动端主视觉渐变柔化/简化

### 迭代指南
1. 永远用奶油色（`#f7f4ed`）做基底——绝不用纯白
2. 灰色由 `#1c1c1c` 以不同不透明度衍生，而非使用独立的十六进制值
3. 用 `#eceae4` 边框做收纳，不用阴影
4. 字间距随字号缩放：60px 用 -1.5px，48px 用 -1.2px，36px 用 -0.9px，16px 用常规
5. 两个字重：400（标题以外的一切）与 600（标题）
6. 深色按钮上的内阴影是标志性细节——不要省略
7. Camera Plain Variable 的 480 字重只用于特殊的展示时刻
