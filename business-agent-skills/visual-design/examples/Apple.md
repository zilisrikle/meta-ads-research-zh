# 受 Apple 启发的设计系统

## 1. 视觉主题与氛围

Apple 的网站是克制戏剧感的教科书——大面积纯黑与近白如电影布景，产品则像陈列在美术馆中的雕塑一样被拍摄。设计哲学是彻底的减法：每个像素都服务于产品，界面本身退后直到隐形。这不是出于审美偏好的极简，而是出于对物件本身的崇敬。

排印（typography）锚定一切。San Francisco（大字号用 SF Pro Display、正文用 SF Pro Text）是 Apple 的专有字体，带有光学尺寸（optical sizing）设计，会根据字号自动调整字母形态（letterforms）。在展示字号（56px）下，600 字重（font weight）、1.07 的紧凑行高（line height）和 -0.28px 的轻微负字间距（letter-spacing），让标题看起来像机加工而非排印——精确、自信、毫不妥协。在正文字号（17px）下，字距（tracking）略微放宽到 -0.374px，行高张开到 1.47，形成舒适而不松散的阅读节奏。

色彩叙事是鲜明的二元对立。产品分区在纯黑（`#000000`）背景配白字与浅灰（`#f5f5f7`）背景配近黑字（`#1d1d1f`）之间交替，营造出电影般的节奏——深色分区沉浸高级，浅色分区开阔明快。唯一的彩色点缀是苹果蓝（Apple Blue）（`#0071e3`），专属用于可交互元素：链接、按钮和聚焦状态。在中性色的海洋中出现唯一的点缀色，让每个可点击的元素都无可错认。

**关键特征：**
- SF Pro Display/Text 带光学尺寸——字母形态随字号语境自动适配
- 明暗分区交替的二元节奏：黑（`#000000`）与浅灰（`#f5f5f7`）交替
- 单一的点缀色：苹果蓝（Apple Blue）（`#0071e3`）专属用于可交互元素
- 产品即主角的摄影落在纯色块上——无渐变、无纹理、无干扰
- 极其紧凑的标题行高（1.07–1.14），形成压缩的广告牌式冲击力
- 全宽分区布局、内容居中——视口本身就是画布
- 胶囊形 CTA（980px 圆角），形成柔和亲和的行动按钮
- 分区间慷慨的留白，让每个产品时刻都能呼吸

## 2. 色彩体系与角色

### 主色
- **纯黑（Pure Black）**（`#000000`）：首屏分区背景、沉浸式产品展示。最暗的画布，衬托最亮的产品。
- **浅灰（Light Gray）**（`#f5f5f7`）：交替分区背景、信息区域。不是白色——微微的蓝灰调避免了冰冷感。
- **近黑（Near Black）**（`#1d1d1f`）：浅色背景上的主文字、深色按钮填充。比纯黑略暖，阅读更舒适。

### 交互
- **苹果蓝（Apple Blue）**（`#0071e3`）：`--sk-focus-color`，主 CTA 背景、聚焦描边。界面中唯一的彩色。
- **链接蓝（Link Blue）**（`#0066cc`）：`--sk-body-link-color`，行内文本链接。比苹果蓝略深，保证文字级可读性。
- **亮蓝（Bright Blue）**（`#2997ff`）：深色背景上的链接。更高亮度以保证在黑色分区上的对比。

### 文字
- **白（White）**（`#ffffff`）：深色背景上的文字，蓝色/深色 CTA 上的按钮文字。
- **近黑（Near Black）**（`#1d1d1f`）：浅色背景上的主正文。
- **黑 80%（Black 80%）**（`rgba(0, 0, 0, 0.8)`）：次级文字、浅色背景上的导航项。略微柔化。
- **黑 48%（Black 48%）**（`rgba(0, 0, 0, 0.48)`）：三级文字、禁用状态、轮播控件。

### 表面与深色变体
- **深色表面 1（Dark Surface 1）**（`#272729`）：深色分区中的卡片背景。
- **深色表面 2（Dark Surface 2）**（`#262628`）：深色语境中微妙的表面变化。
- **深色表面 3（Dark Surface 3）**（`#28282a`）：深色背景上的抬升卡片。
- **深色表面 4（Dark Surface 4）**（`#2a2a2d`）：最高的深色表面层级。
- **深色表面 5（Dark Surface 5）**（`#242426`）：最深的深色表面调。

### 按钮状态
- **按钮激活（Button Active）**（`#ededf2`）：浅色按钮的激活/按压状态。
- **按钮默认（浅色）（Button Default Light）**（`#fafafc`）：搜索/筛选按钮背景。
- **遮罩（Overlay）**（`rgba(210, 210, 215, 0.64)`）：媒体控制罩、浮层。
- **白 32%（White 32%）**（`rgba(255, 255, 255, 0.32)`）：深色弹窗关闭按钮的悬停状态。

### 阴影
- **卡片阴影（Card Shadow）**（`rgba(0, 0, 0, 0.22) 3px 5px 30px 0px`）：产品卡片的柔和弥散抬升。偏移加宽模糊，营造自然的摄影感阴影。

## 3. 排印规则

### 字体族
- **展示**：`SF Pro Display`，回退：`SF Pro Icons, Helvetica Neue, Helvetica, Arial, sans-serif`
- **正文**：`SF Pro Text`，回退：`SF Pro Icons, Helvetica Neue, Helvetica, Arial, sans-serif`
- SF Pro Display 用于 20px 及以上；SF Pro Text 为 19px 及以下优化。

### 原则
- **光学尺寸即哲学**：SF Pro 会在 Display 与 Text 两种光学尺寸之间自动切换。Display 版字间距更宽、笔画更细，为大字号优化；Text 版更紧凑结实，为小字号优化。这意味着字体会根据语境字面改变自己的 DNA。
- **字重克制**：刻度从 300（细体）横跨到 700（粗体），但大多数文字生活在 400（常规）和 600（半粗）。300 只出现在大字号装饰文字上。700 很少见，只用于粗体卡片标题。
- **所有字号都用负字距**：大多数系统只给标题收紧字距，Apple 即使在正文字号也用轻微负字间距（17px 用 -0.374px，14px 用 -0.224px，12px 用 -0.12px）。这造就了全系统紧凑高效的文字。
- **极端的行高区间**：标题压缩到 1.07，正文张开到 1.47，某些按钮语境拉伸到 2.41。这种巨大的区间仅凭节奏就形成了清晰的视觉层级。

## 4. 组件样式

### 按钮

**主按钮（蓝色 CTA）**
- 背景：`#0071e3`（苹果蓝）
- 文字：`#ffffff`
- 内边距：8px 15px
- 圆角：8px
- 边框：1px solid transparent
- 字体：SF Pro Text，17px，400 字重
- 悬停：背景略微提亮
- 激活：`#ededf2` 背景切换
- 聚焦：`2px solid var(--sk-focus-color, #0071E3)` 描边
- 用途：主行动号召（"Buy"、"Shop iPhone"）

**主按钮（深色）**
- 背景：`#1d1d1f`
- 文字：`#ffffff`
- 内边距：8px 15px
- 圆角：8px
- 字体：SF Pro Text，17px，400 字重
- 用途：次级 CTA，深色变体

**胶囊链接（了解更多 / 选购）**
- 背景：透明
- 文字：`#0066cc`（浅色背景）或 `#2997ff`（深色背景）
- 圆角：980px（全胶囊）
- 边框：1px solid `#0066cc`
- 字体：SF Pro Text，14px–17px
- 悬停：下划线装饰
- 用途：「了解更多」和「选购」链接——Apple 标志性的行内 CTA

**筛选/搜索按钮**
- 背景：`#fafafc`
- 文字：`rgba(0, 0, 0, 0.8)`
- 内边距：0px 14px
- 圆角：11px
- 边框：3px solid `rgba(0, 0, 0, 0.04)`
- 聚焦：`2px solid var(--sk-focus-color, #0071E3)` 描边
- 用途：搜索栏、筛选控件

**媒体控件**
- 背景：`rgba(210, 210, 215, 0.64)`
- 文字：`rgba(0, 0, 0, 0.48)`
- 圆角：50%（圆形）
- 激活：scale(0.9)，背景切换
- 聚焦：`2px solid var(--sk-focus-color, #0071e3)` 描边，白底黑字
- 用途：播放/暂停、轮播箭头

### 卡片与容器
- 背景：`#f5f5f7`（浅色）或 `#272729`–`#2a2a2d`（深色）
- 边框：无（Apple 体系中边框很少见）
- 圆角：5px–8px
- 阴影：抬升产品卡片用 `rgba(0, 0, 0, 0.22) 3px 5px 30px 0px`
- 内容：居中，内边距慷慨
- 悬停：无标准悬停状态——卡片是静态的，其中的链接才是可交互的

### 导航
- 背景：`rgba(0, 0, 0, 0.8)`（半透明深色）+ `backdrop-filter: saturate(180%) blur(20px)`
- 高度：48px（紧凑）
- 文字：12px 白字，400 字重
- 激活：悬停时下划线
- 标志：Apple 标志（SVG）居中或左对齐，17x48px 视口
- 手机端：收纳为汉堡菜单带全屏浮层菜单
- 导航浮于内容之上，无论分区背景如何都保持深色半透明玻璃

### 图片处理
- 产品落在纯色块（黑或白）上——无背景、无语境，只有物件本身
- 全幅分区图片铺满整个视口宽度
- 极高分辨率的产品摄影带微妙阴影
- 生活方式图片收进圆角容器（12px+ 圆角）

### 标志性组件

**产品首屏模块**
- 全视口宽分区，纯色背景（黑或 `#f5f5f7`）
- 产品名作为主标题（SF Pro Display，56px，600 字重）
- 下方一句细体描述
- 两个胶囊 CTA 并排：「了解更多」（描边）与「购买」/「选购」（填充）

**产品网格贴片**
- 对比背景上的方形或近方形卡片
- 产品图占据贴片 60–70%
- 下方产品名 + 一句描述
- 底部「了解更多」与「选购」链接对

**特性对比条**
- 产品变体的横向滚动
- 每个变体为竖卡片：图片、名称、关键规格
- 极简铬饰——产品自己说话
## 5. 布局原则

### 间距系统
- 基准单位：8px
- 刻度：2px、4px、5px、6px、7px、8px、9px、10px、11px、14px、15px、17px、20px、24px
- 显著特征：刻度在小尺寸（2–11px）密集、1px 粒度，之后以更大的步长跳跃。允许对排印和图标对齐做精确的微调。

### 网格与容器
- 内容最大宽度：约 980px（胶囊按钮中反复出现的「980px 圆角」呼应了这个宽度）
- 首屏：全视口宽分区，内容块居中
- 产品网格：居中容器内 2–3 列布局
- 首屏时刻用单列——一个产品、一条信息、全部注意力
- 无可见的网格线或槽——间距构成隐含结构

### 留白哲学
- **电影般的呼吸感**：每个产品分区占据一整个视口高度（或接近）。产品之间的留白不是空的——它是电影中场景之间的停顿。
- **用色块形成纵向节奏**：Apple 不只用间距分隔分区，还用交替的背景色（黑、`#f5f5f7`、白）。每次换色都意味着一个新「场景」。
- **内部压缩、之间扩张**：文本块排得紧凑（负字间距、紧凑行高），而周围的空间浩瀚。这种密度与开阔之间的张力，正是设计的呼吸。

### 圆角刻度
- 微型（5px）：小容器、链接标签
- 标准（8px）：按钮、产品卡片、图片容器
- 舒适（11px）：搜索输入框、筛选按钮
- 大（12px）：特性面板、生活方式图片容器
- 全胶囊（980px）：CTA 链接（「了解更多」、「选购」）、导航胶囊
- 圆形（50%）：媒体控件（播放/暂停、箭头）

## 6. 纵深与层级（Depth & Elevation）

| 层级 | 处理 | 用途 |
|------|------|------|
| 平面（层级 0） | 无阴影，纯色背景 | 标准内容分区、文本块 |
| 导航玻璃 | `rgba(0,0,0,0.8)` 上的 `backdrop-filter: saturate(180%) blur(20px)` | 吸顶导航栏——玻璃效果 |
| 微妙抬升（层级 1） | `rgba(0, 0, 0, 0.22) 3px 5px 30px 0px` | 产品卡片、浮动元素 |
| 媒体控件 | `rgba(210, 210, 215, 0.64)` 背景 + 缩放变换 | 播放/暂停按钮、轮播控件 |
| 聚焦（无障碍） | `2px solid #0071e3` 描边 | 所有可交互元素的键盘聚焦 |

**阴影哲学**：Apple 极少用阴影。主阴影（`3px 5px 30px`，0.22 透明度）柔和、宽阔、带偏移——像弥散的影棚灯在实体下投出的自然阴影。这强化了「产品即实体雕塑」的隐喻。大多数元素完全没有阴影；层级来自背景色的对比（深色背景上的深色卡片，或略有差异的灰色上的浅色卡片）。

### 装饰性纵深
- 导航玻璃：半透明模糊的导航栏是最具辨识度的纵深元素，在滚动内容上方营造出浮动 UI 感
- 分区色彩过渡：纵深由黑与浅灰分区的交替暗示，而非阴影
- 产品摄影阴影：产品在照片中自带阴影，UI 无需再加人工阴影

## 7. 该做与不该做

### 该做
- 20px+ 用 SF Pro Display、20px 以下用 SF Pro Text——尊重光学尺寸分界
- 所有字号都用负字间距（不只标题）——Apple 全系统字距收紧
- 苹果蓝（Apple Blue）（`#0071e3`）只用于可交互元素——它必须是唯一的点缀色
- 黑与浅灰（`#f5f5f7`）分区背景交替，形成电影般的节奏
- CTA 链接用 980px 胶囊圆角——标志性的 Apple 链接形状
- 产品图放在纯色块上，不放竞争视觉元素
- 吸顶导航用半透明深色玻璃（`rgba(0,0,0,0.8)` + 模糊）
- 标题行高压缩到 1.07–1.14——Apple 标题以紧凑著称

### 不该做
- 不引入额外的点缀色——整个色彩预算都花在了蓝色上
- 不用厚重阴影或多层阴影——Apple 的阴影体系是一个柔和弥散阴影或干脆没有
- 卡片和容器不用边框——Apple 几乎不用可见边框（特定按钮除外）
- SF Pro 不用宽字距——它在每个字号下都为紧凑而设计
- 不用 800 或 900 字重——上限是 700（粗体），且即使 700 也少见
- 背景不加纹理、图案或渐变——只用纯色
- 导航不做不透明——玻璃模糊效果是 Apple UI 身份的核心
- 正文不居中——Apple 正文左对齐；只有标题居中
- 矩形元素圆角不超过 12px（980px 只给胶囊用）

## 8. 响应式行为

### 断点
| 名称 | 宽度 | 关键变化 |
|------|------|----------|
| 小手机 | <360px | 最低支持，单列 |
| 手机 | 360–480px | 标准手机布局 |
| 大手机 | 480–640px | 更宽的单列、更大的图片 |
| 小平板 | 640–834px | 2 列产品网格开始出现 |
| 平板 | 834–1024px | 完整平板布局、导航展开 |
| 小桌面 | 1024–1070px | 标准桌面布局开始 |
| 桌面 | 1070–1440px | 完整布局、内容最大宽度 |
| 大桌面 | >1440px | 居中，两侧宽边距 |

### 触控目标
- 主 CTA：8px 15px 内边距，形成约 44px 触控高度
- 导航链接：48px 高度，间距充足
- 媒体控件：50% 圆角圆形按钮，最小 44x44px
- 「了解更多」胶囊：内边距慷慨，点按舒适

### 收缩策略
- 首屏标题：56px Display → 40px → 手机端 28px，保持紧凑行高成比例
- 产品网格：3 列 → 2 列 → 单列堆叠
- 导航：完整横向导航 → 紧凑手机菜单（汉堡）
- 产品首屏模块：所有尺寸保持全幅，文字按比例缩小

### 迭代指南
1. 每个可交互元素都用苹果蓝（Apple Blue）（`#0071e3`）——不允许其他点缀色
