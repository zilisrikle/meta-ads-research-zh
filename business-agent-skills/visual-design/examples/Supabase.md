# 源自 Supabase 的设计系统

## 1. 视觉主题与氛围

Supabase 的网站是一个深色原生开发者平台，传递着高端代码编辑器的美学——深黑背景（`#0f0f0f`、`#171717`）配祖母绿点缀（`#3ecf8e`、`#00c573`），呼应品牌开源、PostgreSQL 绿的身份。设计系统仿佛诞生于终端窗口，又演化成精致的营销界面，而不丢失开发者灵魂。

排印（Typography）基于 "Circular"——一款几何无衬线体，圆端点软化了技术棱角。72px 配 1.00 行高的首屏文本被压缩到绝对最小的垂直空间，形成密集、有冲击力的陈述，毫不浪费。等宽伴侣（Source Code Pro）以大写技术标签的形式少量出现，配 1.2px 字间距，形成连接营销站与产品体验的"开发者控制台"标记。

Supabase 的独特之处在于精密的基于 HSL 的色彩令牌系统。Supabase 不用扁平十六进制值，而是对几乎每种颜色用带 alpha 通道的 HSL（`--colors-crimson4`、`--colors-purple5`、`--colors-slateA12`），实现细腻的分层系统，颜色通过透明度相互作用。这通过半透明创造深度——边框用 `rgba(46, 46, 46)`，表面用 `rgba(41, 41, 41, 0.84)`，点缀用部分不透明度，都与深色背景混合，用极简的色彩原料营造丰富、有维度的色板。

绿色点缀（`#3ecf8e`）选择性出现——在 Supabase 标志、链接色（`#00c573`）和边框高亮（`rgba(62, 207, 142, 0.3)`）中——永远作为"这是 Supabase"的信号，而非装饰元素。主 CTA 用胶囊形按钮（9999px 圆角），与次级元素的标准 6px 圆角形成对比，营造清晰的重要性视觉层级。

**关键特征：**
- 深色原生：近黑背景（`#0f0f0f`、`#171717`）——从不纯黑
- 祖母绿品牌点缀（`#3ecf8e`、`#00c573`）节制使用，作为身份标记
- Circular 字体——圆端点的几何无衬线体
- Source Code Pro 用于大写技术标签（1.2px 字间距）
- 基于 HSL 的色彩令牌系统，带 alpha 通道实现半透明分层
- 主 CTA 用胶囊按钮（9999px），次级用 6px 圆角
- 中性灰阶从 `#171717` 经 `#898989` 到 `#fafafa`
- 边框系统用深灰（`#2e2e2e`、`#363636`、`#393939`）
- 极简阴影——通过边框对比和透明度表现深度
- Radix 色彩原语（crimson、purple、violet、indigo、yellow、tomato、orange、slate）

## 2. 色彩体系与角色

### 品牌色
- **Supabase Green**（`#3ecf8e`）：主品牌色，标志、点缀边框
- **Green Link**（`#00c573`）：链接和操作的交互绿
- **Green Border**（`rgba(62, 207, 142, 0.3)`）：微妙的绿色边框点缀

### 中性阶梯（深色模式）
- **Near Black**（`#0f0f0f`）：主按钮背景，最深表面
- **Dark**（`#171717`）：页面背景，主画布
- **Dark Border**（`#242424`）：水平线、区块分隔
- **Border Dark**（`#2e2e2e`）：卡片边框、选项卡边框
- **Mid Border**（`#363636`）：按钮边框、分隔线
- **Border Light**（`#393939`）：次级边框
- **Charcoal**（`#434343`）：三级边框、深色点缀
- **Dark Gray**（`#4d4d4d`）：重次级文本
- **Mid Gray**（`#898989`）：弱化文本、链接色
- **Light Gray**（`#b4b4b4`）：次级链接文本
- **Near White**（`#efefef`）：浅边框、微妙表面
- **Off White**（`#fafafa`）：主文本、按钮文本

### Radix 色彩令牌（基于 HSL）
- **Slate Scale**：`--colors-slate5` 到 `--colors-slateA12`——中性渐进
- **Purple**：`--colors-purple4`、`--colors-purple5`、`--colors-purpleA7`——点缀光谱
- **Violet**：`--colors-violet10`（`hsl(251, 63.2%, 63.2%)`）——活力点缀
- **Crimson**：`--colors-crimson4`、`--colors-crimsonA9`——暖点缀/警示
- **Indigo**：`--colors-indigoA2`——微妙蓝色渲染
- **Yellow**：`--colors-yellowA7`——注意/警告
- **Tomato**：`--colors-tomatoA4`——错误点缀
- **Orange**：`--colors-orange6`——暖点缀

### 表面与叠加
- **Glass Dark**（`rgba(41, 41, 41, 0.84)`）：半透明深色叠加
- **Slate Alpha**（`hsla(210, 87.8%, 16.1%, 0.031)`）：极微妙蓝色渲染
- **Fixed Scale Alpha**（`hsla(200, 90.3%, 93.4%, 0.109)`）：浅霜叠加

### 阴影
- Supabase 在深色主题中**几乎不用阴影**。深度通过边框对比和表面色差而非盒阴影创造。焦点态用 `rgba(0, 0, 0, 0.1) 0px 4px 12px`——极简、功能化。

## 3. 排印规则

### 字体族
- **主要**：`Circular`，回退：`custom-font, Helvetica Neue, Helvetica, Arial`
- **等宽**：`Source Code Pro`，回退：`Office Code Pro, Menlo`

### 层级

| 角色 | 字体 | 字号 | 字重 | 行高 | 字间距 | 备注 |
|------|------|------|--------|-------------|----------|-------|
| 展示首屏 | Circular | 72px (4.50rem) | 400 | 1.00（紧） | normal | 最大密度、零浪费 |
| 章节标题 | Circular | 36px (2.25rem) | 400 | 1.25（紧） | normal | 功能区块标题 |
| 卡片标题 | Circular | 24px (1.50rem) | 400 | 1.33 | -0.16px | 轻微负字距 |
| 副标题 | Circular | 18px (1.13rem) | 400 | 1.56 | normal | 次级标题 |
| 正文 | Circular | 16px (1.00rem) | 400 | 1.50 | normal | 标准正文文本 |
| 导航链接 | Circular | 14px (0.88rem) | 500 | 1.00–1.43 | normal | 导航项 |
| 按钮 | Circular | 14px (0.88rem) | 500 | 1.14（紧） | normal | 按钮标签 |
| 说明文字 | Circular | 14px (0.88rem) | 400–500 | 1.43 | normal | 元数据、标签 |
| 小字 | Circular | 12px (0.75rem) | 400 | 1.33 | normal | 细则、页脚链接 |
| 代码标签 | Source Code Pro | 12px (0.75rem) | 400 | 1.33 | 1.2px | `text-transform: uppercase` |

### 原则
- **字重克制**：几乎所有文本用字重 400（常规/书体）。字重 500 只出现在导航链接和按钮标签。检测到的系统中没有粗体（700）——层级通过字号而非字重创造。
- **1.00 首屏行高**：首屏文本被压缩到绝对零行距。这是定义性的排印手势——文本像终端命令：密集、高效、不浪费垂直空间。
- **卡片负字距**：卡片标题用 -0.16px 字间距，微妙收紧，与正文区分而不明显。
- **等宽即仪式**：大写加 1.2px 字间距的 Source Code Pro 是"开发者控制台"语调——节制用于连接产品体验的技术标签。
- **几何个性**：Circular 的圆端点为可能冰冷的技术界面带来暖意。字体是人性化元素。

## 4. 组件样式

### 按钮

**主胶囊（深色）**
- 背景：`#0f0f0f`
- 文本：`#fafafa`
- 内边距：8px 32px
- 圆角：9999px（全胶囊）
- 边框：`1px solid #fafafa`（深色上白边框）
- 焦点阴影：`rgba(0, 0, 0, 0.1) 0px 4px 12px`
- 用途：主 CTA（"Start your project"）

**次级胶囊（深色、弱化）**
- 背景：`#0f0f0f`
- 文本：`#fafafa`
- 内边距：8px 32px
- 圆角：9999px
- 边框：`1px solid #2e2e2e`（深色边框）
- 不透明度：0.8
- 用途：主 CTA 旁的次级 CTA

**幽灵按钮**
- 背景：透明
- 文本：`#fafafa`
- 内边距：8px
- 圆角：6px
- 边框：`1px solid transparent`
- 用途：三级操作、图标按钮

### 卡片与容器
- 背景：深色表面（`#171717` 或稍浅）
- 边框：`1px solid #2e2e2e` 或 `#363636`
- 圆角：8px–16px
- 无可见阴影——边框定义边缘
- 内部内边距：16px–24px

### 选项卡
- 边框：`1px solid #2e2e2e`
- 圆角：9999px（胶囊选项卡）
- 激活：绿色点缀或更浅表面
- 非激活：深色、弱化

### 链接
- **绿色**：`#00c573`——Supabase 品牌链接
- **主浅色**：`#fafafa`——深色上的标准链接
- **次级**：`#b4b4b4`——弱化链接
- **弱化**：`#898989`——三级链接、页脚

### 导航
- 与页面匹配的深色背景（`#171717`）
- Supabase 标志配绿色图标
- 导航链接用 Circular 14px 字重 500
- 简洁横向布局，带产品下拉
- 绿色"Start your project" CTA 胶囊按钮
- 粘性页眉行为

## 5. 布局原则

### 间距系统
- 基础单位：8px
- 阶梯：1px、4px、6px、8px、12px、16px、20px、24px、32px、40px、48px、90px、96px、128px
- 显著的大跨度：主要区块间距 48px → 90px → 96px → 128px

### 网格与容器
- 居中内容，最大宽度慷慨
- 全宽深色区块，内部内容收敛
- 功能网格：图标式网格，卡片尺寸一致
- "Trusted by" 区块的标志网格
- 页脚：深色背景上的多列

### 断点
| 名称 | 宽度 | 关键变化 |
|------|-------|-------------|
| 移动端 | <600px | 单列、堆叠布局 |
| 桌面 | >600px | 多列网格、扩展布局 |

*注：Supabase 用显著极简的断点系统——主要是单个 600px 断点，暗示移动优先加渐进增强。*

### 留白（Whitespace）哲学
- **戏剧性区块间距**：主要区块间 90px–128px 营造电影般节奏——每个区块都是黑暗虚空中的独立场景。
- **密集内容块**：区块内部间距紧凑（16px–24px），形成集中的信息簇。
- **边框定义的空间**：Supabase 不用留白 + 阴影做分隔，而是用深色背景上的细边框——用线而非间隙分隔。

### 圆角阶梯
- 标准（6px）：幽灵按钮、小元素
- 舒适（8px）：卡片、容器
- 中（11px–12px）：中型面板
- 大（16px）：功能卡片、大容器
- 胶囊（9999px）：主按钮、选项卡指示

## 6. 深度与层级

| 层级 | 处理 | 用途 |
|-------|-----------|-----|
| 扁平（0 级） | 无阴影，边框 `#2e2e2e` | 默认态，大多数表面 |
| 微妙边框（1 级） | 边框 `#363636` 或 `#393939` | 交互元素、悬停 |
| 焦点（2 级） | `rgba(0, 0, 0, 0.1) 0px 4px 12px` | 仅焦点态 |
| 绿色点缀（3 级） | 边框 `rgba(62, 207, 142, 0.3)` | 品牌高亮元素 |

**阴影哲学**：Supabase 刻意避开阴影。在深色原生设计中，阴影几乎不可见，毫无作用。相反，深度通过精密的边框层级传达——从 `#242424`（几乎看不见）经 `#2e2e2e`（标准）到 `#393939`（突出）。绿色点缀边框（`rgba(62, 207, 142, 0.3)`）30% 不透明度是"抬升"态——品牌色本身成为深度信号。

## 7. 应该做与不应该做

### 应该做
- 用近黑背景（`#0f0f0f`、`#171717`）——深度来自灰色边框层级
- Supabase 绿（`#3ecf8e`、`#00c573`）节制使用——它是身份标记，不是装饰
- Circular 几乎一切用字重 400——500 只用于按钮和导航
- 首屏文本设为 1.00 行高——零行距是排印标志
- 通过边框色差创造深度（`#242424` → `#2e2e2e` → `#363636`）
- 胶囊形（9999px）只用于主 CTA 和选项卡
- 用带 alpha 的 HSL 色彩做半透明分层效果
- 开发者语境标记用 Source Code Pro 大写标签

### 不应该做
- 不加盒阴影——深色背景上不可见，还破坏边框定义的深度系统
- 不用粗体（700）字重——系统只用 400 和 500
- 绿色不用于背景或大表面——它用于边框、链接和小点缀
- 暖色（crimson、orange）不作主设计元素——它们是状态的语义令牌
- 首屏行高不高于 1.00——密度是刻意的
- 按钮不用大圆角（16px+）——胶囊（9999px）或标准（6px），两者之间没有
- 主表面背景不浅于 `#171717`——黑暗是结构性的
- 不忘半透明边框——`rgba` 边框色是分层机制

## 8. 响应式行为

### 断点
| 名称 | 宽度 | 关键变化 |
|------|-------|-------------|
| 移动端 | <600px | 单列、堆叠功能、压缩导航 |
| 桌面 | >600px | 多列网格、完整导航、扩展区块 |

### 折叠策略
- 首屏：72px → 按比例缩小
- 功能网格：多列 → 单列堆叠
- 标志行：横向 → 环绕网格
- 导航：完整 → 汉堡
- 区块间距：90–128px → 48–64px
- 按钮：行内 → 全宽堆叠
