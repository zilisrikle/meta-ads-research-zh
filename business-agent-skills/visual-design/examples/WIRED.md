# 受 WIRED 启发的设计系统

## 1. 视觉主题与氛围

WIRED 的首页像一份接了电源的印刷大报。网格密集、线条纤细、字体响亮，几乎每个表面都是纸白或纯黑：无圆角、无任何不配拥有位置的装饰。图片矩形直接顶着标题，发丝分隔线像真正的杂志里用 pica 尺分隔栏位那样分隔故事，除了摄影本身，页面上没有任何灰度之外的颜色。这里没有「带阴影的卡片」——整个布局靠排印（typography）重量与线条、留白（whitespace）的纪律撑起，就像 Condé Nast 印张在拼版室里组装出来的样子。

标志性动作是**排印堆叠**：主标题用极其巨大的定制衬线体（serif）（WiredDisplay），正文与导语用人文主义衬线（BreveText），UI 示能用几何无衬线（Apercu），每篇故事的眉题（kicker）、眉标与时间戳用硬朗的等宽大写（WiredMono）。那个等宽眉题——通常是黑底大写，字间距宽得像盖革计数器的滴答声——是 WIRED 页面隔着房间一眼可辨的原因。

真正重要的点缀色只有一个：饱和的链接蓝（`#057dbc`），悬停时像 CRT 扫描线一样亮起下划线。其余只有黑、纸白和两种灰——这份设计的自信来自拒绝发明更多颜色。

**关键特征：**
- 报摊密度的编辑网格：线条与留白，绝不用卡片或阴影
- 定制衬线展示 + 技术等宽眉题——Condé-Nast 遇上工程实验室的声音
- 每张图片、每个容器、每条缎带都严格直角（只有图标按钮是圆形）
- 按钮与链接用 2px 硬黑边框——印刷感，而非网页感
- 每篇故事配等宽全大写眉标，宽字距（0.9–1.2px）
- 链接用单一墨蓝点缀；其余活在纯灰度里
- 深色主题 = *页脚*，而非页面；页面本身坚守纸白

## 2. 色彩体系与角色

### 主色（编辑墨）
- **WIRED 黑**（`#000000`）：纯墨，用于缎带、区块分隔、按钮边框、标题线——页面上最重的一笔。
- **页面墨**（`#1a1a1a`）：近黑，用于标题与正文。略柔和，长文阅读不至于像盯着电源键。
- **纸白**（`#ffffff`）：全站默认画布。把它当新闻纸纸张看待——不间断、永不染色。

### 辅助（编辑声音）
- **链接蓝**（`#057dbc`）：唯一的品牌点缀。用于内联链接悬停、面包屑（breadcrumb）与极少数按钮——绝不用作背景、绝不装饰。把它想成黑白电影里唯一被允许的颜色。

### 表面与背景
- **新闻纸**（`#ffffff`）：编辑页面、故事网格、首屏区。
- **页脚墨**（`#1a1a1a`）：首页唯一的反转区。纸白字浮在上面。
- **发丝淡彩**（`#e2e8f0`）：专用于区块间的 `<hr>`——几乎不可见，像页边线。

### 中性色与文本
- **标题黑**（`#1a1a1a`）：所有 H1/H2 展示字。
- **正文灰**（`#1a1a1a`）：长文正文——与标题同墨以求统一。
- **说明灰**（`#757575`）：次级元数据：署名、时间戳、图片 credit。
- **禁用灰**（`#999999`）：未激活链接、低优先级标签。
- **发丝边框**（`#e2e8f0`）：仅作微妙分隔。

### 语义色与点缀色
- **品牌悬停蓝**（`#057dbc`）：链接翻转态——也是唯一的「可交互」提示。
- *（WIRED 首页刻意省略语义成功/错误/警告色板——这是编辑部，不是 SaaS 仪表盘。）*

### 渐变系统
无。WIRED 用零渐变。页面上最接近渐变的东西，是照片内部的色调范围——渐变活在*影像*里，不在界面铬里。

## 3. 排印规则

### 字体家族
- **WiredDisplay**（定制衬线，回退 `helvetica`）——展示标题与特稿标题。
- **BreveText**（人文主义衬线，回退 `helvetica`）——文章正文、导语、较长说明。
- **Apercu**（几何无衬线，回退 `helvetica`）——UI 标签、按钮、导航、中字重标题。
- **WiredMono**（定制等宽，回退 `helvetica`）——眉标、眉题、时间戳、区块标签，全大写。
- **Inter**（无衬线，系统回退）——新模块的工具 UI。
- **ProximaNova**（无衬线，回退 `helvetica`）——历史遗留 UI 表面。
- **WIRED Mono**（定制等宽，回退 `Monaco, Courier New, Courier`）——文章页眉题。

### 层级

| 角色（Role） | 字体（Font） | 字号（Size） | 字重（Weight） | 行高（Line Height） | 字间距（Letter Spacing） | 说明（Notes） |
|---|---|---|---|---|---|---|
| 展示标题（首屏） | WiredDisplay | 64px / 4.00rem | regular | 0.93 | -0.5px | 紧凑，几乎碰到下行字母——报摊气场 |
| 展示标题（移动 / 中） | WiredDisplay | 26px / 1.63rem | regular | 1.08 | — | 同一字体，为网格块缩小 |
| 区块标题 | Apercu | 20px / 1.25rem | 700 | 1.20 | -0.28px | 模块标题用粗无衬线（「Most Popular」「Featured」） |
| 副标题 | Apercu | 17px / 1.06rem | 700 | 1.29 | -0.144px | 特稿块内的故事导语 |
| 文章导语（衬线） | BreveText | 19px / 1.19rem | regular | 1.47 | 0.108px | 长文 lead 段落 |

| Inter UI 说明 | Inter | 14px / 0.88rem | 600 | 1.40 | — | 紧凑 UI 元数据 |

### 原则
- **四张脸，四个活。**WiredDisplay 负责喊，BreveText 负责读，Apercu 负责点，WiredMono 负责贴标签。它们从不互换角色。这种分工让页面不至于像字体样张。
- **标题紧凑、正文宽裕。**展示字行低至 0.93（几乎相碰），而正文 BreveText 放到 1.47–1.50。这种对比就是编辑指纹。
- **等宽永远大写。**每次 WiredMono 出场都带 `text-transform: uppercase` 与 0.9–1.2px 字间距。把小写等宽当坏掉处理——它不该出现在 WIRED 页面上。
- **粗体罕见。**Apercu 只在 UI 强调处用字重 700；编辑层（Display + BreveText）完全靠字号与墨色，绝不靠加粗。
- **字间距有两个档位**：全大写等宽用正值（0.9–1.2px），大展示衬线用负值（-0.144 到 -0.5px）。最大号字上绝不用中性值。

### 关于字体替代的说明
层级表中的行高值（尤其是 64px 首屏的 0.93）假设使用**专有的 WiredDisplay 与 BreveText**，这两套字体的度量紧凑、升部/降部短。若用度量宽的开源字体如 **Playfair Display** 或 **Libre Caslon** 替代，展示行高约放宽 **+0.10 到 +0.12**，防止换行时升部/降部碰撞（如 0.93 → 1.05、1.08 → 1.18）。Apercu 替代（Inter、Work Sans、Manrope）可直接用 token 值，无需调整。正文 BreveText 替代（Lora、Source Serif 4）也无需调整，因为正文行距本就宽裕。

## 4. 组件样式

### 按钮

**主 CTA——黑描边（「Subscribe」）**
- 背景：`#ffffff`（纸白）
- 文字：`#000000`（WIRED 黑），Apercu 16px / 700 / 0.3px 字距
- 边框：`2px solid #000000`——印刷式硬线，不是 1px UI 边框
- 圆角：`0`（直角）
- 内边距：垂直约 12–14px，水平约 24px
- 悬停：背景翻为 `#000000`，文字翻为 `#ffffff`——纯反转，线上无缓动
- 过渡：仅颜色/背景约 150ms

**次按钮——反白（深色区的「Sign In」）**
- 背景：`#000000`
- 文字：`#ffffff`
- 边框：`2px solid #ffffff`
- 同样直角，悬停同样反转

**三级——下划线内联链接**
- 包在导航里时按按钮处理：文字 `#1a1a1a`，下划线常在，悬停变 `#057dbc` 且保留下划线
- 无内边距、无边框、无背景——这是编辑链接，不是 UI

**胶囊 / 圆形图标按钮**
- 圆角：`50%`（全站唯一的圆形）
- 专用于头部图标控件（搜索、账号、社交）
- 边框：`1px solid #757575` 或依位置无边框
- 尺寸：约 32–40px 方形占位

**标签 / Span 胶囊**
- 圆角：`1920px`（实际全胶囊——只用在「BREAKING」这类文本 span 内）
- 背景：纯黑或依语境的红点缀
- 文字：白色，等宽 11–12px 大写

### 卡片与容器
- **卡片不存在。**WIRED 首页没有圆角盒子、没有阴影、没有表面阴影层级。
- 一个「故事 tile」只是图片矩形叠在眉题 + 标题 + 导语之上，与邻居以 **1px 发丝线**（`#000000` 或 `#4a5568`）或纯留白分隔。
- 最接近「容器」的是黑色缎带区块头（如「MOST POPULAR」）——全宽黑条，内嵌白色 WiredMono 大写，无内边距打磨，无圆角收尾。
- 故事 tile 的悬停行为：标题链接文字从 `#1a1a1a` 变为 `#057dbc` 并出现下划线。图片本身不缩放、不抬升、不加阴影。

### 输入框与表单
- **订阅输入框**：矩形，`2px solid #000000` 边框，`0` 圆角，白底，Apercu 16px 占位符。
- **聚焦**：边框保持 2px 黑，无辉光环、无变色——聚焦只靠闪烁的光标示意。（如果落地，请加 2px 外扩以满足无障碍——WIRED 自家实现在这里亏待了键盘用户。）
- **错误**：下方文字标签用 `#e53e3e`（Fides cookie 浮层借了这个红——节制使用）。
- **禁用**：文字降到 `#a0aec0`，边框柔化为 `#757575`。

### 导航
- **顶部工具条**：黑色（`#000000`）通栏，约 32–40px 高，等宽大写链接以发丝分隔线隔开，`#ffffff` 文字，悬停 → `#057dbc`。
- **主导航**：bug 标志下方的纸白（`#ffffff`）行，Apercu 14–16px / regular，悬停 → `#057dbc` 下划线。
- **标志**：WIRED bug，约 209×42px，居中或左对齐，绝不换色，永远白底纯黑。
- **移动端**：导航在 bug 标志左侧收起为汉堡菜单。区块导航变为等宽大写链接的下滑抽屉。
- **过渡**：悬停换色即时或约 120ms；无弹性缓动——编辑克制。

### 图片处理
- **宽高比**：首屏图多为 16:9，网格故事 tile 为 4:3，「Most Popular」小图为 1:1。
- **圆角**：永远 0。直角。唯一圆角图片是圆形作者头像（50%）。
- **通栏**：首屏照片撑满所在列的边缘；无内缩、无边框。
- **说明**：BreveText 12.73px / 700，行高宽松 2.20——紧贴图片下方，部分模板斜体。
- **悬停**：不缩放、不透明度变化——只有图片下方的标题响应。
- **懒加载**：首屏以下图片标准 `loading="lazy"`。

### 编辑缎带与区块标记
- 黑条（`#000000`）通栏，内嵌白色 WiredMono 大写标签（如「MOST POPULAR」「BACKCHANNEL」「GEAR」）。
- 高约 32–40px，无内边距打磨，无圆角收尾。
- 有时上下各一条 2px 黑线，把黑条双框起来。

### 编号列表（「Most Popular」）
- 故事垂直列表，前缀 WiredDisplay 数字（01、02、03…）约 40–48px，紧贴所标标题。
- 每项之间发丝线分隔，别无装饰。

## 5. 布局原则

### 间距系统
- **基准单位**：8px。
- **刻度**：1px（发丝）、4px、8px、12px、14.11px、15px、16px、24px、25.46px、29.66px、32px、40px、48px、64px。
- **区块内边距**：主编辑块之间垂直通常 32–48px。
- **卡片内边距**：没有卡片；故事 tile 之间水平槽 24–32px，垂直 16–24px。
- **内联间距**：眉题在标题上约 4–8px；导语在标题下约 8–12px；署名/时间戳在导语下再 8–12px。

### 网格与容器
- **最大宽度**：桌面约 1280–1600px（dembrandt 扫描检测到断点达 1600px），居中，外边距宽裕。
- **列模式**：12 列网格，依模块解析为 2/3/4 列故事排布——特稿块常用「1 大 + 2 小」模式，之间以发丝线分隔。
- **列槽**：约 24–32px，在编辑逻辑需要「折页感」处以发丝 `#000000` 或 `#4a5568` 1px 线分隔。

### 留白哲学
WIRED 对待留白（whitespace）就像杂志美术指导对待页边：它是字体周围的沉默，不是造型选择。页面从不过度呼吸（这不是 Stripe 或 Apple）；它*编辑式地*呼吸——相邻故事不吵架的余量刚好，绝不留出「页面空了」的暗示。如果一块空白看起来能再塞个标题，那块空白就是称职的。

### 圆角刻度
- `0`——每个容器、每张图片、每个按钮、每个输入框。默认。
- `1920px`——只在需要全胶囊观感的文本 span 内（「BREAKING」「LIVE」）。
- `50%`——只用于圆形图标按钮与圆形作者头像。

全站恰好三个圆角，其中两个留给非矩形。这是所有主流编辑产品中最严的**直角纪律**。

## 6. 纵深与阴影层级

| 层级（Level） | 处理（Treatment） | 用途（Use） |
|---|---|---|
| 0 | 无阴影、无边框 | 默认编辑表面——纸上文字 |
| 1 | 1px solid `#e2e8f0` 发丝 `<hr>` | 安静的区块分隔，几乎不可见 |
| 2 | 1px solid `#000000` 发丝线 | 编辑分栏线——印刷式、结构性 |
| 3 | 2px solid `#000000` 边框 | 按钮、输入框、缎带——交互强调 |
| 4 | 黑缎带条（`#000000` 填充） | 区块标签——页面上「最高」的表面 |
| 5 | 反转页脚块 | 深 `#1a1a1a` 区配白字——唯一的反转 |

WIRED 的纵深哲学是**宗教般的扁平**。全站恰好一个阴影 token（默认 `0 0 0 transparent` 占位），故事 tile、头部、弹窗、卡片一概不加 `box-shadow`。纵深靠**线重**表达（1px 发丝 → 2px 硬线 → 纯黑缎带），而非模拟光照。

### 装饰性纵深
无。无渐变、无辉光、无光晕，标准图片说明渐变之外无罩染。WIRED 的视觉趣味来自摄影与排印对比，不来自界面铬。

## 7. 要做与不要做

### 要做
- **要**在每个主按钮上用 2px 硬黑边框——不要 1px 的柔、不要圆角。
- **要**在每篇故事标题上方放 WiredMono 全大写眉题（上 4–8px，0.9–1.2px 字距）。
- **要**对超过两行的段落用 BreveText——Apercu 是 UI 字体，不负责阅读。
- **要**让图片直角、顶边、说明紧贴底边。
- **要**以发丝线或留白分隔故事 tile，绝不用卡片或阴影。
- **要**只在页脚、缎带与工具导航条做反转（黑底白字）。
- **要**把 `#057dbc` 链接蓝专用于悬停态——绝不做背景或按钮填充。
- **要**把标题字号拉开：首屏 64px，网格块 26px，绝不取 32px 的「安全中间值」。

### 不要做
- **不要**给任何东西加 `box-shadow`。永远。WIRED 不发货阴影。
- **不要**给矩形容器倒圆角——`border-radius: 0` 是法律。
- **不要**在一个角色内混字体：WiredDisplay 永不排正文，BreveText 永不排按钮。
- **不要**在灰度 + `#057dbc` 之外用色。没有橙色 CTA，没有绿色成功胶囊。
- **不要**用小写 Apercu 做眉题——那是 WiredMono 的活，而且必须大写。
- **不要**用渐变、模糊、玻璃拟态或氛围效果——它们破坏印刷契约。
- **不要**依赖悬停抬升效果。WIRED 的悬停只是文字换色，仅此而已。
- **不要**发明新的胶囊形。圆 = 只给图标。胶囊 = 只给内联文本 span。其余一律直角。

## 8. 响应式行为

### 断点

| 名称（Name） | 宽度（Width） | 关键变化（Key Changes） |
|---|---|---|
| 小手机 | <375px | 单列，汉堡导航，所有首屏模块收起为图-标题-导语堆叠 |
| 手机 | 375–767px | 单列，故事网格变垂直滚动，「Most Popular」数字缩到 32px |
| 平板 | 768–1023px | 2 列故事网格，侧栏收到主信息流下方，导航变紧凑 |
| 桌面 | 1024–1599px | 完整编辑 3–4 列网格，侧栏恢复，标题最大字号激活 |
| 大桌面 | ≥1600px | 页面上限约 1600px 容器，留白向边距扩展，不再放大 |

dembrandt 扫描检测到一串不寻常的中间断点（1280、1025、1024、1023、768、767、667、599、570、569、480、425、375、320、319）——WIRED 的网格在几乎每个常见视口都微调，尤其 iPad 竖横屏交界处。

### 触控目标
- 主按钮：最小约 44x44px（16px 文字 + 12–14px 垂直内边距满足 WCAG AAA）。
- 工具条里的等宽大写链接较小（高约 32px）——WIRED 自家实现在这里没达到 WCAG。**衍生作品请把等宽导航链接撑到 44px。**
- 头部圆形图标按钮约 40px 圆，触控友好。

### 收起策略
- **导航**：768px 以下工具条消失；主导航收进汉堡抽屉。移动端 bug 标志居中。
- **网格**：4 列 → 3 列 → 2 列 → 1 列随视口收紧。每种列数之间发丝线都在，印刷感在收起中存活。
- **间距**：模块间垂直节奏移动端从 48px → 32px → 24px 收紧。页面水平内边距从 64px → 24px → 16px 收缩。
- **字体**：WiredDisplay 首屏从 64px 缩到移动端约 36–42px，标题从 26px 到约 22px，眉题锁定 12–13px（等宽大写再缩就不可读了）。

### 图片行为
- 所有图片响应式位图（`srcset` 驱动），宽高比保持：16:9 首屏、4:3 中图、1:1 缩略图。
- 无视觉指导切换——同一裁剪跨断点缩放。
- 首屏以下全部 `loading="lazy"`，仅首屏 `eager`。

### 快速色彩参考
- **主墨（文字 + 缎带）**：「WIRED 黑（`#000000`）」
- **页面画布**：「纸白（`#ffffff`）」
- **标题 / 正文**：「页面墨（`#1a1a1a`）」
- **说明 / 元数据**：「说明灰（`#757575`）」
- **发丝 / 安静边框**：「发丝淡彩（`#e2e8f0`）」
- **链接悬停点缀（唯一的颜色）**：「链接蓝（`#057dbc`）」

### 示例组件提示词
1. *「创建编辑故事 tile：16:9 图片（直角），标题上方 `#1a1a1a` 的大写 WiredMono 眉题，26px WiredDisplay 标题。用 1px 黑发丝线与邻居分隔。无卡片、无阴影、无圆角。」*

3. *「构建『Most Popular』模块：全宽黑缎带头配白色 WiredMono 大写标签，接着编号列表（01–05），用 40px WiredDisplay 数字与 17px Apercu 700 标题，以发丝线分隔。」*
4. *「创建订阅表单：2px 纯黑边框输入框，无圆角，Apercu 16px 占位符 `#757575`，旁边配反白黑提交按钮。」*
5. *「设计 `#1a1a1a` 页脚：纸白三级导航 ProximaNova 11px，悬停色 `#057dbc`，区块顶部居中 WIRED bug 标志。」*

### 迭代指南
用该设计系统打磨已有界面时：
1. **先审计圆角。**看到 `0`、`50%`（图标/头像）、`1920px`（文本胶囊）之外的任何 `border-radius`，一律拍平。圆角是最常见的错误。
2. **审计阴影。**剥掉所有 `box-shadow`。tile 需要「浮起」感时，用 2px 黑边框或发丝线代替。
3. **审计字体角色。**确保 WiredDisplay 只排标题、BreveText 只排阅读正文、Apercu 只排 UI、WiredMono 只排全大写标签。角色互换瞬间破音。
4. **审计色彩蔓延。**界面铬（非摄影）中出现 `#000`、`#1a1a1a`、`#757575`、`#e2e8f0`、`#ffffff`、`#057dbc` 之外的颜色就删掉。WIRED 的克制不可妥协。
5. **审计眉题。**每篇故事都应有大写等宽眉题。没有它，页面读起来像普通博客，不像 WIRED。
6. **审计线条。**两个故事或模块相接而无明确视觉断点处，加发丝 `1px solid #000` 分隔。线条是结缔组织。
