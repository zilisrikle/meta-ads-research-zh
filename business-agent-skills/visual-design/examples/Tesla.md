# 受 Tesla 启发的设计系统

## 1. 视觉主题与氛围

Tesla 的网站是一场极致减法的练习——数字展厅里产品即一切，界面近乎于无。页面以全视口首屏（hero）开场，整屏铺满电影感汽车摄影：三辆车列在抛光混凝土地面上，背景是雾蒙蒙的城市天际线，半透明白字悬浮着单个车型名。没有装饰边框、没有渐变、没有图案、没有阴影。UI 的存在只是为了提供刚好够用的导航结构，然后让路。不是产品影像的每个像素都是留白（whitespace），而这种克制正是该设计系统最有力的宣言。

色彩哲学近乎苦行：一个蓝色（`#3E6AE1`）给主行动号召（call-to-action），三种深灰给文字层级，其余全白。全部情感重量由摄影承载——铺展的风景照、影棚打光的车辆侧影、氛围感环境构图，每块视口高度的区块都边缘到边缘铺满。UI 铬溶进影像里。导航栏浮在首屏之上，无可见背景、无边框、无阴影——TESLA 字母标志与五个导航标签就那样存在于空间中，相信下方的内容自会提供足够对比。

排印最近从 Gotham 切换到 Universal Sans——定制家族拆成标题用「Display」、正文/UI 用「Text」——把网站、移动 App 与车机软件统一为单一排印声音。Display 变体以 40px 字重 500 渲染首屏标题，Text 变体处理从导航（14px/500）到正文（14px/400）的一切。该字体带着几何的精确与略带人文主义的终端，感觉像工程产物而非设计作品——恰好匹配 Tesla「技术无需自我宣告」的品牌身份。没有文字阴影、没有文字渐变、没有装饰性字体处理。每个字母都靠清晰赢得位置。

**关键特征：**
- 全视口首屏区块（100vh），电影感汽车摄影主导，叠加 UI 极简
- 近零 UI 装饰：页面任何地方无阴影、无渐变、无边框、无图案
- 单一强调色——电光蓝（Electric Blue）（`#3E6AE1`）——专用于主 CTA 按钮
- Universal Sans 字体家族（Display + Text）统一网页、App 与车机界面
- 摄影优先呈现，产品影像承载全部情感重量
- 磨砂玻璃导航概念，透明/白导航浮于首屏内容之上
- 0.33s cubic-bezier 过渡作为所有交互状态变化的通用时长
- 轮播（carousel）驱动的首屏，圆点指示器 + 边缘箭头导航展示多款车型
- 「Ask a Question」常驻聊天机器人条锚定在视口底部

## 2. 色彩体系与角色

### 主色
- **电光蓝**（`#3E6AE1`）：主 CTA 按钮背景——自信的中饱和蓝（rgb 62, 106, 225），作为整个界面唯一的彩色独立存在。专用于「Order Now」等主动作按钮
- **纯白**（`#FFFFFF`）：所有表面、面板、导航与次按钮填充的主导背景色——让摄影呼吸的画布

### 辅助色与点缀色
- **促销蓝**（`#3E6AE1`）：蓝色也用于首屏影像上的促销文字（「0% APR Available」），与 CTA 同色——在激励信息与行动之间建立视觉关联
- 不存在次级点缀色。Tesla 刻意避免色彩多样性，以维持极致的视觉纪律

### 表面与背景
- **白画布**（`#FFFFFF`）：页面背景、导航面板、下拉菜单与所有表面容器
- **浅灰烬**（`#F4F4F4`）：区块区分的微妙替代表面——与纯白几乎不可察的偏移（rgb 244, 244, 244）
- **碳黑**（`#171A20`）：首屏文字叠加的深色表面，也用于潜在深色模式语境（rgb 23, 26, 32）——带蓝底调的暖近黑
- **磨砂玻璃**（`rgba(255, 255, 255, 0.75)`）：滚动时导航背景滤镜（backdrop-filter）效果的半透明白

### 中性色与文本
- **碳黑**（`#171A20`）：主标题与导航文字——最深的文字值（rgb 23, 26, 32），用于浅底上的车型名、导航标签与首屏标题
- **石墨**（`#393C41`）：正文与次级内容（rgb 57, 60, 65）——默认段落色，比纯灰略暖
- **锡灰**（`#5C5E62`）：三级文字，用于「Learn」「Order」等次级链接（rgb 92, 94, 98）
- **银雾**（`#8E8E8E`）：输入框占位文字与禁用态（rgb 142, 142, 142）
- **云灰**（`#EEEEEE`）：浅边框与分隔线（rgb 238, 238, 238）
- **淡银**（`#D0D1D2`）：微妙 UI 边框与分界（rgb 208, 209, 210）

### 语义色与点缀色
- Tesla 营销站避免语义色彩编码（无绿/红/黄状态指示）。表单语境中的错误、成功、警告态遵循浏览器默认
- 蓝色 CTA（`#3E6AE1`）是唯一的交互色彩信号

### 渐变系统
- 界面任何地方都不用渐变
- 纵深（depth）完全靠摄影、留白，以及全幅影像与干净白表面之间的二元对比实现
- 导航靠不透明度（磨砂玻璃效果）而非渐变或阴影实现分层

## 3. 排印规则

### 字体家族
- **Universal-Sans-Text**：主正文与 UI 字体（字体加载失败时回退到系统栈）
- **Universal-Sans-Display**：展示/标题字体——首屏标题与大车型名
- **系统回退**：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`——字体文件加载失败时的通用系统字体
- OpenType 功能：标题层级无显式风格集激活

### 层级

| 角色（Role） | 字号（Size） | 字重（Weight） | 行高（Line Height） | 字间距（Letter Spacing） | 说明（Notes） |
|---|---|---|---|---|---|
| 首屏展示标题（Display） | 40px | 500 | 48px（1.2） | -0.5px | 半透明白色，用于首屏影像上的车型名 |
| 首屏副标题（Display） | 28px | 500 | 36px | -0.5px | 与首屏标题紧接的副标题 |
| 页内展示 | 34px | 500 | 44px | -0.6px | 用于页面区块的 Display 变体标题 |
| 一级标题 | 28px | 500 | 36px（1.29） | -0.5px | 用 Display 变体的大区块标题 |
| 二级标题 | 24px | 500 | 28px（1.17） | -0.5px | Display 变体——区块标题 |
| 三级标题 | 20px | 500 | 28px（1.4） | -0.5px | Display 变体——小区块标题 |
| 四级标题 | 17px | 500 | 24px（1.41） | -0.5px | Text 变体——紧凑标题 |
| 五级标题 | 14px | 500 | 20px（1.43） | -0.1px | Text 变体——最小标题 |
| 六级标题 | 12px | 500 | 20px（1.67） | -0.1px | Text 变体——眉题层级 |
| 正文 | 14px | 400 | 20px（1.43） | 0 | 默认正文色为 #393C41 |
| 正文大 | 16px | 400 | 24px（1.5） | 0 | 长段落用 |
| 按钮/CTA | 14px | 500 | 20px（1.43） | 0 | 全大写，用在蓝色 CTA 与描边按钮上 |
| 说明文字 | 12px | 400 | 16px（1.33） | 0 | 页脚文字、元数据、表单说明 |
| 导航标签 | 14px | 500 | 20px（1.43） | 0 | 主导航与页脚链接 |

### 原则
- **全部标题字间距为负**（-0.5px 到 -0.6px），营造大字号下的紧密精确观感
- **字重几乎全是 500**——系统不用粗黑体制造强调；层级仅靠字号与颜色实现
- **Display 与 Text 变体分工明确**：h1–h3 用 Display（28–40px），h4–h6 用 Text（12–17px）
- **按钮文字全大写**（「ORDER NOW」「LEARN MORE」），正文全小写
- **行高偏紧**（1.17–1.5），强化工程般的紧凑感

### 关于字体替代的说明
Universal Sans 是 Tesla 专有定制字体（从 Apple Sans 演进而来，2023 年推出），Google Fonts 尚无。若需匹配外观：
- **Inter**（Google Fonts）——最接近的几何人文主义无衬线，支持字重 500
- **Manrope** 或 **Space Grotesk**——类似技术感几何气质
- 需特别注意：Tesla 的 `-0.5px` 负字距与 500 字重的「标题」外观——Inter 的 Medium（500）加 `letter-spacing: -0.5px` 能逼近，但 Universal Sans 的字形更窄、升部更短

## 4. 组件样式

### 按钮

**主按钮——「Order Now」**
- 背景：电光蓝（`#3E6AE1`）
- 文字：纯白（`#FFFFFF`）
- 边框：`3px solid #3E6AE1`（略厚于常见的 1–2px——签名式处理）
- 圆角：`4px`——轻微打磨，不圆润
- 内边距：`8px 24px`
- 字体：Universal-Sans-Text，14px，字重 500，全大写
- 悬停：背景色维持 `#3E6AE1` 不变；不翻转为深色——Tesla 的悬停态极为克制，仅靠光标与微妙亮度变化示能
- 过渡：`0.33s cubic-bezier(0.5, 0, 0, 0.75)`——标准缓动曲线
- 焦点：`2px` 外扩描边（无障碍）

**次按钮——「Learn More」/「Demo Drive」**
- 背景：`rgba(244, 244, 244, 0.65)`——半透明白（影像上的描边风）或描边样式
- 文字：碳黑（`#171A20`）
- 边框：`3px solid #171A20` 或当前文字色
- 圆角：`4px`
- 内边距：`8px 24px`
- 字体：Universal-Sans-Text，14px，字重 500，全大写
- 与主按钮并排出现，形成主/次动作对比

**描边按钮变体（页脚/工具区）**
- 背景：透明或纯白
- 文字：`#171A20` 或 `#393C41`
- 边框：`1px solid #D0D1D2`（比 CTA 边框细——次级信号）
- 圆角：`4px`
- 内边距：`8px 16px`
- 字体：14px，字重 400–500，非全大写

**按钮的签名细节：**
- 3px 边框在同类产品中独一无二——大多数系统用 1–2px；Tesla 的 3px 赋予按钮微妙的「工程机械」感
- 按钮不依赖阴影表现可点击性——仅靠色彩与边框
- 悬停态无背景色翻转——违反常规做法，是识别该系统的快速方法

### 卡片与容器

Tesla 基本不用卡片。内容靠以下方式组织：

**全视口首屏区块**
- 高度：`100vh`
- 背景：全幅产品摄影（edge-to-edge）
- 内容：底部居中的标题 + 副标题 + 双按钮行
- 文字叠加：白色半透明（`rgba(255, 255, 255, 0.9)`）标题，配深色影像背景

**促销横幅**
- 位于主导航下方、首屏上方的全宽条
- 背景：透明（浮于首屏影像上）或纯白
- 文字：「0% APR Available」等促销信息，电光蓝（`#3E6AE1`）14px/500
- 无边框、无背景填充——仅靠文字颜色与位置示意

**产品展示区块**
- 全幅影像 + 底部文字叠加
- 影像边缘到边缘，无内边距、无圆角、无阴影
- 文字：白色，Display 变体
- CTA 行：主蓝按钮 + 次描边按钮

**下拉面板（导航菜单）**
- 背景：纯白（`#FFFFFF`）
- 阴影：无——仅靠位置与内容示意（Tesla 连下拉都不加阴影）
- 边框：`1px solid #EEEEEE`（极淡）
- 圆角：`4px`
- 内边距：`16px 24px`

### 输入框与表单

**文本输入框**
- 背景：纯白（`#FFFFFF`）
- 边框：`1px solid #D0D1D2`
- 圆角：`4px`
- 内边距：`11px 12px`
- 字体：Universal-Sans-Text，14px，字重 400
- 占位文字：`#8E8E8E`，14px
- 聚焦：边框变为 `#171A20`（2px），无辉光环
- 过渡：`0.33s cubic-bezier(0.5, 0, 0, 0.75)`

**选择框/下拉**
- 与文本输入框相同样式，右侧配下箭头图标（`#5C5E62`）
- 选项列表：白底，无阴影，`1px solid #EEEEEE` 边框

**复选框/单选**
- 尺寸：`20px × 20px`
- 边框：`1px solid #8E8E8E`，圆角 `4px`（复选框）/ `50%`（单选）
- 选中：电光蓝（`#3E6AE1`）填充，白色对勾/圆点

**表单标签**
- 字体：Universal-Sans-Text，14px，字重 500，`#171A20`
- 位置：输入框上方，间距 `8px`
- 必填标记：`*`，电光蓝或红色（依语境）

### 导航

**主导航（浮于首屏）**
- 背景：透明——直接浮于首屏影像之上
- 滚动后：`rgba(255, 255, 255, 0.75)` 磨砂玻璃（backdrop-filter: blur）
- 高度：`56px`
- 布局：左为 TESLA 字母标志（约 120×24px），中为五个导航标签（Vehicles、Energy、Charging、Discover、Shop），右为搜索/账号/菜单图标
- 导航标签：Universal-Sans-Text，14px，字重 500，`#171A20`（影像上时为白色）
- 悬停：标签得 `rgba(0, 0, 0, 0.05)` 圆角背景（`4px`），无下划线
- 无边框、无阴影——仅靠磨砂玻璃不透明度示意分层

**页脚导航**
- 背景：纯白或 `#F4F4F4`
- 链接：12px，字重 400，`#5C5E62`，行列排布
- 底部行：版权 + 法律链接，12px，`#8E8E8E`

**移动导航**
- 汉堡菜单图标（右上）
- 全屏抽屉：白底，导航标签 24px/500 垂直堆叠
- 关闭按钮：右上 X 图标

### 图片处理
- **宽高比**：首屏 16:9 或更宽（21:9 电影感），产品展示区块全视口
- **圆角**：0——所有影像严格直角
- **滤镜**：无——Tesla 不给影像加滤镜或罩染
- **懒加载**：首屏以下标准懒加载
- **文字叠加**：白色半透明文字直接叠在影像上，无渐变罩染（Tesla 甚至不用底部渐变来保证文字可读性——靠影像本身的暗部构图）

### 轮播/车型选择器
- 首屏轮播：底部圆点指示器（`8px` 圆点，激活态为 `#171A20`，非激活为 `rgba(0,0,0,0.2)`）
- 边缘箭头：左右两侧 `<` `>` 导航按钮，`48px` 圆形，半透明白底（`rgba(255,255,255,0.7)`），`#171A20` 箭头图标
- 自动播放：约 6 秒间隔，悬停暂停
- 过渡：`0.33s cubic-bezier(0.5, 0, 0, 0.75)` 淡入淡出

### 「Ask a Question」聊天条
- 位置：视口底部固定，全宽或居中浮条
- 背景：纯白，`1px solid #EEEEEE` 顶边框
- 高度：约 `56px`
- 内容：左侧气泡图标 + 「Ask a Question」文字（14px/500），右侧展开箭头
- 无阴影——仅靠顶边框与位置示意

## 5. 布局原则

### 间距系统
- **基准单位**：4px
- **刻度**：4px、8px、12px、16px、24px、32px、48px、64px、96px
- **区块内边距**：首屏区块内容底边距约 48–64px；产品展示区块垂直内边距 64–96px
- **按钮内边距**：`8px 24px`（主/次 CTA 通用）
- **导航内边距**：水平 24–32px，垂直 16px
- **卡片内边距**：不适用（无卡片系统）

### 网格与容器
- **最大宽度**：约 1440px，居中
- **首屏内容**：底部居中，最大宽度约 600px 的文字块
- **产品网格**：2–3 列等宽，槽 24px（用于车型陈列区）
- **页脚**：多列链接网格，槽 32px

### 留白哲学
Tesla 的留白是**影像留白**——不是页面上的空白，而是影像内部的负空间。每块全视口影像都经过构图，让车辆周围有大量「空气」，UI 文字就放在这些空气里。页面本身从不「空」——它总是被影像填满，但影像内部的留白让界面呼吸。这是最高级的留白运用：留白不在 DOM 里，在摄影里。

### 圆角刻度
- `4px`——按钮、输入框、下拉面板（通用值）
- `50%`——单选框、轮播圆点、圆形图标按钮
- `0`——所有影像、首屏区块、横幅

## 6. 纵深与阴影层级

| 层级（Level） | 处理（Treatment） | 用途（Use） |
|---|---|---|
| 0 | 无阴影 | 默认——几乎所有表面 |
| 1 | 磨砂玻璃 `rgba(255,255,255,0.75)` + backdrop blur | 滚动后的导航 |
| 2 | 全幅影像 | 首屏与产品展示——影像本身即纵深 |

Tesla 的纵深哲学是**零阴影**。整个营销站几乎找不到 `box-shadow`。分层靠：
1. **影像 vs 白表面**的二元对比
2. **磨砂玻璃**的不透明度变化
3. **文字颜色**在影像上的反白

### 装饰性纵深
无。无渐变、无辉光、无投影。Tesla 相信摄影的纵深足够了——界面不需要再发明一次。

## 7. 要做与不要做

### 要做
- **要**让影像铺满视口——首屏永远 100vh，边缘到边缘
- **要**只用一个蓝色（`#3E6AE1`）做所有主 CTA——它是全站唯一的彩色
- **要**用 3px 边框做主按钮——这是签名细节
- **要**让导航透明浮于首屏上，滚动后才变磨砂玻璃
- **要**标题用 -0.5px 负字距，字重 500——不用粗黑体
- **要**按钮文字全大写——「ORDER NOW」不是「Order Now」
- **要**所有过渡用 `0.33s cubic-bezier(0.5, 0, 0, 0.75)`

### 不要做
- **不要**加阴影——Tesla 的营销站几乎零 `box-shadow`
- **不要**用渐变——纵深靠摄影，不靠 CSS
- **不要**给影像倒圆角——永远直角
- **不要**引入第二个点缀色——蓝色之外无彩色
- **不要**用卡片组织内容——用全幅影像区块
- **不要**悬停时翻转按钮背景色——Tesla 的悬停极克制
- **不要**用粗黑体（700+）做标题——500 是上限
- **不要**在影像上加文字罩染渐变——靠影像构图保证可读性

## 8. 响应式行为

### 断点

| 名称（Name） | 宽度（Width） | 关键变化（Key Changes） |
|---|---|---|
| 手机 | <600px | 单列，首屏标题 32px，按钮全宽堆叠，汉堡导航 |
| 平板 | 600–1023px | 首屏标题 36px，双按钮并排，导航标签收起部分 |
| 桌面 | 1024–1439px | 完整导航，首屏标题 40px，产品网格 2–3 列 |
| 大桌面 | ≥1440px | 内容上限 1440px 居中，首屏影像继续铺满视口 |

### 触控目标
- 主/次按钮：`8px 24px` 内边距 + 14px 文字 ≈ 高 36px——移动端建议撑到 44px
- 导航标签：桌面 14px/500；移动端抽屉 24px/500，行高 48px，触控友好
- 轮播圆点：`8px` 视觉圆点，但点按区扩展到 32px

### 收起策略
- **导航**：1024px 以下收起为汉堡菜单 + 全屏抽屉
- **首屏**：100vh 保持，但标题从 40px → 32px，按钮从并排 → 全宽堆叠
- **产品网格**：3 列 → 2 列 → 1 列
- **页脚**：多列 → 单列堆叠

### 图片行为
- 首屏影像：`object-fit: cover`，移动端切换为竖构图裁剪（Tesla 为移动端准备了专门的竖版首屏图）
- 产品影像：响应式 `srcset`，桌面 16:9 → 移动端 4:5
- 无装饰性图片处理——无滤镜、无罩染、无圆角

1. *「创建 Tesla 主 CTA 按钮：电光蓝（`#3E6AE1`）背景，白色文字『ORDER NOW』（全大写），Universal Sans Text 14px 字重 500，`3px solid #3E6AE1` 边框，`4px` 圆角，`8px 24px` 内边距。悬停不翻转背景色。过渡 `0.33s cubic-bezier(0.5, 0, 0, 0.75)`。」*

### 迭代指南
用该设计系统打磨已有界面时：
1. **先审计阴影。**看到任何 `box-shadow` 就删掉——Tesla 不用阴影表达层级。
2. **审计色彩。**界面铬中出现 `#3E6AE1` 之外的彩色就删掉。蓝色是唯一的彩色。
3. **审计圆角。**按钮/输入框 `4px` 之外的值一律改回。影像永远 `0`。
4. **审计字重。**标题出现 700+ 就降到 500——Tesla 的层级靠字号，不靠字重。
5. **审计按钮边框。**主 CTA 必须是 3px 边框——1px 或 2px 会失去签名感。
6. **审计悬停态。**按钮悬停翻转背景色的，一律改为维持原色——Tesla 的悬停极克制。

### 已知缺口
- Universal Sans 是 Tesla 专有字体——公开实现用 Inter + `-0.5px` 字距逼近，并记录替换
- 具体断点值（600/1024/1440）为推断——Tesla 未公开设计 token，需按实现微调
- 表单错误态、成功态的具体样式未在营销站暴露——落地时需自行定义，但须延续零阴影/单蓝色的纪律
- 车机/移动 App 的深色模式 token 未覆盖——本文档仅覆盖营销站浅色体系
- 「Ask a Question」聊天机器人的展开态交互细节未捕获——仅记录了收起条样式
