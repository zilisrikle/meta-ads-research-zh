# Sanity 风格设计系统

## 1. 视觉主题与氛围

Sanity 的网站是一个面向开发者内容平台，被渲染成夜间指挥中心——深邃、精准、高度结构化。整个体验坐落在近黑的画布（`#0b0b0b`）上，读起来不像"深色模式开关"，而像是为活在终端里的人打造的工具的自然状态。大多数 CMS 营销页面倾向友好的粉彩与柔和插画，Sanity 则拥抱其产品自身的重力：结构化内容值得一个结构化的舞台。

标志性的排印（Typography）语调是 waldenburgNormal——独特的、略带几何感的无衬线字体，紧负字距（展示尺寸下 -0.32px 到 -4.48px），赋予标题压缩的、工程化的质感。112px 主视觉尺寸配 -4.48px 字距，字体几乎如机加工般——像精密切割的钢质字母。与之搭配的是用于代码与技术标签的 IBM Plex Mono，形成双声部语调：编辑权威遇见开发者可信。

Sanity 的独特性在于其单色深色板与鲜明饱和点缀的互动。中性色阶从纯黑走过严格控制的灰色坡度（`#0b0b0b` -> `#212121` -> `#353535` -> `#797979` -> `#b9b9b9` -> `#ededed` -> `#ffffff`），无暖无冷偏向——纯粹的、无彩色的精准。在此克制的背景下，霓虹绿点缀（display-p3 绿色）与电光蓝（`#0052ef`）如黑暗控制室中的信号灯般落地。橙红 CTA（`#f36458`）在 otherwise 偏冷的系统中提供唯一的暖触。

**关键特征：**
- 近黑画布（`#0b0b0b`）作为默认、自然的环境——不是深色"模式"，而是主要身份
- waldenburgNormal 展示尺寸用极端负字距，塑造精密工程的排印语调
- 纯无彩灰色阶——无暖无冷底调，纯粹的中性纪律
- 鲜明的点缀标点：深色底上的霓虹绿、电光蓝（`#0052ef`）与珊瑚红（`#f36458`）
- 胶囊形主要按钮（99999px 圆角）对比次级操作的微妙圆角矩形（3–6px）
- IBM Plex Mono 作为编辑型展示字体的技术对位
- 全幅深色版块，内容收拢于有节制的最大宽度容器
- 悬停状态全系统统一变为电光蓝（`#0052ef`）——一致的"激活"信号

## 2. 色彩体系与角色

### 主品牌色
- **Sanity 黑**（`#0b0b0b`）：主要画布与主导表面色。不是纯黑但足够接近，感觉绝对。是整个视觉身份的基础。
- **纯黑**（`#000000`）：用于最大对比时刻、深层叠加与某些边框点缀。
- **Sanity 红**（`#f36458`）：主要 CTA 与品牌点缀——暖珊瑚红，作为主要行动召唤色。用于 "Get Started" 按钮与主要转化点。

### 点缀与交互
- **电光蓝**（`#0052ef`）：全系统统一的悬停/激活状态色。按钮、链接、交互元素悬停时一律变蓝。也用作 `--color-blue-700` 聚焦环与激活状态。
- **浅蓝**（`#55beff` / `#afe3ff`）：次级蓝变体，用于点缀背景、徽章与弱化蓝色表面。
- **霓虹绿**（`color(display-p3 .270588 1 0)`）：鲜明的宽色域绿色，用作 `--color-fg-accent-green` 的成功状态与高级功能高光。sRGB 回退为 `#19d600`。
- **点缀品红**（`color(display-p3 .960784 0 1)`）：鲜明的宽色域品红，用于专门的点缀时刻。

### 表面与背景
- **近黑**（`#0b0b0b`）：默认页面背景与主要表面。
- **深灰**（`#212121`）：抬高表面色，用于卡片、次级容器、输入框背景，以及基础画布之上的微妙分层。
- **中深**（`#353535`）：第三级表面与边框色，在深色层之间创造纵深。
- **纯白**（`#ffffff`）：用于反白版块、深底上的浅色文字与特定按钮表面。
- **浅灰**（`#ededed`）：反白/浅色版块的浅色表面与微妙背景色调。

### 中性色与文字
- **白**（`#ffffff`）：深色表面上的主要文字色，最大可读性。
- **银**（`#b9b9b9`）：次级文字、深色表面上的正文、弱化描述与占位文字。
- **中灰**（`#797979`）：第三级文字、元信息、时间戳与弱化内容。
- **炭**（`#212121`）：浅色/反白表面上的文字。
- **近黑文字**（`#0b0b0b`）：白色/浅色按钮表面上的主要文字。

### 语义
- **错误红**（`#dd0000`）：破坏性操作、校验错误与严重警告——纯粹、高饱和的红。
- **GPC 绿**（`#37cd84`）：隐私/合规指示绿。
- **聚焦环蓝**（`#0052ef`）：无障碍聚焦环色，与交互蓝一致。

### 边框系统
- **深边框**（`#0b0b0b`）：深色容器的主要边框——几乎不可见，保持最小收纳感。
- **微妙边框**（`#212121`）：深色表面上输入框、文本域与卡片边缘的标准边框。
- **中边框**（`#353535`）：更显眼的边框，用于强调收纳与分割线。
- **浅边框**（`#ffffff`）：反白/浅色元素或需要对比分隔的按钮上的边框。
- **橙边框**（`color(display-p3 1 0.3333 0)`）：高亮/精选元素的特殊点缀边框。

## 3. 排印规则

### 字体族
- **展示/标题**：`waldenburgNormal`，回退：`waldenburgNormal Fallback, ui-sans-serif, system-ui`
- **正文/UI**：`waldenburgNormal`，回退：`waldenburgNormal Fallback, ui-sans-serif, system-ui`
- **代码/技术**：`IBM Plex Mono`，回退：`ibmPlexMono Fallback, ui-monospace`
- **回退/CJK**：`Helvetica`，回退：`Arial, Hiragino Sans GB, STXihei, Microsoft YaHei, WenQuanYi Micro Hei`

*注：waldenburgNormal 是定制字体。外部实现时用 Inter 或 Space Grotesk 作为无衬线替代（几何、略压缩的观感）。IBM Plex Mono 可在 Google Fonts 获取。*

### 原则
- **大尺寸极端负字距**：72px+ 的展示标题用激进的负字距（-2.88px 到 -4.48px），营造紧凑、工程化的质感，区别于更松散的编辑排印。
- **一字体，多声部**：waldenburgNormal 兼顾编辑展示与功能 UI 文字。字重范围窄（多数 400–425，仅微型标签用 500–600），语调保持一致。
- **OpenType 特性控制**：排印使用刻意的特性设置，展示尺寸用 `"cv01", "cv11", "cv12", "cv13", "ss07"`，正文用 `"calt" 0`，为不同场景微调字符变体。
- **标题紧、正文松**：标题行高 1.00–1.24（极紧），正文 1.50 舒展。这种对比创造清晰的视觉层级。
- **技术标签全大写**：IBM Plex Mono 注释与小标签常用 `text-transform: uppercase` 配紧行高，营造技术元数据的"系统读数"美学。

### 网格与容器
- 最大内容宽度：约 1440px（从断点推断）
- 页面页边距：桌面 32px，手机 16px
- 内容版块用全幅背景配居中、最大宽度内容
- 多列布局：桌面 2–3 列，手机单列
- 卡片网格：CSS Grid，间距一致（16–24px）

### 留白（Whitespace）哲学
Sanity 在版块间使用激进的垂直间距（64–120px），在深色画布上创造呼吸空间。版块内部间距更紧（16–32px），形成被充裕虚空分隔的密集信息簇。这种节奏赋予页面"幻灯片"质感——每个版块都像一帧聚焦的画面。

| Token | 值 | 用途 |

## 6. 纵深与层级

### 阴影系统

| 层级 | 值 | 用途 |
|-------|-------|-------|
| 0 级（平面） | none | 多数元素的默认状态——深色表面仅通过颜色创造纵深 |
| 1 级（微妙） | 0px 0px 0px 1px `#212121` | 类边框阴影，无可见边框的最小收纳 |
| 2 级（聚焦） | 0 0 0 2px `var(--color-blue-500)` | 输入框与交互元素的聚焦环 |
| 3 级（叠加） | 背景模糊 + 半透明深色 | 导航叠加、模态框背景 |

### 纵深哲学
Sanity 的纵深系统几乎完全是**色彩度量**而非阴影。抬高通过表面色变化传达：`#0b0b0b`（地面）-> `#212121`（抬高）-> `#353535`（显著）-> `#ffffff`（反白/最高）。这种方式原生于深色界面——传统投影在深色中不可见。少数存在的阴影是环状（0px 0px 0px Npx）或模糊型（backdrop-filter），而非偏移阴影，保持平坦、精密工程的美学。

基于边框的收纳（1px solid `#212121` 或 `#353535`）是主要的空间分隔手段，边框深浅校准到可见但不抢眼。系统避免"悬浮卡片"美学——一切都感觉装嵌在表面上，而非悬在其上。

## 7. 做法与禁忌

### 应该做
- 以无彩灰色阶为基础——保持纯粹的中性纪律，不带暖/冷调
- 全系统统一用电器蓝（`#0052ef`）作为所有交互元素的悬停/激活状态
- 48px 及以上的展示标题用极端负字距（-2px 到 -4.48px）
- 主要 CTA 保持全胶囊形（99999px 圆角）配珊瑚红（`#f36458`）
- 技术标签、标记与系统元数据用 IBM Plex Mono 全大写
- 用表面色（深到浅）而非阴影传达纵深
- 深色画布上保持充裕的垂直版块间距（64–120px）
- 展示排印使用 `"cv01", "cv11", "cv12", "cv13", "ss07"` OpenType 特性

### 不要做
- 中性色阶不要引入暖或冷色调——Sanity 的灰是纯无彩的
- 纵深不要用投影——深色界面需要色彩度量纵深
- 圆角不要用 13px 到 99998px 之间的值——系统从 12px（大卡）直接跳到胶囊（99999px）
- 同一元素不要混用珊瑚红 CTA 与电光蓝交互色
- 不要用粗字重（700+）——系统最高 600，且仅用于 11px 全大写标签
- 不检查灰上灰的对比度，不要将浅色文字放在浅色表面、或深色文字放在深色表面
- 不要用传统偏移 box-shadow——只用环状阴影（0 0 0 Npx）或基于边框的收纳
- 不要打破标题的紧行高——展示文字的行高范围是 1.00–1.24，永不到 1.5+

- **主视觉排印**：112px → 72px → 48px → 38px 跨断点缩放，保持紧字距比例
- **网格布局**：约 960px 处 3 列 → 2 列，768px 以下单列
- **卡片网格**：手机上横向滚动而非换行（保持卡片宽高比）
- **版块间距**：手机上垂直内边距缩减约 40%（120px → 64px → 48px）
- **按钮尺寸**：CTA 胶囊保持内边距但字号减小；幽灵按钮固定
- **代码块**：横向滚动，保持等宽格式

### 移动端特定调整
- 全幅版块边缘到边缘延伸，内部页边距 16px
- 触控目标：所有交互元素最小 44px
- 手机尺寸下标题字距略放宽（负字距不那么激进）
- 图片容器从固定宽高比切换为全宽自适应高度
