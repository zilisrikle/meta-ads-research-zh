# 受 BMW 启发的设计系统

## 1. 视觉主题与氛围

BMW 的网站是汽车工程的视觉化——一套传递精密、性能与德国工业自信的设计系统。页面在深邃的深色首屏分区（全幅汽车摄影）与干净的白色内容区之间交替，形成电影般的节奏，像走进一家豪华车展厅，车辆在黑暗中被灯光照亮。BMW CI2020 设计语言（其品牌视觉刷新）定义了每一个元素。

排印（typography）建立在 BMWTypeNextLatin 之上——一款专有字体，有两种变体：BMWTypeNextLatin Light（300 字重（font weight））用于巨型大写展示标题，BMWTypeNextLatin Regular 用于正文和界面文字。60px 大写标题配 300 字重是决定性的排印手势——细字重低语般传递权威，而非大喊大叫。回退栈包含 Helvetica 和日文字体（Hiragino、Meiryo），反映了 BMW 的全球布局。

BMW 的独特之处在于它的 CSS 变量驱动主题系统。语境感知变量（`--site-context-highlight-color: #1c69d4`、`--site-context-focus-color: #0653b6`、`--site-context-metainfo-color: #757575`）表明这套设计系统是为多品牌、多语境部署而建，颜色可以全局替换。蓝色高亮色（`#1c69d4`）是 BMW 的标志性蓝——只克制地用于可交互元素和聚焦状态，绝不作装饰。检测到零圆角（border-radius）——BMW 的设计是棱角分明的、锐角的、毫不妥协的几何。

**关键特征：**
- BMWTypeNextLatin Light（300 字重）大写用于展示——低语的权威
- 宝马蓝（BMW Blue）（`#1c69d4`）作为唯一的点缀色——只用于可交互元素
- 检测到零圆角——棱角分明、锐角、工业几何
- 深色首屏摄影 + 白色内容分区——展厅灯光的节奏
- CSS 变量驱动主题：`--site-context-*` 令牌保证品牌灵活性
- 导航强调处用 900 字重——与 300 展示字重形成极端对比
- 全系统紧凑行高（line height）（1.15–1.30）——压缩、高效、德国工程
- 全幅汽车摄影作为主要视觉内容

## 2. 色彩体系与角色

### 主品牌色
- **纯白（Pure White）**（`#ffffff`）：`--site-context-theme-color`，主表面、卡片背景
- **宝马蓝（BMW Blue）**（`#1c69d4`）：`--site-context-highlight-color`，主交互点缀
- **宝马聚焦蓝（BMW Focus Blue）**（`#0653b6`）：`--site-context-focus-color`，键盘聚焦与激活状态

### 中性色阶
- **近黑（Near Black）**（`#262626`）：浅色表面上的主文字、深色链接文字
- **元信息灰（Meta Gray）**（`#757575`）：`--site-context-metainfo-color`，次级文字、元信息
- **银（Silver）**（`#bbbbbb`）：三级文字、弱化链接、页脚元素

### 交互状态
- 所有链接悬停变白（`#ffffff`）——暗示导航主要在深色表面上
- 文本链接悬停时下划线：无——干净的交互

### 阴影
- 极简的阴影系统——纵深靠摄影与深/浅分区对比实现

## 3. 排印规则

### 字体族
- **展示（细体）**：`BMWTypeNextLatin Light`，回退：`Helvetica, Arial, Hiragino Kaku Gothic ProN, Hiragino Sans, Meiryo`
- **正文/界面**：`BMWTypeNextLatin`，相同回退栈

### 层级

| 角色 | 字体 | 字号 | 字重 | 行高 | 说明 |
|------|------|------|------|------|------|
| 展示主视觉 | BMWTypeNextLatin Light | 60px (3.75rem) | 300 | 1.30（紧凑） | `text-transform: uppercase` |
| 分区标题 | BMWTypeNextLatin | 32px (2.00rem) | 400 | 1.30（紧凑） | 主要分区标题 |
| 导航强调 | BMWTypeNextLatin | 18px (1.13rem) | 900 | 1.30（紧凑） | 导航粗体项 |
| 正文 | BMWTypeNextLatin | 16px (1.00rem) | 400 | 1.15（紧凑） | 标准正文 |
| 按钮（粗体） | BMWTypeNextLatin | 16px (1.00rem) | 700 | 1.20–2.88 | CTA 按钮 |
| 按钮 | BMWTypeNextLatin | 16px (1.00rem) | 400 | 1.15（紧凑） | 标准按钮 |

### 原则
- **细体展示、重体导航**：首屏标题 300 字重营造低语般的优雅；导航 900 字重形成凛然的权威。这种极端字重对比（300 对 900）是标志性的排印张力。
- **全大写展示**：60px 首屏永远大写——形成纪念碑般的建筑感。
- **一切紧凑**：全系统行高 1.15 到 1.30。什么都不松弛——每一行都被压缩、高效、德国工程化。
- **单一字体族**：BMWTypeNextLatin 从 60px 展示到 16px 正文一肩挑——以同一款字体在不同字重下的统一达成统一。

## 4. 组件样式

### 按钮
- 文字：16px BMWTypeNextLatin，主按钮 700 字重，次按钮 400 字重
- 行高：1.15–2.88（变化大，暗示以内边距驱动尺寸）
- 边框：深色表面上的白色底边框（`1px solid #ffffff`）
- 无圆角——锐利的矩形按钮

### 卡片与容器
- 无圆角——所有容器都是锐角矩形
- 浅色分区用白底
- 首屏/特性分区用深色背景
- 大多数元素无可见边框

### 导航
- 主导航链接：BMWTypeNextLatin 18px 900 字重
- 深色导航上的白字
- BMW 标志 54x54px
- 悬停：保持白色，text-decoration none
- 导航中的 "Home" 文字链接

### 图片处理
- 全幅汽车摄影
- 深色电影感灯光
- 首屏图片顶天立地
- 汽车摄影作为主要视觉内容

## 5. 布局原则

### 间距系统
- 基准单位：8px
- 刻度：1px、5px、8px、10px、12px、15px、16px、20px、24px、30px、32px、40px、45px、56px、60px

### 网格与容器
- 全宽首屏摄影
- 居中的内容分区
- 页脚：多列链接网格

### 留白哲学
- **展厅式节奏**：深色首屏分区配慷慨内边距，像在展厅中穿行，每辆车都在自己的空间里被聚光灯照亮。
- **压缩的内容**：正文区用紧凑行高和密集间距——信息密度高，毫不浪费。

### 圆角刻度
- **未检测到。** BMW 只用锐角——每个元素都是精确的矩形。这是分析过的设计系统中最棱角分明的一套。

## 6. 纵深与层级（Depth & Elevation）

| 层级 | 处理 | 用途 |
|------|------|------|
| 摄影（层级 0） | 全幅深色影像 | 首屏背景 |
| 平面（层级 1） | 白色表面，无阴影 | 内容分区 |
| 聚焦（无障碍） | 宝马聚焦蓝（BMW Focus Blue）（`#0653b6`） | 聚焦状态 |

**阴影哲学**：BMW 几乎不用阴影。纵深完全靠深色摄影分区与白色内容分区的对比实现——汽车灯光自己完成了抬升的工作。

## 7. 该做与不该做

### 该做
- 所有展示标题都用 BMWTypeNextLatin Light（300）大写
- 所有角保持锐利（0px 圆角）——棱角几何不可妥协
- 宝马蓝（BMW Blue）（`#1c69d4`）只用于可交互元素——绝不作装饰
- 导航强调处用 900 字重——极端字重对比是刻意为之
- 首屏分区用全幅汽车摄影
- 全系统保持紧凑行高（1.15–1.30）
- 主题用 `--site-context-*` CSS 变量

### 不该做
- 不给角倒圆——零圆角就是 BMW 的身份
- 宝马蓝不用在背景或大面积表面上——它只是点缀色
- 不用中等字重（500–600）——这套系统只用 300、400、700、900 极端档位
- 不加装饰元素——摄影和排印承载一切
- 不用宽松行高——BMW 的文字永远是压缩的
- 不提亮深色首屏分区——与白色的对比本身就是设计

## 8. 响应式行为

### 断点
| 名称 | 宽度 | 关键变化 |
|------|------|----------|
| 超小手机 | <375px | 最低支持 |
| 手机 | 375–480px | 单列 |
| 大手机 | 480–640px | 轻微调整 |
| 小平板 | 640–768px | 2 列开始出现 |
| 平板 | 768–920px | 标准平板 |
| 小桌面 | 920–1024px | 桌面布局开始 |
| 桌面 | 1024–1280px | 标准桌面 |
| 大桌面 | 1280–1440px | 展开 |
| 超宽屏 | 1440–1600px | 最大布局 |

### 收缩策略
- 首屏：60px → 按比例缩小，保持大写
- 导航：横向 → 汉堡菜单
- 摄影：所有尺寸保持全幅
- 内容分区：纵向堆叠
- 页脚：多列 → 堆叠
