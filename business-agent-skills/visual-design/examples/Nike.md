# Nike 风格设计系统

## 1. 视觉主题与氛围

Nike.com 是一座动感的零售殿堂——将运动的爆发能量注入数字购物体验的网站。设计遵循激进的简约原则：剔除一切，只剩黑、白、灰，让运动摄影与产品色彩得以毫无竞争地主导视觉。结果更像一本以奢侈杂志精度排版的运动编辑刊物，而非网站。每像素的版面不是在卖货，就是在通向卖货。

"Podium CDS"（Nike 内部的核心设计系统，Core Design System）建立了极具攻击性的单色基础。UI 隐入黑（`#111111`）文字与白色表面，让主视觉摄影——汗流浃背的运动员、腾空中的鞋、体育场的能量——承载情感重量。当 UI 中出现色彩时，几乎纯粹是功能性的：红表错误、蓝表链接、绿表成功。产品本身就是色彩故事。这种克制创造了视觉悖论：互联网上色彩最丰富的页面却最极简，因为所有活力都来自商品而非界面。

排印（Typography）系统是 Nike 视觉身份的另一半。Nike Futura ND 中的巨大大写标题——定制的压缩版 Futura，行高紧到 0.90——如排印冲击波般穿透主视觉图片。标题之下，Helvetica Now 家族以瑞士精度的清晰处理从导航到产品描述的一切。这种表现型展示字体与功能型正文体的分工，映照着 Nike 的品牌双重性：灵感与执行并存。

**关键特征：**
- 单色 UI（黑/白/灰），让产品摄影成为唯一的色彩来源
- 巨大的全大写展示字体（96px，行高 0.90），穿透主视觉图片
- 全幅摄影，无圆角——影像填满每一个边缘
- 胶囊形按钮（30px 圆角）作为主要交互元素
- 8px 间距网格，纪律如运动员——每个尺寸都贴合系统
- 品类驱动的购物架构，配大型导航图片卡
- 无阴影、极简边框的层级模型——仅通过灰度变化区分表面

## 2. 色彩体系与角色

### 主色

- **Nike 黑**（`#111111`）：基础——主要文字、按钮背景、导航文字、主视觉叠加。刻意不用纯黑（#000000），阅读体验更柔和
- **Nike 白**（`#FFFFFF`）：主要页面画布、深底上的按钮文字、卡片表面、导航栏背景

### 表面与背景

- **雪**（`#FAFAFA`）：最浅表面，近白的微妙区分（--podium-cds-color-grey-50）
- **浅灰**（`#F5F5F5`）：次级背景、搜索框填充、图片占位、加载骨架（--podium-cds-color-grey-100）
- **悬停灰**（`#E5E5E5`）：悬停状态背景、禁用按钮填充（--podium-cds-color-grey-200）
- **深表面**（`#28282A`）：深色/反白版块的主要背景（--podium-cds-color-grey-800）
- **深炭**（`#1F1F21`）：反白主要背景，最深的非黑表面（--podium-cds-color-grey-900）
- **深悬停**（`#39393B`）：深色背景上的悬停状态（--podium-cds-color-grey-700）

### 中性色与文字

- **主要文字**（`#111111`）：正文、标题、导航链接（--podium-cds-color-text-primary）
- **次级文字**（`#707072`）：描述文案、元信息、时间戳、价格标签（--podium-cds-color-text-secondary）
- **禁用文字**（`#9E9EA0`）：未激活元素、不可用选项（--podium-cds-color-text-disabled）
- **禁用反白**（`#4B4B4D`）：深色背景上的禁用文字（--podium-cds-color-text-disabled-inverse）
- **边框主色**（`#707072`）：标准边框色，与次级文字同色
- **边框次级**（`#CACACB`）：微妙边框、输入框边框、分割线（--podium-cds-color-grey-300）
- **边框禁用**（`#CACACB`）：未激活的边框状态
- **边框激活**（`#111111`）：激活/聚焦边框，与主要文字同色

### 语义与点缀

- **Nike 红**（`#D30005`）：严重错误、促销徽章、紧急通知（--podium-cds-color-red-600）
- **亮红**（`#EE0005`）：red-500，稍亮的红用于强调
- **Nike 橙徽章**（`#D33918`）：徽章文字、促销标语（--podium-cds-color-text-badge）
- **橙闪**（`#FF5000`）：表现型橙色点缀（--podium-cds-color-orange-400）
- **成功绿**（`#007D48`）：确认、可用、积极状态（--podium-cds-color-green-600）
- **成功反白**（`#1EAA52`）：深色背景上的成功色（--podium-cds-color-green-500）
- **链接蓝**（`#1151FF`）：文字链接、信息高光（--podium-cds-color-blue-500）
- **信息反白**（`#1190FF`）：深色背景上的链接（--podium-cds-color-blue-400）
- **警告黄**（`#FEDF35`）：警告背景、注意横幅（--podium-cds-color-yellow-200）
- **聚焦环**（`rgba(39, 93, 197, 1)`）：键盘聚焦指示环

### 扩展色谱（Podium CDS）

每条色阶 50–900，用于营销活动与产品页的表现型色彩：

- **红**：`#FFE5E5` → `#EE0005` → `#530300`
- **橙**：`#FFE2D6` → `#FF5000` → `#3E1009`
- **黄**：`#FEF087` → `#FCA600` → `#99470A`
- **绿**：`#DFFFB9` → `#1EAA52` → `#003C2A`
- **青**：`#D4FFFB` → `#008E98` → `#043441`
- **蓝**：`#D6EEFF` → `#1151FF` → `#020664`
- **紫**：`#E4E1FC` → `#6E0FF6` → `#1C0060`
- **粉**：`#FFE1F3` → `#ED1AA0` → `#4C012D`

### 渐变体系

Nike 避免 UI 渐变。出现渐变时皆为摄影性渐变——用于产品主视觉背景（如红鞋配红到深红的渐变）。设计系统本身只用纯色。

## 3. 排印规则

### 字体族

**展示：** Nike Futura ND（Nike 专属的定制压缩 Futura 变体）
- 回退：Helvetica Now Text Medium、Helvetica、Arial
- 仅用于大尺寸全大写展示标题
- 特征是极紧的行高（0.90）与大写变换

**标题：** Helvetica Now Display Medium
- 回退：Helvetica、Arial
- 用于 24–32px 的版块标题与产品标题

**正文（中）：** Helvetica Now Text Medium（字重 500）
- 回退：Helvetica、Arial
- 用于链接、按钮、注释、强调正文

**正文：** Helvetica Now Text（字重 400）
- 回退：Helvetica、Arial
- 用于标准正文、描述、元信息

**阿拉伯语：** Neue Frutiger Arabic——针对特定区域语言的替代字体

### 层级

| 角色 | 字号 | 字重 | 行高 | 字距 | 说明 |
|------|------|--------|-------------|----------------|-------|
| 展示 | 96px | 500 | 0.90 | — | Nike Futura ND，全大写，主视觉标题 |
| 标题 1 | 32px | 500 | 1.20 | — | Helvetica Now Display Medium，版块标题 |
| 标题 2 | 24px | 500 | 1.20 | — | Helvetica Now Display Medium，次级版块 |
| 标题 3 | 16px | 500 | 1.50 | — | Helvetica Now Text Medium，卡片标题 |
| 正文 | 16px | 400 | 1.75 | — | Helvetica Now Text，产品描述 |
| 正文（中） | 16px | 500 | 1.75 | — | Helvetica Now Text Medium，强调文字 |
| 链接 | 16px | 500 | 1.75 | — | Helvetica Now Text Medium，导航链接 |
| 链接（小） | 14px | 500 | 1.86 | — | Helvetica Now Text Medium，页脚/工具链接 |
| 按钮 | 16px | 500 | 1.50 | — | Helvetica Now Text Medium，CTA 文字 |
| 按钮（小） | 14px | 500 | 1.50 | — | Helvetica Now Text Medium，次级按钮 |
| 注释 | 14px | 500 | 1.50 | — | Helvetica Now Text Medium，价格标签 |
| 小字 | 12px | 500 | 1.50 | — | Helvetica Now Text Medium，时间戳 |
| 微字 | 12px | 400 | 1.50 | — | Helvetica Now Text，法律文本 |

### 原则

Nike 的排印是张力的研究。展示层——96px 的 Nike Futura ND 配 0.90 的行高——被设计得像体育场记分牌：巨大、压缩、全大写、无法忽视。它将标题变成战斗口号。展示层之下，Helvetica Now 提供冷静的对位：瑞士精度的易读性，配 1.75 的宽松行高，让产品浏览舒适。字重 500（Medium）主导正文，赋予 Nike 的文案一种轻微的果断感而不至沉重——每句话都像自信的推荐，而非喊叫。

## 4. 组件样式

### 按钮

**主要**
- 背景：Nike 黑（`#111111`）
- 文字：白（`#FFFFFF`），16px/500，Helvetica Now Text Medium
- 边框：无
- 圆角：全圆胶囊（30px）
- 内边距：约 12px 24px
- 悬停：背景变为灰 500（`#707072`），文字悬停色
- 激活：scale(0) 波纹效果，不透明度 0.5
- 聚焦：`rgba(39, 93, 197, 1)` 的 2px box-shadow 环
- 过渡：background 200ms ease

**主要（深底）**
- 背景：白（`#FFFFFF`）
- 文字：黑（`#111111`）
- 悬停：背景变为灰 300（`#CACACB`）

**次级（描边）**
- 背景：transparent
- 文字：Nike 黑（`#111111`）
- 边框：1.5px solid `#CACACB`（grey-300）
- 圆角：30px
- 悬停：边框加深到 `#707072`，背景变为 grey-200

**禁用**
- 背景：灰 200（`#E5E5E5`）
- 文字：灰 400（`#9E9EA0`）
- 光标：not-allowed

**图标按钮**
- 背景：灰 100（`#F5F5F5`）
- 形状：30px 圆角（圆形用 50%）
- 内边距：6px
- 悬停：灰 500 背景

### 卡片与容器

- 背景：白（`#FFFFFF`）——大多数情况下无可见卡片边界
- 圆角：产品图片卡片 0px（边缘到边缘的影像），交互容器 20px
- 阴影：无——Nike 完全不用卡片阴影
- 悬停：产品卡片无抬升效果；卡片内文字链接加下划线
- 产品卡片：顶部图片（无圆角），下方 12px 间距的文字元信息
- 品类卡片：全幅摄影配深色渐变上的文字叠加
- 过渡：悬停图片切换用 opacity 200ms ease

### 输入框与表单

- 背景：灰 100（`#F5F5F5`）
- 边框：可见时 1px solid `#CACACB`，搜索框无边框
- 圆角：搜索输入框 24px，表单输入框 8px
- 字体：Helvetica Now Text，16px
- 聚焦：边框变为 `#111111`（border-active），`rgba(39, 93, 197, 1)` 的 2px 聚焦环
- 错误：边框 `#D30005`（critical）
- 占位符：灰 500（`#707072`）
- 过渡：border-color 200ms ease

### 导航

- 背景：白（`#FFFFFF`），吸顶
- 高度：桌面约 60px
- 左：Nike Swoosh logo（24x24px SVG）
- 中：品类链接（New & Featured、Men、Women、Kids、Sale），16px/500 Helvetica Now Text Medium
- 右：搜索（24px 圆角输入框）、收藏、购物车图标
- 悬停：文字颜色变为灰 500（`#707072`）
- 移动端：汉堡菜单，全屏覆盖
- 顶部横幅：深色背景（#111111）白字的促销信息条

### 图片处理

- 主视觉图片：全幅，无圆角，边缘到边缘
- 产品网格：正方形（1:1）或 4:3 宽高比，无圆角
- 品类卡片：16:9 或 4:3，全幅配文字叠加
- 图片占位：灰 100（`#F5F5F5`）纯色背景
- 懒加载：原生 loading="lazy"，骨架用 #F5F5F5 背景
- 产品悬停：次图切换（正面 → 侧面）

### 促销横幅

- 全宽深色（`#111111`）背景配白字
- 紧凑内边距（8–12px 垂直）
- 居中文字，12px/500 Helvetica Now Text Medium
- 用于运费促销、会员权益、促销公告

## 5. 布局原则

### 间距系统

基础单位：4px（主网格为 8px 倍数）

| Token | 值 | 用途 |
|-------|-------|-----|
| space-1 | 4px | 紧凑图标间距、内联间距 |
| space-2 | 8px | 基础单位、按钮图标间距 |
| space-3 | 12px | 卡片内部内边距、紧凑外边距 |
| space-4 | 16px | 标准内边距、导航间距 |
| space-5 | 20px | 产品卡片间距 |
| space-6 | 24px | 版块内部内边距、网格间距 |
| space-7 | 32px | 版块分隔 |
| space-8 | 48px | 主要版块内边距 |
| space-9 | 64px | 主视觉版块内边距 |
| space-10 | 80px | 大版块间距 |

### 网格与容器

- 最大容器宽度：1920px
- 标准内容宽度：约 1440px 配水平内边距
- 产品网格：桌面 3 列，平板 2 列，手机 1 列
- 品类网格：3 列配全幅图片
- 网格间距：产品卡片间 4–12px（刻意紧凑）
- 水平内边距：桌面 48px，平板 24px，手机 16px

### 留白（Whitespace）哲学

Nike 的留白（Whitespace）策略刻意激进——不是时尚品牌那种奢侈的呼吸感，而是压缩的高密度：每个像素要么是内容，要么是刻意的留白。产品网格用极小的间距（4–12px）营造丰富与选择的氛围。版块分隔充裕（48–80px）以区分购物场景。整体效果是一间塞满产品却依然好逛的店——如同一家组织良好的运动超市。

### 圆角（Border Radius）尺度

| 值 | 场景 |
|-------|---------|
| 0px | 产品图片、主视觉摄影（锐利边缘） |
| 8px | 表单输入框（非搜索） |
| 18px | 小型交互元素 |
| 20px | 容器、带 UI 内容的卡片 |
| 24px | 搜索输入框、中型胶囊 |
| 30px | 按钮、标签、筛选器（全胶囊） |
| 50% | 圆形图标按钮、头像占位 |

## 6. 纵深与层级

| 层级 | 处理 | 用途 |
|-------|-----------|-----|
| 平面 | 无阴影、无边框 | 一切的默认状态 |
| 分割线 | `0px -1px 0px 0px #E5E5E5 inset` | 版块间的微妙内嵌线 |
| 聚焦 | `0 0 0 2px rgba(39, 93, 197, 1)` | 键盘聚焦环 |
| 叠加 | 摄影上的深色罩 | 图上文字的可读性 |

Nike 的层级哲学是彻底的平面。没有卡片阴影、没有悬停抬升、没有悬浮元素。纵深只通过颜色传达——深色版块后退、浅色版块前进、灰度变化表示状态变化。这种平面强化了运动的、不废话的品牌个性：没有视觉花边，只有直接沟通。整个系统中唯一的"阴影"是 1px 的内嵌分割线和无障碍必需的聚焦环。

### 装饰性纵深

- **主视觉摄影叠加**：全幅摄影上的深色渐变罩，保证文字可读性
- **产品背景渐变**：主视觉产品图后的彩色背景（如红鞋配红色渐变）
- **横幅条**：页面顶部纯深色（#111111）促销条

## 7. 做法与禁忌

### 应该做

- 主要文字一律用 Nike 黑（#111111）——永不用纯 #000000
- 按钮保持胶囊形（30px 圆角），仅限主要/次级两种变体
- 主视觉版块用全幅、边缘到边缘的摄影——图片无圆角
- 让产品摄影提供所有色彩活力；UI 保持单色
- 全大写 Nike Futura ND 仅用于展示标题（96px+）
- 保持紧凑的产品网格间距（4–12px），营造密集、丰富的感觉
- 所有输入框与占位背景用灰 100（#F5F5F5）
- 色彩专属语义含义（红=错误、绿=成功、蓝=链接）
- 所有交互文字用字重 500（Medium）

### 不要做

- 不要给卡片加阴影——Nike 的层级模型完全平面
- 产品图片不要用圆角——只有 UI 元素能圆角
- UI 元素不要引入灰阶以外的品牌色
- Nike Futura ND 不要用在 24px 以下——它是专属展示字体
- 不要加悬停抬升效果——Nike 卡片悬停不动
- 按钮与链接不要用常规字重（400）——一律用 500
- UI 元素后面不要放彩色背景——色彩专属产品场景
- 每张卡片不要超过两级文字层级（标题 + 正文）
- 不要加装饰性分割线——1px 内嵌是唯一的分割模式
- 不要柔化对比——Nike 的设计刻意将黑白对比推到最大

## 8. 响应式行为

### 断点

| 名称 | 宽度 | 关键变化 |
|------|-------|-------------|
| 手机 | <640px | 单列、汉堡导航、展示文字缩小、16px 紧凑内边距 |
| 小平板 | 640–768px | 2 列产品网格开始，导航仍折叠 |
| 平板 | 768–960px | 2 列网格、品类卡片缩放、水平内边距 24px |
| 小桌面 | 960–1024px | 导航展开为完整横向，3 列产品网格 |
| 桌面 | 1024–1440px | 完整布局、展开导航、3 列网格、48px 内边距 |
| 大桌面 | >1440px | 最大宽度容器居中、页边距增大、主视觉图片全幅 |

### 触控目标

- 最小触控目标：44x44px（WCAG AAA）
- 移动端导航图标：48x48px 触控区域
- 产品卡片：整个表面可点
- 筛选胶囊：最小 36px 高配 12px 内边距

### 折叠策略

- **导航**：完整品类链接 → 960px 以下变为汉堡菜单；搜索、收藏、购物车图标保留可见
- **产品网格**：960px 处 3 列 → 2 列 → 640px 处 1 列
- **主视觉版块**：展示文字 96px → 64px → 48px 缩放；所有尺寸下主视觉图片保持全幅
- **品类卡片**：3 列 → 2 列 → 1 列，保持全幅影像
- **版块内边距**：80px → 48px → 32px → 24px 随视口收窄
- **促销横幅**：文字换行或截断，保持深色背景

### 图片行为

- 通过 Nike CDN（`c.static-nike.com`）响应式图片，带宽度参数
- 产品图片：srcset 多分辨率（w_320、w_640、w_960、w_1920）

- 艺术指导：桌面与手机的主视觉裁剪构图不同

### 迭代指南

用本设计系统优化已生成界面时：
1. 一次只聚焦一个组件
2. 引用本文档中的具体颜色名与色值
3. 记住：产品摄影即色彩——UI 保持单色
4. 用灰阶表达状态变化：#F5F5F5 → #E5E5E5 → #CACACB → #707072
5. 如果 UI 中某处感觉太花，八成就是——Nike 的 UI 保持灰阶
6. 展示字体（Nike Futura）必须全大写，且永不小于 24px
