# Bugatti 灵感设计系统

## 1. 视觉主题与氛围

Bugatti.com 的表现不像一个网站——它更像一部访客恰好置身其中的长篇汽车电影。画布是纯粹的 `#000000`，静态下出现的唯一颜色是白色，整个页面由通栏（full-bleed）主视觉（hero）视频与摄影承载，顶部叠加着一个排印瞬间。没有卡片、没有网格（grid）、没有促销模块、没有通讯订阅注册（newsletter signup）、没有三栏编辑布局。它是一条连续的影院黑通道，只有车辆本身和几枚胶囊形（pill）行动号召（CTA）将其打断，后者用 ALL CAPS 等宽字体安静地说着诸如 "EXPLORE OUR OPPORTUNITIES" 这样的文案。

整个系统中最具辨识度的手法是**尺度**：`Bugatti Display` 字体在主视觉时刻以 **288px** 呈现。二百八十八像素。这不是笔误——dembrandt 扫描提取到的标题样式以 18rem 尺寸渲染，ALL CAPS，行高（line-height）1.0，意在像阅读 Chiron 车头的品牌徽标那样被阅读：隔着整个展厅的距离。在 288px 下，标题不再是文字，而是建筑。与之相比，60px 的次级展示尺度几乎显得袖珍，36px 的中幅展示则像精细印刷品。这一排印层级（typographic hierarchy）是本目录中所有生产级品牌网站里最极端的一个，也正是它赋予了 Bugatti.com 雕塑般的高定时装展厅气质。

另一个标志是**单色克制（monochromatic austerity）**。整个首页在静态下恰好使用三种颜色：`#000000`、`#ffffff` 和 `#999999`（用于禁用/三级状态的中灰）。没有点缀色、没有品牌蓝、没有警示色、没有电商橙、没有渐变冲刷。设计师有意做出决定：Bugatti 的色彩体系应当就是车漆本身——页面是一个黑色丝绒展示台，存在的唯一色彩是主视觉车辆今天恰好穿着的黑底蓝色车漆。这种克制与 PlayStation 的 PlayStation Blue 或 The Verge 的 Jelly Mint 完全相反：Bugatti 拒绝与自己的产品争抢注意力。

**关键特征：**
- 整个页面采用影院黑 `#000000` 画布——无渐变、无色调、无点缀色
- 288px `Bugatti Display` 全大写标题——本目录中最极端的展示尺度
- 三字体定制家族：`Bugatti Display`（雕塑感）、`Bugatti Monospace`（UI 标签）、`Bugatti Text Regular`（正文）
- 纯单色色板：黑、白，以及唯一用于三级/禁用状态的 `#999999` 中灰
- 圆角（border-radius）`9999px` 的胶囊按钮（pill button）——透明底、1px 白色边框、内边距（padding）`12px 24px`
- 视频与摄影优先的页面——界面框架（chrome）近乎无声，让产品自己发声
- 所有 CTA、导航链接和图注（caption）均采用等宽全大写标签，字间距（letter-spacing）1.2–1.4px

## 2. 色板与角色

### 主色
- **丝绒黑（Velvet Black）**(`#000000`)：整个画布。不是近黑、不是暖黑——是纯粹的 HTML `#000`。Bugatti 将其视为展示台表面，就像珠宝品牌对待黑色丝绒布那样。
- **展厅白（Showroom White）**(`#ffffff`)：所有文字、所有边框、所有 CTA。白色是界面框架上静态时出现的唯一颜色，它有着如哑光博物馆标签上印刷字体的分量。

### 次级与点缀色
- **银雾灰（Silver Mist）**(`#999999`)：系统中唯一的灰色。用于次级按钮边框、禁用状态和最细的发丝分割线（hairline divider）。把它当作白色的"75% 音量"版本——永远不是一种颜色，只是同一种声音更安静的版本。

### 表面与背景
- **丝绒黑（Velvet Black）**(`#000000`)：唯一的表面。没有次级表面、没有上浮卡片、没有模态（modal）背景。如果某物需要显得"独立"，它就坐在同样的黑色上，并用一条细细的 `#999999` 边框标记——不改变颜色。

### 中性色与文字
- **主文字**(`#ffffff`)：所有标题、正文、按钮标签和导航项。
- **三级文字**(`#999999`)：免责声明文本、占位标签，以及最淡的辅助元数据。谨慎使用——Bugatti 更倾向于隐藏次级内容，而非将其调暗。

### 语义与点缀色
- **Tailwind 轮廓环泄漏（Tailwind Ring Leak）**(`rgba(59, 130, 246, 0.5)`)：构建系统提取的 token 中混入了 Tailwind 默认的 `--tw-ring-color`——这**不是** Bugatti 品牌色板的一部分。忽略它。如需真实的焦点（focus）态，改用 1px `#ffffff` 圆环。

### 渐变体系
无。Bugatti.com 上没有任何装饰性渐变。页面上唯一的"渐变"是主视觉车辆视频中自然存在的光线渐变。品牌拒绝使用任何可能与产品摄影氛围光竞争的界面框架渐变。

## 3. 排印规则

### 字体家族
- **Bugatti Display**——fallback：`ui-sans-serif`、`system-ui`。专为超大尺寸设计的专有定制展示字体，仅用于主视觉和中幅展示标题。它的设计目标是在建筑尺度下被阅读——在 288px 时，其字形几何兼具视觉元素而非仅是文字。该字体隐约带着 20 世纪初大奖赛（Grand Prix）排印的韵味（Ettore Bugatti 征战赛场的年代），但从不流于怀旧。
- **Bugatti Monospace**——fallback：`ui-sans-serif`、`system-ui`。专为网站所有 UI 标签保留的定制等宽字体。负责所有导航链接、所有按钮标签、所有图注和所有全大写元数据。严格的等宽字距（tracking）（所有用法均为 1.2–1.4px 字间距）让 UI 读起来像技术档案或仪表盘遥测打印件——对一家制造 1600 马力超跑的公司而言恰如其分。
- **Bugatti Text Regular**——fallback：`ui-sans-serif`、`system-ui`。正文主力字体，用于偶尔出现的段落和内联阅读文本。字重和样式都极其克制——这款字体的存在感为零，正好在展示字体呐喊、等宽字体低语时隐身。

### 原则
- **Bugatti Display 是雕塑，不是字体。**如果你发现自己在用 Bugatti Display 排正文或按钮，你用错了工具。将这款字体保留给 **36px 起步**的标题，理想是 60px 以上，每页至少一次使用 200px 以上的尺寸，营造品牌赖以立身的纪念碑式效果。
- **Bugatti Monospace 统领 UI。**每个导航链接、每个按钮、每条图注、每个眉题都用 Bugatti Monospace——通常是 UPPERCASE 加 1.2–1.4px 字距。这种等宽大写的纪律让 UI 读起来像大奖赛遥测面板，而非奢侈品购物车。
- **Bugatti Text Regular 是隐形的。**它只出现在短段落和内联阅读文本中，通常为 14–20px。绝不用于标签、按钮或展示。
- **没有加粗。**所提取 token 中的每个字重（font weight）都是常规（400）。Bugatti 不用字重做层级——它用尺度。需要强调时，把字放大，而不是加粗。
- **字距（tracking）有两种语域。**等宽大写永远带 1.2–1.4px 字间距。60px 以上的展示字体在主视觉尺度上有时会带 1.4px 字距。正文字体无字距。
- **展示字体的行高残酷地紧。**每个 Bugatti Display 用法都采用 1.00 或 1.11 的行高。标题换行时彼此相触——这就是设计。不要放松行距。

### 关于字体替代的说明
1.00 的行高和 288px 的展示尺度都基于**专有的 Bugatti Display 字体**，它为建筑尺度专门绘制了紧凑的垂直度量。如果用 **Unbounded**、**Big Shoulders Display** 或 **Archivo Black** 等开源宽体几何展示字体替代，请做两处调整：(1) **将行高放宽到约 1.05–1.10**，防止升部碰撞；(2) **在大多数视口（viewport）上将最大展示尺寸上限设为约 104–128px**——这些替代字体的水平度量比 Bugatti Display 更宽，288px 的巨幅标题会折成 4 行以上并压垮布局。将 200px 以上的尺度只保留给单个词的纪念碑式时刻（例如单独的 "BUGATTI"）。Bugatti Monospace 的替代字体（Space Mono、JetBrains Mono）和 Bugatti Text Regular 的替代字体（Inter、DM Sans）可按 token 值直接使用，无需调整。

## 4. 组件样式

### 按钮

**主按钮——白色描边胶囊**
- Background: transparent
- Text: `#ffffff`，Bugatti Monospace 14px / 400 / 1.4px 字距，UPPERCASE
- Border: `1px solid #ffffff`
- Border radius: `9999px`——完整胶囊
- Padding: `12px 24px`
- Outline: 静态下为 `rgb(255, 255, 255) none 0px`
- Hover：悬停时很可能填充 `#ffffff` 背景配黑色文字，或轻微降低不透明度（所提取的 token 集未捕获定制悬停态——由于 Bugatti 默认的交互就是克制，将此视为安全假设）
- Active：不透明度降至约 0.7
- Focus：用 1px `#ffffff` 外环，以 `box-shadow: 0 0 0 1px #ffffff, 0 0 0 2px #000000` 实现对比
- Transition：背景/颜色 200–300ms ease——安静，绝不弹跳

**次级——灰色圆角按钮**
- Background: transparent
- Text: `#ffffff`，Bugatti Monospace 12px / 400 / 1.2px 字距，UPPERCASE
- Border: `1px solid #999999`（银雾灰（Silver Mist））
- Border radius: `6px`——轻微圆角，系统中唯一非胶囊、非零的圆角
- Padding: `6px 12px`
- Hover：边框过渡为 `#ffffff`，文字保持白色
- Active：不透明度 0.7
- 用于紧凑型功能按钮（菜单切换、关闭对话框按钮）

**幽灵——无边框链接按钮**
- Background: transparent
- Text: `#ffffff`，Bugatti Monospace 12px / 400——常规大小写或 UPPERCASE
- 无边框、无内边距（除行内）
- 用于页脚和三级导航

### 卡片与容器
- **没有卡片。**Bugatti.com 没有卡片组件。整个页面是一连串通栏媒体区块，叠加标题和可选 CTA——更像电影章节，而非卡片网格。
- 最接近"容器（container）"的是罕见的有边框区块：`1px solid #999999` 边框、`6px` 圆角、`#000000` 内底。这些保留给 Cookie 同意（cookie-consent）通知和模态框（modal）式对话框，不用于编辑内容。
- 媒体区块的悬停（hover）态：无。视频播放，CTA 变得可点击——这就是全部交互词汇。

### 输入框与表单
- 所提取的 token 中**没有捕获任何输入框样式**（`⚠ Inputs: 0 styles`）。因为 Bugatti.com 首页几乎没有表单——没有通讯订阅注册、没有搜索栏、没有联系表单、没有邮箱采集。当表单出现时（在更深页面），请采用以下与系统其余部分一致的默认值：
  - **Default**：`#000000` 背景，`1px solid #999999` 边框，`6px` 圆角，Bugatti Text Regular 16px `#ffffff` 文字，占位符 `#999999`。
  - **Focus**：边框过渡为 `#ffffff`，无辉光——边框变化即是焦点信号。
  - **Error**：边框保持白色；下方添加 `#999999` 内联消息。Bugatti 不用红色错误色——始终保持单色色板。
  - **Transition**：边框颜色约 250ms ease。

### 导航

- **顶部导航**：黑色（`#000000`）细条，居中放置 Bugatti "EB" 字母徽标（monogram）或完整 "BUGATTI" 字标（wordmark），左侧是汉堡菜单（hamburger）"MENU" 链接，右侧是 "STORE" 链接。两个导航链接均为 Bugatti Monospace 14px UPPERCASE，加 1.4px 字距。
- **Logo**：桌面端尺寸 128×29px——比本目录中几乎所有其他品牌都小。Bugatti 不需要大声喊出自己的名字。
- **导航链接悬停**：颜色保持 `#ffffff`——悬停信号是细微的 text-decoration 下划线，或不透明度偏移到约 0.75。不改变颜色。
- **移动端**：完整导航收拢为仅三个元素——"MENU"、字标和 "STORE"——基本就是去掉分隔间距的桌面布局。
- **粘性（sticky）行为**：滚动时导航固定（pinned）在顶部，保持黑底黑字。当它与深色视频重叠时几乎不可见——这是有意为之。

### 图片与视频处理
- **长宽比（aspect ratio）**：主视觉视频 16:9 与 21:9，中幅特写摄影 4:3，罕见的竖构图 1:1。
- **边角**：罕见——大多数媒体通栏展示、圆角为零。出现圆角时为 `6px`。
- **通栏（full-bleed）**：是，永远。主视觉视频填满视口（viewport）。次级特写视频填满区块 100% 宽度。
- **图注**：Bugatti Monospace 12px UPPERCASE，`#ffffff`，约 1.2px 字距，置于媒体下方或左下角。
- **悬停**：无缩放、无放大、无遮罩。视频播放，这就是悬停态。
- **懒加载（lazy loading）**：首屏以下每张图片使用 `loading="lazy"`；主视觉视频预加载。

### 氛围叠加层
- 当文字压在可能影响可读性的摄影或视频上时，Bugatti 使用细微的 `rgba(0, 0, 0, 0.4)` 线性渐变，从底部（40% 黑）到顶部（透明）——这是系统中唯一的"类阴影"效果。它是暗角（vignette），不是投影（drop shadow）。

## 5. 布局原则

### 间距系统
- **基准单位**：8px。
- **尺度**（来自 token）：4、6、12、36、48、64px。六个值。**六个。**这是所有主流品牌网站中最小的间距尺度之一——Bugatti 只用一把离散的间距值，拒绝发明中间值。
- **区块内边距**：通常纵向 48–64px。主视觉面板为整视口高度，完全绕开该尺度。
- **按钮内边距**：6px 12px（紧凑）或 12px 24px（主按钮）。别无其他。
- **行内间距**：堆叠标签之间 4–12px；到 36/48/64 的大跳跃发生在内容区块之间。

### 网格与容器
- **最大宽度**：1720px（dembrandt 检测到的断点（breakpoint）上限为 1720）。网站可扩展到超宽，适配豪华展厅大屏和宽幅影院显示器。
- **分栏模式**：首页几乎没有多列网格——它是一叠单列通栏区块。当更深页面需要分栏时（配置器、定制工坊、技术规格），使用基于 Tailwind 的 12 列网格。
- **外边距（margin）**：极小。大多数区块直接出血到视口边缘，内边距只施加在叠加的文字与 CTA 区块上（通常距底部中央 48–64px）。

### 留白哲学
Bugatti 的留白（whitespace）哲学是**电影感负空间**——即使有内容，页面 90% 也是空的，因为内容通常只是一辆车的视频或照片。节奏是：通栏媒体 → 纪念碑式标题 → 单个胶囊 CTA → 滚动 → 下一个通栏媒体。没有任何"信息密度"可言。页面像博物馆一样呼吸，每个展品都拥有自己安静的房间。

### 圆角尺度
- **0**——所有媒体和主视觉画布的默认值
- **6px**——次级圆角按钮、有边框框架、小型功能容器
- **9999px**——主胶囊按钮

三个值。没有 `12px`、没有 `24px`、没有 `20px`。Bugatti 的圆角体系是本目录所有网站中最克制的一个——品牌主动决定"微圆角矩形"是一种庸俗的形状，并承诺只用真矩形或真胶囊。

## 6. 纵深与层级

| 层级 | 处理方式 | 用途 |
|---|---|---|
| 0 | 无阴影（shadow）、无边框 | `#000000` 上的默认文字与媒体 |
| 1 | `1px solid #999999` | 次级容器、Cookie 风格对话框 |
| 2 | `1px solid #ffffff` | 主按钮描边、激活态指示器 |
| 3 | 自下而上 `rgba(0, 0, 0, 0.4) → transparent` 暗角 | 文字压在视频上时的可读性渐变 |

**这就是全部纵深体系。**所提取的 token 集中有 1 个阴影（没有有意义的 `box-shadow` 值——只是一个占位符）。Bugatti 不用投影（drop shadow）。不用层级圆环。不用发光焦点态。纵深仅由 1px 的边框发丝线或暗角渐变的存在来暗示——别无其他。

### 装饰性纵深
无。零渐变（除细微的文字可读性暗角外）、零模糊、零辉光、零氛围效果。Bugatti 网站的装饰性纵深完全来自产品摄影中烘焙好的光线。界面框架不与之竞争。

## 7. 建议与禁忌

### 建议
- **要**让整个画布保持 `#000000`。不偏黑、不近黑、不暖黑。Bugatti 是纯粹的黑。
- **要**以建筑尺度使用 Bugatti Display——最低 36px，理想 60px 以上，每页至少落地一个 200px 以上的纪念碑式标题。
- **要**为每个按钮、链接、导航项和图注使用 Bugatti Monospace UPPERCASE，加 1.2–1.4px 字距。
- **要**在静态下只用白色文字。`#999999` 仅用于禁用、三级和细边框。
- **要**为主按钮使用 9999px 圆角——完整胶囊、1px 细白描边、透明填充。
- **要**为每个主视觉区使用通栏视频和摄影。产品即 UI。
- **要**让展示标题保持 1.00–1.11 的行高。紧凑的行距即是建筑。
- **要**把留白当作电影感负空间——给每个区块自己安静的房间。

### 禁忌
- **不要**引入点缀色。不用蓝、不用红、不用电商橙、不用悬停青、不用警示红。色板只有黑、白和一种灰。
- **不要**用加粗字重做层级。尺度是唯一的层级手段——放大，而不是加粗。
- **不要**在任何元素上用投影。Bugatti 的界面框架中没有 `box-shadow`。
- **不要**用卡片或上浮表面。Bugatti 没有卡片组件。
- **不要**用 6px 到 9999px 之间的圆角矩形。圆角体系只有矩形、微圆角功能形或完整胶囊——中间没有其他。
- **不要**把 Bugatti Display 用于正文、按钮或 UI 标签。只为 36px 以上的标题保留。
- **不要**在主 UI 中用小写的 Bugatti Monospace。按钮和导航链接永远是 ALL CAPS。
- **不要**在任何地方加渐变、辉光、模糊或玻璃拟态（glassmorphism）。界面框架是沉默的。
- **不要**在可读性受威胁时，把文字直接压在摄影上而不加 `rgba(0, 0, 0, 0.4)` 自下而上的暗角。

## 8. 响应式（responsive）行为

### 断点

| 名称 | 宽度 | 主要变化 |
|---|---|---|
| 移动端 | <640px | 单列、汉堡菜单 "MENU"、主视觉视频锁定 9:16 或 16:9、主视觉标题缩放到约 48–72px |
| 小平板 | 640–767px | 仍为单列，内边距略放开，字体放大 |
| 平板 | 768–1023px | 内容仍为单列，导航展开纳入字标，标题缩放到约 120px |
| 小桌面 | 1024–1279px | 完整桌面导航，标题缩放到约 200px |
| 桌面 | 1280–1535px | 完整布局，标题 240–260px |
| 大桌面 | 1536–1719px | 标题最大尺度（288px），超宽主视觉视频 |
| 超宽屏 | ≥1720px | 容器（container）封顶，主视觉视频锁定 21:9 或更宽，其余按比例不变 |

dembrandt 扫描检测到 6 个断点（1720 → 1536 → 1280 → 1024 → 768 → 640）。这比 PlayStation 的 30 个断点窄得多——Bugatti 为六个干净阈值调优，而非微调每个设备边界。品牌的假设是访客要么在高端笔记本上，要么在桌面显示器上，要么在手机上，网站无需为中间地带操心。

### 触控目标（touch target）
- 主胶囊按钮内边距 `12px 24px`、文字 14px——高度约 38–42px。**这略低于 WCAG AAA 44px 的建议**。做衍生设计时，请把纵向内边距提到 14–16px 以达到 44px 以上。
- 内边距 `6px 12px` 的次级按钮高度约 28–32px——明显低于触控目标最小值。仅在桌面指针场景使用。
- 导航链接没有显式内边距——点击区域就是文字框，14px 太小。在移动端加 `12–14px` 纵向内边距使其可点击。

### 收拢策略
- **导航**：桌面端显示 `MENU / BUGATTI 字标 / STORE`。移动端保持相同布局——没有抽屉，因为只有三个项。
- **网格**：没有可收拢的网格。页面在每个断点下本就是单列。
- **间距**：随视口变窄，区块内边距从 64 → 48 → 36 → 12px 收紧。
- **字体**：随视口变窄，Bugatti Display 从 288px → 200px → 120px → 60px → 48px 缩放。尺度曲线很激进——从最大到移动端主视觉之间缩水了 240px。
- **视频**：在 21:9 桌面版与 16:9 或 9:16 移动端主视觉剪辑之间做艺术指导（art direction）切换。

### 图片与视频行为
- 主视觉视频使用自适应码率流和 `poster=` 回退。
- 首屏以下媒体使用 `loading="lazy"`，配 `srcset` 艺术指导。
- Bugatti 通过 `imgix` 提供高密度图片——你会看到带变换参数的 `bugatti.imgix.net` URL。

## 9. Agent 提示词指南

### 颜色速查
- **主画布**：「丝绒黑（Velvet Black，`#000000`）」
- **主文字**：「展厅白（Showroom White，`#ffffff`）」
- **次级文字/禁用/发丝边框**：「银雾灰（Silver Mist，`#999999`）」
- **点缀色**：无。不要添加。
- **悬停信号**：不透明度变化或边框颜色变化——不改变颜色

### 示例组件提示词
1. *"用 Bugatti Display 以 288px 创建一个纪念碑式主视觉标题，ALL CAPS，`#ffffff` 文字置于纯 `#000000` 画布上，行高 1.0，无字间距。背后放置通栏 21:9 主视觉视频，配 `rgba(0, 0, 0, 0.4) → transparent` 自下而上的暗角以保证可读性。"*
2. *"设计一个主胶囊 CTA 按钮：透明背景、1px solid `#ffffff` 边框、`9999px` 圆角、12px × 24px 内边距，Bugatti Monospace 14px / 400 / 1.4px 字间距 UPPERCASE 标签，颜色 `#ffffff`。悬停态填充白色背景配黑色文字，250ms ease。"*
3. *"构建一个导航栏：纯 `#000000` 背景，左侧 `MENU` 链接，居中 `BUGATTI` 字标（128×29px），右侧 `STORE` 链接。所有链接为 Bugatti Monospace 14px UPPERCASE、1.4px 字间距、`#ffffff`。无分隔线、无悬停色——悬停时仅轻微降低不透明度。"*
4. *"创建一个中幅特写章节标题：Bugatti Display 60px ALL CAPS，`#ffffff`，行高 1.0，居中叠加在通栏照片上。在标题下方 48–64px 处放置单个主胶囊 CTA。"*
5. *"为 Cookie 对话框设计一个次级功能按钮：透明背景、1px solid `#999999` 边框、6px 圆角、6px × 12px 内边距，Bugatti Monospace 12px / 400 / 1.2px 字距 UPPERCASE 标签，颜色 `#ffffff`。"*

### 迭代指南
用本设计系统打磨已有界面时：
1. **检查画布。**如果背景不是纯 `#000000`，改掉它。Bugatti 不容忍偏黑。
2. **检查色板。**任何非 `#000000`、`#ffffff`、`#999999` 的颜色都是漂移。移除它——包括所有点缀色，以及 `#0070cc` Tailwind 蓝这类常见默认值。
3. **检查展示尺度。**如果页面最大标题小于 60px，就是尺度不足。Bugatti 的"纪念碑时刻"下限是 60px，上限是 288px。目标放在上半区。
4. **检查等宽大写纪律。**每个按钮、每个导航链接、每条图注、每个 CTA 都应是 Bugatti Monospace UPPERCASE 加 1.2–1.4px 字间距。如果在按钮上看到句首大写或混合大小写，那就是漂移。
5. **检查阴影与渐变。**剥离所有 `box-shadow`。剥离所有渐变，只保留视频上的那一个可读性暗角。Bugatti 的界面框架是沉默的。
6. **检查圆角。**每个容器都应落在 `0`、`6px` 或 `9999px`。如果看到 `12px`、`16px`、`20px`、`24px`，修正为最接近的 Bugatti 值（几乎总是 `6px` 或 `9999px`）。
7. **检查字重。**所有字重都应为 400。如果在任何地方看到 `bold` 或 `700`，改掉它。尺度而非字重，才是层级。
8. **检查留白。**如果某区块感觉局促，加 48–64px。如果感觉通透，就别动——Bugatti 的负空间本身就是特性。
9. **检查产品存在感。**每个主视觉区都应有一辆车——视频或照片——作为主视觉。界面框架应给人"在为车装裱"的感觉，而非与车竞争。
