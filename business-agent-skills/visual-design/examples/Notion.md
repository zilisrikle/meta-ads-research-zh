# Notion 风格设计系统

## 1. 视觉主题与氛围

Notion 的网站体现了工具本身的哲学：一块让路的空白画布。设计系统建立在暖中性色而非冷灰之上，营造出独特的亲和极简主义——像优质纸张而非冰冷玻璃。页面画布是纯白（`#ffffff`），但文字不是纯黑——而是暖的近黑（`rgba(0,0,0,0.95)`），微妙地柔化了阅读体验。暖灰色阶（`#f6f5f4`、`#31302e`、`#615d59`、`#a39e98`）带有黄棕底调，赋予界面触感般、近乎模拟时代的暖意。

定制的 NotionInter 字体（Inter 的修改版）是系统的骨干。在展示尺寸（64px）下使用激进的负字距（-2.125px），标题显得压缩而精准。字重范围比典型系统更宽：400 用于正文、500 用于 UI 元素、600 用于半粗标签、700 用于展示标题。大号文字启用了 OpenType 特性 `"lnum"`（等高数字，lining numerals）与 `"locl"`（本地化字形，localized forms），增加了细读时可感的排印（Typography）精致度。

Notion 视觉语言的独特性在于其边框哲学。Notion 不用粗边框或重阴影，而是使用超细的 `1px solid rgba(0,0,0,0.1)` 边框——如耳语般存在的边框，几乎察觉不到的分割线，创造结构而不增加重量。阴影系统同样克制：多层叠加的累计不透明度从不超过 0.05，营造"感受到而非看到"的纵深。

**关键特征：**
- NotionInter（Inter 修改版），展示尺寸用负字距（64px 下 -2.125px）
- 暖中性色板：灰色带黄棕底调（`#f6f5f4` 暖白、`#31302e` 暖深）
- 近黑文字用 `rgba(0,0,0,0.95)`——非纯黑，创造微暖
- 超细边框：全站 `1px solid rgba(0,0,0,0.1)`——耳语级分割
- 多层阴影叠加，不透明度低于 0.05，营造若有似无的纵深
- Notion 蓝（`#0075de`）作为 CTA 与交互元素的唯一点缀色
- 胶囊徽章（9999px 圆角）配淡蓝底，用于状态指示
- 8px 基础间距单位，尺度有机、非刚性

## 2. 色彩体系与角色

### 主色
- **Notion 黑**（`rgba(0,0,0,0.95)` / `#000000f2`）：主要文字、标题、正文。95% 不透明度柔化纯黑而不损可读性。
- **纯白**（`#ffffff`）：页面背景、卡片表面、蓝色上的按钮文字。
- **Notion 蓝**（`#0075de`）：主要 CTA、链接色、交互点缀——核心 UI 饰面中唯一的饱和色。

### 品牌次级
- **深藏青**（`#213183`）：次级品牌色，用于强调与深色功能版块，少量使用。
- **激活蓝**（`#005bab`）：按钮激活/按下状态——Notion 蓝的深色变体。

### 暖中性色阶
- **暖白**（`#f6f5f4`）：背景表面色调、版块交替、微妙的卡片填充。黄色底调是关键。
- **暖深**（`#31302e`）：深色表面背景、深色版块文字。比标准灰更暖。
- **暖灰 500**（`#615d59`）：次级文字、描述、弱化标签。
- **暖灰 300**（`#a39e98`）：占位文字、禁用状态、注释文字。

### 语义点缀色
- **青**（`#2a9d99`）：成功状态、积极指示。
- **绿**（`#1aae39`）：确认、完成徽章。
- **橙**（`#dd5b00`）：警告状态、注意指示。
- **粉**（`#ff64c8`）：装饰点缀、功能高光。
- **紫**（`#391c57`）：高级功能、深色点缀。
- **棕**（`#523410`）：大地色调点缀、暖色功能版块。

### 交互
- **链接蓝**（`#0075de`）：主要链接色，悬停加下划线。
- **浅链接蓝**（`#62aef0`）：深色背景上的浅色链接变体。
- **聚焦蓝**（`#097fe8`）：交互元素的聚焦环。
- **徽章蓝底**（`#f2f9ff`）：胶囊徽章背景，淡蓝色表面。
- **徽章蓝字**（`#097fe8`）：胶囊徽章文字，更深的蓝保证可读性。

### 阴影与纵深
- **卡片阴影**（`rgba(0,0,0,0.04) 0px 4px 18px, rgba(0,0,0,0.027) 0px 2.025px 7.84688px, rgba(0,0,0,0.02) 0px 0.8px 2.925px, rgba(0,0,0,0.01) 0px 0.175px 1.04062px`）：多层卡片抬高。
- **深阴影**（`rgba(0,0,0,0.01) 0px 1px 3px, rgba(0,0,0,0.02) 0px 3px 7px, rgba(0,0,0,0.02) 0px 7px 15px, rgba(0,0,0,0.04) 0px 14px 28px, rgba(0,0,0,0.05) 0px 23px 52px`）：五层深层抬高，用于模态框与精选内容。
- **耳语边框**（`1px solid rgba(0,0,0,0.1)`）：标准分割边框——卡片、分割线、版块。

## 3. 排印规则

### 字体族
- **主要**：`NotionInter`，回退：`Inter, -apple-system, system-ui, Segoe UI, Helvetica, Apple Color Emoji, Arial, Segoe UI Emoji, Segoe UI Symbol`
- **OpenType 特性**：展示与标题文字启用 `"lnum"`（等高数字）与 `"locl"`（本地化字形）。

### 原则
- **大尺寸压缩**：展示尺寸的 NotionInter 在 64px 用 -2.125px 字距，26px 放宽到 -0.625px，16px 回到 normal。压缩在标题营造密度，正文尺寸保持可读。
- **四字重系统**：400（正文/阅读）、500（UI/交互）、600（强调/导航）、700（标题/展示）。比大多数系统更宽的字重范围，允许更细腻的层级。
- **暖缩放**：行高随字号增大而收紧——正文 16px 用 1.50，次级标题用 1.23–1.27，展示用 1.00–1.04。标题更密集、更有冲击力。
- **徽章微字距**：12px 徽章文字用正字距（0.125px）——系统唯一的正字距，小字更宽、更易读。

## 5. 布局原则

### 间距系统
- 基础单位：8px
- 尺度：2px、3px、4px、5px、6px、7px、8px、11px、12px、14px、16px、24px、32px
- 非刚性有机尺度，微调用小数值（5.6px、6.4px）

### 网格与容器
- 最大内容宽度：约 1200px
- 主视觉：居中单列，顶部内边距充裕（80–120px）
- 功能版块：卡片 2–3 列网格
- 全宽暖白（`#f6f5f4`）版块背景用于交替
- 代码/面板截图收拢呈现，配耳语边框

### 留白（Whitespace）哲学
- **充裕的垂直节奏**：主要版块间 64–120px。Notion 让内容以巨大的垂直内边距呼吸。
- **暖色交替**：白色版块与暖白（`#f6f5f4`）版块交替，营造温和的视觉节奏而无突兀的色彩断裂。
- **内容优先的密度**：正文块紧凑（行高 1.50），但被充裕的外边距环绕，形成留白（Whitespace）海洋中可读内容的岛屿。

### 圆角（Border Radius）尺度
- 微型（4px）：按钮、输入框、功能性交互元素
- 微妙（5px）：链接、列表项、菜单项
- 标准（8px）：小卡片、容器、内联元素
- 舒适（12px）：标准卡片、功能容器、图片顶部
- 大（16px）：主视觉卡片、精选内容、促销块
- 全胶囊（9999px）：徽章、胶囊、状态指示
- 圆形（100%）：页签指示、头像

## 6. 纵深与层级

| 层级 | 处理 | 用途 |
|-------|-----------|-----|
| 平面（0 级） | 无阴影、无边框 | 页面背景、文本块 |
| 耳语（1 级） | `1px solid rgba(0,0,0,0.1)` | 标准边框、卡片描边、分割线 |
| 柔卡（2 级） | 4 层阴影叠加（最大不透明度 0.04） | 内容卡片、功能块 |
| 深卡（3 级） | 5 层阴影叠加（最大不透明度 0.05，52px 模糊） | 模态框、精选面板、主视觉元素 |
| 聚焦（无障碍） | `2px solid var(--focus-color)` 描边 | 所有交互元素的键盘聚焦 |

**阴影哲学**：Notion 的阴影系统使用多层极低单层不透明度（0.01 到 0.05），叠加成柔和、自然的抬高感。4 层卡片阴影从 1.04px 铺展到 18px 模糊，形成纵深渐变而非单一硬阴影。5 层深阴影在 0.05 不透明度下延伸到 52px 模糊，产生环境遮挡（ambient occlusion），像自然光而非计算机生成的纵深。这种分层方式让元素感觉嵌入页面，而非浮在页面之上。

### 装饰性纵深
- 主视觉版块：装饰性角色插画（俏皮、手绘风）
- 版块交替：白色到暖白（`#f6f5f4`）的背景切换
- 无硬版块边框——分隔来自背景色变化与间距

## 7. 响应式行为

### 断点
| 名称 | 宽度 | 关键变化 |
|------|-------|-------------|
| 小手机 | <400px | 紧凑单列，最小内边距 |
| 手机 | 400–600px | 标准手机，堆叠布局 |
| 小平板 | 600–768px | 2 列网格开始 |
| 平板 | 768–1080px | 完整卡片网格，内边距展开 |
| 小桌面 | 1080–1200px | 标准桌面布局 |
| 桌面 | 1200–1440px | 完整布局，最大内容宽度 |
| 大桌面 | >1440px | 居中，充裕页边距 |

### 触控目标
- 按钮使用舒适内边距（8px–16px 垂直）
- 导航链接 15px，间距充足
- 胶囊徽章 8px 水平内边距作为点击目标
- 移动端菜单切换用标准汉堡按钮

### 折叠策略
- 主视觉：64px 展示 → 缩至 40px → 手机 26px，保持比例字距
- 导航：横向链接 + 蓝色 CTA → 汉堡菜单
- 功能卡片：3 列 → 2 列 → 单列堆叠
- 产品截图：保持宽高比，响应式图片
- 信任栏 logo：手机上网格 → 横向滚动
- 页脚：多列 → 堆叠单列
- 版块间距：80px+ → 手机 48px

### 图片行为
- 所有尺寸下工作区截图保持耳语边框
- 主视觉插画按比例缩放
- 产品截图用响应式图片，保持一致的圆角
- 全宽暖白版块保持边缘到边缘的处理

## 8. 无障碍与状态

### 聚焦系统
- 所有交互元素都有可见的聚焦指示
- 聚焦描边：`2px solid` 配聚焦色 + shadow level 200
- 所有交互组件支持键盘 Tab 导航
- 高对比文字：白底近黑超过 WCAG AAA（>14:1 对比度）

### 交互状态
- **默认**：标准外观配耳语边框
- **悬停**：文字颜色变化，按钮 scale(1.05)，链接加下划线
- **激活/按下**：scale(0.9) 变换，更深的背景变体
- **聚焦**：蓝色描边环配阴影强化
- **禁用**：暖灰（`#a39e98`）文字，降低不透明度

### 色彩对比
- 主要文字（rgba(0,0,0,0.95)）白底：约 18:1 对比度
- 次级文字（#615d59）白底：约 5.5:1 对比度（WCAG AA）
- 蓝色 CTA（#0075de）白底：约 4.6:1 对比度（大号文字 WCAG AA）
- 徽章文字（#097fe8）徽章底（#f2f9ff）：约 4.5:1 对比度（大号文字 WCAG AA）
