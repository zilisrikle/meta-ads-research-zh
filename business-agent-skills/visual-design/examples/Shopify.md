# Shopify 风格设计系统

## 1. 视觉主题与氛围

Shopify.com 是一座深色优先的数字剧场——将自家电商平台如电影首映般舞台化的网站。整个体验在近黑表面的深渊中展开，带着深林绿最轻微的一丝耳语（`#02090A`、`#061A1C`、`#102620`），营造出夜幕氛围：不像 SaaS 营销页，更像科技 keynote 上的独家产品发布。这种黑暗不冷不企业——它是奢侈体验般温暖、包裹的暗，如坐在暗下来的礼堂前排。

排印（Typography）是无可争议的主角。NeueHaasGrotesk——精炼的 Helvetica 后裔——以纪念碑级尺寸（96px）呈现，字重轻得不可思议（330–400），标题如光刻而非墨印。`ss03` OpenType 特性赋予字母独特个性，将 Shopify 的字体与通用 Helvetica 用法区分开。展示层之下，Inter Variable 以外科手术般的精度处理正文，使用同样不寻常的可变字重（420、450、550），活在传统字重档位之间的空隙里。这种精度昭示着一家死磕每个细节的公司。

色彩的使用极度克制。主要点缀是 Shopify 霓虹绿（`#36F4A4`）——电光薄荷绿，只出现在聚焦环与点缀高光上，在深色画布上如生物荧光信号般脉动。更柔的绿色调（芦荟 `#C1FBD4`、开心果 `#D4F9E0`）提供氛围渲染。白色是深色表面上唯一重要的文字色，而锌基中性色阶（`#A1A1AA` 到 `#3F3F46`）处理安静信息的层级。结果是让电商技术仿佛属于科幻未来的设计。

**关键特征：**
- 深色优先设计，带深林青的底调（非纯黑）
- 纪念碑级尺寸（96px）的超轻展示排印（字重 330），营造空灵的存在感
- 霓虹绿（`#36F4A4`）作为深色上唯一的的高能点缀
- 全胶囊按钮（9999px 圆角）作为主要交互形状
- 分层、多阶段的 box 阴影，营造摄影级纵深
- 产品截图嵌入深色 UI 语境，与周围的黑暗融为一体
- 锌基中性色阶做文字层级——冷暖之间保持平衡

## 2. 色彩体系与角色

### 主色

- **Shopify 白**（`#FFFFFF`）：深色表面上的主要文字、按钮填充、高对比元素
- **Shopify 黑**（`#000000`）：正文背景、白底上的按钮文字、最大对比基底（--color-shade-100）

### 次级与点缀

- **霓虹绿**（`#36F4A4`）：标志性点缀——聚焦环、交互高光、激活状态指示。电光感、生物荧光感
- **芦荟**（`#C1FBD4`）：装饰背景的柔绿渲染、氛围卡片（--color-aloe-10）
- **开心果**（`#D4F9E0`）：最浅的绿色调，用于微妙的表面区分（--color-pistachio-10）

### 表面与背景

- **虚空**（`#000000`）：根页面背景——纯黑带来最大纵深
- **深青**（`#02090A`）：卡片表面、内容容器——带绿色底调的近黑
- **暗林**（`#061A1C`）：有明显绿色性格的版块背景
- **林**（`#102620`）：抬高的深色表面、页眉背景——最暖的深色调
- **深卡边框**（`#1E2C31`）：深色表面上的卡片边框，微妙的边界定义

### 中性色与文字（锌色阶）

- **Shade-30**（`#D4D4D8`）：最浅中性色，深底上若有似无的边框（--color-shade-30）
- **弱化文字**（`#A1A1AA`）：次级文字、元信息、描述——安静的语调
- **Shade-50**（`#71717A`）：第三级文字、时间戳、最不重要的信息（--color-shade-50）
- **Shade-60**（`#52525B`）：禁用文字、装饰中性色（--color-shade-60）
- **Shade-70**（`#3F3F46`）：微妙分割线、几乎不可见的 UI 边界（--color-shade-70）
- **浅边框**（`#E4E4E7`）：浅色表面上的边框（罕见——仅浅色模式模态框）

### 语义与点缀

- **链接弱化**（`#9797A2`）：带下划线装饰的弱化链接文字
- **链接鼠尾草**（`#9DABAD`）：青色调的弱化链接
- **链接薰衣草**（`#BDBDCA`）：更浅的链接变体
- **链接薄荷**（`#99B3AD`）：主题版块的绿色调链接变体

### 渐变体系

- **深青渲染**：从中心 `#102620` 到边缘 `#02090A` 的径向渐变——用于产品展示之后
- **绿色氛围**：主视觉版块后的微妙绿色调环境渐变，不用纯色创造纵深
- **聚光灯**：聚焦的亮区渐隐到黑——营造 keynote 式演讲照明

## 3. 排印规则

### 字体族

**展示：** NeueHaasGrotesk（精炼的 Helvetica 后裔，可变字体）
- 回退：Helvetica、Arial、sans-serif
- OpenType 特性：`ss03`（风格集 3——独特的字母变体）
- 可用字重：330、360、400、500、750（可变）
- 用于所有标题、主视觉文字与大展示元素

**正文：** Inter-Variable
- 回退：Helvetica、Arial、sans-serif
- OpenType 特性：`ss03`
- 可用字重：400、420、450、500、550（可变）
- 用于正文、链接、按钮、UI 元素

**等宽：** ui-monospace
- 回退：SFMono-Regular、Menlo、Monaco、Consolas、Liberation Mono、Courier New
- 用于代码片段、数据标签、技术内容

### 原则

Shopify 的排印是可变字体精度的大师课。展示层几乎完全活在字重 330–400——羽毛般的文字仿佛投影光般悬浮在深色背景之上。这与大多数 SaaS 网站的粗重路线正相反：别人在喊，Shopify 在大尺寸下低语。96px 标题配字重 330，创造出巨大尺寸与纤细笔画的悖论，既纪念碑又脆弱。`ss03` OpenType 特性激活的风格集让特定字符（可能是 'a'、'g' 和某些数字）外观更精炼，将 Shopify 的排印与标准 Helvetica Neue 用法区分开。Inter Variable 以外科手术精度处理正文层，使用 420、550 等活在传统档位之间的字重——每段文字都有恰好所需的视觉分量。

## 4. 组件样式

### 按钮

**主要（白填充）**
- 背景：白（`#FFFFFF`）
- 文字：黑（`#000000`）
- 边框：2px solid transparent
- 圆角：全胶囊（9999px）
- 内边距：12px 26px 12px 16px（不对称——右侧更多内边距以求视觉平衡）
- 悬停：轻微降低不透明度或背景变化
- 聚焦：2px `#36F4A4`（霓虹绿）描边环
- 过渡：all 200ms ease

**次级（幽灵/描边）**
- 背景：transparent
- 文字：白（`#FFFFFF`）
- 边框：2px solid 白（`#FFFFFF`）
- 圆角：全胶囊（9999px）
- 内边距：12px 26px 12px 16px
- 悬停：填充为白底黑字
- 聚焦：2px `#36F4A4` 描边

**徽章/标签（中性填充）**
- 背景：`rgba(255, 255, 255, 0.2)`（磨砂玻璃）
- 文字：白（`#FFFFFF`）
- 边框：无
- 圆角：微妙圆角（4px）
- 内边距：12px 16px
- 字体：16px regular

### 卡片与容器

- 背景：深色页上的深青（`#02090A`）
- 边框：1px solid `#1E2C31`（深卡边框）——几乎不可见的边界
- 圆角：标准卡片 8px，精选卡片 12px，顶部圆角卡片 20px 20px 0 0
- 阴影：多层系统：
  - 静息：`rgba(0,0,0,0.1) 0px 0px 0px 1px, rgba(0,0,0,0.1) 0px 2px 2px, rgba(0,0,0,0.1) 0px 4px 4px, rgba(0,0,0,0.1) 0px 8px 8px` + `rgba(255,255,255,0.03) 0px 1px 0px inset`
  - 内嵌白高光营造微妙的顶部边缘光
- 悬停：阴影扩展，卡片可能轻微提亮
- 过渡：box-shadow 300ms ease，transform 200ms ease

### 输入框与表单

- 背景：transparent 或暗林（`#061A1C`）
- 文字：白（`#FFFFFF`）
- 边框：1px solid `#3F3F46`（Shade-70）
- 圆角：8px
- 内边距：12px 16px
- 聚焦：2px solid `#36F4A4`（霓虹绿聚焦环）
- 占位符：Shade-50（`#71717A`）
- 过渡：border-color 200ms ease

### 导航

- 背景：transparent（叠加在深色主视觉上），滚动后变为林（`#102620`）
- 高度：约 64px
- 左：Shopify 文字标识 logo（SVG，深底白字）
- 中/右：导航链接 18px/500 NeueHaasGrotesk，白色，字距 0.72px
- CTA：白色胶囊按钮 "Start for free"（右）
- 次级 CTA：白边框幽灵按钮
- 悬停：链接变为弱化文字（`#A1A1AA`）或加下划线
- 移动端：汉堡菜单，全屏深色覆盖
- 过渡：滚动时 background 300ms ease

### 图片处理

- 产品截图：嵌入深色 UI 语境，与周围的黑暗融为一体
- 管理后台界面预览：展示在深色背景上，配微妙卡片边框
- 宽高比：多样——主视觉图宽（约 16:9），功能图灵活
- 所有图片与深色容器齐平——无亮色边框或画框
- 懒加载配深色占位表面

### 信任指标

- 数据醒目展示："15+"（年）、"150M+"（买家）
- 数字用 NeueHaasGrotesk 展示级尺寸
- 合作伙伴/开发者生态标语版块
- 深色主题的用户评价融入页面流

## 5. 布局原则

### 间距系统

基础单位：8px

| Token | 值 | 用途 |
|-------|-------|-----|
| space-1 | 4px | 紧凑内联间距 |
| space-2 | 8px | 基础单位、图标间距 |
| space-3 | 12px | 卡片内边距、紧凑外边距 |
| space-4 | 16px | 标准元素内边距 |
| space-5 | 24px | 卡片间距、版块内边距 |
| space-6 | 28px | 中等版块间距 |
| space-7 | 32px | 版块分隔 |
| space-8 | 36px | 大内边距 |
| space-9 | 40px | 主要版块内边距 |
| space-10 | 64px | 主视觉版块内边距、大间距 |

### 网格与容器

- 最大容器宽度：约 1280px（居中）
- 主视觉：全宽，深色背景边缘到边缘，文字居中
- 功能版块：文字 + 产品截图的 2 列布局
- 数据版块：大数字的横向布局
- 水平内边距：桌面 64px，平板 32px，手机 16px
- 网格间距：主要内容块间 24–32px

### 留白（Whitespace）哲学

Shopify 的留白（Whitespace）策略是戏剧化的。版块间以广阔的深色空间分隔——80px 到 120px 的纯黑呼吸空间——营造演讲而非网页的节奏。每个内容块都是 keynote 式滚动中的一张"幻灯片"。版块内部间距更紧、更刻意，在广阔虚空前形成焦点密度。宏观空旷与微观精度之间的对比，赋予网站电影般的节奏。

### 圆角（Border Radius）尺度

| 值 | 场景 |
|-------|---------|
| 4px | 标签、徽章、微元素 |
| 8px | 标准卡片、输入框、视频容器 |
| 12px | 精选卡片、图片容器、按钮（非胶囊） |
| 20px | 顶部圆角卡片（20px 20px 0 0）、模态框头 |
| 340px | 大圆角装饰元素 |
| 9999px | 胶囊按钮、胶囊徽章、导航元素 |

## 6. 纵深与层级

| 层级 | 处理 | 用途 |
|-------|-----------|-----|
| 基础 | 无阴影，深色表面 | 默认页面背景 |
| 微妙 | `rgba(0,0,0,0.1) 0px 0px 0px 1px` + 内嵌白光 | 静息卡片 |
| 中等 | 多层：1px 环 + 2px + 4px + 8px 阴影叠加 | 抬高卡片、精选版块 |
| 高 | `rgba(0,0,0,0.25) 0px 25px 50px -12px` | 模态框、下拉、叠加层 |
| 聚焦 | `0px 0px 0px 2px #36F4A4` | 键盘聚焦环（霓虹绿） |

Shopify 的阴影系统异常精致。卡片不用单值阴影，而是叠加的多层方案：1px 环定义边界，2px/4px/8px 渐进模糊营造自然光衰减，精致的内嵌白光（`rgba(255,255,255,0.03)`）模拟顶部打光的玻璃表面。在深色背景上，阴影从本已深色的表面再加深，因此阴影更像"环境遮挡"而非传统抬高——卡片仿佛微微沉入表面而非浮在其上。

### 装饰性纵深

- **深青渐变**：主视觉版块与产品展示后的环境径向渲染
- **聚光灯效果**：中央亮区渐隐到黑，营造 keynote 式戏剧照明
- **边缘光**：内嵌 box-shadow 在深色卡片上营造微妙的浅色边缘
- **绿色氛围光晕**：背景渐变中微弱的绿色调，呼应品牌点缀

## 7. 做法与禁忌

### 应该做

- 用深青黑表面层级（虚空 → 深青 → 暗林 → 林）表达纵深
- 展示排印保持字重 330–400——空灵的轻盈是设计的签名
- 霓虹绿（`#36F4A4`）专用于聚焦状态与关键点缀高光
- 所有主要 CTA 按钮用 9999px 圆角——全胶囊不容妥协
- 卡片抬高用多层阴影系统——单层阴影显得扁平
- 所有文字保持 `ss03` OpenType 特性——它是排印身份的一部分
- 正文用 Inter Variable、标题用 NeueHaasGrotesk——永不互换角色
- 版块间营造戏剧性间距（80px+），获得电影节奏

### 不要做

- 深色背景上的文字不要用纯黑（#000000）——只用白色（#FFFFFF）
- 不要引入暖色（橙、红、黄）——色板严格偏冷（绿、青、中性）
- NeueHaasGrotesk 正文不要用 500 以上的字重——重字重破坏空灵感
- 大面积表面不要用绿色点缀——霓虹绿只做小而精准的高光
- 交互元素不要用锐利棱角（0px 圆角）——一切都圆润
- 不要加亮色背景——深色主题是根本，不是可选项
- 不要用单层 box 阴影——叠加方案才是系统
- 正文行高不要超过 1.56——Shopify 的文字相对紧凑
- 同尺寸/同角色不要混用 NeueHaasGrotesk 与 Inter——它们的字重尺度不同
- 标题字距不要用 0 以下——Shopify 标题字距中性或正向

## 8. 响应式行为

### 断点

| 名称 | 宽度 | 关键变化 |
|------|-------|-------------|
| 手机 | <640px | 单列、汉堡导航、展示文字缩至 48px、16px 内边距 |
| 平板 | 640–1024px | 2 列网格开始、展示文字 70px、32px 内边距 |
| 桌面 | 1024–1440px | 完整布局、展开导航、96px 展示、64px 内边距 |
| 大桌面 | >1440px | 最大宽度容器居中、版块间距增大 |

### 触控目标

- 最小触控目标：44x44px（WCAG AAA）
- 胶囊按钮：最小 48px 高配充裕水平内边距
- 导航链接：44px 触控区域
- 卡片表面：带链接的卡片整卡可点

### 折叠策略

- **导航**：完整横向链接 → 1024px 以下汉堡菜单；logo 与 CTA 按钮保留可见
- **主视觉版块**：96px 展示 → 平板 70px → 手机 48px；保持单列居中对齐
- **功能版块**：2 列文字+图 → 768px 以下堆叠单列
- **数据**：横向行 → 手机堆叠纵向
- **版块内边距**：64px → 40px → 24px → 16px 随视口收窄
- **卡片**：网格 → 堆叠，手机上保持全宽

### 图片行为

- 所有图片用 CDN（`cdn.shopify.com`）配响应式 srcset

### 迭代指南

用本设计系统优化已生成界面时：
1. 一次只聚焦一个组件
2. 引用本文档中的具体颜色名与色值
3. 记住：这是深色优先设计——浅色表面是例外，不是常规
