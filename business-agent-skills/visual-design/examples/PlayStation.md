# 受 PlayStation 启发的设计系统

## 1. 视觉主题与氛围

PlayStation.com 像一家高端消费电子品牌旗下的营销部门，恰好在销售娱乐产品。页面被组织成一条**交替表面的垂直通道（vertical channel）**：近黑色的页眉（masthead）与首屏（hero）、中间一连串纸白色的编辑面板，以及深钴蓝色的页脚锚定整个体验。在这些表面模式之间，网站重度依赖摄影与 3D 产品渲染——PS5 主机、游戏封面艺术、DualSense 手柄——让硬件去做情感表达，而界面铬（chrome）保持克制。

标志性的排印（typography）手法是**大字号下的 SST Light（字重 300）**。Sony 定制的 SST 字体家族（font family）从 22px 到 54px 全部采用字重（weight）300，让展示标题（display headlines）拥有一种低语般的优雅气质，更接近奢侈腕表广告而非游戏商店。这种「安静的权威感」与 The Verge 的 Manuka 式呐喊、WIRED 的报摊密度恰恰相反——PlayStation 希望字体退后、产品领衔。正文与 UI 采用 500–700 字重，但*展示*声音始终轻盈而平静。

唯一打破克制的地方是**交互（interaction）**。每个主按钮都有相同的悬停（hover）动作：填充色切换为电光青 `#1eaedb`，出现 2px 白色边框，按钮背后绽放一圈 2px 的 PlayStation 蓝外环，整个按钮**放大 1.2 倍**。色彩弹出、边框、光环与抬升缩放的组合，是 Sony 在各大品牌中独有的标志性动作——一个微缩的「开机」动画，在单个页面上会重复数百次。

**关键特征：**
- 三表面通道布局：近黑首屏、纸白内容、钴蓝页脚——交替出现，绝不融合
- SST 字重 300、22–54px 的展示标题——「安静的权威感」标题，让产品摄影领衔
- PlayStation 蓝（PlayStation Blue）`#0070cc` 作为品牌锚点；青色（Cyan）`#1eaedb` 专用于悬停/焦点（focus）状态
- 每个可交互元素悬停时放大 1.2 倍——PlayStation 独有的标志性「开机」抬升
- 胶囊按钮（pill buttons）采用 999px 全圆角（border radius）；卡片（card）图稿采用 12–24px 圆角矩形
- 商业橙（Commerce Orange）`#d53b00` 专用于 PlayStation Store / 购买态 CTA（行动号召，call-to-action）
- 宽断点（breakpoints）覆盖至 2120px——网站一路适配到 4K 电视浏览场景

## 2. 色彩体系与角色

### 主色（品牌锚点）
- **PlayStation 蓝**（`#0070cc`）：品牌的锚点色。用于主页脚、内联链接、深色表面上的主按钮填充，以及每个「官方」标记。将其视为不可动摇——它是消费者记忆中与该品牌关联最深的颜色。
- **主机黑**（`#000000`）：纯黑，用于页眉、首屏背景与产品展示区。PlayStation 用黑色框定硬件，就像博物馆用黑色框定雕塑。

### 辅助色与点缀色
- **PlayStation 青**（`#1eaedb`）：交互色。**仅**用于按钮与链接的悬停、焦点与按下（active）状态。绝不作为默认背景或静止态文本色出现。悬停时搭配 2px `#ffffff` 边框与 2px `#0070cc` 外环，即可获得完整的标志性处理。
- **链接悬停蓝**（`#1883fd`）：内联文本链接悬停时使用的更亮变体。与青色不同——这是链接色，青色是按钮色。
- **深链接蓝**（`#0068bd`）：浅色表面上链接的静止态颜色——品牌蓝略微更饱和的近亲。

### 表面与背景
- **纸白**（`#ffffff`）：页眉与页脚之间编辑面板的主内容画布。
- **冰雾**（`#f5f7fa`）：浅色区块渐变（section gradient）的氛围终点。在某些面板后微妙使用，将其从纯白上托起。
- **分隔淡彩**（`#f3f3f3`）：内容行之间安静的水平分隔线颜色。
- **页眉黑**（`#000000`）：顶部导航与首屏画布——专用于以产品为先的区域。
- **阴影黑**（`#121314`）：当面板需要氛围纵深时，深色区块渐变的起始锚点。
- **滤镜雾**（`rgba(245, 247, 250, 0.3)`）：粘性（sticky）筛选条后的半透明背景——全站唯一的「玻璃拟态（glassmorphism）」时刻。

### 中性色与文本
- **展示墨**（`#000000`）：白色表面上的主展示标题。
- **深炭**（`#1f1f1f`）：正文标题与链接静止态颜色——比纯黑略柔，减少大面积色块的视觉振铃。
- **正文灰**（`#6b6b6b`）：次级正文与元数据。
- **静音灰**（`#cccccc`）：三级标签、禁用态。
- **占位墨**（`rgba(0, 0, 0, 0.6)`）：表单占位文本（placeholder）——60% 黑，而非单独的灰色值。
- **反白**（`#ffffff`）：深色与蓝色表面上的主文本。
- **深色链接蓝**（`#53b1ff`）：深色/黑色表面上链接的静止态颜色——为保证黑色上的可读性而调亮的 PlayStation 蓝空中变体。

### 语义色与商业色
- **商业橙**（`#d53b00`）：专用于 PlayStation Store 购买态 CTA、价格强调与「促销」徽章。全站唯一的暖色——节制使用，绝不出现在商业语境之外。
- **商业橙按下态**（`#aa2f00`）：商业按钮的按下/激活态。
- **警告红**（`#c81b3a`）：表单错误与破坏性操作警告。
- **阴影罩 80**（`rgba(0, 0, 0, 0.8)`）：产品摄影上首屏文字后的戏剧性遮罩（scrim）。
- **阴影罩 16**（`rgba(0, 0, 0, 0.16)`）：卡片上的低权重阴影层级（elevation）环。
- **阴影罩 08**（`rgba(0, 0, 0, 0.08)`）：羽量级卡片阴影层级——几乎不可见，但能将白色面板与白色背景分离。
- **阴影罩 06**（`rgba(0, 0, 0, 0.06)`）：系统中最轻的阴影。

### 渐变系统
PlayStation 只使用**两种区块渐变**，别无其他：
- **浅色区块渐变**：从 `#ffffff` → `#f5f7fa`——近乎不可察觉的晕染，安静地将面板托离画布。
- **深色区块渐变**：从 `#121314` → `#000000`——短促的垂直晕染，为首屏面板带来微妙暗角（vignette），不引入任何色相偏移。

两种渐变**仅用作区块背景**，绝不进入组件内部。没有渐变按钮、没有渐变文字、没有发光光晕。品牌是蓝色——不是蓝到紫，也不是蓝到青。

## 3. 排印规则

### 字体家族
- **SST** / **Playstation SST**（Sony 专有）——回退（fallback）：`Arial`、`Helvetica`。Sony 定制的全球字体，由 Toshi Omagari 与 Akira Kobayashi 设计。覆盖首页的 300 / 500 / 600 / 700 字重。**22–54px 的字重 300** 是 PlayStation 的排印签名。
- **SST（压缩 / 替代版）**——回退：`helvetica`、`arial`。在宽度受限的少数 UI 模块中使用的压缩变体。
- **Arial**——极少数以系统无衬线渲染的按钮变体的工具性回退。

### 原则
- **大字号的字重 300 就是声音。** PlayStation 是唯一用轻字重展示标题做首屏标题的主流主机品牌。克制住把展示字「升级」到 500 或 700 的冲动——安静即个性。
- **UI 层字重跳跃。** 18px 以下系统切换到 500–700 以保证可读性。从 300（展示）→ 400（正文）→ 500（说明）→ 700（按钮）的字重渐变就是层级。
- **字间距几乎不存在。** 多数值为 0.1–0.45px，正或微负。54px 首屏标题上的 `-0.1px` 恰好把展示字收紧到「被设计过」的程度，又不至于成为排印宣言。
- **两种 SST 字壳。** 「SST」与「Playstation SST」功能上是同一家族，只是度量（metrics）略有差异（Playstation SST 在小字号下更紧）。在 Sony 内部授权之外，可视为可互换。
- **没有全大写。** 与 The Verge 或 WIRED 不同，PlayStation 极少使用大写标签。眉题（kicker）与标签保持标题式大小写（title case）或句式大小写（sentence case）——又一记「安静的权威感」。
- **全站无衬线。** 整个系统都是无衬线（sans）。没有印刷声音的对位。

## 4. 组件样式

### 按钮

**主按钮——PlayStation 蓝胶囊**
- 背景：`#0070cc`（PlayStation 蓝）
- 文字：`#ffffff`，SST 18px / 500 / 0.4px 字距
- 边框：静止态无
- 圆角：`999px`——全胶囊
- 内边距：约 `12px 24px`（依尺寸等级变化）
- 轮廓：静止态为 `rgb(255, 255, 255) none 0px`
- **悬停（标志性动作）**：
  - 背景填充为 `#1eaedb`（PlayStation 青）
  - 文字保持 `#ffffff`
  - 出现 2px `#ffffff` 边框
  - 2px `#0070cc` 外环阴影绽放（`0 0 0 2px #0070cc`）
  - `transform: scale(1.2)`——按钮实际放大 20%
- 按下态：`opacity: 0.6`——快速变暗以示按压
- 焦点态：同悬停，但光环变为 `rgb(0, 114, 206) 0px 0px 0px 2px` 焦点阴影
- 过渡：背景、变换与阴影约 180ms 缓动

**次按钮——深色上的白色描边**
- 背景：`#ffffff`
- 文字：`#0172ce`（PlayStation 蓝变体）
- 边框：`2px outset #000000`——真正的 `outset` 边框，在现代 CSS 中极为罕见
- 圆角：多变（常为 `999px` 或 `36px`）
- 内边距：`16px 20px`
- 悬停：同样的标志性青填充 + scale(1.2) + 光环处理
- 焦点：同样的光环处理

**商业橙**
- 背景：`#d53b00`（商业橙）
- 文字：`#ffffff`，SST 18px / 700 / 0.45px 字距
- 圆角：`999px`——胶囊
- 仅用于 PS Store / 购买 / 订阅 Plus 的 CTA
- 按下态：背景加深为 `#aa2f00`
- 悬停：与其他按钮一样遵循青色反转规则（**不是**橙色专属悬停）

**透明幽灵按钮（Ghost）**
- 背景：透明
- 文字：`#1f1f1f`（深炭）
- 边框：`1px solid #dedede`
- 内边距：`0 10px`（紧凑，导航优化）
- 悬停：青填充、白字、2px 白边框、scale(1.2)
- 按下态：文字变为 `#0072ce`，不透明度 0.6

**图标圆**
- 背景：摄影上为 `rgba(0, 0, 0, 0.2)`；浅色表面上为 `#ffffff`
- 圆角：`100%`——正圆
- 用于轮播（carousel）上/下箭头与分享按钮
- 悬停：浅色上提亮为 `var(--color-role-backgrounds-primary-link-hover)`（约 `#e5e5e5`）

**迷你 CTA（卡片内）**
- SST 14px / 700 / 0.324px 字距
- 内边距约 8px 16px
- 圆角：`999px`
- 用于游戏卡片内的「立即购买」/「加入购物车」迷你 CTA

### 卡片与容器

**首屏卡片（游戏特性）**
- 背景：摄影/渲染——通常以黑色为锚
- 圆角：特性卡片为 `24px` 或 `19px`
- 内边距：32–48px
- 阴影：`rgba(0, 0, 0, 0.8) 0px 5px 9px 0px`——仅当卡片叠加在首屏摄影上时使用的戏剧性投影（drop shadow）
- 悬停：微妙的缩放变换，主 CTA 上出现青色描边

**游戏封面 tile**
- 背景：游戏封面图，无内边距
- 圆角：`12px` 或 `13px`（图片）/ `19px`（卡片框）
- 阴影：`rgba(0, 0, 0, 0.08) 0px 5px 9px 0px`——羽量级阴影层级
- 悬停：卡片的主 CTA 亮起青色，卡片本身可放大 1.02 倍
- 过渡：变换 200ms 缓动

**内容面板（白）**
- 背景：`#ffffff` 或浅色区块渐变 `#ffffff → #f5f7fa`
- 边框：通常无；以间距与微妙阴影与相邻面板分离
- 圆角：依面板层级为 `12px`–`24px`
- 阴影：`rgba(0, 0, 0, 0.06) 0px 5px 9px 0px`——系统中最轻

**深色上的深卡**
- 背景：摄影上的 `rgba(0, 0, 0, 0.2)`
- 圆角：`6px`（紧凑）或 `24px`（特性）
- 用于首屏视频上的「媒体资料包」或「数据块」内嵌

### 输入框与表单
- **默认**：`#ffffff` 背景，`1px solid #cccccc` 边框，`3px` 圆角（比系统其余部分更紧——输入框是 PlayStation 唯一真正紧凑的地方），SST 16px 文字为 `#1f1f1f`，占位符为 `rgba(0, 0, 0, 0.6)`。
- **焦点**：2px `#0070cc` 焦点环（focus ring），通过 `box-shadow: 0 0 0 2px #0070cc` 实现。不改变边框色——光环完成工作。
- **错误**：边框与文字变为 `#c81b3a`（警告红），下方内联错误文本同为红色。
- **过渡**：边框与阴影约 180ms 缓动。

### 导航

- **顶部导航**：黑色（`#000000`）通栏条，PlayStation 标志（白色）左对齐，分类链接居中（SST 14–16px / 500），右侧一个小「登录」CTA。
- **导航链接悬停**：颜色从 `#ffffff` 过渡到 `#1883fd`（链接悬停蓝），无下划线。
- **当前区块**：以 `#0070cc` 的 2px 下划线微妙标记。
- **移动端**：导航收起为汉堡抽屉（drawer）。抽屉内链接垂直堆叠，16px 间距、20px 水平内边距。
- **粘性行为**：导航滚动时固定在顶部；进入浅色表面区域时**不反转**——始终保持黑色底。

### 图片处理

- **宽高比（aspect ratio）**：16:9 首屏视频/摄影、1:1 主机渲染、3:4 游戏封面、4:3 生活方式影像。
- **圆角**：依卡片语境为 `12px`、`13px` 或 `24px`。游戏封面取 `6–12px`，首屏图片取 `24px`。
- **通栏**：仅用于页眉首屏与页脚促销横幅。其余全部置于带内边距的内容列内。
- **阴影**：首屏用戏剧性 `rgba(0, 0, 0, 0.8) 0 5px 9px 0` 投影，网格 tile 用羽量级 `rgba(0, 0, 0, 0.06) 0 5px 9px 0`。
- **悬停**：图片静止，卡片框与主 CTA 响应。
- **懒加载（lazy loading）**：首屏以下全部 `loading="lazy"`，页眉首屏用 `eager`。

### 游戏商店胶囊（特色）
- 背景：`#ffffff`
- 文字：`#000000`，SST 14px / 500
- 内边距：`14px 18px`
- 圆角：`9999px`——全胶囊
- 置于游戏封面旁标注平台（「PS5」「PS4」「PSVR2」）的中性胶囊标签。深底白字对比。

## 5. 布局原则

### 间距系统（Spacing System）
- **基准单位（base unit）**：8px。
- **刻度**：1、2、3、4.5、5、8、9、10、12、14、15、16、18、20、21px。
- **区块内边距**：主面板之间垂直 48–96px。首屏到内容的过渡取较大值。
- **卡片内边距**：20–32px。特性首屏卡片可扩展到 48px。
- **内联间距**：标题与副标题之间 8–12px，副标题与 CTA 之间 12–16px。
- **微刻度**：1/2/3/4.5/5/9/10/12 的值用于胶囊内边距、说明间距与边框偏移——不用于编辑节奏。

### 网格（Grid）与容器
- **最大宽度**：约 1920px（dembrandt 检测到断点达 2120px）。容器上限通常依面板为 `1280–1920px`。
- **列模式**：12 列响应式网格，依层级解析为 3/4/6 列的游戏 tile 行。首屏区常占满 12 列；特性 tile 采用 6+3+3 或 4+4+4 配置。
- **外边距**：16px（移动）→ 48px（平板）→ 64–96px（桌面）。
- **槽距（gutters）**：列之间 16–24px，tile 簇内部更紧（8–12px）。

### 留白哲学（Whitespace Philosophy）
PlayStation 对待留白（whitespace）就像奢侈品牌对待店内灯光——是一种高级信号。模块之间的垂直呼吸空间明显大于其他任何主流零售网站，白色编辑面板在首屏级内边距下常常只放一个标题 + 一张图 + 一个 CTA。效果是「画廊节奏」：每个产品拥有自己的房间，而不是在缩略图网格中竞争。

### 圆角刻度
- **2px**——cookie 横幅按钮与小管理 UI
- **3px**——表单输入框、标签页（比其余都紧——一种刻意的「功能 UI」提示）
- **6px**——紧凑按钮与内联图片
- **12px**——标准游戏封面图与内容图
- **13px**——某些 figure 包裹层（为嵌套与 12px 差 1px 偏移）
- **19px**——特性卡片
- **20px**——内联标签 span
- **24px**——首屏卡片、主特性框
- **36px**——全胶囊导航与次按钮变体
- **48px**——大特性按钮
- **999px / 100%**——全胶囊主按钮与圆形图标按钮

十一个离散圆角值——本目录中圆角系统最丰富的网站之一。存在这个跨度是因为 PlayStation 刻意为不同*层级*使用不同圆角：3px 给工具、12px 给媒体、24px 给特性、999px 给 CTA。

## 6. 纵深（Depth）与阴影层级（Elevation）

| 层级（Level） | 处理（Treatment） | 用途（Use） |
|---|---|---|
| 0 | 无阴影 | `#ffffff` 上的默认内容 |
| 1 | `rgba(0, 0, 0, 0.06) 0 5px 9px 0` | 羽量级编辑面板抬升 |
| 2 | `rgba(0, 0, 0, 0.08) 0 5px 9px 0` | 标准网格 tile 阴影层级 |
| 3 | `rgba(0, 0, 0, 0.16) 0 5px 9px 0` | 强调卡片（悬停或激活） |
| 4 | `rgba(0, 0, 0, 0.8) 0 5px 9px 0` | 首屏叠加阴影——摄影上的戏剧性投影 |
| 5 | `0 0 0 2px #0070cc`（焦点环） | 主按钮焦点态 |
| 6 | `0 0 0 2px #000000`（悬停环） | 次按钮悬停环 |
| 7 | 区块渐变 `#121314 → #000000` | 深色首屏面板的氛围纵深 |

PlayStation 的纵深哲学是**分层但克制**。阴影刻度正常态从 0.06 到 0.16，首屏投影直接跳到 0.8——没有 0.2、0.3、0.4 的中间地带。效果是页面大部几乎全平，但当首屏卡片需要在摄影上浮起时，它是真的*浮*起来。阴影层级要么低语，要么呐喊，从不含糊。

### 装饰性纵深
- **区块渐变**（深色与浅色，均如上所述）——仅用作区块背景
- **焦点/悬停环** 2px，依状态为蓝色或青色
- 除两种区块渐变外**无辉光、模糊或氛围效果**
- **无渐变按钮或文字**——除区块过渡外，视觉系统处处是纯色块

## 7. 要做与不要做

### 要做
- **要**用 PlayStation 蓝（`#0070cc`）作为主 CTA 填充与页脚锚点。它是品牌的锚点色。
- **要**对 22px 及以上的每个展示标题使用 SST 字重 300。轻字重标题就是声音。
- **要**给每个主按钮应用完整的悬停签名：青填充 + 2px 白边框 + 2px 蓝外环 + `scale(1.2)`。
- **要**在主按钮与商业按钮上使用全胶囊圆角（`999px`）。
- **要**把 PlayStation 青（`#1eaedb`）专用于悬停、焦点与激活态——绝不作为静止态背景。
- **要**只在 PlayStation Store / 购买 CTA 与价格强调上使用商业橙（`#d53b00`）。
- **要**交替深色首屏面板与白色内容面板，并以深蓝页脚锚定——三表面通道布局就是页面节奏。
- **要**在卡片叠加产品摄影时使用戏剧性的 `rgba(0, 0, 0, 0.8)` 首屏投影。
- **要**让顶部导航在任何滚动位置都保持黑色——它不会在浅色面板上反转为白色。

### 不要做
- **不要**加粗展示标题。22–54px 的字重 300 就是 PlayStation 的声音。700 字重的展示字读起来像「另一家游戏零售商」。
- **不要**使用全大写标签或眉题。PlayStation 极少用大写——它是安静权威的品牌，不是警戒带品牌。
- **不要**在两种已声明的区块渐变之外使用渐变按钮、文字或背景。
- **不要**在商业橙之外引入暖色。没有红色 CTA、没有黄色高亮、没有绿色成功胶囊。
- **不要**在按钮或媒体上使用直角。系统有十一个圆角——选一个，但绝不用 `0`。
- **不要**在主按钮上跳过 `scale(1.2)` 悬停动作。抬升缩放是品牌交互签名。
- **不要**使用衬线体。系统 100% 是 SST 无衬线。
- **不要**让青色 `#1eaedb` 在静止态作为文本或背景色出现。它只存在于动效中。
- **不要**设计互相争抢注意力的面板。PlayStation 的留白节奏给每个模块自己的「画廊房间」。

## 8. 响应式行为

### 断点

| 名称（Name） | 宽度（Width） | 关键变化（Key Changes） |
|---|---|---|
| 小手机 | <400px | 单列，导航收起为汉堡菜单，SST 首屏标题缩至约 28px |
| 手机 | 400–599px | 单列，tile 全宽堆叠，内边距开到 16px |
| 大手机 | 600–767px | 仍为单列，但部分模块可选 2 列 tile |
| 平板竖屏 | 768–1023px | 2 列游戏网格，导航仍为紧凑态 |
| 平板横屏 | 1024–1279px | 3–4 列网格，完整导航恢复 |
| 桌面 | 1280–1599px | 完整编辑网格，首屏展示最大字号（44–54px） |
| 大桌面 | 1600–1919px | 容器上限 1600px，外边距扩展 |
| 4K / 大屏 | ≥1920px | 容器扩展至最大 1920px，首屏内容放大以匹配电视观看距离 |
| 超宽屏 | ≥2120px | 极限断点——页面保持锚定，超宽部分由外边距吸收 |

dembrandt 扫描在 320px 到 2120px 之间检测到 30 个断点——响应范围异常之宽。PlayStation 专门为**大屏场景**（1920–2120px）调优，因为 PS5 用户经常通过主机浏览器或手机投屏在电视上浏览本站。多数零售网站调到 1440px 就停了；PlayStation 一直调到 4K。

### 触控目标（Touch Targets）
- 主胶囊按钮高约 48–56px（SST 18px 文字 + 约 12–16px 垂直内边距）——轻松达到 WCAG AAA。
- 桌面端导航链接较小（高约 32–40px）；移动端在抽屉内撑到 48px+。
- 图标圆按钮 40–48px——触控友好。

### 收起策略
- **导航**：随视口变窄，完整导航 → 紧凑 → 汉堡抽屉。标志固定在左，CTA 固定在右。
- **网格**：6 列 → 4 列 → 3 列 → 2 列 → 1 列。游戏 tile 卡片重排（reflow）不裁剪封面图。
- **间距**：区块内边距随视口变窄从 96px → 64px → 48px → 32px → 24px 收紧。
- **字体**：SST 首屏标题从 54px → 44px → 35px → 28px → 22px 缩放。每种字号都保留轻字重 300。
- **首屏摄影**：视觉指导（art direction）切换——桌面用宽 16:9 裁剪，移动用 4:3 或 1:1 裁剪并居中产品。

### 图片行为
- 响应式位图（`srcset` + 带视觉指导的 `<picture>`），各断点保持宽高比。
- 4K 就绪：1920px+ 提供高密度图片，避免在电视浏览时放大模糊。
- 首屏以下全部 `loading="lazy"`；首屏 `eager` 并带预加载提示。

## 9. Agent 提示词指南

### 快速色彩参考
- **主 CTA**：「PlayStation 蓝（`#0070cc`）」
- **悬停 / 焦点点缀**：「PlayStation 青（`#1eaedb`）」
- **背景（白色表面）**：「纸白（`#ffffff`）」
- **背景（深色表面）**：「主机黑（`#000000`）」
- **白色上的标题文字**：「展示墨（`#000000`）」
- **白色上的正文**：「深炭（`#1f1f1f`）」
- **黑色上的正文**：「反白（`#ffffff`）」
- **商业 / 购买点缀**：「商业橙（`#d53b00`）」
- **页脚锚点**：「PlayStation 蓝（`#0070cc`）」

### 示例组件提示词
1. *「创建一个主 CTA 按钮：`#0070cc` PlayStation 蓝填充，白色文字，SST 18px / 500 / 0.4px 字距，999px 圆角，12px × 24px 内边距。悬停时背景过渡为 `#1eaedb` PlayStation 青，出现 2px `#ffffff` 边框，通过 box-shadow 绽放 2px `#0070cc` 外环，整个按钮放大 1.2 倍——全部在 180ms 缓动过渡内完成。」*
2. *「设计 `#000000` 主机黑画布上的首屏面板：54px SST 字重 300 标题，`#ffffff`，-0.1px 字间距，1.25 行高。下方放一个带标准 PlayStation 悬停处理的主 CTA。任何地方都不用全大写标签。」*
3. *「构建游戏封面 tile：3:4 宽高比图片，12px 圆角，羽量级 `rgba(0, 0, 0, 0.08) 0 5px 9px 0` 投影，下方 14px SST 700 标题、12px SST 500 平台标签，以及 PlayStation 蓝的迷你 14px / 700 / 0.324px 字距主 CTA。」*
4. *「创建 PlayStation Store 购买用的商业胶囊按钮：`#d53b00` 商业橙填充，`#ffffff` 文字，SST 18px / 700 / 0.45px 字距，999px 圆角，12px × 28px 内边距。按下态加深为 `#aa2f00`。悬停遵循标准青色反转 + 1.2 倍缩放。」*
5. *「设计深色首屏区块之间的白色内容面板：`#ffffff` 背景带微妙的 `#ffffff → #f5f7fa` 浅色区块渐变，24px 圆角，48px 内边距，羽量级 `rgba(0, 0, 0, 0.06) 0 5px 9px 0` 阴影层级，35px SST 300 标题，一段 18px 正文，一个主 CTA。」*

### 迭代指南
在用该设计系统打磨已有界面时：
1. **审计展示字重。** 22px 及以上的每个标题都应为 SST 字重 300。如果在首屏字号看到 500 或 700 字重，PlayStation 的声音就丢了。
2. **审计悬停处理。** 每个主按钮悬停必须 1.2 倍放大，并带青填充 + 白边框 + 蓝光环组合。缺了四者之一，交互签名就破了。
3. **审计圆角。** 每个容器与按钮都应落在 2、3、6、12、13、19、20、24、36、48 或 999px / 100% 上。直角破坏声音。
4. **审计色彩蔓延。** 界面铬中只应出现 PlayStation 蓝（`#0070cc`）、青（`#1eaedb`）、商业橙（`#d53b00`）与已声明的灰/黑/白。看到其他色相就纠正。
5. **审计表面交替。** 页面应交替：深色首屏 → 白色内容 → 深色首屏 → 白色内容 → 蓝色页脚。若两个同表面面板相邻，插入过渡。
6. **审计大小写。** 只用句式与标题式大小写。标签、按钮、眉题不用全大写。看到大写就转掉。
7. **审计阴影权重。** 阴影不透明度应落在 0.06 / 0.08 / 0.16 / 0.8——之间没有。如果看到 0.1、0.2、0.3、0.5 的投影，纠正到最近的已声明层级。
8. **审计留白。** 如果两个模块感觉在「竞争」（争抢注意力），加 48–96px 垂直呼吸空间。PlayStation 的画廊节奏不可妥协。
