# Google Demand Gen

## 运营实践

Demand Gen 是视觉化、社交风的 Google 广告系列类型。规划和评估它时更接近付费社交（paid social）而不是 Search：它更多是创造和预热需求，而不是收割明确意图。

### 最重要的事

- **创意和受众种子质量是主要杠杆。** 高质量的购买者 / 客户列表、相似受众、短视频、生活方式图、轮播、商品 Feed 创意，通常比微小的定向调优重要得多。
- **相似受众用高质量种子。** 近期购买者、高 LTV 客户、合格线索、留存用户，比"所有网站访客"或"所有转化者"更好。弱种子产出弱相似受众。
- **创意必须在 YouTube / Discover / Gmail 里看起来原生。** 通用图库、logo 堆砌的横幅、Search 风文案通常表现差。用钩子、产品场景、真人 / 产品使用中的画面、清晰的 offer 路径。
- **按角色评判，不只看末次点击。** Demand Gen 能带动品牌搜索、助攻转化、再营销池和 P-MAX 表现。直接 CPA 重要，但在中漏斗角色下可能低估贡献。
- **除非任务不同，避免和 P-MAX 重叠。** Demand Gen 要有明确的角色：冷启动视觉拉新、商品发现、中漏斗教育、再营销或交叉销售。
- **量级支撑拆分之前先合并。** 按人群拆的微型广告组常常把广告系列困在学习期。只有创意、受众、出价目标或业务目标真不同才拆。
- **预算要有意义。** 很小的 B2B 或小众广告系列常常失败，因为系统永远攒不够信号。这种情况下，先用 Demand Gen 做再营销 / 客户列表。

- **Demand Gen 要有明确的漏斗任务。** 好的任务包括冷启动视觉拉新、商品发现、中漏斗教育、达人 / UGC 风信任状、再营销、交叉销售。"像 P-MAX 一样拿更多转化"太含糊。
- **相似受众的种子质量压倒相似受众设置。** 首选近期购买者、高 LTV 客户、合格线索、活跃订阅者、留存应用用户。质量差异大时避免用"所有访客"这种稀释的种子。
- **付费社交的赢家是好的起点。** 在 Meta / TikTok 风信息流里跑出来的创意，适配 Demand Gen 往往比 Search 或 Display 横幅更好。
- **Shorts 能给量但要原生创意。** 默认竖版、快开场、配文字的创意。横版硬改常常浪费这个版位。
- **创意数量在一定范围内胜过精致度。** 持续产出差异化切入角度的管线，通常胜过几条精雕细琢的素材。审批瓶颈要当运营问题处理。
- **Demand Gen 能带动 Search。** 末次点击 CPA 看起来弱时，先查品牌搜索提升、助攻转化和再营销池变化，再下"没价值"的结论。

### 诊断

| 症状 | 先查 | 可能的行动 |
|---|---|---|
| CTR 低 | 钩子、首帧、原生感、offer 清晰度、素材比例 | 更新概念，加视频 / 轮播，用社交风赢家 |
| CTR 好但 CVR 弱 | 落地页、受众种子、offer、转化动作 | 改进落地页 / offer，优化种子，用合格的转化 |
| 花不出去 | 受众太窄、目标太紧、素材 / 广告效力弱 | 合并、放宽、放目标、加素材 |
| 按末次点击看很弱 | 品牌搜索提升、助攻转化、对照组可行性 | 评估增量性或混合漏斗影响 |

### 常见陷阱

- 把 Search 文案直接当视觉信息流文案用。
- 2–3 条精致素材跑几个月不更新概念。
- 质量差异大时还用"所有转化者"或"所有访客"列表做相似受众种子。
- 转化延迟和助攻影响还没显现就杀掉广告系列。

## 1. 广告格式

### 1-1. 单图广告（多素材广告）

上传多张图片、标题、描述和 CTA；Google AI 按版位和用户选最优组合。

- 三种比例（横版、方版、竖版）都上，可投放库存最大。
- 每条素材必须自成一体——AI 会生成任意组合。

### 1-2. 视频广告（自适应视频广告）

用已上传到 YouTube 的视频。横版、方版、竖版组合，覆盖信息流内、Feed、Shorts。

- 前 5 秒讲清品牌和价值主张。
- 按静音播放设计（字幕、文字叠加）。
- 建议：16:9（横版）+ 1:1（方版）+ 9:16（竖版）一套。

### 1-3. 轮播图片广告

2–10 张可滑动卡片。每张卡可以有自己的标题和目标网址。

- 轮播里所有卡必须同比例。
- 支持的比例：1.91:1（横版）/ 4:5（竖版）/ 1:1（方版）。
- 适合叙事弧线（问题 → 解决 → CTA）或并排展示多个商品。

### 1-4. 商品 Feed 广告（电商）

Merchant Center 商品 Feed + 图片 / 视频创意组合。三种子类型：

| 子类型 | 说明 |
|---|---|
| **图片 + 商品** | 图片创意 + 商品 Feed |
| **视频 + 商品** | 视频创意 + 商品 Feed |
| **仅商品** | 无创意；只靠商品 Feed 投放 |

## 2. 提审规格

制作规格见 [creative-strategy.md](creative-strategy.md#demand-gen-baseline)。Demand Gen 专属规划规则：

- 尽量上横版、方版、竖版素材；Shorts 需要竖版创意。
- 每个标题、描述、图片、视频、轮播卡都必须自成一体，因为 Google 动态组装组合。
- CTA 用"自动"，除非有明确理由强制指定 CTA。
- 轮播保持卡片质量和信息一致；一张弱卡会拖累整个单元。
- 电商用商品 Feed 创意前，先核对 Merchant Center Feed 地区和配送设置。

## 3. 版位

### 3-1. 版位详情

| 版位 | 计费模式 | 格式 | 特点 |
|---|---|---|---|
| **YouTube 信息流内（In-Stream）** | CPM | 视频 | 前贴片 / 中贴片，可跳过 |
| **YouTube 信息流（In-Feed）** | CPC | 图片 / 视频 | 首页 Feed、搜索结果、相关视频 |
| **YouTube Shorts** | CPM | 竖版图片 / 视频 | 插在 Shorts 之间；建议 9:16 |
| **Discover** | CPC | 图片 / 轮播 | Google App 信息流；以移动端为主 |
| **Gmail** | CPC | 图片 | 促销 / 社交标签页；可展开 |
| **GDN**（2025 年 4 月加入） | CPM / CPC | 图片 / 视频 | Demand Gen 库存扩展到 300 万 + 网站和应用；Demand Gen 内的 Google Video Partners 更名为 GDN（[Google Ads 帮助](https://support.google.com/google-ads/answer/15890515?hl=en)） |

### 3-2. 按版位选择（2025 年 3 月 +）

Demand Gen 渠道控制允许在 YouTube、Discover、Gmail 和 Google 展示网络之间单独选择版位（[Google Ads 帮助](https://support.google.com/google-ads/answer/15973205?hl=en)）。

- 可以只跑 Shorts 的广告系列
- 版位级渠道选择和排除；预算分配通过符合条件的渠道间接实现
- YouTube / Discover / Gmail / GDN 独立开关

**使用场景：**
- 只跑 Shorts 的广告系列，最大化竖版创意
- 关掉 GDN 投放，聚焦优质版位（YouTube / Discover）
- 加更多版位前先验证单版位效果

### 3-3. 覆盖规模

- Demand Gen 的覆盖和增量数字是 Google 公布的基准，不是账户预测；写进对客方案前先核对最新说法（[Google Ads 博客](https://blog.google/products/ads-commerce/new-demand-gen-features-2025/)）。

## 4. 受众定向

### 4-1. 第一方数据

| 类型 | 内容 |
|---|---|
| **Customer Match** | 上传自己的客户列表（邮箱 / 电话）。也用作相似受众扩展的种子 |
| **再营销列表** | 网站访客、应用用户、YouTube 频道观众 / 订阅者 |
| **高 LTV 分段** | 上传高 LTV 客户列表，提高相似受众精度 |

### 4-2. 相似受众分段——仅 Demand Gen

**Google Ads 唯一原生支持相似受众（Lookalike）的广告系列类型。** 用第一方数据做种子扩展到相似用户（[Google Ads 帮助](https://support.google.com/google-ads/answer/15594567?hl=en)）。

| 覆盖设置 | 占目标人群比例 | 用途 |
|---|---|---|
| **窄（Narrow）** | ~2.5% | 高精度；CPA 收紧 |
| **均衡（Balanced）** | ~5% | 建议起点 |
| **宽（Broad）** | ~10% | 最大覆盖；认知扩展 |

**重要运营说明：** 把相似受众的覆盖设置当作方向性控制，而不是保证的硬受众边界，除非当前界面明确确认是严格定向行为。上线前先核对优化型定向、人口扩展、受众排除是否符合预期的受众控制设计。

### 4-3. 自定义分段

- 用搜索关键词建自定义受众（取头部 20–30 个词）
- 也可以按网站访问和应用使用定义
- 在广告组层级应用

### 4-4. Google 预置受众

| 类型 | 内容 |
|---|---|
| **意向（In-market）** | 正在主动研究特定产品 / 服务的用户 |
| **人生大事（Life events）** | 搬家、结婚、毕业等 |
| **兴趣（Affinity）** | 长期兴趣 / 习惯 |
| **详细人口属性** | 父母身份、婚姻、教育、住房、就业 |

### 4-5. 优化型定向（Optimized Targeting）

自动扩展到手动受众之外、可能转化的用户。

| 场景 | 建议设置 |
|---|---|
| 新客拉新（冷受众） | **开**——广泛探索 |
| 再营销 | **关**——受众保持紧 |
| 弃购人群 | **关**——受众保持紧 |
| 手动分段 | **关**——尊重手动配置 |

**注意：** 开启时受众设置被当作"信号（建议）"而不是"定向约束"——Google 可能自行扩展。

### 4-6. 受众排除

- 排除已转化的用户
- 用受众排除避免和其他广告系列重叠（尤其 P-MAX）

## 5. 创意设计最佳实践

### 5-1. 按版位定策略

Demand Gen 各版位计费模式和用户状态不同，创意切入角度要分开：

| 版位 | 计费 | 用户状态 | 创意角度 |
|---|---|---|---|
| **YouTube（信息流内 / Shorts）** | CPM | 在看视频 | 前 5 秒钩子；早露信任状 / 结果；必须字幕 |
| **Discover / Gmail** | CPC | 在刷信息流 | 标题里放价格门槛或筛选条件，过滤低质量点击 |

### 5-2. 图片设计原则

| 原则 | 说明 |
|---|---|
| 品牌优先 | logo 和品牌色突出，在信息流里一眼可认 |
| 启发感 | 展示使用场景或体验到的利益，不只放产品本身 |
| 文字叠加极简 | 小版位难读。文字控制在图片面积 ≤20% |
| 高清高对比 | 清晰、专业。模糊 / 低分辨率不可接受 |
| 三种比例全覆盖 | 横版 + 方版 + 竖版覆盖所有版位 |

### 5-3. 视频设计原则

| 原则 | 说明 |
|---|---|
| 前 5 秒最重要 | 前 5 秒出现品牌 + 价值主张 |
| 静音播放就绪 | Discover / Gmail 观众常静音；字幕和文字叠加必需 |
| 多种比例 | 理想 16:9 + 1:1 + 9:16 |
| Shorts 就绪：10–20 秒 | 短、节奏快。最长 1 分钟 |
| 建议 15 秒 + | 15 秒以上能拿到最多库存 |

### 5-4. 文案（标题 / 描述）设计原则

- 每个标题必须**自成一体**（AI 生成任意组合）。
- 5 条标题用不同切入角度（价格、功能、信任状、稀缺、情感等）。
- 标题和描述**不要重复**（组合会冗余）。
- Discover / Gmail 版位（CPC 计费），标题里放价格或筛选条件，预先过滤低质量点击。

### 5-5. 创意更新周期

| 素材类型 | 建议更新间隔 |
|---|---|
| 静态图片 | 每 4–6 周 |
| 视频 | 每 8–12 周 |

### 5-6. AI 创意功能（2025+）

| 功能 | 说明 |
|---|---|
| **动态图片** | 从静态图自动生成动态变体 |
| **自适应设计** | 自动给图片加品牌文字叠加 |
| **视频自动生成** | AI 从静态图素材自动生成视频 |
| **视频缩短** | 自动把长视频剪成适配版位的短版 |
| **视频翻转** | 从横版视频自动生成竖版（9:16） |

## 6. 出价策略（Demand Gen 专属）

### 6-1. 可用出价策略

| 策略 | 目标 | 用途 |
|---|---|---|
| **Maximize Conversions** | 预算内最大化转化数 | 新广告系列、转化数据少、早期。预算小也建议 |
| **目标 CPA（tCPA）** | 按指定 CPA 最大化转化数 | 积累 50+ 转化后；每天 3–5× 目标 CPA 可跑，15×+ 读数更干净 |
| **Maximize Conversion Value** | 预算内最大化转化价值 | 已设置转化价值（收入等）时 |
| **目标 ROAS（tROAS）** | 按指定 ROAS 最大化转化价值 | 转化价值数据充足 + ROAS 目标明确时 |
| **目标 CPC（tCPC）** | 控制平均 CPC | 只有广告系列目标是"点击"时可用——认知或流量目标（[Google Ads 帮助](https://support.google.com/google-ads/answer/16262529?hl=en)） |

### 6-2. Demand Gen 出价策略决策流

```
广告系列的核心目标是流量 / 认知吗？
├── 是 → 目标 CPC
└── 否（转化）→ 有转化数据吗？
    ├── 没有 → Maximize Conversions
    └── 有 → 50+ 转化了吗？
        ├── 没有 → Maximize Conversions（攒数据）
        └── 有 → 跟踪了转化价值（收入等）吗？
            ├── 没有 → 目标 CPA
            └── 有 → 目标 ROAS
```

### 6-3. 出价说明

| 说明 | 描述 |
|---|---|
| **目标 CPC 粒度** | 广告系列和广告组层级都能设；广告组层级优先 |
| **转化目标的预算** | 实用工作区间是每广告组每天 $100–500，或约 15× 目标 CPA（想要干净读数时）；收窄的测试可以更小 |
| **小预算替代方案** | 限制地域、受众或版位可以 $20–35 / 天起步，但当学习测试看待，不要当放量计划 |
| **学习期** | 上线后 3–4 周避免大改动 |

## 7. 商品 Feed 集成（电商）

### 7-1. 前置条件

| 条件 | 细节 |
|---|---|
| Merchant Center 账户 | 有效且已批准（批准最长 3 天） |
| Google Ads 关联 | Merchant Center 已关联到 Google Ads 账户 |
| 最低商品数 | **4+**（建议 50+） |
| 转化目标 | 广告系列上把"购买"设为转化目标 |
| 地域匹配 | 定向地域必须与 Merchant Center 配送地区设置一致 |

### 7-2. 关键 Feed 属性

| 属性 | 规格 | 说明 |
|---|---|---|
| **title** | 最多 150 字符 | 显示为广告标题 |
| **short_title** | — | 短而抓眼的标题 |
| **description** | 最多 5,000 字符 | 商品描述 |
| **image** | 最小 300×300 px，最大 10 MB | 商品图 |
| **price** | 含货币代码 | 价格展示 |
| **item_group_id** | — | 防止变体图片重复 |

> 商品 Feed 优化的细节见 [shopping-ads.md](shopping-ads.md)。

### 7-3. 站内链接

- 最少 4 条，最多 20 条
- 显示网址路径：每条最多 15 字符

### 7-4. 2025 年 Feed 增强

- 不跳转商品页，直接在广告内看完整商品信息
- 本地库存展示也带动线下到店
- 全渠道竞价：在线购买 vs 到店购买自动优化
## 8. 广告系列结构与运营设计

### 8-1. 结构原则

| 原则 | 说明 |
|---|---|
| **先合并** | 从单个广告系列起步，加速 AI 学习 |
| **按版位拆广告组** | 用广告组拆 YouTube Shorts / 信息流内 / Discover+Gmail，让单版位结果可见 |
| **再营销和拉新分开** | 不要混温受众和冷受众 |
| **不用共用预算** | Demand Gen 不支持共用预算池 |

### 8-2. 推荐的广告系列结构模板

```
Demand Gen（3 个广告组）
│
├── 广告组 1：[DG] Prospecting - Lookalike
│   ├── 定向：相似受众（Balanced）+ 自定义分段
│   ├── 优化型定向：开
│   ├── 排除：再营销列表、已转化用户
│   ├── 创意：图片 + 视频（3 种比例）
│   └── 版位：YouTube + Discover + Gmail
│
├── 广告组 2：[DG] Prospecting - In-Market
│   ├── 定向：意向分段 + 兴趣
│   ├── 优化型定向：开
│   ├── 排除：再营销列表、已转化用户
│   └── 创意：图片 + 视频（3 种比例）
│
└── 广告组 3：[DG] Remarketing
    ├── 定向：网站访客 / YouTube 观众 / Customer Match
    ├── 优化型定向：关
    ├── 排除：已转化用户
    └── 创意：再营销风信息（稀缺 / 提醒）
```

### 8-3. 纯 Shorts 广告系列（可选）

```
Demand Gen（Shorts 聚焦）
├── 版位：仅 YouTube Shorts（渠道控制）
├── 创意：仅竖版 9:16 视频 / 图片
├── 视频时长：10–20 秒
└── 目标：单独验证 Shorts 版位效果
```

### 8-4. 预算设计

| 项目 | 建议 |
|---|---|
| 工作日预算 | 每广告组每天 $100–500，或约 15× 目标 CPA（想要公平的转化读数时） |
| 小规模测试 | 限制地域 / 受众 / 版位的测试可以 $20–35 / 天起步，但学习更慢 |
| 广告系列总预算 | 也可以设为在整个投放周期内均匀花费 |

## 9. 衡量与评估

### 9-1. 关键指标

| 指标 | 用途 |
|---|---|
| **CPA / ROAS** | 直接效果评估 |
| **EVC（观看后转化）** | 看了足够时长的视频广告、之后转化的用户。支持的 Demand Gen 库存里计入 Conversions；评估直接效果时按广告事件类型细分 |
| **VTC（浏览型转化）** | 看了广告但没点击、没观看互动、之后转化的用户。VTC 优化是 YouTube 限定的公开测试，默认关闭；开启后保持 VTC 窗口短，展示归因单独汇报 |
| **跨平台可比转化** | 只做报表的 Demand Gen 指标，可含 VTC，用于和付费社交口径对比；不要用来和 Search、Shopping、P-MAX 对比 |
| **归因品牌搜索** | 可用时，归因到 Demand Gen 的品牌搜索行为 |
| **助攻转化** | 参与了最终转化的 Demand Gen 触点 |

### 9-2. 正确读效果

Demand Gen 是中漏斗的需求创造型广告系列——和 Search 不同。只看报表里的转化数容易低估它。

| 评估方法 | 说明 |
|---|---|
| **混合 CPA** | 按账户整体混合 CPA 评判（不要单独隔离 Demand Gen） |
| **助攻转化** | 确认 Demand Gen 首触 → Search 转化的路径 |
| **品牌搜索提升** | Demand Gen 上线前后，品牌搜索量涨了吗？ |
| **地域对照组** | 投放地区 vs 未投放地区的转化率对比 |
| **开关对比** | 暂停固定周期；对比前后转化数 |

**注意：** P-MAX 常常"偷走"Demand Gen 的首触转化，计成自己的末次转化。用助攻转化报告和混合 CPA 一起评估。

### 9-3. 素材级报表

单素材效果标签：

| 标签 | 含义 | 行动 |
|---|---|---|
| Best | 跑赢其他选项 | 保留；测试类似模式 |
| Good | 平均 | 保留；测试改进变体 |
| Low | 跑输其他选项 | 换新素材替换 |
| Learning | 还在收集数据 | 等结果 |

## 11. 和其他广告系列的关系

### 11-1. Demand Gen vs P-MAX

| 项目 | Demand Gen | P-MAX |
|---|---|---|
| **漏斗位置** | 顶部–中部（需求创造、考虑） | 全漏斗（尤其转化最大化） |
| **受众控制** | 高（参数指定） | 低（全 AI 自动化） |
| **版位** | YouTube / Discover / Gmail / GDN | 全部 7 个渠道（含搜索和地图） |
| **格式** | 图片 / 视频 / 轮播 / 商品 Feed | 文案 / 图片 / 视频 |
| **相似受众** | 有（Demand Gen 独占） | 无 |
| **报表透明度** | 高（按版位、按素材） | 在改善但有限 |
| **战略角色** | "创造"意图——教育、探索 | "收割"意图——转化、再营销 |

**共存要点：**
- Demand Gen = 拉新 / 教育型创意
- P-MAX = 再营销 / offer 型创意
- 用受众排除防止重叠和蚕食

### 11-2. Demand Gen vs Display

| 项目 | Demand Gen | Display |
|---|---|---|
| **版位** | YouTube + Discover + Gmail + GDN | 仅 GDN |
| **格式** | 图片 / 视频 / 轮播 / 商品 Feed | 横幅 / 富媒体 / 视频 |
| **相似受众** | 有 | 无（用优化型定向代替） |
| **内容定向** | 无 | 有（关键词 / 主题 / 展示位置指定） |
| **AI 优化程度** | 高 | 中 |

**怎么选：**
- **Display**：需要 GDN 专属控制 + 内容定向（关键词 / 主题 / 展示位置指定）时。
- **Demand Gen**：要 YouTube / Discover 投放、视觉型创意、相似受众分段时。

> Demand Gen 和 Display 库存的重叠比以前多了。Display 只在有明确任务时保留，比如 GDN 专属控制、内容定向或展示位置策略。

## 12. 易变功能核查

Demand Gen 的控制项和版位变化频繁。实施前先核对影响广告系列设计的功能：

| 功能 | 为什么重要 |
|---|---|
| YouTube、Discover、Gmail、GDN 的版位选择 | 决定计划能否单独隔离 Shorts、自有 Google 版位或 GDN 库存 |
| 流量 / 点击目标的 Target CPC | 只有 Demand Gen 被当流量工具而不是转化优化用时才相关 |
| 商品 Feed 和电商功能 | 电商 Demand Gen 相关；确认 Merchant Center 地区和 Feed 资格 |
| VTC 优化 | 只有展示归因优化符合衡量模型时才开 |
| 归因品牌搜索和助攻报表 | 中漏斗读数有用，但不要当增量性的替代品 |
| 相似受众覆盖行为 | 除非当前界面确认是严格定向，否则把覆盖设置当方向性看待 |

## 13. 常见失败模式（Demand Gen 专属）

| 失败 | 应对 |
|---|---|
| **预算太小** | 通常最低 $70–200 / 天。$10 / 天攒不出学习 |
| **把 Demand Gen 当第一个广告系列** | 先用 Search / Shopping / P-MAX 建转化基线。Demand Gen 是辅助型广告系列 |
| **再营销和拉新混一起** | 同一广告组不要混温受众和冷受众。数据变脏、优化崩 |
| **优化型定向误用** | 再营销或弃购人群开 ON 会无界扩展定向。只给冷拉新开 ON |
| **报表照单全信** | 只看 Google Ads 报表会低估。用混合 CPA、助攻转化、品牌搜索提升确认 |
| **撤得太早** | 中漏斗转化落地慢。至少留 3 个月数据 |
| **单一模板的泛泛创意** | 要多样性：5 标题、5 描述、15+ 图片 |
| **漏掉无效流量** | 查 0 秒会话和异常的微转化率。先上 Google 自有版位（YouTube / Discover / Gmail）；GDN 等质量验证后再加 |
| **被 P-MAX 蚕食** | P-MAX 常把 Demand Gen 的首触计成自己的末次转化。用受众排除和助攻转化报告管理 |
| **忽略单版位数据** | YouTube 信息流内 / Shorts / Discover / Gmail 效果不同。用渠道控制优化预算分配 |

## 15. 广告政策

Demand Gen 广告政策和展示广告共用。细节见 [display-ads.md](display-ads.md) 第 5 节。

补充说明：

| 项目 | 说明 |
|---|---|
| **Discover 版位质量门槛** | Discover 信息流期待个性化、高质量内容。过度标题党 / 噱头拒登率高 |
| **YouTube Shorts 版位** | 看起来像原生短视频的创意效果最好。广告味太重的跳过率高 |
| **轮播一致性** | 所有卡信息和质量一致。一张低质量卡可能导致整个广告拒登 |
