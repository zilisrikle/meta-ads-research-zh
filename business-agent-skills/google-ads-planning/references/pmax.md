# P-MAX（Performance Max）操作手册

## 操作实践

Performance Max 会放大你给它的输入质量：转化目标、价值、Feed、创意、受众信号、落地页和排除项。它不是策略的替代品。

### 最重要的事

- **衡量质量决定广告系列的方向。**P-MAX 会激进地朝着所选主要目标优化。线索广告中，当线索质量随查询、地理、设备或受众变化时，用增强型线索转化（Enhanced Conversions for leads）和线下转化导入。
- **为学习而合并，为控制而拆分。**只有当业务需要独立预算、目标每次转化费用（CPA, Cost Per Action）/ 目标广告支出回报率（ROAS, Return on Ad Spend）、毛利、地理 / 语言、客户类型、到店目标或产品归属时才拆分 P-MAX。为了报表好看而拆分常常饿死模型。
- **素材组应该是连贯的业务主题。**一个素材组要把产品 / 服务主题、受众信号、落地页、信息、图片、视频串起来。通用的「全部产品 / 全部服务」素材组通常削弱学习和创意相关性。
- **受众信号是引导，不是定向。**客户匹配（Customer Match）、再营销、自定义细分、搜索主题都是起点提示。不要向用户承诺 P-MAX 会待在这些受众里。
- **品牌和 URL 控制是策略控制。**品牌流量掩盖非品牌表现时用品牌排除。网站含信息、支持、招聘或低意向页面时，用 URL 排除或关闭最终到达网址扩展（Final URL expansion）。
- **Feed 质量就是零售的创意质量。**产品标题、图片、价格、库存、GTIN、product_type、自定义标签，常常比广告系列开关更能拉动表现。
- **P-MAX 的 ROAS 要带着怀疑看。**上报表现可能被品牌流量、再营销偏置、建模转化和 VTC 虚增。做重大决策时，用搜索词洞察、品牌排除、实验、地理测试或客户对照。
- **P-MAX 很少只是一种东西。**根据 Feed、素材、信号和目标，它可以表现得像购物、再营销、品牌搜索、展示、YouTube 或拓客。做策略判断前先诊断渠道组合和查询 / 品类洞察。
- **品牌排除不只是清理；是增量性控制。**当 P-MAX 在认领搜索或自然流量本来就能拿到的需求时用它。
- **URL 扩展在强商业站点上很强，在乱站点上很危险。**很多落地页都有商业价值时保持开启；网站有博客 / 支持 / 招聘 / 低意向页面时关闭或激进排除。
- **素材组报告是方向性的。**用素材组表达连贯主题，但不要把噪声大的素材组表现当干净的 A/B 真相过度解读。
- **同时做大幅改动会带来可避免的波动。**除非广告系列根本错了，否则不要一次改预算、目标、转化目标、URL 扩展、品牌控制和素材组。
- **纯 Feed 的 P-MAX 可以成立。**对素材匮乏、SKU 繁多或高度实用型目录，Feed 主导的投放可能跑赢弱通用创意。素材稀释购买意向时，全素材不自动更好。
- **新客获取模式需要干净的定义。**只有客户列表和新 / 老客价值可靠时才用；否则会扭曲出价。

### 诊断

| 症状 | 先查 | 可能动作 |
|---|---|---|
| 上报 ROAS 高但业务提升弱 | 品牌捡漏、再营销占比、VTC 比率、增量营收 | 加品牌排除、拆分上报、跑实验 / 对照 |
| 线索质量差 | 主要转化操作、线下导入、URL 扩展、线索表单质量 | 导入合格线索、移除弱主要目标、排除弱页面 |
| 花不出去 | 政策 / Feed 问题、目标太紧、预算太小、素材太弱 | 放松目标、修复资格、放宽产品 / 素材、合并 |
| 好产品被饿死 | 上架组（Listing groups）、产品表现、毛利 / 优先级标签 | 用自定义标签隔离长尾或战略 SKU |
| 素材组噪声大 | 一个组里主题太多，或太多微型组 | 围绕连贯主题重建，保证素材覆盖完整 |

### 常见坑

- 上线一个又薄又通用的素材组，指望自动化凭空发明定位。
- 把受众信号当严格定向用。
- 把品牌、再营销、拓客结果混成一个成功故事。
- 销售质量参差时还按原始线索优化。
- 一次改预算、tROAS / tCPA、转化目标和素材组。

各 playbook 通用术语见 [SKILL.md 术语表](../SKILL.md#common-google-ads-glossary)。

## 决策矩阵

何时、如何部署 P-MAX。

### 采用决策

| 条件 | 决策 | 原因 |
|------|------|------|
| 30+ 月转化（账户级） | 考虑采用 | 更稳定学习的可操作基线 |
| 50+ 月转化 | 放心采用 | 稳定优化可实现 |
| 月转化 < 10 | 太早 | 学习数据不足。先用搜索积累转化历史 |
| 还没有搜索广告系列 | 先跑搜索 | P-MAX 会利用你现有广告系列的转化数据 |

### 跑几个广告系列

| 月转化（账户级） | 推荐 P-MAX 广告系列数 | 备注 |
|---------------------------|----------------------|------|
| 30–50 | 1 个 | 集中数据，学习效率最高 |
| 50–150 | 1–2 个 | 考虑拆品牌 vs 非品牌 |
| 150+ | 2–4 个 | 按品类、毛利档或客户类型拆 |

### 按业务类型的设计方法

| 业务类型 | 广告系列结构 | 素材策略 | 备注 |
|--------------|----------------|------------|---------|
| 电商（小目录） | 1 个广告系列 / 2–3 个素材组 | 推荐全素材 | Feed 优化是最重要的杠杆 |
| 电商（大目录） | 2–4 个广告系列（按品类 / 毛利） | 纯 Feed 或全素材 | 用自定义标签切分产品 |
| B2B 线索 | 1–2 个广告系列 | 必须全素材 | 推荐 URL 扩展关闭——防止流量跑到博客等 |
| B2C 线索 | 1–2 个广告系列 | 必须全素材 | 策略性用人口统计排除 |
| 到店 | P-MAX 到店目标 | 推荐全素材 | 需要 Google 商家资料（Google Business Profile）集成 |

## 快速上手

首次上线 P-MAX 的最短路径。细节见下文各节。

### 上线前准备

| 检查 | 必需 / 推荐 | 不满足怎么办 |
|------------|---------|----------|
| 转化跟踪准确 | 必需 | 先搭好转化跟踪（见 [§9](#9-conversion-measurement-optimization)） |
| 已部署增强型转化 | 强烈推荐 | 提高衡量准确度 |
| 30+ 月转化（账户级） | 强烈推荐 | 低于此，学习更慢更不稳定。可能时先用搜索积累转化历史 |
| 搜索广告系列已在跑 | 强烈推荐 | 品牌关键词控制和蚕食监控需要它 |
| 产品 Feed 已优化（电商） | 必需（电商） | 见 [shopping-ads.md](shopping-ads.md) |
| 线下转化导入就位（线索） | 推荐 | 建 CRM 集成采集 GCLID |

### 上线步骤

| 步骤 | 动作 | 参考 |
|---------|----------|-------|
| 1. 定结构 | 广告系列数和素材组数（1 个广告系列、1–3 个素材组起步） | [§2](#2-campaign-structure-design) |
| 2. 建素材 | 文案（11+ 标题、4+ 描述）、图片（5+ 横版、5+ 方版）、视频（1+ 横版、1+ 竖版） | [§4](#4-asset-specs-and-submission-requirements) |
| 3. 设受众信号 | 客户匹配列表 + 有购买意向细分 | [§5](#5-audience-signals) |
| 4. 搜索主题 | 8–12 个主题 | [§6](#6-search-themes-and-url-expansion) |
| 5. 排除项 | 品牌排除 + 不相关否定关键词 + URL 排除规则（线索广告 URL 扩展关闭） | [§7](#7-negative-keywords-and-brand-exclusion) |
| 6. 出价 | 从争取转化（Maximize Conversions）或争取转化价值（Maximize Conversion Value）起步（不加约束） | [§8](#8-bid-strategy) |
| 7. 预算 | 可能时日预算 3–5× 目标 CPA；窄测试 1–3× | [§8](#8-bid-strategy) |
| 8. 上线 | 激活广告系列 | — |

### 前两周（学习期）

| 做 | 不做 |
|---------|------------|
| 每天看预算消耗节奏 | 换出价策略 |
| 盯异常花费模式 | 加 / 减预算 |
| 看搜索词报告（只排除明显不相关的词） | 批量换素材 |
| 看渠道报告（只做趋势感知） | 加 tCPA / tROAS 约束 |

### 第 3–6 周（稳定 → 优化）

| 决策 | 条件 | 动作 |
|------|------|----------|
| 迁到 tCPA / tROAS | 30+ 月转化稳定 | 按过去 30 天实际设目标（见 [§8-3](#8-bid-strategy)） |
| 加素材组 | 现有素材组月转化 20+ | 为新品类 / 目标加素材组 |
| 优化素材 | 有素材评级「低」 | 替换「低」素材 |
| 加否定关键词 | 搜索词报告发现不相关 | 策略性排除——按品类，不按单个词 |

## 1. 易变能力检查

P-MAX 能力随账户、国家、界面 rollout 频繁变化。实施前先核实影响规划的特性的当前状态：

| 能力 | 为什么重要 |
|---|---|
| 广告系列级否定关键词与共享列表 | 决定规划能对搜索 / 购物查询控制承诺多少 |
| 搜索词与渠道绩效报告 | 决定诊断查询、渠道、蚕食问题时能多自信 |
| 品牌排除与购物品牌投放选项 | 决定 P-MAX 是否被允许吃自有品牌或被排除品牌的流量 |
| 人口统计排除 | 决定年龄、性别、设备限制能否当真控制杠杆 |
| 素材测试与素材级报告 | 决定创意测试能设计成实验，还是只能做运营刷新 |
| 到店目标的地图 / Waze 等资源 | 只与本地 / 到店策略相关；确认区域可用性 |

## 2. 广告系列结构设计

### 2-1. 结构原则

把 P-MAX 想成三层。

```
Account
 └── Campaign  (the unit for budget, bid strategy, geo, negatives)
      └── Asset group  (the unit for creative, audience signals, search themes)
           └── Listing group  (filter on the product feed — for e-commerce)
```

**拆独立广告系列，当：**
- 需要不同的预算分配
- 需要不同的出价策略（tCPA vs tROAS）
- 需要不同的地理定向
- 需要不同的否定关键词策略

**拆独立素材组，当：**
- 不同产品品类 / 服务线
- 不同受众细分
- 不同创意主题 / 信息

> **原则：拿不准时，广告系列宁少、素材组宁多。**数据够了再拆广告系列。每个广告系列至少需要 30+ 月转化做基线。

### 2-2. 电商广告系列结构模式

| 模式 | 结构 | 适用 |
|---------|------|----------|
| 简单 | 1 个广告系列 / 1–3 个素材组 | 30–100 月转化。小目录 |
| 按品类拆 | 2–3 个广告系列 / 每个 2–3 个素材组 | 100+ 月转化。品类间毛利差异大 |
| 按毛利拆 | 高 / 中 / 低毛利 3 个广告系列 | tROAS 运营。产品毛利 spread 大 |
| 品牌 vs 非品牌 | 2 个广告系列：品牌词 / 通用词 | 想独立管品牌预算和 ROAS 时 |

### 2-3. 线索广告系列结构模式

| 模式 | 结构 | 适用 |
|---------|------|----------|
| 简单 | 1 个广告系列 / 2–3 个素材组（按服务） | 30–50 月转化。服务线少 |
| 按服务拆 | 2 个广告系列：服务 A / 服务 B | 各服务 CPA 目标不同时 |
| 按漏斗拆 | 高意向（转化 = 咨询）/ 低意向（转化 = 白皮书下载） | 想按转化类型用不同出价策略时 |

### 2-4. 广告系列设置清单

| 设置 | 推荐 | 备注 |
|---------|---------|------|
| 目标 | 销售 / 线索 | 对齐业务目标 |
| 出价策略 | 价值导向 → tROAS / 量导向 → tCPA | 见 [§8](#8-bid-strategy) |
| 预算 | 可能时日预算 3–5× 目标 CPA | 窄测试 1–3× 可行；低于 1× 通常太慢 |
| 地理 | 明确目标位置 | 推荐只用「所在地（Presence）」 |
| 语言 | 明确目标语言 | |
| 投放时段 | 按需 | 默认 24/7 |
| URL 扩展 | 按目标开 / 关 | 见 [§6](#6-search-themes-and-url-expansion) |
| 品牌排除 | 按需 | 见 [§7](#7-negative-keywords-and-brand-exclusion) |
| 新客获取 | 按需开启 | 见 [§12](#12-new-customer-acquisition-mode) |

## 3. 素材组设计

### 3-1. 基础

一个素材组包含：

| 元素 | 说明 |
|------|------|
| 文案素材 | 标题、长标题、描述、商家名称、显示网址路径 |
| 图片素材 | 横版、方版、竖版图片，外加徽标 |
| 视频素材 | YouTube 视频（横版、竖版、方版） |
| 受众信号 | 目标用户的提示 |
| 搜索主题 | 搜索意图主题（每个素材组最多 25 个） |
| 最终到达网址 | 点击后的目标页 |
| 上架组 | 筛选哪些产品可投放（电商） |

### 3-2. 拆分策略

| 方法 | 说明 | 适用 |
|---------|------|----------|
| 按品类 | 镜像网站主品类 | 好管理。通用 |
| 按人群 | 人设 / 细分 | 服装、美妆等人群驱动品类 |
| 按信息 | 价格导向 / 品质导向 / 便利导向 | 想做创意 A/B 测试时 |
| 按促销 | 大促 / 季节性 | 限时优惠，不打乱常青素材组 |

### 3-3. 素材组规则

| 规则 | 原因 |
|-------|------|
| 每个素材组保持 20+ 月转化 | 学习的最少数据 |
| 月转化 < 5 的素材组合并 | 数据不足以让 AI 优化 |
| 1–3 个素材组起步 | 过度切分会碎片化数据 |
| 素材组之间避免产品 / 人群重叠 | 会混淆学习 |
| 注册每种素材类型（文案 + 图片 + 视频） | 全渠道投放需要 |
| 广告效力目标「良好」或更好，条件允许时向「优秀」优化 | 更好的素材覆盖可提高资格和投放质量 |

## 4. 素材规格与提交要求

制作规格见 [creative-strategy.md](creative-strategy.md#p-max-asset-baseline)。策略规则留在这里：

- 文案：11+ 标题、4+ 描述，角度要不同，不是换说法。
- 图片：至少覆盖横版和方版；移动视觉资源重要时加竖版。
- 视频：至少一个横版、一个竖版。不要依赖自动生成的视频。
- 零售：Feed 质量和自定义标签与上传创意同等重要。
- 每个素材组要有足够格式覆盖全渠道，同时与素材组产品 / 服务主题保持连贯。

## 5. 受众信号

### 5-1. 信号是什么

受众信号不是定向——是提示。它们告诉 Google 算法你的理想潜在客户长什么样。P-MAX 从信号冷启动，然后自动向外扩展。

### 5-2. 信号类型与优先级

| 优先级 | 信号 | 说明 | 设置方式 |
|-------|-------------|------|---------|
| 最高 | 客户匹配（Customer Match） | 现有客户邮箱列表 | 上传客户匹配列表 |
| 高 | 网站访客 | 再营销列表 | Google Ads 受众列表 |
| 高 | YouTube 观众 | 订阅者 / 视频观众 | YouTube 关联 |
| 中 | 有购买意向（In-market） | 某品类处于积极购买考虑的用户 | 从 Google 预设细分中选 |
| 中 | 自定义细分 | 按搜索词或访问过的网址构建 | 用关键词 / 网址定义 |
| 低 | 兴趣相似（Affinity） | 兴趣类别 | 从 Google 预设细分中选 |
| 低 | 人生大事 | 结婚、搬家、新工作 | 从 Google 预设细分中选 |
| 低 | 人口统计 | 年龄、性别、家庭收入、父母状态 | 设基础属性 |

### 5-3. 信号设计规则

| 规则 | 原因 |
|-------|------|
| 优先客户匹配 | 最强信号——AI 起点的理想选择 |
| 每个素材组组合多种信号类型 | 多角度信号提高学习质量 |
| 理解信号是提示不是约束 | Google 会向外扩展 |
| 避免太小的列表 | 推荐最少 1,000+ 用户 |
| 各素材组用不同的信号 | 多个素材组用同一信号会碎片化数据 |

## 6. 搜索主题与 URL 扩展

### 6-1. 搜索主题

搜索主题引导 P-MAX 在搜索渠道的投放。与搜索广告系列的关键词不同，主题是 AI 自动扩展的起点。

| 项目 | 规格 |
|------|------|
| 上限 | 每个素材组 50 个主题 |
| 行为 | 除 AI 预测匹配外，还会扩展到指定主题内的词（加法） |
| 匹配类型 | 无——AI 自动扩展到相关词 |

**设计规则：**
- 推荐 8–12 个主题
- 包含主要服务名、产品品类和客户用的搜索词
- 参考搜索广告系列的高表现关键词找灵感
- 不要列竞品品牌名（与品牌排除冲突）
- 按「主题」思考，不按「关键词」——不要用完全匹配思维

### 6-2. URL 扩展（最终到达网址扩展，Final URL Expansion）

URL 扩展默认开启。Google 按搜索查询把流量导向指定最终到达网址之外的落地页（[Google Ads Help](https://support.google.com/google-ads/answer/14337539?hl=en)）。

| 设置 | 行为 | 何时用 |
|------|------|----------|
| 开（默认） | Google 自动选最佳落地页；生成动态标题 / 描述 | 落地页多的电商站 |
| 关 | 只导向指定的最终到达网址 | 想固定落地页的线索广告 |
| 开 + URL 排除规则 | 自动选择开启，排除特定路径 | 想屏蔽 /blog、/careers 等的电商 |

**风险与缓解：**

| 风险 | 缓解 |
|-------|------|
| 导向非转化页（博客、私隐政策） | 给 /blog/、/privacy/、/careers/ 等加 URL 排除规则 |
| 广告出现在非预期的品牌页 | 加 URL 排除规则 |
| 落地页信息匹配丢失（也会破坏落地页 A/B 测试设计） | 线索广告推荐 URL 扩展关闭 |

## 7. 否定关键词与品牌排除

### 7-1. 否定关键词

P-MAX 支持自助管理的广告系列级否定关键词，覆盖搜索和购物资源（[Google Ads Help](https://support.google.com/google-ads/answer/15726455?hl=en)）。也支持共享否定关键词列表（[negative keyword lists Help](https://support.google.com/google-ads/answer/2453983?hl=en)）。

| 项目 | 规格 |
|------|------|
| 上限 | 每个广告系列 10,000 个否定关键词 |
| 共享列表 | 支持（一次应用到多个 P-MAX 广告系列） |
| 范围 | 主要影响搜索和购物渠道（对展示、YouTube 等无效） |

> 账户级否定仍单独上限 1,000。大批量操作前先核实当前界面，因为限额可能变。

**否定关键词策略：**

| 类别 | 排除示例 |
|---------|------------|
| 不相关词 | jobs、careers、salary、reviews（不带来转化时） |
| 竞品名 | 明确不投竞品词时 |
| 纯信息类 | "what is"、"how to"、"comparison"（不带来转化时） |
| 负面含义 | "worst"、"scam"、"cancel" |

> **不要过度排除。**条件反射式地排除每个不转化的查询，会收窄 AI 的探索空间，丢掉新客发现。正确做法是策略性、按品类的排除。

### 7-2. 品牌排除

品牌排除阻止你的广告在包含特定品牌名的查询上展示（[Google Ads Help](https://support.google.com/google-ads/answer/16669487?hl=en)）。

| 设置 | 效果 | 何时用 |
|------|------|----------|
| 自有品牌排除 | 阻止 P-MAX 吃掉你的品牌搜索 | 搜索广告系列已在跑品牌关键词时 |
| 竞品品牌排除 | 阻止广告出现在竞品名上 | 已决定不投竞品词时 |
| 仅购物排除 | 品牌排除只作用于文字广告——购物广告仍可在品牌搜索上投放 | 想让购物吃品牌流量的电商（2025+） |

## 8. 出价策略

### 8-1. 可用出价策略

P-MAX 支持四种出价策略。

| 策略 | 优化目标 | 何时用 |
|---------|----------|----------|
| 争取转化（Maximize Conversions） | 转化数 | 首次上线、数据积累期 |
| 目标每次转化费用（tCPA, Target CPA） | 转化数（带成本约束） | 转化价值统一的线索广告 |
| 争取转化价值（Maximize Conversion Value） | 转化价值（营收） | 电商、数据积累期 |
| 目标广告支出回报率（tROAS, Target ROAS） | 转化价值（带 ROAS 约束） | 转化历史充足的电商 |

### 8-2. 怎么选

```
Does CV value vary by product?
├── Yes (e-commerce, etc.)
│   ├── 50+ monthly CVs → tROAS
│   └── Under 50 monthly CVs → Maximize Conversion Value (no tROAS constraint)
└── No (lead-gen with uniform CV value)
    ├── 30+ monthly CVs → tCPA
    └── Under 30 monthly CVs → Maximize Conversions (no tCPA constraint)
```

### 8-3. 出价策略设计规则

| 规则 | 原因 |
|-------|------|
| 不加约束起步（"Maximize" 家族） | 不约束学习；优先积累数据 |
| tCPA / tROAS 目标按实际设 | 锚定实测表现，不是许愿目标 |
| tROAS 从过去 30 天实际 ROAS 的 80–90% 起步 | 约束过紧会崩掉投放量 |
| tCPA 从过去 30 天实际 CPA 的 110–120% 起步 | 同上 |
| 目标按 10–20% 步长调整 | 大幅调整会重置学习 |
| 出价和预算不同时改 | 会混淆学习——一次改一个，测完再动 |
| 改动后留 2–4 周学习 | 没稳定就反复改，学习会永久不稳定 |

### 8-4. 预算设计

| 项目 | 推荐 | 备注 |
|------|------|------|
| 下限 | 1× 目标 CPA | 低于此，学习极慢，预算消耗节奏会掩盖需求 |
| 窄测试区间 | 日预算 1–3× 目标 CPA（例：$50 CPA → 日 $50–$150） | 结构紧、预期克制时可行 |
| 健康区间 | 日预算 3–5× 目标 CPA | 更稳定学习和更快读数的实操起点 |
| 放量 / 快速学习区间 | 日预算 5–10×+ 目标 CPA | 经济模型允许、且广告系列有足够受众 / Feed / 创意深度时 |
| 加预算 | 每 7–14 天最多 +20% | 猛加会重置学习 |
| 减预算 | 每 7–14 天最多 -15% | 猛减会破坏投放稳定 |

## 9. 转化衡量优化

### 9-1. 为什么转化衡量在 P-MAX 里重要

转化数据是 P-MAX 唯一的学习信号。转化定义和跟踪的质量直接决定广告系列质量。

### 9-2. 转化衡量设计规则

| 规则 | 原因 |
|-------|------|
| 优化目标只放真实业务结果 | 把低意向动作（PDF 下载、Newsletter 订阅）放进去，AI 会批量生产它们 |
| 符合条件时部署增强型转化 | 提高衡量韧性，给智能出价更干净的一方信号 |
| 转化价值设准（电商：动态；线索：按线索评分） | 转化价值精度直接决定 tROAS 精度 |
| 合适时用数据驱动归因 | 账户存在实际辅助转化路径时，帮助给非最终点击触点记功 |

### 9-3. 点击、互动观看与浏览转化

> 另见 SKILL.md「VTC 统一政策」。P-MAX 受非点击归因影响很大，但标准 P-MAX 通常不把纯 VTC 放进主要转化列。实操风险是把点击、EVC、到店目标 VTC、品牌、再营销、建模转化混成一个成功故事。

P-MAX 把符合条件的视频互动的互动观看转化（EVC, Engaged-view conversions）计入转化。标准浏览转化（VTC：有展示、无点击无互动）通常只上报，P-MAX 到店目标除外。非点击占比高时，即使上报技术上没错，也会高估因果影响。

| 指标 | 说明 | 注意 |
|------|------|-------|
| 点击转化 | 点击 → 转化 | 最强的直接响应信号 |
| 互动观看转化 | 有意义的视频观看 → 转化 | 所支持的 P-MAX 视频资源可参与出价，但仍是非点击 |
| 浏览转化 | 有展示但无点击 / 互动 → 转化 | 标准 P-MAX 通常只上报；到店目标可参与出价 |

**缓解（高级）：**
- 按广告事件类型切分转化：点击、互动 / 互动观看、展示。
- 非点击贡献扭曲决策时，建一个点击优先的上报视图或广告系列实验；不要盲目把有用的 EVC 踢出出价。
- 到店目标：用 POS 或门店级营收对账到店 / 到店销售，再从 VTC 占比高的结果上放量。
- 这是高级技巧：先用默认，监控事件组合，再做决定。

**在你的账户里验证：**
1. 用细分 → 转化 → 广告事件类型，把点击、互动观看、展示分开。
2. 用渠道绩效报告看搜索、购物、YouTube、展示、Discover、Gmail、地图、搜索合作伙伴里谁在驱动事件组合。
3. 展示归因转化占比可观时，先和后端营收、门店销售或对照组对比，再加预算。
4. 记录重大目标或归因视角变更前后的 CPA / ROAS / 转化数，评估真实改进。

### 9-4. 线下转化导入

线索广告导入后期数据（合格商机、已成交）——不只是表单提交——能实质性改善 P-MAX 优化。

| 步骤 | 细节 |
|---------|------|
| 1. 采集 GCLID | 表单提交时把 GCLID 存进 CRM |
| 2. 定义后期转化 | 把合格商机 / 已成交定义为转化操作 |
| 3. 定期导入 | 从 CRM 定期上传到 Google Ads |
| 4. 设为 P-MAX 优化目标 | 把导入的转化纳入优化目标 |

## 10. 产品 Feed 集成（电商）

### 10-1. Feed 的角色

电商 P-MAX 用你的 Google Merchant Center（GMC）产品 Feed 投放购物广告和动态再营销。Feed 质量是最大的表现驱动因素。

> **Feed 设计与优化细节见 [shopping-ads.md](shopping-ads.md)。**

### 10-2. 上架组（产品筛选）

上架组（Listing groups）控制 Feed 里哪些产品可在每个素材组投放。

**可筛选属性：**

| 属性 | 用途 | 示例 |
|------|------|-----|
| 品类（Google 产品品类） | 顶层切分 | Apparel > Men's |
| 品牌 | 按品牌管理 | Nike / Adidas |
| 产品 ID | 单品包含 / 排除 | 排除某个 SKU |
| 状况 | 全新 vs 二手 | 仅全新 |
| 自定义标签（0–4） | 自由分类 | 毛利、季节性、销量排名等 |

### 10-3. 自定义标签模式

| 标签 | 用途 | 示例值 |
|-------|------|-------|
| custom_label_0 | 毛利档 | high_margin / mid_margin / low_margin |
| custom_label_1 | 销售表现 | best_seller / mid_performer / long_tail |
| custom_label_2 | 季节性 | spring / summer / autumn / winter / year_round |
| custom_label_3 | 促销 | on_sale / clearance / new_arrival |
| custom_label_4 | 库存 | in_stock / low_stock / pre_order |

**用自定义标签拆广告系列的示例：**

```
P-MAX Campaign A (high margin, high performance)
 ├── tROAS: 400%
 ├── AG1: best_seller × high_margin
 └── AG2: mid_performer × high_margin

P-MAX Campaign B (mid margin, the rest)
 ├── tROAS: 250%
 ├── AG1: best_seller × mid_margin
 └── AG2: remaining products
```

## 11. 纯 Feed vs 全素材

### 11-1. 纯 Feed 是什么

不提交文案 / 图片 / 视频素材、只靠产品 Feed 跑的广告系列。实际聚焦购物广告和动态再营销。

### 11-2. 对比

| 项目 | 纯 Feed | 全素材 |
|------|---------------|------------|
| 渠道 | 主要是购物 + 动态再营销 | 全部 7 个渠道（搜索、购物、YouTube、GDN、Discover、Gmail、地图） |
| 素材制作 | 不需要（只有 Feed） | 需要制作文案、图片、视频 |
| 上线速度 | 快 | 素材制作耗时 |
| CPA / ROAS | 短期 CPA 往往更低（集中高意向用户） | 靠触达扩张带来长期转化增长潜力 |
| 触达 | 有限（主要是高意向用户） | 广（覆盖认知 → 考虑 → 购买） |
| 品牌认知 | 几乎没有 | YouTube / GDN 投放建立品牌触达 |

### 11-3. 怎么选

| 情况 | 推荐 | 原因 |
|-------|---------|------|
| 短期要 ROAS | 纯 Feed | 剥离浪费版位，集中高意向 |
| 没有素材制作资源 | 纯 Feed | 只靠 Feed 就能上 |
| 新客 / 品牌认知目标 | 全素材 | 全渠道触达找到新客 |
| 长期增长策略 | 全素材 | 覆盖全漏斗：认知 → 考虑 → 购买 |
| 已单独跑展示 / YouTube 广告系列 | 纯 Feed | 防止与 P-MAX 重叠蚕食 |

## 12. 新客获取模式

### 12-1. 概览

P-MAX 有专门的新客获取优先模式。

| 模式 | 行为 | 何时用 |
|-------|------|----------|
| 新客价值模式（New Customer Value Mode） | 给新客转化加额外价值，出价更激进抢新客；老客仍投放 | 强化新客获取，同时保留老客转化机会 |
| 仅新客模式（New Customer Only Mode） | 只为新客转化优化；老客排除 | 全力聚焦新客获取 |
| 高价值新客模式（High-Value New Customer Mode） | 用客户匹配定义高价值老客，对可能高 LTV 的新客出价更激进 | 客户间 LTV 方差大的业务 |

### 12-2. 设置要求

| 要求 | 细节 |
|------|------|
| 客户匹配列表 | 上传现有客户邮箱列表 |
| 转化标签 | 部署区分新客 / 老客的参数 |
| 高价值模式 | 额外上传定义高价值客户的客户匹配列表 |

### 12-3. 设计要点

- 不要把新客「额外价值」设太高。按实际新客 LTV 设。
- 「仅新客」模式会实质性缩小投放量——流量充足时才用。
- 定期刷新客户匹配列表（至少每月）。

## 14. 与其他广告系列共存

### 14-1. P-MAX 与搜索

P-MAX 也在搜索渠道投放，与现有搜索广告系列的蚕食不可避免。

**竞价优先级规则：**

| 条件 | 谁赢得竞价 |
|------|-------------------|
| 搜索关键词匹配搜索广告系列里的完全匹配关键词 | **搜索广告系列** |
| 搜索关键词匹配搜索广告系列里的词组 / 广泛匹配 | 广告评级（Ad Rank）高的赢（常是 P-MAX） |
| 搜索关键词在任何搜索广告系列都不存在 | **P-MAX** |

**蚕食缓解：**

| 缓解 | 效果 |
|------|------|
| 在搜索广告系列把品牌关键词加为完全匹配 | 品牌查询导向搜索 |
| P-MAX 加品牌排除 | 阻止 P-MAX 吃掉品牌搜索 |
| 定期看 P-MAX 搜索词洞察 | 理解 P-MAX 在哪投放 |
| 高表现词在搜索加为完全匹配 | 把优先级锁给搜索广告系列 |
| 盯搜索广告系列的 CPC 趋势 | 验证 P-MAX 上线后 CPC 没飙升 |

### 14-2. P-MAX 与购物

| 情况 | 推荐 |
|------|------|
| 标准购物在跑 | P-MAX 赢得竞价。同时跑要盯产品分段重叠 |
| 只跑 P-MAX | 通常推荐。一个广告系列可管理 |
| 混合 | 标准购物精细控制特定产品（高毛利），其余给 P-MAX |

### 14-3. P-MAX vs 其他广告系列类型

| 广告系列类型 | 蚕食风险 | 推荐 |
|----------------|-------------|---------|
| 搜索 | 高 | 用完全匹配关键词锁优先级。P-MAX 加品牌排除 |
| 购物（标准） | 高 | 消除产品分段重叠 |
| 展示 | 中 | 不同目标可共存。都以转化为目标时要小心 |
| 视频（YouTube） | 低–中 | 可与认知导向的视频广告系列共存 |
| Demand Gen | 高 | 都以转化为目标时，Demand Gen 有被压制的风险 |
| 应用 | 无 | 渠道不重叠 |

> **各广告系列类型的最佳实践见各参考：[search-ads.md](search-ads.md)、[display-ads.md](display-ads.md)、[shopping-ads.md](shopping-ads.md)、[video-campaigns.md](video-campaigns.md)、[app-campaigns.md](app-campaigns.md)。**

## 15. P-MAX 到店目标

### 15-1. 概览

P-MAX 到店目标（P-MAX for Store Goals）是优化本地动作（到店、来电、导航）的专用变体。2022 年 7 月推出，整合了旧的本地广告系列。

### 15-2. 优化目标

| 目标 | 说明 |
|------|------|
| 到店 | 优化到店访问 |
| 到店销售 | 优化到店后的购买 |
| 本地动作（导航、来电） | 优化 Google 地图里的路线查询和一键拨号 |

### 15-3. 渠道

Google Search / Google Maps / YouTube / GDN / Gmail / Discover。

区域或账户专属资源会随时间增加。例如，符合条件的到店目标广告系列在支持的市场可能有 Waze 资源；纳入规划前先确认当前可用性。

### 15-4. 设置要求

| 要求 | 细节 |
|------|------|
| Google 商家资料（GBP, Google Business Profile）集成 | 需要门店信息、地址、营业时间 |
| 到店衡量已启用 | 兼容 Google 的到店转化衡量 |
| 多门店 | 配置门店组做区域投放优化 |

### 15-5. 区域资源检查

| 项目 | 细节 |
|------|------|
| 验证什么 | 目标市场和广告系列目标是否有导航类等额外本地资源 |
| 资格 | 通常绑定到店、到店销售或本地动作目标 |
| 设置 | 确认是自动可用还是需要账户 / 广告系列级开启 |
| 规划立场 | 把区域资源当增量利好，不当默认渠道 |

**用法：**

- 验证搜索主题的效果

| 可见数据 | 细节 |
|----------------|------|

### 17-1. 素材 A/B 测试

| 项目 | 细节 |
|------|------|

| 分流 | 推荐 50/50 |
| 推荐时长 | 4–6 周或更长 |

**测试设计规则：**
- 3 周以下的测试结果不稳定——至少跑 4 周
- 每次测试只改一个变量（只改标题、只改图片等）
- 低转化账户延长到 6–8 周

## 18. AI 生成素材规则

| 规则 | 原因 |
|-------|------|
| AI 是补充——自己的素材是核心 | 品牌一致性 |
| AI 生成素材批准前必审 | 有不当语言或图像风险 |
| 用表现最好的素材做 AI 生成的底 | 学习质量更好 |
| AI 生成素材的绩效一视同仁 | 不因来源偏袒或歧视 |

## 19. 学习期与运营节奏

### 19-1. 学习期

| 阶段 | 时长 | 细节 |
|---------|------|------|
| 初始学习 | 2–4 周 | AI 学习优化出价、定向、创意。表现不稳定 |
| 稳定 | 4–6 周 | 学习成熟；表现趋稳 |
| 成熟 | 6 周+ | 稳定。可以考虑优化和扩张 |

**会重置学习的改动：**
- 换出价策略
- 预算改动 ≥20%
- 增 / 改 / 删转化操作
- 素材组大改（替换 50%+ 素材）
- 地理定向大改

### 19-2. 运营节奏

| 节奏 | 动作 |
|------|----------|
| 每天 | 预算消耗节奏。盯异常花费 |
| 每周 | 渠道报告 / 素材表现 / 搜索词报告 / 花费集中度检查（前 20% 产品 / 素材组吃掉 80%+ 花费？） |
| 双周 | 替换「低」评级素材 / 加否定关键词 |
| 每月 | 受众洞察分析 / 复核出价目标 / 预算再分配 / 刷新客户匹配列表 |
| 每季度 | 素材全面刷新 / 重构广告系列 / 交叉检查竞品动作 |

### 19-3. 优化优先级

表现不达标时，按此顺序排查。

| 优先级 | 检查 | 动作 |
|-------|------------|------|
| 1 | 转化衡量准吗？ | 部署增强型转化 / 重审转化定义 |
| 2 | 预算够吗？ | 窄测试日预算 1–3× 目标 CPA；稳定学习 3–5×+ |
| 3 | 素材质量够吗？ | 替换「低」素材 / 补缺口 |
| 4 | 受众信号合适吗？ | 加客户匹配 / 修订信号 |
| 5 | 否定词和品牌排除对吗？ | 用搜索词报告加不相关词 |
| 6 | 出价目标现实吗？ | 按实际重新锚定 |
| 7 | URL 扩展设置对吗？ | 验证流量没漏到错页面 |
| 8 | 在蚕食吗？ | 盯搜索广告系列的 CPC 和展示份额（IS） |

## 20. 常见失败模式

### 20-1. 设计阶段错误

| 错误 | 为什么失败 | 避免 |
|------------|----------|-------|
| 转化数据不足就上线 | 学习更慢更不稳定 | 可能时先积累更多真实转化量 |
| 广告系列拆太碎 | 每个广告系列都缺转化数据 | 只为真实控制需求拆分，保证每个有足够量级 |
| 素材组拆太碎 | 数据碎片化拖慢学习 | 1–3 个素材组起步；按数据扩张 |
| 无搜索只跑 P-MAX | 控不住品牌关键词，也判断不了蚕食 | 先建搜索，再加 P-MAX |

### 20-2. 素材错误

| 错误 | 为什么失败 | 避免 |
|------------|----------|-------|
| 只有通用图库图 | 转化率低；无品牌区分 | 用产品 / 服务的实拍 |
| 无视频素材 | Google 用图片自动生成低质视频 | 至少一个横版 + 一个竖版视频 |
| 文案素材太少 | AI 可测试的组合有限 | 11+ 标题、4+ 描述 |
| 图片文字过多 | GDN、Discover 有政策风险 / 投放限制 | 图片文字 ≤20% 面积 |

### 20-3. 运营阶段错误

| 错误 | 为什么失败 | 避免 |
|------------|----------|-------|
| 学习期频繁改动 | 重置学习；永久不稳定 | 改动后至少 2 周不动 |
| URL 扩展默认开着 | 流量漏到博客 / 招聘 | 配 URL 排除规则；线索广告关掉 |
| 不做品牌排除就跑 | P-MAX 吃掉品牌搜索转化——表面 ROAS 高但真实增量小 | 配品牌排除，与搜索划清界线 |
| 排除所有不转化的词 | 收窄 AI 探索；丢掉新客发现 | 只做策略性、按品类的排除 |
| 只看 ROAS 评判 | 品牌、再营销、建模转化、EVC 或到店目标 VTC 可能高估增量 | 同时看纯点击 / 广告事件类型 ROAS 和业务营收 |
| 猛加预算 | 触发学习重置 | 每 7–14 天最多 +20% |
| tCPA / tROAS 目标设成许愿值 | 投放崩掉，学习停滞 | 锚定实际 |
| 「设完不管」P-MAX | 环境变化表现衰减 | 每周健康检查成例行 |

### 20-4. P-MAX 再营销偏置

P-MAX 默认优先现有客户和网站访客——「可能转化的用户」。这让 ROAS 看着高，真实新客获取却很低。

**缓解：**
- 开启新客获取模式（见 [§12](#12-new-customer-acquisition-mode)）
- 用客户匹配识别现有客户
- 看渠道报告里的展示 / YouTube 占比（再营销重 → 展示占比高）
- 定期分析新客 vs 老客转化拆分

## 附录 A：按症状排查

反向查找：从症状定位原因、决定动作。

| 症状 | 可能原因 | 动作 |
|------|---------|-------|
| 有转化但 ROAS 在掉 | 非点击事件组合、tROAS 太松、或低毛利产品主导转化 | 按广告事件类型切分 / 按实际逐步收紧 tROAS / 用自定义标签按毛利拆分 |
| 花费集中在少数产品 / 素材组 | AI 优化进了少数易转化的产品 | 用上架组拆分 / 提高低花费素材组的素材质量 / 拆广告系列独立管预算 |
| YouTube / 展示占比过高 | 全素材投放偏向再营销 / 搜索渠道竞争激烈 | 考虑纯 Feed / 开启新客获取模式 / 在渠道报告里验证真实转化贡献 |
| CPA / CPC 突然上涨 | 学习重置 / 竞争变化 / 季节性 | 查近期改动（出价、预算、素材）/ 等 2–3 周稳定 / 查搜索词有无新的高 CPC 查询 |
| 搜索广告系列表现掉了 | 与 P-MAX 蚕食 | 查 P-MAX 搜索词重叠 / 设品牌排除 / 关键关键词在搜索加为完全匹配 |
| 转化太少 / 学习不推进 | 预算不足 / 转化定义太严 / 素材质量差 | 经济允许时提高日预算 / 改善主要转化路径 / 只用验证过的代理信号 / 补全素材 |
| 广告效力卡在「低」 | 素材数量不足 / 缺素材类型 | 11+ 标题、4+ 描述、每种格式 5+ 图片、1+ 视频 |
