# 业务模式手册（Business-model playbooks）

选广告系列类型之前先看本参考。业务模式、销售方式、利润率和转化延迟决定了"好的" Google Ads 架构长什么样。

## 选择原则

| 业务模式 | 第一个问题 | 默认倾向 | 主要风险 |
|---|---|---|---|
| B2B 线索获取 | 能不能导入合格 pipeline，而不只是表单提交？ | 先 Search，信号质量可靠后再上 P-MAX / Demand Gen | 对便宜但不合格的线索优化 |
| 本地服务 | 服务范围、电话接听、排班清楚吗？ | 先 Search + 电话 / 线索跟踪 | 为跨区或低意向搜索词付费 |
| 电商 | Feed、利润率数据、购买价值跟踪干净吗？ | 带 Feed 的 Shopping / P-MAX，再加 Search 吃高意向主题 | 收入 ROAS 掩盖了糟糕的利润率 |
| 高客单 / 长销售周期 | 哪个代理指标能可靠预测收入？ | Search + 再营销，配线下转化导入 | 用浅层线索过早下判断 |
| 应用 / 订阅 | 哪个事件能预测留存或 LTV？ | 应用广告系列，分阶段加深事件 | 永远对安装优化 |
| 到店 / 全渠道 | 到店或到店销售能量得准吗？ | P-MAX 到店目标（Store Goals）+ 地域 Search | 平台上报的到店和销售对不上 |

## B2B 线索获取

### 适配的广告系列组合

| 阶段 | 广告系列 | 角色 |
|---|---|---|
| 上线 | Search 非品牌 + 品牌 | 捕获明确需求，建立搜索词 / 线索质量基线 |
| 稳定 | Search + 再营销 Display / Demand Gen | 召回研究过的访客，温暖长周期买家 |
| 放量 | Search + P-MAX / Demand Gen | 线下转化质量已导入或代理指标质量已验证后再扩展 |

### 转化设计

| 信号 | 用途 |
|---|---|
| 原始表单提交 | 只有线索质量稳定、成交率方差小时才做 Primary |
| 合格线索 / MQL / SQL | 导入量级和延迟可接受时首选的核心信号 |
| 商机 / 成交 | 最好的信号，但常常太延迟或太稀，不能单独用 |
| 白皮书 / 研讨会 / 定价页浏览 | 默认 Secondary。只有被证明能预测 pipeline 才做 primary |

### 设计要点

- 品牌和非品牌拆开。品牌线索常常看起来便宜，但很少代表完整的增量需求。
- 不要把演示申请和低意向的内容下载混在一个目标 CPA 下。
- P-MAX 做线索时，如果网站有博客、招聘、支持或低意向页面，关掉最终网址扩展（Final URL expansion）或用严格的网址排除。
- 用 CRM 反馈评估线索来源、线索质量、商机率和成交率，不只看表单 CPA。

## 本地服务

### 适配的广告系列组合

| 阶段 | 广告系列 | 角色 |
|---|---|---|
| 上线 | Search 按服务 + 地点 | 捕获紧急的本地需求 |
| 稳定 | 品牌 Search + 非品牌 Search | 把防御性需求和获客分开 |
| 放量 | 符合条件时上 P-MAX 到店目标 / 本地 P-MAX | 衡量可信时加 Maps 和更广的本地版位 |

### 转化设计

| 信号 | 用途 |
|---|---|
| 超过合格时长的电话 | 电话接听能力强时做 Primary |
| 表单提交 / 预约 | 预约质量可跟踪时做 Primary |
| 导航 / 到店 | 本地目标可用，但尽量和预约或 POS 对账 |

### 设计要点

- 用"实际所在地（Presence）"地域定向，除非远程意向也有价值。
- 否定词覆盖招聘、DIY、考证、免费、跨区和不提供的服务。
- 广告排期对齐电话接听；浪费的电话是衡量和运营问题，不只是广告问题。
- 跟踪未接电话和已预约。没有服务收入的电话量会误导出价。

## 电商

### 适配的广告系列组合

| 阶段 | 广告系列 | 角色 |
|---|---|---|
| 上线 | 标准 Shopping 或带 Feed 的 P-MAX，加品牌 Search | 建立 Feed / 商品 / 搜索词基线 |
| 稳定 | P-MAX + 高意向类目 Search | 放大购买捕获，保护战略搜索词 |
| 放量 | 按利润率 / 类目分的 P-MAX + Demand Gen 商品发现 | 扩展发现的同时保护利润 |

### 转化设计

| 信号 | 用途 |
|---|---|
| 带动态价值的购买 | Primary 基线 |
| 毛利或边际贡献价值 | 利润率差异大时比收入更好 |
| 加购 / 开始结账 | 默认 Secondary。购买太稀且代理指标已验证时才做 primary |

### 设计要点

- Feed 质量就是定向质量：标题、GTIN、价格、库存、图片、product_type、自定义标签，先于广告系列调优。
- 按利润率分组只在它改变出价、预算或目标 ROAS 决策时做。
- 不看利润率不评估收入 ROAS。高 ROAS 的低利润 SKU 可能是糟糕的业务结果。
- 做商品级分析：赢家、成长中商品、烧钱货、无曝光 SKU，动作各不相同。

## 高客单 / 长销售周期

### 适配的广告系列组合

| 阶段 | 广告系列 | 角色 |
|---|---|---|
| 上线 | Search 高意向 + 品牌 | 流量质量收紧 |
| 稳定 | Search + 再营销 | 召回长考虑周期的用户 |
| 放量 | Demand Gen / YouTube 做教育 | 衡量和跟进够强之后才做需求创造 |

### 转化设计

| 信号 | 用途 |
|---|---|
| 咨询申请 / 报价申请 | 质量稳定时做 Primary |
| 合格商机 | 能导入时首选 |
| 购买 / 成交 | 业务真相，但作为唯一优化信号通常太延迟 |

### 设计要点

- 用更长的评估窗口，考虑转化延迟。
- 教育 / 中漏斗和高度意向捕获分开预算。
- 落地页围绕信任状、风险逆转、筛选和销售流程清晰度来建。
- 低门槛的获客钩子除非能预测 pipeline，否则不做核心目标。

## 应用 / 订阅

### 适配的广告系列组合

| 阶段 | 广告系列 | 角色 |
|---|---|---|
| 上线 | 应用安装广告系列 | 建立安装量和事件基线 |
| 稳定 | 应用行为广告系列 | 对最深层的稳定事件优化 |
| 放量 | 量级支撑时上 tROAS / 价值出价 | 向收入或留存价值优化 |

### 转化设计

| 信号 | 用途 |
|---|---|
| 安装 | 只做早期量级信号 |
| 注册 / 教程完成 / 付费墙浏览 | 能预测留存或购买时做代理事件 |
| 试用开始 / 订阅 / 购买 | 量级稳定后首选 |
| 留存 / LTV | 放量决策的业务真相 |

### 设计要点

- 上线时浅，量级支撑后再逐步加深。
- iOS 和 Android 拆开，因为衡量、归因、学习都不同。
- 创意多样性指不同动机和用场景，不只是改尺寸的剪辑版。
- 再营销要对增量性保持怀疑；很多回流用户不打广告也会回来。

## 到店 / 全渠道

### 适配的广告系列组合

| 阶段 | 广告系列 | 角色 |
|---|---|---|
| 上线 | 本地 Search + 品牌 | 捕获明确的附近需求 |
| 稳定 | P-MAX 到店目标 | 扩展本地版位，对到店 / 本地行为优化 |
| 放量 | 全渠道 P-MAX + Demand Gen（有条件时） | 支持商品发现和到店流量 |

### 转化设计

| 信号 | 用途 |
|---|---|
| 到店 | 方向性优化信号 |
| 到店销售 / POS 导入 | 首选的业务真相 |
| 电话 / 导航 | 有用的本地行为信号，但不能替代销售对账 |

### 设计要点

- Google 商家资料、营业时间、库存、本地落地页保持准确。
- 只有预算、服务范围、库存或门店经济模型不同时才按地域拆。
- 尽量用 POS、预约或门店级收入对账到店流量。
- 没有增量性检验时，不要给品牌 / 本地搜索过度记功。

## 多广告类型组合模式

当业务模式或漏斗角色需要不止一种广告系列类型时，用这些模式做起点。按预算充足度、转化量、衡量质量、创意供给和增量性风险调整结构。

### 现代自动化组合

2025–2026 年常见的自动化组合：

1. **Performance Max**——账户信号充足且有护栏时，做核心转化引擎。
2. **Demand Gen**——视觉型拉新、商品发现、中漏斗预热。
3. **Search 的 AI Max**——转化信号、网址控制、品牌控制就绪时，做 AI 增强的搜索扩展。

把它当作待评估的选项，不要当作默认强制项。如果预算、衡量、创意或 Feed 质量支撑不起，先收窄结构。

### Search + P-MAX

高意向捕获和自动化扩展都成立时最常见的模式。

```
Search（品牌词）              <- 品牌防御
Search（高意向词）            <- 完全匹配捕获
P-MAX（全素材或 Feed）        <- 自动化扩展
```

Search 完全匹配优先于 P-MAX。品牌截流会掩盖获客表现时，给 P-MAX 设品牌排除。

### 电商全漏斗

Feed、购买跟踪、利润视角、商品页质量都够强、能支撑自动化放量时最适配。

```
P-MAX（带 Feed）               <- 跨 Google 版位的主引擎
Search（非品牌、高意向）       <- 捕获 P-MAX 可能漏掉的意图
标准 Shopping（可选）          <- 保护诊断或覆盖不足的商品
展示再营销                     <- 弃购和商品浏览者
```

### B2B 线索获取

Search 意图清晰、线索质量能监控或从 CRM 导入时最适配。

```
Search（品牌 + 问题词）            <- 捕获高意向用户
P-MAX（全素材，网址扩展关）       <- 扩展和再营销
Video（YouTube，可选）            <- 教育和信任
```

P-MAX 做线索时，网站有博客、招聘、支持或低意向页面就关掉网址扩展，或用严格的网址排除。

### 认知到转化

目标是先创造需求再捕获，而不是只看末次点击 CPA 时最适配。

```
Video（YouTube 覆盖 / 观看） <- 认知阶段
Demand Gen / Display        <- 认知加强和中漏斗预热
Search（品牌词）            <- 捕获品牌搜索提升
P-MAX                       <- 广泛的转化覆盖
```

这个模式用量级允许时的混合效果、品牌搜索提升、助攻转化、受众增长和增量测试来评估。
