# 创意策略（Creative strategy）

规划 Search 文案、P-MAX 素材、Demand Gen、Display、Video、App 或 Shopping 创意时使用本参考。创意策略应在素材规格之前先定义说服逻辑。

## 创意规划顺序

| 步骤 | 问题 | 输出 |
|---|---|---|
| 1. 受众 | 买家是谁，他们已经相信什么？ | 人群 / 分段假设 |
| 2. 痛点或欲望 | 什么问题、紧迫感或渴望创造了需求？ | 钩子方向 |
| 3. Offer | 现在行动的具体理由是什么？ | offer / CTA |
| 4. 信任状 | 用户为什么要相信？ | 评价、数字、演示、logo、资质、保障 |
| 5. 异议 | 什么会阻止用户？ | 风险逆转、筛选、FAQ、对比 |
| 6. 版式适配 | 该版位奖励什么？ | 搜索文案、商品图、Shorts 钩子、轮播故事等 |
| 7. 衡量 | 什么结果能证明这个切入角度有效？ | CTR、CVR、CPA、合格线索率、ROAS、提升度 |

---

## 切入角度库

| 角度 | 什么时候最有效 | 示例用途 |
|---|---|---|
| 问题 / 痛点 | 买家知道痛点但不知道解决方案 | Search、YouTube 钩子、Demand Gen |
| 结果 / 利益 | 结果在情感或金钱上很清晰 | Search 标题、P-MAX 文案、Display |
| 信任状 / 可信度 | 信任是转化障碍 | B2B、高客单、医疗、金融 |
| Offer / 促销 | 价格或紧迫感驱动行动 | 电商、本地服务、季节性投放 |
| 对比 | 买家在几个选项之间选 | Search、落地页、轮播 |
| 演示 | 产品价值展示比解释更容易 | 视频、Demand Gen、App |
| 社会认同 | 采用率降低感知风险 | SaaS、应用、消费品 |
| 风险逆转 | 对损失的恐惧阻碍行动 | 试用、保障、退货、咨询 |
| 筛选 | 低质量点击 / 线索是问题 | B2B、本地服务、高客单 |
| 新奇 / 新鲜感 | 类目奖励发现感 | Demand Gen、YouTube、Shopping 新品上线 |

不要做同一个想法的十五个变体。做几个差异化的切入角度，再把每个角度适配到所需的素材版式。

---

## 按业务模式的创意优先级

| 业务模式 | 强角度 | 避免 |
|---|---|---|
| B2B 线索获取 | ROI、运营痛点、信任状、集成、降风险、筛选 | 含糊的生产力宣称，以及把低意向获客钩子当主打 |
| 本地服务 | 服务范围、速度、信任、评价、执照、紧急可约、价格清晰 | 没有本地信任状的泛泛"最佳服务"宣称 |
| 电商 | 产品使用场景、价格 / 价值、评价、配送 / 退货、对比、组合装 | 藏起产品的泛泛生活方式图 |
| 高客单 | 信任状、流程清晰、咨询价值、风险逆转、分期或筛选 | 没有信任支撑的强硬紧迫感 |
| 应用 / 订阅 | 核心使用场景、习惯回路、社会认同、试用、应用界面、留存价值 | 留存或订阅重要时还只写安装文案 |
| 到店 | 附近有货、库存、导航、本地 offer、门店信任 | 只有品牌信息、没有本地行动 |

## 版式适配

| 版式 | 创意任务 | 设计规则 |
|---|---|---|
| Search RSA | 匹配明确意图并筛选点击 | 用差异化标题：关键词相关性、结果、信任状、offer、异议、CTA |
| Shopping | 让商品清晰、有竞争力 | 商品标题、图片、价格、配送、评价、库存就是创意 |
| P-MAX | 提供连贯的素材组 | 受众信号、搜索主题、落地页、文案、图片、视频、商品集合对齐 |
| Demand Gen | 在信息流环境里创造或预热需求 | 用原生视觉钩子、产品使用场景、短视频、轮播、社交风信任状 |
| Display | 提醒、召回，或在有护栏下便宜触达 | 一个视觉想法、清晰的 CTA、频次控制、展示位置卫生 |
| YouTube / Video | 先赢得注意力再要行动 | 早钩子、早出现品牌 / 产品、建立信任状、用具体行动收尾 |
| App | 展示安装后的体验 | 应用界面、游戏 / 产品时刻、动机、信任状、快节奏移动端构图 |

## P-MAX 素材组创意体系

每个 P-MAX 素材组应回答一个连贯的业务问题：

| 元素 | 对齐什么 |
|---|---|
| 商品 / 服务主题 | 一个类目、服务、利润等级或客户类型 |
| 搜索主题 | 与主题和落地页匹配的词 |
| 受众信号 | 与主题相关的客户列表、再营销、自定义分段或意向提示 |
| 落地页 | 兑现广告承诺的商业页面 |
| 文案素材 | 差异化切入角度，不是改写 |
| 图片 | 产品、使用场景、信任状、品牌线索 |
| 视频 | 每个概念一个清晰的钩子和 offer |

避免做"全商品 / 全受众 / 全信息"的通用素材组，除非账户小到支撑不起分组。

## Demand Gen 创意体系

| 组件 | 做法 |
|---|---|
| 种子受众 | 从高质量客户、购买者、合格线索或留存用户起步 |
| 钩子 | 用在社交信息流里成立的视觉或文案钩子 |
| 信任状 | 用评价、产品演示、UGC 风场景、客户 logo，或政策允许的前后对比 / 流程清晰度 |
| Offer 路径 | 下一步显而易见：买、比、约、下载、试用、报价 |
| 版位覆盖 | 有意做竖版、方版、横版变体，不要盲目裁剪 |
| 更新 | 疲劳出现时轮换概念；换想法，不只是换颜色 |

冷启动拉新不要以泛泛的品牌宣称开头。以痛点、使用场景、产品时刻、信任状或 offer 开头。

## Search 文案设计

按不同任务写 RSA 素材：

| 素材任务 | 示例方向 |
|---|---|
| 相关性 | 用买家语言写产品 / 服务词 |
| 结果 | 购买或咨询之后什么变好了 |
| 信任状 | 评分、客户数、资质、案例结果 |
| Offer | 试用、报价、折扣、组合装、咨询 |
| 筛选 | 服务区域、价格带、企业规模、资格 |
| 异议处理 | 无合约、快速开通、保修、价格透明 |
| CTA | 获取报价、预约演示、购买、对比、安装 |

只有法律、品牌或清晰度要求时才固定（pin）。否则保留组合多样性。

## 视频概念检查清单

| 环节 | 问题 |
|---|---|
| 前 1–3 秒 | 有动态、产品、问题、人物或视觉对比吗？ |
| 前 5 秒 | 用户知道这是什么、为什么重要吗？ |
| 品牌记忆 | 品牌 / 产品出现得够早、能被记住吗？ |
| 信任状 | 有相信这个宣称的理由吗？ |
| 行动 | 下一步具体且可见吗？ |
| 移动端适配 | 文字清晰、重要内容在安全区内吗？ |
| 变体 | 概念有实质差异，不只是改尺寸吗？ |

## 创意测试

| 测试类型 | 好问题 | 差问题 |
|---|---|---|
| 钩子测试 | 痛点导向胜过结果导向吗？ | 蓝色胜过绿色吗？ |
| Offer 测试 | 免费咨询胜过定价指南吗？ | "了解更多"胜过"今天就了解更多"吗？ |
| 信任状测试 | 评价胜过客户 logo 吗？ | 一个小措辞改动重要吗？ |
| 版式测试 | 竖版 UGC 风视频胜过精致横版吗？ | 同一条素材裁三种尺寸表现不同吗？ |
| 筛选测试 | 加价格 / 服务区域能提高线索质量吗？ | 更宽泛的文案能拿更多点击吗？ |

按创意任务匹配的指标评判创意。拉新创意可能先带动 CTR、有效访问、助攻转化或品牌搜索，再到直接 CPA 稳定。

## 素材制作基线

本节用于实施交接。广告系列手册聚焦策略，只在规格改变策略决策时才重复规格。

### 跨渠道原则

- 上传所有有用的比例，不要依赖自动裁剪。
- 规格易变；生产交接前在 Google Ads 界面核对。
- 日 / 中 / 韩文案注意：很多 Google Ads 限制把 CJK 字符按 2 个字符计。
- 素材多样性指差异化概念，不只是改尺寸或改颜色的变体。

### 常用图片比例

| 比例 | 常用场景 | 实用制作尺寸 |
|---|---|---|
| 1.91:1 横版 | P-MAX、Demand Gen、Display | 1200x628 |
| 1:1 方版 | P-MAX、Demand Gen、Display、App | 1200x1200 |
| 4:5 竖版 | Demand Gen / 类 Discovery 版位 | 960x1200 |
| 9:16 竖版 | Shorts / 竖版视频或图片版位 | 1080x1920 |
| 1:1 logo | P-MAX / Demand Gen / Display | 1200x1200 源文件；按平台上限导出 |

### P-MAX 素材基线

| 素材 | 最低实用套装 | 更好的套装 |
|---|---|---|
| 文案 | 11+ 标题、4 描述、最终网址 | 差异化切入角度：相关性、信任状、offer、异议、CTA |
| 图片 | 5 横版 + 5 方版 | 有条件加 3–5 张竖版 |
| 视频 | 1 横版 + 1 竖版 | 加方版和 2–3 个概念变体 |
| Feed | 零售必需 | 加自定义标签：利润率、库存、季节性、爆品 / 长尾 |

### Demand Gen 基线

| 素材 | 最低实用套装 | 说明 |
|---|---|---|
| 标题 / 长标题 / 描述 | 各最多 5 条 | 每条素材自成一体；组合是自动的 |
| 图片 | 横版 + 方版；强烈建议竖版 | Discover / Shorts 相邻库存用得上 |
| 视频 | 尽量横版 + 方版 + 竖版 | Shorts 需要原生竖版创意 |
| 轮播 | 2–10 张卡 | 一张弱卡可能拖累或拒登整个单元 |
| 商品 Feed | 电商可选 | Merchant Center 地区和配送设置必须与定向匹配 |

### Display 基线

| 版式 | 最低实用套装 | 说明 |
|---|---|---|
| 自适应展示广告 | 横版图、方版图、logo、标题、描述 | 让 Google 组装组合，但每条素材独立看也要有意义 |
| 上传型展示广告 | 只有品牌 / 版式控制重要时用 | 优先常用尺寸如 300x250、336x280、728x90、300x600、320x50、970x250 |
| Display 中的视频 | 有且策略上用得上时用 | EVC 和 VTC 分开评估 |

### 视频基线

| 版式 | 实用指引 |
|---|---|
| 可跳过信息流内 | 多数效果场景 15–60 秒；可跳过点之前露出品牌 / 价值 |
| 不可跳过 | 15–30 秒，看地区 / 库存 |
| Bumper | 6 秒或更短 |
| 信息流内 | 缩略图和首帧重要；用户自己选择看不看 |
| Shorts | 9:16，第一帧有强动态 / 文字 / 产品提示 |
| CTV | 当覆盖 / 品牌影响处理，除非账户有强的提升或 MMM 读数 |

### 应用广告系列基线

| 素材 | 实用指引 |
|---|---|
| 文案 | 多条短文案，围绕不同动机和异议 |
| 图片 | 方版和横版截图 / 产品时刻；避免只有泛泛的生活方式图 |
| 视频 | 尽量 16:9、1:1、9:16；快速展示应用内体验 |
| 可玩 / HTML5 | 只有应用 / 游戏体验能从互动中受益、且有制作 QA 时用 |

### Shopping / Feed 创意基线

对 Shopping 来说，Feed 就是创意。优先：

- 商品标题：类目、关键属性、品牌 / 型号、相关的尺码 / 颜色 / 材质。
- 主图：商品清晰、无误导性叠加、缩略图可读性强。
- 价格 / 促销价 / 配送 / 退货：与落地页一致。
- 评价、促销、库存：用影响 CTR / CVR 的 Merchant Center 合规功能。

## 创意简报最低要求

需要创意简报时，包含：

1. 广告系列角色和漏斗阶段。
2. 受众和触发点。
3. 核心 offer 和 CTA。
4. 三到五个差异化创意切入角度。
5. 可用的信任状素材。
6. 要处理的异议。
7. 所需版式和安全区约束。
8. 衡量计划和更新节奏。
