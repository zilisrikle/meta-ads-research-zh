# Google 展示广告（Display Ads）

## 运营实践

展示广告要有明确的任务：再营销、温受众召回、便宜的增量覆盖，或审慎控制的拉新。不要把每个展示广告系列都当 Search 来评估。

### 最重要的事

- **角色清晰比设置更重要。** 再营销、拉新、品牌覆盖、客户召回通常要分开，因为它们的 CPA、频次、创意、衡量逻辑都不同。
- **低 CPM 只在质量约束之后有用。** 受众已经够好、广告系列有出价 / 创意纪律时，便宜的覆盖能胜过过度定向。当展示位置、地域、品牌安全或转化质量差时，它就是浪费。
- **优化型定向对再营销很危险。** 它可能扩展到预期的温受众之外。任务是严格再营销时保持关闭；只有明确要做拉新时才考虑开。
- **浏览型转化不该单独支撑业务结论。** 展示 VTC 可能被没有产生真实注意力的展示虚高。除非对照组 / 提升测试证明了这个功劳，否则 VTC 单独看或打折看。
- **频次是品牌和 CPA 杠杆。** 小的再营销池很快会被过度曝光。频次上限从每人每周 3–5 次展示起步，通常比无限制投放更好。
- **创意信息胜过视觉精致度。** 清晰的价值主张、行动理由、CTA 通常比装饰性的图片质量更重要。视觉类目里图片就是信息；多数线索类目里标题 / offer 承担转化。
- **展示位置卫生要聚焦，不要极繁主义。** 排除已知的不良库存和不合适的应用 / 内容类目，但避免巨型排除列表——那只会抬高 CPM 而不改善结果。

- **够宽 + 够便宜能胜过精准定向。** 温受众或拉新信号已经够好时，过度叠加受众层的 CPM 涨速会快过 CVR 涨速。例外是合规重或匹配极窄的产品——坏展示有真实成本。
- **独立展示广告系列通常不是第一冷启动获客引擎。** P-MAX 和 Demand Gen 常常覆盖广泛视觉库存更有效。展示广告在有差异化任务时用：再营销、频次可控的覆盖、客户唤回，或精选的 B2B 展示位。
- **移动应用库存要刻意审阅。** 对非应用广告主，应用展示位可能产生低质量点击或误触。质量差时按类目或展示位排除，但测试前不要条件反射地全量屏蔽。
- **小的共用排除列表比无尽的排除更健康。** 维护已知不良展示位 / 内容类目；不要把展示位清理变成主要优化策略。
- **展示创意疲劳真实存在。** 活跃的广告系列按新概念和新 offer 规划更新，不只是改尺寸的横幅。
- **不要让展示和 P-MAX 抢同一个任务。** P-MAX 已经在做转化导向的广泛覆盖时，展示就做再营销、唤回、可控覆盖，或讲不同的信息。

### 诊断

| 症状 | 先查 | 可能的行动 |
|---|---|---|
| 流量便宜但业务没提升 | 展示位置质量、VTC 占比、转化动作、互动质量 | 收紧目标、排除弱库存、做增量测试 |
| 再营销 CPA 恶化 | 优化型定向、频次、受众新鲜度、创意疲劳 | 关扩展、设频次上限、按新鲜度分段、更新创意 |
| 拉新花不出去 | 受众太窄、出价目标太紧、素材弱 | 放宽、放目标、提高 RDA 覆盖 |
| VTC 占比高 | VTC 窗口、可见度、核心转化设置 | VTC 单独汇报、缩短窗口、用点击 / 互动信号 |

### 常见陷阱

- 展示拉新和 P-MAX 对同一目标、同一受众跑，没有定义不同任务。
- 追逐最低 CPM，忽略展示位置质量和下游线索 / 销售质量。
- 收入质量重要时还对页面浏览、订阅这类微转化优化。
- 在稳定的 Smart Bidding 广告系列里一次换掉所有创意。

## 1. 广告格式

### 1-1. 自适应展示广告（RDA）

**当前默认格式。** 上传图片、logo、标题、描述，Google AI 为每个展示位自动调整最优组合和尺寸。

- GDN 图片广告库存的绝大多数现在以自适应形式投放。
- 一套素材覆盖所有展示位；运营轻量。
- Google AI 按版位和用户学习最佳组合。

### 1-2. 上传型展示广告

想要像素级设计控制时用。

| 类型 | 特点 |
|---|---|
| 静态图片广告 | JPG / PNG / GIF。每种尺寸单独制作 |
| 动态 GIF | ≤30 秒、≤5 fps。文件 ≤150 KB |
| HTML5 广告 | ZIP 包。支持互动表达 |
| AMPHTML 广告 | 符合 AMP 规范。移动端快 |

### 1-3. 视频广告（展示库存）

- YouTube 视频可以作为素材加到自适应展示广告里。
- 最多 5 条视频，每条最长 30 秒。
- 建议比例：16:9、1:1、4:3、9:16。
- 带视频素材的广告 CTR 倾向高于纯图片。

## 2. 提审规格

制作规格见 [creative-strategy.md](creative-strategy.md#display-baseline)。展示专属规划规则：

- 除非需要严格的版式控制，优先自适应展示广告。
- 上传型展示广告适合品牌控制场景，但制作优先保证高库存尺寸。
- 重要视觉元素居中，因为 Google 可能裁剪自适应素材。
- 图片文字太多通常效果差，还可能带来政策 / 投放风险。
- 用了视频就把 EVC 和 VTC 与点击归因 CPA 分开评估。

## 3. 创意设计最佳实践

### 4-1. 图片设计原则

#### 要做

| 原则 | 说明 |
|---|---|
| 用高质量图片 | 清晰、专业。模糊 / 低分辨率不可接受 |
| 主体居中 | Google 裁剪时保住重要元素 |
| 构图简洁 | 一个清晰的信息；塞元素适得其反 |
| 高对比色 | 背景和前景强对比；在宿主网站上跳出来 |
| 展示产品 / 服务 | 真实产品摄影或使用场景带来更强响应 |
| 品牌一致 | 颜色、字体、调性遵循品牌规范 |
| 照片 > 插画 | 照片的 CTR / CVR 倾向优于插画 |

#### 原则上避免

| 项目 | 原因 | 说明 |
|---|---|---|
| 图片上叠文字 | 小版位（320×50 等）看不清；和标题重复 | 实在避免不了：最小 16 px 字号、高对比、≤ 图片面积 20% |
| 图片里放 logo | logo 应该作为 logo 素材上传 | RDA 自动渲染 logo；图内 logo 会重复显示 |
| 拼贴图 | 小尺寸难读；一张图一个信息 | — |
| 过度滤镜 | 看起来不自然；保持自然观感 | — |
| 模糊 / 低分辨率 | 低质伤害品牌形象 | — |
| 纯白底白图 | 广告融进白底网站 | 加细边框或底色界定边界 |

#### 硬性禁止（政策违规）

| 项目 | 原因 |
|---|---|
| 像按钮的假 UI 元素 | 误导性政策违规；广告会被拒登 |
| 假系统警告或通知 | 模仿病毒警告或系统通知的图片 |

### 4-2. 文案（标题 / 描述）设计原则

#### 短标题（30 字符 / CJK 实际 15）

- 清晰传达产品、服务或品牌
- 带 offer / 价格 / 促销倾向提升 CTR
- 每个标题必须自成一体
- 5 条用不同切入角度（价格、功能、情感、稀缺、信任状等）

#### 长标题（90 字符 / CJK 实际 45）

- 在不展示短标题的版位显示
- 一句话讲完价值主张
- 有时不带描述单独显示；必须能独立成立

#### 描述（90 字符 / CJK 实际 45）

- 给标题补充信息
- 写具体利益或 CTA
- 5 条各不相同，且能和任意标题组合
- 不要改写标题（Google 自动组合标题 + 描述）

### 4-3. 选择 CTA

| CTA | 适合 |
|---|---|
| 自动（建议） | Google AI 选最优 CTA。拿不准就用这个 |
| 了解更多 | 信息 / 认知 |
| 立即购买 | 电商、直接销售 |
| 注册 | 注册、订阅 |
| 联系我们 | B2B 线索获取 |
| 下载 | 应用、资料 |

### 4-4. 上传型广告的设计要点

| 要点 | 说明 |
|---|---|
| CTA 按钮突出 | 粗字体 + 高对比按钮色 |
| 引导视线 | 图片 → 标题 → CTA，按这个自然流 |
| 留白 | 不要塞；保持呼吸感 |
| 文件 ≤150 KB | 用压缩工具；加载速度重要 |
| 跨尺寸一致 | 尺寸变了品牌体验一致 |
| 动画克制 | 动态抓注意力，但过度会被无视 |

### 4-5. 用视频素材

- 带视频的展示广告 CTR 倾向高于纯图片
- 前 5 秒讲清品牌和价值主张
- 按静音播放设计（文字叠加、字幕）
- 多种比例（16:9 + 1:1 + 9:16）拿更广库存

## 4. 广告政策与规则

把展示政策工作当上线风险筛查，不当静态政策手册。上线前先核对当前 Google Ads 政策，监管类目尤其。

| 领域 | 上线前检查什么 |
|---|---|
| 编辑质量 | 无过度符号、噱头式大小写、含糊文案、正文里放电话号码、模糊图片、假 UI、看不清的文字 |
| 误导 / 标题党 | 无耸动措辞、欺骗性提示、恐惧型 imagery、身体前后对比宣称、过度修图的身体部位图 |
| 受限类目 | 酒精、赌博、医疗 / 药品、金融服务、政治广告、成人内容等监管行业可能需要认证、地域限制、披露或排除 |
| 禁止内容 | 假货、危险品、不诚实行为、仇恨 / 暴力等违禁内容必须完全排除 |
| 落地页 | 域名必须匹配、页面可用、浏览器导航不被阻断、内容有用、移动端渲染可接受 |

被拒登就到 Google Ads 里诊断确切的政策原因，修广告或落地页，记录改动，确认根本问题解决后再申请审核。

## 5. 定向策略

### 5-1. 受众定向

| 类型 | 内容 | 适合 |
|---|---|---|
| **兴趣（Affinity）** | 按兴趣 / 习惯分的分段 | 认知（顶部漏斗） |
| **意向（In-market）** | 正在主动研究特定产品 / 服务的用户 | 考虑（中部漏斗） |
| **自定义分段** | 按关键词 / 网址 / 应用自定义 | 灵活定向 |
| **再营销** | 来过网站的用户 | 转化（底部漏斗） |
| **Customer Match** | 上传自己的客户列表（邮箱等） | 触达老客户；做种子 |
| **人口属性** | 年龄、性别、家庭收入、父母身份 | 按属性过滤 |
| **人生大事** | 结婚、搬家、毕业等 | 在人生阶段变化时触达 |

### 5-2. 内容定向

| 类型 | 内容 |
|---|---|
| **关键词** | 内容与指定关键词相关的页面 |
| **主题** | 与指定主题相关的页面 |
| **展示位置** | 指定的网站、应用或 YouTube 频道 |

### 5-3. 优化型定向（Optimized Targeting）

- 展示广告系列默认在广告组层级开启
- Google AI 扩展到手动定向之外、可能转化的用户
- 用第一方数据（再营销列表、Customer Match）做种子扩展到相似用户（实际是"相似受众"的继任者）
- 早期或转化量低时有用；转化数据越多精度越高
- 想保持紧控制时考虑关（建议拉新 vs 再营销做 ON / OFF 的 A/B 测试）

### 5-4. 定向 vs 观察

给展示广告系列加受众分段时，在定向（Targeting）和观察（Observation）之间选：

| 模式 | 行为 | 用途 |
|---|---|---|
| **定向** | 投放只限指定的受众 / 内容 | 想收窄覆盖时 |
| **观察** | 不收窄覆盖；按指定条件汇报效果 | 数据收集 → 出价调整输入。想评估效果又不想丢覆盖时 |

**模式：** 再营销列表用定向（收窄就是目的），兴趣 / 人口属性用观察（先攒数据，之后可能切定向）。

### 5-5. 旧术语 → 当前界面映射

| 旧术语 | 当前（截至 2026） | 说明 |
|---|---|---|
| 相似受众（Similar Audiences / similar segments） | **已下线**（2023 年 8 月） | 替代：优化型定向 + 第一方数据 |
| Lookalike audiences | **已下线** | 同上 |
| Lookalike segments | **仅 Demand Gen**（展示广告系列不可用） | Demand Gen 里从 Customer Match 等扩展 |
| 受众扩展 | 并入**优化型定向** | 改名并改了界面 |

### 5-6. 定向设计说明

| 说明 | 描述 |
|---|---|
| 不要过度收窄 | 多层定向叠加可能让投放量崩掉 |
| 再营销单独成广告组 | 和拉新信息不同；隔离开 |
| 排除也要用 | 排除不想要的受众 / 展示位能砍浪费 |
| 人口属性"未知" | 排除"未知"可能大幅砍覆盖。谨慎决定 |

## 6. 出价策略（展示专属）

### 6-1. Smart Bidding（建议）

| 策略 | 目标 | 使用时机 |
|---|---|---|
| **Maximize Conversions** | 最大化转化数 | 转化跟踪已上线但还没目标 CPA |
| **目标 CPA** | 按指定 CPA 最大化转化数 | 转化历史充足（粗略指引：每月 30+） |
| **Maximize Conversion Value** | 最大化转化价值（例如收入） | 已设置转化价值 |
| **目标 ROAS** | 按指定 ROAS 最大化转化价值 | 转化价值数据充足 |

### 6-2. 展示专属出价策略

| 策略 | 目标 | 说明 |
|---|---|---|
| **可见展示 CPM（vCPM）** | 每千次可见展示成本 | 认知目标用；展示 / 视频用 |

**注意：** 增强型 CPC（eCPC）已不再支持 Search 和展示广告系列；没主动迁移的广告系列现在实际用人工 CPC（[Google Ads 帮助](https://support.google.com/google-ads/answer/2464964?hl=en)）。

### 6-3. 展示出价策略决策流

```
转化跟踪上线了吗？
├── 没有 → Maximize Clicks / 人工 CPC / vCPM
└── 有 → 每月转化 ≥ 30？
    ├── 没有 → Maximize Conversions（攒学习数据）
    └── 有 → 跟踪了转化价值（收入等）吗？
        ├── 没有 → 目标 CPA
        └── 有 → 目标 ROAS
```

## 7. 衡量与评估（展示版）

展示广告和 Search 行为不同——"非点击贡献"、"浏览触点"、"误触"常见。纯用 Search 式 CPA 评估展示，要么低估展示，要么放任浪费投放。

### 7-1. 浏览型转化（VTC）

用户看了广告、没互动、之后在浏览转化窗口内转化的记为 VTC。

| 项目 | 说明 |
|---|---|
| 计数条件 | Active View——广告至少 50% 展示 ≥1 秒 |
| 默认衡量窗口 | 1 天 |
| 可调范围 | 1–30 天 |
| 去重 | 同一用户之后点击了广告，点击转化优先，VTC 排除 |

**VTC 运营政策：**

按 SKILL.md 的统一 VTC 政策处理：

| 政策 | 用途 | 条件 |
|---|---|---|
| **只监控（建议起点）** | VTC 报在浏览型转化 / 所有转化列；不做主要优化信号 | 默认用这个 |
| **作辅助证据** | VTC 配点击 / EVC、频次、展示位置质量、提升测试、后端结果一起看 | 再营销和认知读数尤其有用 |

**注意：** VTC 权重过高会让预算流向实际不带来转化的展示。VTC 窗口保持短（1 天）有助于防虚高。点击归因 / EVC 效果和 VTC 助攻贡献永远分开跟踪。

### 7-2. 主要 vs 次要转化

Google Ads 允许把转化动作分成 Primary 或 Secondary。

| 类型 | 出价优化 | 报表 | 展示用途 |
|---|---|---|---|
| **Primary** | 用 | 计入"转化数"列 | 希望出价策略优化的转化动作（购买、表单提交等） |
| **Secondary** | 不用 | 只在"所有转化"里 | 只监控（页面浏览、滚动、VTC 等） |

**设计示例：**

| 业务 | Primary | Secondary |
|---|---|---|
| 电商 | 购买 | 加购、商品浏览 |
| B2B 线索获取 | 表单提交 | 资料下载、点击拨号、VTC |
| 认知目标 | —（无转化；vCPM 出价） | 网站访问、页面停留 |

### 7-3. 按目标的 KPI

展示的正确指标因目标差异极大。

| 目标 | 核心 KPI | 次要 KPI |
|---|---|---|
| **认知** | vCPM（可见 CPM）、覆盖、频次 | 品牌搜索提升、直接网站流量变化 |
| **考虑** | CTR、落地页跳出率、页面停留 | 微转化（资料下载、视频观看） |
| **转化获取** | CPA、转化数、ROAS | VTC、助攻转化、LTV |
| **再营销** | CPA、转化数、ROAS | VTC、频次、列表利用率 |

### 7-4. 增量评估（轻量）

验证展示是否真在产生增量转化的方法。

| 方法 | 怎么做 | 精度 |
|---|---|---|
| **地域对照组** | A 地区（投放）vs B 地区（不投放）的转化率对比 | 中–高 |
| **开关时段** | 暂停展示固定周期；对比前后转化数和品牌搜索量 | 中 |
| **优化型定向开 / 关** | 同等条件下开 vs 关的广告组对比 | 中 |
| **拉新 vs 再营销拆分** | 拆成独立广告系列，看清各自的增量贡献 | 中 |
| **转化提升（Conversion Lift）** | 符合条件时用平台的提升衡量流程 | 高 |

### 7-5. 落地页要求（展示专属）

用户是被动看到展示广告的，落地页流失比 Search 更常见。

| 要求 | 原因 |
|---|---|
| **信息匹配** | 广告视觉 / 标题必须和落地页首屏对齐；不匹配立刻跳出 |
| **加载速度** | 移动端 3 秒内渲染。展示流量偏移动端 |
| **CTA 清晰** | 首屏必须回答"我在这里该做什么？" |
| **表单极简** | 线索获取尽量减少表单字段 |

## 8. 广告系列结构与运营设计

### 8-1. 为什么拆广告系列

| 拆分维度 | 示例 | 原因 |
|---|---|---|
| **按目标** | 认知 / 再营销 / 转化获取 | 出价策略和 KPI 不同 |
| **按产品** | 产品 A / 产品 B | 预算独立管理 |
| **按地域** | 国内 / 国际 | 定向和信息不同 |

### 8-2. 推荐的广告系列结构模板

展示的基础规则是：**拉新（新用户）和再营销不要混。** 3 广告系列结构是建议模板。

```
Display（3 广告系列结构）
│
├── 广告系列 1：[Display] Prospecting - {product}
│   ├── 出价：Maximize Conversions 或目标 CPA
│   ├── 定向：兴趣 / 意向 / 自定义分段
│   ├── 优化型定向：开（初期；数据攒够后 A/B 测试开 / 关）
│   ├── 排除：再营销列表（老访客 / 已转化）
│   └── 广告组 1：主题 A / 广告组 2：主题 B……
│
├── 广告系列 2：[Display] Remarketing - {product}
│   ├── 出价：目标 CPA 或 Maximize Conversions
│   ├── 定向：再营销列表
│   │   ├── 广告组 1：网站访问（7 天内）
│   │   ├── 广告组 2：网站访问（8–30 天）
│   │   └── 广告组 3：弃购 / 弃表单等
│   ├── 优化型定向：关（再营销保持定向紧）
│   └── 排除：已转化用户
│
└── 广告系列 3：[Display] Awareness - {product}（只有认知是目标时）
    ├── 出价：vCPM 或 Maximize Clicks
    ├── 定向：更宽的受众
    ├── 频次上限：每天 3–5 次
    └── KPI：覆盖、vCPM、品牌搜索提升
```

**要点：**
- 拉新广告系列排除再营销列表，防止重叠。
- 再营销关掉优化型定向，受众控制保持紧。
- 应用内库存误触流量大？用展示位置排除（见第 10 节）。

### 8-3. 广告组设计

| 原则 | 说明 |
|---|---|
| 一个主题 | 一个广告组 = 一个定向主题 |
| 再营销分开 | 拉新和再营销分属不同广告组 |
| 信息匹配 | 每个目标受众配定制创意 |
| 广告数 | 每广告组 3–4 条自适应展示广告 |

### 8-4. 频次上限

| 项目 | 设置 |
|---|---|
| 范围 | 广告系列 / 广告组 / 广告 |
| 周期 | 天 / 周 / 月 |
| 计数基准 | 仅可见展示（展示广告系列） |

**建议值：**
- 认知目标：每天 3–5 次
- 再营销：每天 1–3 次
- 投放量低时放宽上限做验证

### 8-5. 地域、语言、设备设置

| 设置 | 说明 |
|---|---|
| **地域** | 注意默认的"实际所在地或兴趣"设置。不想要兴趣型投放就改成"仅实际所在地" |
| **语言** | 按浏览器语言过滤。用网站主语言；只有分析、搜索词或市场背景显示有意义需求时才加次要语言 |
| **设备** | Smart Bidding 下设备出价调整基本失效。设备专属策略在结构上拆（广告系列级） |

## 9. 品牌安全与展示位置管理

### 9-1. 库存类型

| 类型 | 内容 | 建议 |
|---|---|---|
| **扩展库存** | 投放到所有可变现内容，含强内容 | 最大覆盖；品牌约束少 |
| **标准库存** | 适合大多数品牌的内容 | **默认建议** |
| **受限库存** | 严格排除粗俗语言和性内容 | 品牌规范严格的用 |

### 9-2. 内容类型排除

#### 敏感内容排除

| 类别 | 说明 |
|---|---|
| 悲剧与冲突 | 战争、自然灾害、社会悲剧 |
| 敏感社会议题 | 种族、宗教、性取向等 |
| 粗俗语言 | 含粗俗语言的内容 |
| 性暗示 | 性暗示内容 |
| 耸动与惊悚 | 过度刺激的内容 |

#### 内容类型排除

| 类型 | 建议 |
|---|---|
| 直播 | 无法预审；建议排除 |
| 嵌入式 YouTube 视频 | 网站上的嵌入视频；上下文不明时排除 |
| 首屏以下 | 需要滚动才能看到的广告位 |
| 停放域名 | 空域名；建议排除 |

### 9-3. 展示位置排除

| 层级 | 说明 |
|---|---|
| 账户级 | 适用于所有广告系列；品牌安全基线 |
| 广告系列级 | 只适用于特定广告系列 |
| 广告组级 | 最细粒度 |

**注意：** 排除是叠加的。账户级排除的展示位不能在广告系列级重新启用。

#### 考虑排除的展示位

| 类别 | 原因 |
|---|---|
| 移动应用（不需要时） | 误触多。排除 `adsenseformobileapps.com` |
| 游戏应用 | 儿童向应用的误触；品牌不匹配 |
| 表现差的网站 | 在展示位置报告里找低 CTR / 低 CVR 的网站 |
| 品牌不兼容的网站 | 和行业或品牌形象不符的网站 |

### 9-4. 每周展示位置复盘流程

1. **看展示位置报告**：广告系列 → 内容 → 广告展示位置；复盘每个投放过的网站 / 应用。
2. **找误触信号**：CTR 异常高（例如 >5%）且 0 转化的展示位很可能是误触。
3. **排除低质量展示位**：展示多但 CTR / CVR 极低的网站加入排除列表。
4. **核对品牌匹配**：肉眼看每个投放展示位的网站名 / URL，品牌不合适的排除。
5. **积累排除列表**：维护账户级排除列表，新广告系列直接套用。

### 9-5. 排除移动应用

移动应用误触多，品牌不兼容的应用也多。

| 方法 | 步骤 |
|---|---|
| **按网址批量排除** | 展示位置排除里加 `adsenseformobileapps.com`（排除所有 GDN 应用） |
| **按应用类目排除** | 广告系列设置 → 内容排除 → 选应用类目（游戏、娱乐等） |
| **排除单个应用** | 在展示位置报告里找表现差的应用 ID，加到展示位置排除 |

**建议：** 先做类目排除而不是全量排除，再按效果调整。全量排除会大幅砍掉覆盖。

## 10. 广告效力与优化

### 10-1. 什么是广告效力

创建自适应展示广告时显示的评分。按 4 档评估素材量、多样性、质量：较差 / 一般 / 良好 / 优秀。

### 10-2. 冲"优秀"

| 元素 | 建议 |
|---|---|
| 短标题 | 5 条填满；切入角度各异 |
| 长标题 | 1 条；精炼的价值主张 |
| 描述 | 5 条填满；不和标题重复 |
| 横版图 | 5+ 张 |
| 方版图 | 5+ 张 |
| logo | 至少 1 个；理想 1:1 和 4:1 都上 |

### 10-3. 素材效果报告

数据攒够后，每条素材（标题、描述、图片）会有一个效果标签：

| 标签 | 含义 | 行动 |
|---|---|---|
| Best | 跑赢同类 | 保留；测试类似变体 |
| Good | 平均表现 | 保留；测试改进版 |
| Low | 跑输同类 | 换新素材替换 |
| Learning | 还在收集数据 | 等结果 |

### 10-4. 创意更新周期

| 周期 | 行动 |
|---|---|
| 上线到第 2 周 | 学习期；避免大改动 |
| 第 2–4 周 | 看素材效果；识别"Low"素材 |
| 第 4 周后 | 替换低效素材；加新创意 |
| 持续 | 每 2–4 周更新创意，防广告疲劳 |

## 12. 和 Demand Gen 广告系列的关系（2025+）

### 概述

Demand Gen 广告系列的投放扩展到了 GDN 图片库存（[Google Ads 帮助](https://support.google.com/google-ads/answer/15890515?hl=en)）。也就是说 Demand Gen 现在投放：

- YouTube（信息流、Shorts 等）
- Discover
- Gmail
- **Google 展示网络（GDN）** ← 2025 年新增

### 展示广告系列 vs Demand Gen

| 项目 | 展示广告系列 | Demand Gen |
|---|---|---|
| 版位 | 仅 GDN | YouTube + Discover + Gmail + GDN |
| 创意 | 图片 + 文案（+ 视频） | 图片 + 视频 + 文案（丰富） |
| 定向 | 受众 + 内容 + 优化型定向 | 相似受众 + 受众 + 优化型定向 |
| 主要用途 | 认知到转化（宽） | 需求创造、考虑 |
| AI 利用度 | 中 | 高（版位 / 创意优化强） |

### 怎么选

- **展示广告系列**：需要 GDN 专属控制，或想用内容定向（关键词、主题、展示位置）时。
- **Demand Gen**：想要 YouTube、Discover、Gmail 统一覆盖，或想用视频创意时。
