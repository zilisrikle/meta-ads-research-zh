# 诊断决策树（Diagnostic decision trees）

现有账户优化用本参考。先诊断失败模式，再提改动。大多数 Google Ads 问题由五件事之一造成：信号差、流量错、目标页面弱、经济模型不现实，或优化过早。

如果用户以任何形式提供了账户数据——导出、复制的表格、截图、看板、CRM 数据、Merchant Center 诊断或指标汇总——先读 [account-data-diagnostics.md](account-data-diagnostics.md)。那份参考定义了在用下面的症状树之前，如何检查来源、日期范围、行粒度、缺失字段、Ads / GA4 / CRM / Feed 对账，以及花费加权的优先级。

## 首轮分诊

| 检查项 | 如果坏了 | 优先级 |
|---|---|---|
| 转化跟踪 | 标签缺失、重复触发、核心转化错 | 改出价或结构之前先修 |
| 转化质量 | 原始线索 / 微转化主导、销售质量弱 | 修转化设计或导入 |
| 流量相关性 | 搜索词、展示位置、商品或网址错了 | 加护栏、收紧结构 |
| 目标页面质量 | 落地页 / Feed / 应用 / 商店页弱 | 放量前先修目标页面 |
| 经济模型 | 目标 CPA / ROAS 不可能实现 | 重置目标或改 offer / 利润策略 |
| 学习稳定性 | 近期改过预算 / 出价 / 目标 / 素材 | 先等或隔离改动，再下判断 |

---

## 花费高、转化少

```
花费高、转化少
├── 跟踪坏了？
│   └── 修标签、primary / secondary 转化、重复计数
├── 流量不相关？
│   ├── Search：查搜索词、匹配扩展、AI Max、否定词
│   ├── P-MAX：查搜索主题、网址扩展、品牌控制、商品组合
│   ├── Display / Demand Gen / Video：查展示位置、受众、优化型定向、VTC 占比
│   └── Shopping：查 Feed 标题、商品资格、搜索词 / 商品不匹配
├── 流量相关但 CVR 弱？
│   └── 修 offer、落地页、表单、结账、信任、速度、定价、页面信息匹配
├── CPC / CPM 太高？
│   └── 查竞价压力、质量得分、受众过窄、出价目标
└── 预算太碎？
    └── 围绕最干净的信号合并
```

---

## 转化多、质量差

```
转化多、质量差
├── 核心转化太浅？
│   └── 弱动作降为次要；导入合格结果
├── 线索来源随搜索词 / 受众 / 地域而异？
│   └── 分段看报表，加否定词、排除或价值规则
├── 表单太好填或 offer 吸引了不匹配的人？
│   └── 加筛选、价格清晰度、服务范围清晰度，或更强的反筛选
├── P-MAX / 广泛自动化找到了便宜的低质量洼地？
│   └── 加网址排除、品牌排除、受众排除，或更严格的转化价值
└── 销售跟进造成质量损失？
    └── 审计首触速度、电话接听、CRM 状态、预约流程
```

## CTR 低

| 第一个问题 | 诊断 | 行动 |
|---|---|---|
| 搜索词 / 受众意图对吗？ | CTR 低可能是流量不匹配 | 收紧搜索词、受众、展示位置或商品资格 |
| 广告承诺具体吗？ | 泛泛的文案淹没在竞价里 | 加结果、offer、信任状、价格、筛选或紧迫感 |
| 品牌 / 信任弱吗？ | 用户不认识或不相信这个 offer | 加信任状、评分、客户 logo、保障或资质 |
| 版式错了吗？ | 视觉广告需要更强的首帧；Search 需要关键词-信息匹配 | 按版位行为重建创意 |
| 排名 / 广告评级低吗？ | 广告出现了但没竞争力 | 改进素材、落地页相关性、出价和质量得分驱动因素 |

不要孤立优化 CTR。CTR 更高可能吸引低匹配点击，反而恶化 CPA。

---

## CVR 低

```
CVR 低
├── 广告承诺和落地页不匹配？
│   └── 对齐标题、offer、商品、价格、信任状、CTA
├── 流量意图太宽？
│   └── 按搜索词 / 主题 / 受众分段，隔离弱坑
├── 页面摩擦大？
│   └── 改进速度、移动端排版、结账 / 表单步骤、信任信号
├── Offer 没竞争力？
│   └── 看价格、配送、退货政策、试用、保障、获客钩子
├── 转化动作错了？
│   └── 查 primary / secondary 设置和事件触发
└── 转化延迟？
    └── 改出价前先拉长判断窗口
```

---

## CPC / CPM 上涨

| 原因 | 怎么识别 | 行动 |
|---|---|---|
| 竞价压力 | 竞价洞察、排名型展示份额损失 | 提高相关性、质量得分驱动因素、offer，或选择性加价 |
| 出价目标太松 | 花费涨但质量没涨 | 把 tCPA / tROAS 锚回近期实际值 |
| 加预算重置了学习 | 近期有大的预算改动 | 等稳定；避免同时改多项 |
| 受众太窄 | 频次高、CPM 高、投放量低 | 放宽，或拆认知 vs 再营销 |
| 质量得分弱 | 预期点击率 / 广告相关性 / 落地页体验低 | 改进主题匹配、RSA 素材、落地页 |
| 搜索词组合变了 | 搜索词漂向更宽 / 更竞争的词 | 加否定词、高价值词完全匹配锁定、收紧广泛匹配控制 |

---

## P-MAX ROAS 高、业务收入没动

```
P-MAX ROAS 高、业务收入没动
├── 品牌截流高？
│   └── 加品牌排除或品牌单独汇报
├── 再营销偏差高？
│   └── 分析新客 vs 老客；合适时用 NCA 模式
├── VTC 占比高？
│   └── 点击归因和 VTC 分开汇报；用业务数据校准
├── 低利润商品主导？
│   └── 按利润率分组或传递利润感知的价值
├── Search / Shopping 被蚕食？
│   └── 检查和 Search、标准 Shopping 的重叠
└── 没有增量性证据？
    └── 量级够就跑地域 / 时段 / 客户对照组
```

---

## Demand Gen 直接 CPA 弱、助攻影响可能存在

| 检查项 | 解读 | 行动 |
|---|---|---|
| 品牌搜索量涨了 | 需求创造可能在起作用 | 评估混合 CPA 和搜索提升 |
| 再营销池变大了 | 广告系列可能在预热未来的转化者 | 跟踪助攻路径和受众增长 |
| VTC 主导 | 上报的影响可能虚高 | VTC 单独看，做增量测试 |
| CTR 强、CVR 弱 | 创意抓住了注意力但落地页 / offer / 受众不对 | 改进落地路径或给创意加筛选 |
| 花费低 | 受众、目标或素材太受限 | 合并、放目标、加素材 |
| P-MAX 拿了最终转化记功 | Demand Gen 助攻、P-MAX 收割 | 评估整个系统，不只看末次触点 CPA |

---

## Shopping / Feed 效果不佳

| 症状 | 先查 | 行动 |
|---|---|---|
| 展示少 | 拒登、GTIN、标题、类目、出价 / 目标 | 修 Feed 资格和标题相关性 |
| CTR 低 | 商品图、价格、标题、评价、配送 | 改进标题 / 图片、价格可见度、促销 |
| CVR 低 | 落地页、配送、退货、结账、价格对不上 | 修商品页和购买路径 |
| 商品间 ROAS 方差大 | 利润率和需求不同 | 用自定义标签分组设目标 |
| 长尾商品拿不到花费 | 自动化集中在赢家 | 战略重要的 SKU 有需求就单独隔离 |

---

## 诊断回答格式

诊断账户时，返回：

1. 按确信度排序的可能根因。
2. 确认或排除每个根因需要的证据。
3. 现在要改的。
4. 数据更多之前不要改的。
5. 预期稳定窗口。
