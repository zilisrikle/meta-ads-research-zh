# 预算规划与可行性

用本参考判断拟议的广告系列组合能否用现有预算学会、转化和被评估。预算规划应从经济模型和所需信号量出发，而不是从通用的渠道组合出发。

## 核心公式

| 问题 | 公式 | 用途 |
|---|---|---|
| 盈亏平衡 CPA | 平均订单 / 成交价值 × 毛利率 × 成交率 | 盈利前的最高获客成本 |
| 所需点击数 | 目标转化数 ÷ 预期 CVR | 预算能否买到足够的流量 |
| 所需花费 | 所需点击数 × 预期 CPC | 计划在财务上是否可行 |
| 预期转化数 | 预算 ÷ 预期 CPC × 预期 CVR | Smart Bidding 有没有足够的量 |
| 盈亏平衡 ROAS | 1 ÷ 毛利率 | 电商的收入 ROAS 下限 |
| 边际贡献 ROAS | 边际贡献 ÷ 广告花费 | 运费、折扣、COGS、退货重要时更好用 |

线索获取场景，把毛利率换成每合格线索的预期贡献：

```
可承受 CPA = 平均成交价值 × 毛利率 × 商机率 × 成交率
```

电商场景：

```
盈亏平衡 ROAS = 1 / 毛利率
扣除退货、运费、折扣和运营成本后，目标 ROAS 应高于盈亏平衡线。
```

## 可行性检查

推荐广告系列类型之前，按顺序回答这些问题。

| 步骤 | 问题 | 决策 |
|---|---|---|
| 1 | 真实的业务结果是什么？ | 购买、合格线索、已预约工单、留存的应用用户、到店销售 |
| 2 | 可承受 CPA / 所需 ROAS 是多少？ | 未知就从单位经济学算一个区间 |
| 3 | CPC / CPM / CPI 大概什么范围？ | 用账户历史或规划估算 |
| 4 | 当前落地页 / 应用 / Feed 的 CVR 大概多少？ | 有历史用历史；没有就保守 |
| 5 | 预算能买多少转化？ | 决定出价和广告系列复杂度 |
| 6 | 转化延迟可接受吗？ | 延迟长意味着判断窗口更长、优化更慢 |
| 7 | 核心转化能测什么？ | 用最深层的、可靠且量级够的信号 |

## 预算-结构决策

| 预计每月真实转化 | 结构姿态 | 出价姿态 |
|---|---|---|
| 0–10 | 非常收窄。一个高意向广告系列或数据收集型设置 | 人工 CPC / Max Clicks / 信号干净时才用 Max Conversions |
| 10–30 | 仍保持合并。避免多广告系列碎片化 | Max Conversions；tCPA 谨慎 |
| 30–50 | 不同目标各一个主广告系列可行 | CPA 稳定时 tCPA 可能可行 |
| 50–100 | 有可控扩展的空间 | 按业务模式测试 Broad + Smart Bidding、P-MAX 或 Demand Gen |
| 100+ | 更广的结构和实验变得现实 | tCPA / tROAS / 组合策略更有依据 |

这些是运营阈值，不是平台要求。如果转化动作质量差，量再大也没用。

## 按预算充足度的广告系列组合

| 预算状况 | 建议姿态 |
|---|---|
| 预算买不到每天 10 个有意义的点击 | 不要分散到多个广告类型。用收窄的 Search 或 Shopping 测试，先改进落地页 / Feed，或重新评估付费搜索是否可行 |
| 预算能买流量但买不到每月 15+ 真实转化 | 用高意向捕获，从搜索词 / 商品数据里学习。微转化保持次要，除非代理指标已验证 |
| 预算能产出每月 30+ 真实转化 | Smart Bidding 和有限自动化更现实 |
| 预算能产出每月 50+ 真实转化 | 可以测试 P-MAX、Broad + Smart Bidding 和可控扩展 |
| 预算能支撑多个目标、每个都有量 | 按业务经济模型拆分：品牌 / 非品牌、利润率、类目、客户类型、地域或漏斗角色 |

### 月预算速记

只作粗略量级参考。永远用本地 CPC、预期 CVR、目标经济模型和预期真实转化量覆盖它们。

| 月预算 | 建议结构 |
|---|---|
| ~$1,000 以内 | 单个 Search 广告系列（品牌词 + 高意向词） |
| ~$1,000–$3,000 | Search + P-MAX 或展示再营销，信号和预算支撑得起才做 |
| ~$3,000–$10,000 | Search + P-MAX + Video 或 Display，角色清晰时做 |
| $10,000 以上 | 全漏斗结构；按目标、经济模型、衡量质量拆广告系列 |

## 预算分配原则

| 原则 | 做法 |
|---|---|
| 先给核心学习循环充足资金 | 把够量的预算投给转化信号最干净的广告系列 |
| 不要过早拆分测试 | 50/50 测试两边都没转化就毫无意义 |
| 品牌词要单独设上限 | 品牌词看起来高效但会吸预算；以获客为目标就设上限 |
| 扩展要有明确的任务 | Demand Gen、Display、Video 要有"拿更多转化"之外的角色 |
| 预算逐步加 | 大跳会破坏学习、掩盖因果 |
| 留储备金修问题 | Feed、落地页、跟踪、创意、CRM 的工作常常比多买流量更重要 |

## 红旗

| 症状 | 含义 | 行动 |
|---|---|---|
| 目标 CPA 低于现实 CPC ÷ CVR | 当前流量质量下经济模型不成立 | 提高 CVR / offer、收窄意图，或重置目标 |
| P-MAX 预算低于目标 CPA | 学习会很慢、很吵 | 先用 Search / Shopping 或加预算 |
| Demand Gen 预算极小且目标是直接 CPA | 可能永远攒不够信号 | 用再营销 / 客户列表，或推迟上线 |
| 线索 CPA 好看但 SQL 率弱 | 出价策略在学低质量线索 | 导入质量信号或换核心转化 |
| ROAS 好看但利润弱 | 利润结构错了 | 按利润率分组或传递利润感知的价值 |
| 预算分配照着渠道偏好而不是经济模型 | 规划是照菜单点菜 | 从可承受 CPA / ROAS 和信号质量重建分配 |

## 最低回答格式

回答预算可行性时，包含：

1. 经济目标：可承受 CPA 或所需 ROAS。
2. 预期信号量：可能的每月转化数。
3. 学习可行性：Smart Bidding 或自动化是否现实。
4. 结构含义：几个广告系列 / 广告组是合理的。
5. 先不上什么：哪些广告类型会预算不足或测不出来。

## 出价策略升级与降级

本节用于在真实账户里选择、更换和回滚出价策略。[SKILL.md](../SKILL.md) 中凡是涉及出价、预算充足度或 Smart Bidding 稳定性的规划都路由到这里。

### Smart Bidding 如何学习

- 学习期最长约 50 个转化事件或约 3 个转化周期，先到为准（[Google Ads 帮助](https://support.google.com/google-ads/answer/13020501)）。窗口关闭前不要评判结果。
- **换策略**（Max Clicks → Max Conv、Max Conv → Max Conv Value 等）会触发新的学习期。
- **改目标值**（tCPA / tROAS 数字）**不会**触发学习，但出价会快速变化。目标不变时，优先调目标而不是换策略。
- 出价策略状态 `Limited` 通常意味着转化量低、预算封顶或目标太激进。先查原因再调。

### 策略名 vs 目标设置

**Search** 广告系列的独立"目标 CPA"和"目标 ROAS"策略已在 2022 年 7 月并入 Maximize Conversions / Maximize Conversion Value，成为**可选目标**，至今如此（[Google Ads 帮助](https://support.google.com/google-ads/answer/10353027)）。Demand Gen 和 P-MAX 同理。**Shopping、Display、Video Action 和 App** 仍可能把 Target CPA / Target ROAS 作为具名策略露出。算法是一样的：带目标 CPA 的 Maximize Conversions 和独立 Target CPA 行为一致。所有广告系列类型统一原则：目标不变时，优先调目标而不是换策略。

### 量级阈值——官方 vs 从业者

| 策略 | 官方最低 | 从业者标准 |
|---|---|---|
| tCPA（Search / Shopping / Display） | 无公开最低值；"≥30 转化"出现在衡量指引里，不是迁移规则 | 30+ / 30 天，且 ≥3 个转化周期、≥4 周数据稳定（Optmyzr） |
| tROAS（Search / Shopping / Display） | **15 / 30 天**（[帮助](https://support.google.com/google-ads/answer/6268637)） | 稳定优化要 50+ / 30 天 |
| tROAS（Video Action） | **30 / 30 天** | 同上 |
| tROAS（酒店） | **50 / 周 / 广告系列** | 同上 |
| tROAS（旅游） | **50 / 7 天 / 广告系列** | 同上 |
| Demand Gen — Max Conv → tCPA / tROAS | 迁移前 **50 个转化**（[帮助](https://support.google.com/google-ads/answer/14509385)） | 同上 |
| Demand Gen 价值出价 | 50 个带价值转化 / 35 天（近 7 天 ≥10），或账户级 100 / 35 天 | 同上 |

### 转化延迟与转化窗口

- 应用 tROAS：窗口覆盖 ≥90% 的转化但 **<30 天**（[帮助](https://support.google.com/google-ads/answer/12073727)）。
- 其他广告系列类型：官方无窗口上限；看出价策略报告的"转化延迟"列。
- B2B 销售周期 >30 天：窗口延长到 60–90 天，但 **GCLID 90 天过期**——更长的只能在平台外衡量（CRM、MMP），用 OCI 回传。
- 高延迟账户不要用滚动 7 天窗口评判；算法会自动降权近期点击数据。

### 组合出价策略（Portfolio bid strategies）

以下情况用组合策略：

- 多个广告系列共用同一 offer 和 CPA / ROAS 目标。
- 需要出价下限 / 上限（只有组合策略支持）。
- 各广告系列合起来的量达标，单个不够。

以下情况不用：各广告系列 KPI、利润率或单系列预算控制不同。**P-MAX 不能用组合出价策略**（[帮助](https://support.google.com/google-ads/answer/6263072)）——量级低时就用 Max Conv / Max Conv Value。

### 回滚流程

"Google Ads 死亡螺旋" / "CPA 瓶颈"：目标过紧 → 出价被压 → 竞价参与减少 → 转化下跌 → 算法进一步收紧。SKILL.md 里的降级信号一旦触发，按以下顺序执行：

1. **先止血。** 去掉 tCPA / tROAS 目标。策略保持 Maximize Conversions / Maximize Conversion Value（无目标）。
2. **等 2–3 周**，让量和 CPA 在宽松策略下稳定。窗口内不改其他设置。
3. **按新的平均值之上重设目标**，而不是回到旧目标。新平均值反映真实的竞价现实。
4. **阶梯式走**：±10–15% 调整，每次间隔 ≥2 周。

初始 tCPA 绝不要低于广告系列当前平均值——这是"量瞬间崩掉"最常被引用的原因。

### 线索质量门（线索获取专用）

Smart Bidding 优化你标为 Primary 的任何东西。用原始表单填写做转化，它会找到最便宜的线索、最便宜的地域，CPA 好看但 SQL 率崩掉。在线索广告系列启用 tCPA 之前：

- 部署线下转化导入（Offline Conversion Import）或线索增强型转化（新搭建优先 ECfL）。
- 回传最深层的、量级够的可靠阶段——通常是 SQL 或商机，不是原始线索。
- 用广告系列专属的转化目标；不要把中漏斗和底漏斗动作混在同一 Primary 集合里（"目标劫持"）。

### 价值出价成熟度阶梯

只有下层信号可靠才往上走。传递的是*利润*或*边际贡献*，不是毛收入。

| 层级 | 信号 | 使用时机 |
|---|---|---|
| 1. CPA | 转化数 | 量级薄、无价值数据 |
| 2. CPS（每销售成本） | 只计销售 / 合格线索 | 多个 Primary CV 会稀释 |
| 3. ROAS | 收入 | AOV 稳定、商品组合混杂 |
| 4. 利润感知 ROAS | 利润率或边际贡献 | 利润率因 SKU、地域、客户类型而异 |
| 5. LTV 感知 | 预测 LTV | 复购或订阅业务 |

实例（Vallaeys / Optmyzr）：B2B，$3,000 AOV、45% 毛利率、20% 线索成交率 → 传递的转化价值 = $3,000 × 0.45 × 0.20 = $270 / 线索。加上预期增购（$5,000 LTV）→ 约 $720 / 线索。

用**价值规则（value rules）**给 Smart Bidding 看不到的东西加地域 / 设备 / 受众乘数——利润率差异、B2B vs B2C 组合、复购概率。

### 季节性调整与数据排除

| 工具 | 用于 | 不用于 |
|---|---|---|
| **季节性调整** | 可预测的 1–7 天 spike（黑五网一、闪购、计划内活动）。官方上限 14 天；实践中 4–7 天后效果衰减（[JumpFly](https://www.jumpfly.com/blog/control-your-bids-with-google-ads-data-exclusions-and-seasonality-adjustments/)） | 持续的季节（如整个 Q4）——Smart Bidding 原生会学。永久的转化率变化。 |
| **数据排除** | 跟踪坏了、暂停、已知衡量缺口的时间段 | 想"忘记"的低迷表现 |

大促模式：大促**期间**用季节性调整 → 大促**之后**用数据排除，把大促后的噪声挡在训练数据之外。

### 预算-出价比——完整表

| 广告系列类型 | 日预算下限 | 来源 |
|---|---|---|
| Search / Shopping | 3–5× tCPA，绝对最低 1× | 从业者共识（StoreGrowers、30characters） |
| P-MAX | 3× tCPA 或 $150 / 天下限 | 从业者共识（SEJ） |
| Demand Gen | 20× tCPA 或 $100 / 天，取高者 | 从业者综合（Lunio） |
| App ACi tCPI | ≥50× tCPI 出价 | 官方（[帮助](https://support.google.com/google-ads/answer/12073727)） |
| App ACi tCPA | ≥10× 出价 | 官方 |
| App ACe tCPA | ≥15× 出价 | 官方 |
| Shopping / P-MAX（无历史） | 学习期 2× 预期目标花费 | 官方（[帮助](https://support.google.com/google-ads/answer/15624876)） |

点击量比绝对预算倍数更重要：$200 预算、$5 CPC 给 Smart Bidding 的学习燃料，多于 $500 预算、$40 CPC（Sarah Stemen）。验证下限能产出有意义的点击量——不够就调。

### 预算紧张时的决策优先级

预算覆盖不了上面所有下限时，按以下顺序优先：

1. 转化信号最干净的广告系列按满比例给足。
2. 品牌搜索给最低但非零的花费（假设一部分本就会自然转化）。
3. 其他广告系列只在转化信号可靠时给 1× tCPA。
4. 先砍拆分测试和扩展广告系列，再让核心循环预算不足。
