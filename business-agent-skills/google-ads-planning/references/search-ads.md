# Google 搜索广告（Listing 广告）

## 操作实践

当明确的意图、相关的承诺、强大的落地页和可靠的转化信号对齐时，搜索广告就能起效。不要把它当成纯粹的关键词/设置练习。

### 最重要的事项

- **转化操作质量是第一杠杆。** 针对原始表单提交优化的搜索系列，与针对合格潜在客户或购买优化的系列，会买到不同的竞价流量。对于潜在客户开发，尽可能导入 CRM/离线质量数据；否则，只有在代理指标与合格结果确有相关性时才使用代理指标。
- **品牌和非品牌必须分开评估。** 品牌搜索通常报告的广告支出回报率（ROAS, Return On Ad Spend）很高，因为大部分需求本来就存在。把品牌隔离出来，使其无法掩盖疲弱的非品牌表现或抬高账户级 ROAS。
- **搜索字词揭示真相。** 如果每次转化费用（CPA, Cost Per Action）很差，先看查询组合，再改出价。相关的昂贵查询通常指向报价、落地页、转化率（CVR, Conversion Rate）或目标经济性问题；不相关的查询则指向匹配类型、否定词或 AI 扩展控制问题。
- **宽泛匹配是智能出价（Smart Bidding）的战术，而不是手动出价的战术。** 当转化跟踪干净、预算能承受探索成本，且否定词/品牌控制到位时，使用宽泛匹配 + 智能出价。在点击昂贵或合规风险高的地方，保留精确匹配/短语匹配。
- **自适应搜索广告（RSA, Responsive Search Ad）的素材多样性比表面变体更重要。** 提供不同的角度：问题、结果、证明、报价、异议处理、品牌信任和紧迫感。避免 15 条几乎相同的标题。
- **落地页匹配胜过巧妙的广告文案。** 广告承诺、关键词意图、页面标题、证明材料、表单/购买路径和移动端速度需要保持一致。
- **出价目标应逐步调整。** 目标每次转化费用（tCPA, Target CPA）/目标广告支出回报率（tROAS, Target ROAS）大幅波动会先压制流量，并可能造成数周的波动。除非业务经济性变化大到需要重置，否则采用小步调整。

- **当品牌和非品牌混合时，报告的搜索 ROAS 失真最严重。** 高混合 ROAS 可能掩盖疲弱的非品牌获客。做策略工作时，永远要问："剔除品牌提振后，非品牌表现如何？"
- **不要像在 2018 年那样优化匹配类型。** 近似变体、宽泛匹配 + 智能出价和 AI Max 降低了精细化匹配类型架构的价值。关键词卫生仍然重要，但查询质量和转化质量更重要。
- **只有当系列经济属性相近时，组合出价才有帮助。** 把品牌和泛词、低 CPA 和高 CPA、或潜在客户质量不匹配的系列混在一起，组合出价会优化出错误的平均值。
- **当有意义的助攻路径多样性存在时，数据驱动归因（DDA, Data-Driven Attribution）有用。** 在纯搜索的简单账户里它可能改变不大；在多系列账户里它能更好反映助攻路径。跨归因变更对比同比表现时，必须注明模型变化。
- **搜索合作伙伴应该是深思熟虑的测试。** 它能带来增量，但质量因垂直行业和地区而异。先单独评估，再决定是否作为默认开启。
- **竞品系列需要隔离的经济性。** 它们通常质量得分较低、每次点击费用（CPC, Cost Per Click）更高、CVR 更弱。只有当战略价值或夺取策略的经济性成立时才运行。

### 诊断

| 症状 | 先查什么 | 可能的动作 |
|---|---|---|
| 花费高、质量低 | 搜索字词、转化操作、落地页/表单质量 | 加否定词、改进转化信号、导入质量数据、收紧落地页路径 |
| 流量低、CPA 可接受 | 预算、出价目标、匹配限制、因评级/预算损失的展示份额 | 放宽匹配、放松目标、改进素材/质量得分、提高预算 |
| CPA 高、查询相关 | 报价、落地页 CVR、目标经济性、竞争 | 修落地页/报价、调目标、拆分高价值词 |
| 品牌看起来很好、非品牌弱 | 品牌隔离、增量性、查询组合 | 分开报告，条件允许时做品牌对照组测试 |
| AI Max 带来奇怪的流量 | 最终到达网址扩展、网址排除、品牌控制 | 排除弱页面、约束生成文本、严格控制落地页时关闭 AI Max |

### 常见陷阱

- 在数据足够之前，把每个匹配类型或微小关键词变体拆成独立系列。
- 把广告效力（Ad Strength）当目标，而不是当诊断工具。
- 未经验证代理指标与收入相关，就把微转化作为主要操作加进来"喂算法"。
- 让最终到达网址扩展把流量送到博客、招聘、支持、政策或泛泛页面。
- 在转化延迟和学习期稳定之前，每隔几天就优化一次。

跨 playbook 使用的术语见 [SKILL.md 术语表](../SKILL.md#common-google-ads-glossary)。

## 按月转化量划分的决策矩阵

| 月转化数 | 出价策略 | 匹配类型 | 转化设计 |
|-----------|---------|-------------|--------|
| **0–15** | 手动 CPC 或争取更多点击 | 精确匹配、短语匹配 | 以真正的业务结果为主要转化。微转化只做次要跟踪；只有代理指标经验证与合格结果相关时，才将其作为主要转化 |
| **15–30** | 争取更多转化（不设 tCPA） | 精确匹配、短语匹配 | 只用主要转化运行。微转化移为次要 |
| **30–50** | tCPA（根据实际数据设定） | 以短语为主，开始测试宽泛匹配 | 只用主要转化。考虑导入离线转化（B2B） |
| **50–100** | tCPA 或 tROAS | 宽泛匹配 + 智能出价作为主力 | 开始使用转化价值规则。除非需要保守的最终点击视角，否则用 DDA |
| **100+** | tROAS / 组合出价 | 以宽泛匹配为主 | 认真跑 tROAS。细化转化价值 |

## 1. 账户与系列结构设计

### 如何拆分系列

核心原则：**只要目标、预算或出价目标不同，就分开做系列。**

| 拆分维度 | 说明 | 原因 |
|--------|------|------|
| 品牌 vs. 非品牌关键词 | 把公司/产品名称与泛关键词完全分开 | 品牌关键词 CVR 非常高——混在一起会掩盖非品牌关键词的真实表现 |
| 产品 / 服务 | 按服务类别分别建系列 | 可以独立分配预算和调整出价策略 |
| 竞品关键词 | 把竞品名称/产品单独做系列 | 隔离风险和测量 |
| 地理 | 需要时按目标区域拆分 | 按区域的预算和出价管理 |

> **注意**：务必把品牌关键词作为否定关键词加到非品牌系列中。

### 广告组设计：STAG（单一主题广告组）

把 **STAG（Single Theme Ad Group，单一主题广告组）** 作为常见起点，而不是放之四海的规则。

传统的 SKAG（每个广告组一个关键词）做法已不再推荐，原因如下：

- Google 的"近似变体"扩展意味着即使精确匹配也不再是严格匹配
- 数据被碎片化——智能出价无法积累足够的转化信号来学习
- 管理开销已无法被回报抵消

**STAG 设计原则：**

| 项目 | 建议 |
|------|------|
| 每个广告组的关键词数 | 足以表达一个共享主题和意图，又不碎片化学习 |
| 每个广告组的广告数 | 最多 3 条启用的 RSA（账户硬性上限，见 [Google Ads 帮助](https://support.google.com/google-ads/answer/6372658)）；2–3 条信息不同的 RSA 是实际默认做法 |
| 每个系列的广告组数 | 按业务逻辑尽量少；当主题、落地页、经济性或信息不同时再加组 |
| 相关性 | 广告文案和落地页必须与每个广告组的主题紧密匹配 |

**混合做法**：高价值的利基关键词保留 SKAG，其余全部跑 STAG。

### 现代精简结构

全球通用的原则很简单：保持账户结构足够集中，让自动化能学习；同时保留反映真实业务控制需求的拆分。不要只为了报表好看而过度拆分系列或广告组。

| 原则 | 实际含义 |
|---|---|
| 集中学习信号 | 当查询、广告和转化共享目标、经济性和落地页意图时，把它们放在一起 |
| 为控制而拆分 | 只有当预算、目标 CPA/ROAS、利润、地区/语言、合规、客户类型或负责人不同时才分开 |
| 对齐意图、信息和落地页 | 每个广告组应有清晰的搜索主题、相关的 RSA 素材和匹配的落地页 |
| 带护栏扩张 | 只有当转化跟踪、否定词、网址控制和品牌控制就绪时，才使用宽泛匹配、智能出价、DSA / AI Max 和 RSA |

### Google 2025–2026 推荐结构

1. **结构保持简单、集中数据**——AI 不需要过度碎片化的结构。它需要的是足够的转化数据。
2. **宽泛匹配 + 智能出价**是月转化 50+ 账户的标准做法。
3. **AI Max for Search**——新增的一层，自动生成标题/描述，并在你的关键词列表之外匹配查询。
4. **不要在一个系列里混入冲突的目标**——保持信号干净。

## 2. 关键词策略

### 关键词调研输入

使用能揭示需求、竞价经济性和当前用户语言的来源。工具选择可以因市场而异；规划逻辑不应依赖某一个本地工具。

| 来源 | 用途 |
|--------|------|
| Google 关键词规划师 | 官方的搜索量、竞争度和建议 CPC 区间 |
| Google Search Console | 已触达网站的真实自然搜索查询 |
| 现有 Google Ads 系列的搜索字词 | 付费查询的现实：无关花费、转化的词和扩展机会 |
| SERP 与自动补全检查 | 当前措辞、修饰词和意图模式 |
| 竞品调研工具 | 竞品主题的方向性视图，不是真相来源 |
| CRM / 销售电话语言 | 关键词工具经常遗漏的买家词汇和资质词 |

### 调研流程

```
1. 列出业务的主要主题 / 服务
2. 用种子关键词在关键词规划师中扩展候选词
3. 用竞品工具（SpyFu / SEMrush）找出竞品在投什么词
4. 用建议词工具挖掘长尾词
5. 按搜索意图分组（信息型 / 比较型 / 购买型）
6. 按搜索量、竞争度、预估 CPC 筛选和排序
```

### 匹配类型策略

#### 分阶段做法

```
阶段 1（数据稀疏）：从精确匹配开始，积累数据
    ↓
阶段 2（需要流量）：加上短语匹配
    ↓
阶段 3（月转化 50+）：扩展到宽泛匹配 + 智能出价
    ↓
所有阶段：大力建设否定关键词列表
```

#### 2025–2026 趋势

- 当配合智能出价、干净的转化数据和严谨的否定关键词运营时，宽泛匹配越来越有用。
- 即使精确匹配也不再是"严格"匹配——Google 的 AI 会对所有匹配类型做语义解读
- 主流做法是整体化的：少量核心关键词 + 合适的受众信号

#### 宽泛匹配 + 智能出价成功的条件

- 准确的转化跟踪已就位
- 月转化 30–50+
- 使用了全面的否定关键词列表
- 定期检查搜索字词报告

### 关键词组织 / 分组

| 维度 | 示例 |
|--------|-----|
| **按搜索意图** | 信息型（"是什么"、"如何"）/ 比较型（"vs"、"最佳"）/ 购买型（"价格"、"购买"） |
| **按主题** | 围绕同一产品 / 服务 / 问题分组关键词 |
| **按漏斗阶段** | 认知（TOFU）/ 考虑（MOFU）/ 决策（BOFU） |
| **按转化价值** | 优先吸引高生命周期价值（LTV, Lifetime Value）客户的关键词 |

### 长尾关键词

长尾关键词（4 个词以上、具体的短语）通常 CPC 更低、CVR 更高。

| 短尾 | 长尾 |
|---------------|-------------|
| "CRM software" | "B2B CRM software for small business comparison" |
| "running shoes" | "best running shoes for marathon training" |

- 让每个广告组聚焦一个清晰的主题
- 针对长尾关键词优化广告文案和落地页
- 宽泛匹配 + 智能出价也可以自动挖掘长尾词

### 如何处理品牌关键词

**标准做法：永远在隔离的系列中运行。**

| 原因 | 详情 |
|------|------|
| 数据清晰 | 品牌关键词 CVR 非常高——混在一起会掩盖非品牌表现 |
| 预算控制 | 独立管理品牌 vs. 非品牌的预算 |
| 出价策略 | 品牌关键词 CPC 低，适合不同的出价策略 |
| 防守 | 如果竞品竞价你的品牌，防守优先级更高 |

### 否定关键词运营

#### 检查节奏

| 账户规模 | 建议节奏 |
|----------------|----------|
| 高花费 | 每日 |
| 中型 | 每周 |
| 所有账户 | 每月定期检查 |

#### 层级

| 层级 | 用途 | 示例 |
|--------|------|-----|
| 账户级 | 永远不应匹配的词 | "free"、"jobs"、"how to" |
| 系列级 | 系列特定的噪音 | 属于其他系列的主题 |
| 广告组级 | 防止内部蚕食 | 广告组之间的去重 |

#### 匹配类型用法

- **宽泛否定词**：明显不相关的词（"jobs"、"salary"、"free"）
- **短语否定词**：在其他语境下可能相关的词
- **精确否定词**：非常具体的排除

> 否定词不会像正向关键词那样自动扩展到同义词。但自 2024 年 6 月起，拼写错误也会被屏蔽。

#### 上限（截至 2025）

- 共享否定关键词列表：最多 20 个列表，每个 5,000 个关键词
- 账户级否定词：最多 1,000 个关键词

> 通用的起始列表见 [附录 A](#appendix-a-starter-negative-keyword-set)。

## 3. 出价策略操作细节

> **注意**：增强型每次点击费用（eCPC, Enhanced CPC）已不再适用于搜索和展示系列，未主动迁移的系列现在实际使用手动 CPC（[Google Ads 帮助](https://support.google.com/google-ads/answer/2464964?hl=en)）。

### tCPA vs tROAS

| 项目 | tCPA | tROAS |
|------|---------|----------|
| 何时用 | 所有转化的价值大致相等（潜在客户开发、SaaS 等） | 转化价值差异大（电商等） |
| 优化目标 | 流量（在可接受的成本内） | 收入 / 利润 |
| 最低数据 | 30 天内 15+ 转化（推荐 30+） | 30 天内 50+ 转化（推荐 100+） |

### 目标值的设定与调整

**初始设置：**
- 基于**实际**的过去 30 天数据（不是理想目标）
- tCPA：从过去 30 天的平均 CPA 开始
- tROAS：从过去 30 天的"转化价值 / 花费"开始
- 目标设得太激进会严重压制流量

**调整经验法则：**

| 规则 | 详情 |
|--------|------|
| 20% 规则 | 单次调整不超过 20%（剧烈波动会重置学习） |
| 逐步收紧 | tCPA：每次降低 5–10% / tROAS：每次提高 5–10% |
| 决策周期 | 以 2–4 周为窗口判断，而不是按周 |
| 转化延迟 | 在转化周期长的行业要考虑延迟 |

### 学习期管理

- **时长**：通常 7–30 天；多数情况约 2 周稳定。
- **所需数据**：约 50 次转化事件，或 3 个转化周期

**会重置学习的触发动作：**
- 切换出价策略
- tCPA / tROAS 大幅调整（>20%）
- 日预算大幅调整
- 更改转化操作
- 定向 / 创意 / 受众大幅调整

**最佳实践：**
- 预算 / 出价 / 设置变化控制在每周 20% 以内
- 至少 2–3 周后再评判表现
- 迁移后尽量减少系列改动

### 组合出价策略

一个出价策略应用于多个系列 / 广告组 / 关键词。

- 自动把资源集中到表现好的系列
- 跨同目标系列共享数据，提高预测准确性
- **把目标相同的系列归组**——绝不混入冲突的目标
- 适合把各自数据稀薄的小系列汇聚起来补足学习数据

### 季节性

使用 Google Ads 的**季节性调整（Seasonality Adjustments）**功能。

- 在促销 / 大促 / 活动前后，提前告知智能出价预期的 CVR 变化
- **最适合 1–7 天**的短期事件（不推荐 14 天以上）
- 之后不需要反向调整（会自动恢复）
**通用 playbook：**

| 阶段 | 动作 |
|------|------|
| 高峰前 | 逐步提高预算（每次调整在 20% 以内） |
| 高峰期 | 使用季节性调整 |
| 淡季 | 削减预算；集中高意图关键词 |
| 年度 | 从往年实际数据提前规划 |

## 4. RSA 操作细节

### 描述写作

| 要点 | 详情 |
|---------|------|
| 结构 | 第一句先讲价值主张，第二句佐证或放行动号召（CTA, Call To Action） |
| CTA | 包含清晰的行动号召（"获取免费报价"、"免费试用"） |
| 差异化 | 具体说出竞品没有的优势 |
| 数字 | 尽可能包含具体数字 |

### 固定（Pinning）

- 默认尽量少固定
- 迫不得已时，**2–3 条固定到同一位置**以保持多样性
- 固定通常会降低广告效力，但广告效力和表现并不总是相关

### 广告效力

- 更好的广告效力可以提高展示资格和组合质量，但它是诊断工具而非最终目标。
- 话虽如此，最终以实际指标（CPA / ROAS）评判
- 目标是"良好"或更高（"极佳"不是必须）

### A/B 测试

- **广告变体**工具是最容易的入口
- 每次只改一个变量
- 至少跑 2–4 周以获得统计显著性
- 关键指标：**CPI（CTR × CVR）**

> 详细的测试设计模板见 [附录 B](#appendix-b-ab-test-design-template)。

### 广告定制工具

| 功能 | 详情 |
|------|------|
| DKI（动态关键词插入） | 根据搜索字词自动替换标题 / 描述文本 |
| 倒计时 | 自动显示距离促销结束的剩余时间 |
| 地理位置插入 | 自动插入用户所在地 |
| IF 函数 | 根据设备或受众展示不同文案 |

### 与动态搜索广告（DSA, Dynamic Search Ads）结合

DSA 正在升级为 AI Max。从 2026 年 9 月起，使用动态搜索广告、自动创建的素材和系列级宽泛匹配设置的系列，计划自动升级到 AI Max（[Google Ads 帮助](https://support.google.com/google-ads/answer/2471185?hl=en)、[Google 发布更新](https://blog.google/products/ads-commerce/dsa-upgrade-to-ai-max-2026/)）。

- 强组合：核心关键词用 RSA 覆盖，用 DSA 发现关键词缺口
- 可以在同一系列中共存（但不能在同一广告组）
- 把 DSA 发现的高表现关键词提升到 RSA 广告组中

## 5. 广告文案框架

### 核心框架

**AIDA（注意 → 兴趣 → 欲望 → 行动）**
- 标题 1：抓住注意
- 标题 2：建立兴趣
- 描述：激发欲望并促进行动

**PAS（问题 → 激化 → 解决方案）**
- 标题 1：点出问题
- 标题 2：激化痛点
- 描述：给出解决方案

**4P（承诺 → 画面 → 证明 → 推动）**
- 承诺：说出核心利益
- 画面：描绘具体的未来状态
- 证明：用数据 / 业绩佐证
- 推动：促进行动

### 各行业的有效角度

| 行业 | 强角度 |
|------|-------------|
| B2B | 成本降低百分比、ROI、客户数、免费试用 |
| B2C | 价格、评价、便利性、免费配送 |
| 电商 | 免费配送、当日达、选品规模、退货保障 |
| 专业服务 | 资质、从业年限、咨询完成数、首次免费咨询 |
| SaaS | 免费试用时长、轻松上手、集成能力 |
| 房地产 | 房源数、地段、房龄、便捷的看房预约 |

### 数字与证明技巧

| 技巧 | 示例 |
|-----------|-----|
| 换算成更小的单位 | $90/月 → "每天只需 $3" |
| 零框架 | "$0 安装费"、"无取消费" |
| 社会证明 | "5,000 家公司在用"、"98% 满意度" |
| 具体结果 | "平均成本降低 30%"、"询盘量提升 2.5 倍" |
| 时间具体化 | "3 天上线"、"1 分钟注册" |

### CTA 模式

| 模式 | 示例 |
|---------|-----|
| 直接行动 | "获取免费咨询"、"30 秒报价" |
| 利益导向 | "下载免费指南"、"获取最新洞察" |
| 紧迫感 | "仅限今天"、"仅剩 3 个名额" |
| 风险逆转 | "开始免费试用（无需信用卡）" |

### 情感与逻辑的平衡

| 目标 | 建议配比 |
|-----------|-------------|
| B2B | 逻辑 7 : 情感 3 |
| B2C 高客单价 | 逻辑 5 : 情感 5 |
| B2C 冲动型 | 逻辑 3 : 情感 7 |

在 RSA 中混合两种风格的标题，让 Google 的 AI 找到最佳组合。

## 6. 广告素材

设置四种或更多类型的素材是标准建议。素材是免费的，其预期影响可以影响广告评级和更丰富广告格式的展示资格。

### 核心素材与建议设置

| 素材 | 建议数量 | 说明 |
|---------|--------|---------|
| **站内链接** | 至少 4 个，理想 8–20 | 链接到不同页面（定价、案例、FAQ）。务必填写描述 |
| **宣传信息** | 至少 2 条，理想 8+ | ≤25 字符的具体卖点（免费配送、24/7 支持） |
| **结构化摘要** | 2–3 个标题，每个 4+ 值 | 服务列表、品牌、覆盖区域 |
| **图片** | 至少 4 张（方形 + 横版） | 产品 / 服务的具体视觉 |
| **电话** | 电话转化重要时必填 | 设置为仅在营业时间展示 |
| **潜在客户表单** | 按需使用 | 在移动端尤其有效 |
| **促销** | 活动期间 | 用于限时折扣 |
| **价格** | 电商 / 服务 | 有价格竞争力时有效 |

### 最佳实践

- 每个系列至少设置四种素材类型
- 广告组级素材会覆盖系列级和账户级
- 定期检查表现并替换弱素材
- 务必填写站内链接描述（能扩大可见版面）

## 7. 落地页优化

### 广告 / 落地页一致性

当质量得分的三个组成部分（预期点击率（CTR, Click-Through Rate）、广告相关性、落地页体验）都是"高于平均水平"时，底层广告质量通常很强。更高的广告质量可以提高展示资格、广告评级和 CPC 效率，但 1–10 分的质量得分本身是诊断指标，不是竞价输入。

### 落地页设计基础

| 原则 | 详情 |
|------|------|
| 与广告匹配 | 广告承诺的内容应在落地页首屏出现 |
| 一个落地页一个目标 | 每个落地页一个转化目标 |
| 清晰的 CTA | 首屏放 CTA，滚动后加浮动 CTA |
| 信任信号 | 公司信息、隐私政策、客户评价、真实数字 |
| 关键词对齐 | 每个广告组配专属落地页（不要用泛泛的首页） |

### 页面速度

- 页面速度延迟对移动端 CVR 的伤害不成比例。
- 目标：LCP 低于 2.5 秒，总加载低于 2 秒
- 改进方法：图片压缩、减少无用 JS、CDN、懒加载

### 移动端优化

- 响应式设计
- 点击友好的按钮尺寸（至少 48×48 px）
- 电话号码支持点按拨打
- 表单易用性（支持自动填充）

### 表单优化

- 减少不必要的表单字段通常能提高 CVR。
- 多步骤表单效果好（把个人身份信息放在最后一步）
- 显示进度条
- 实时错误提示

### 质量得分与落地页

质量得分和广告质量诊断仍然围绕相关性和落地页体验：

- 内容相关性（广告关键词 vs. 落地页内容对齐）
- 易于导航
- 页面速度（尤其是移动端）
- 透明度（公司信息、联系方式、隐私政策）

## 8. 转化测量操作细节

### 按业务模型的转化设计模板

#### B2B（潜在客户开发）

| 项目 | 设置 |
|------|------|
| 主要转化 | 询盘表单提交、电话 |
| 次要转化 | 白皮书下载、订阅、定价页浏览 |
| 转化价值设定方法 | 潜在客户评分 × 商机率 × 平均客单价（例如 A=$500、B=$200、C=$50） |
| 出价策略 | tCPA（月转化 30+ 后引入） |
| 离线转化 | **必需。** 从 CRM 回传商机 / 赢单数据，让 AI 学会"高质量潜在客户" |
| 微转化的用法 | 如果月询盘低于 30，把"表单开始"作为主要转化 |

#### 电商

| 项目 | 设置 |
|------|------|
| 主要转化 | 购买完成 |
| 次要转化 | 加购、开始结账、创建账户 |
| 转化价值设定方法 | 实际订单金额（动态）。固定价格产品用平均订单金额 |
| 出价策略 | tROAS（月转化 50+ 后引入） |
| 转化价值规则 | 例如"复购客户转化价值 ×1.5"——把 LTV 信号嵌入出价 |
| 微转化的用法 | 如果月购买低于 30，把"加购"作为主要转化 |

### 更改转化操作时的流程

更改转化操作（新增、删除或修改主要转化）会重置智能出价的学习。谨慎操作。

```
1. 记录变更前表现（过去 30 天的 CPA、ROAS、转化数）
2. 做出变更
3. 在 2–4 周的学习期内避免大幅调整出价 / 预算
4. 前后对比时排除"变更日 → 学习完成"这段时间
5. 学习完成后，按需重新设置 tCPA / tROAS
```

### 转化价值规则

根据受众 / 地理位置 / 设备自动调整转化价值的功能。

示例：
- "纽约来的潜在客户转化价值 ×1.5"（本地潜在客户成交率更高）
- "移动端转化价值 ×0.8"（移动端成交率较低）
- "再营销名单用户的转化价值 ×1.3"

### 转化窗口

| 设置 | 建议 | 说明 |
|------|--------|------|
| 点击转化 | 30–90 天 | B2B（考虑周期长）→ 90；电商（冲动型）→ 30 |
| 浏览转化 | 1 天（默认） | 用于展示 / 视频。对纯搜索影响很小 |
| 互动浏览转化 | 有意义的视频互动后的转化（例如可跳过插播 10 秒、信息流 / Shorts 5 秒） | YouTube / 含视频的系列 |

## 9. 搜索系列设置检查清单

实际中频繁引发事故、对结果影响巨大的设置。

### 地理位置定位陷阱

Google Ads 有两种地理位置定位选项：

| 选项 | 详情 | 建议 |
|-----------|------|------|
| **实际所在地** | 只向实际位于目标区域的用户展示 | **多数情况下推荐** |
| **实际所在地或兴趣** | 向目标区域用户 + 对该区域表现出兴趣的用户展示 | 默认选项。只有当区域兴趣与意图相关时才选（旅游、观光、房地产等） |

> **重要**：默认是"实际所在地或兴趣"。不改的话，广告会展示给目标区域以外的用户，浪费预算。**大多数本地商家应切换到"实际所在地"。**

**位置**：系列设置 → 地理位置 → 地理位置选项 → 定位

**排除的地理位置**：
- 排除设置也要用"实际所在地"
- 半径定位时，定期检查是否有半径外的展示

### 搜索合作伙伴

如果勾选了"Google 搜索合作伙伴"，广告会展示到非 Google 网站（其他搜索引擎、Google 地图等）。

| 情况 | 建议 |
|------|------|
| 早期 / 预算有限 | **建议关闭。** 先在 Google 搜索上积累数据 |
| 转化数据充足、准备扩大覆盖 | 开启并测试。按网络单独看表现 |
| 搜索合作伙伴 CPA 超出可接受范围 | 关回去 |

**查看方法**：报告 → 细分 → 网络——单独看"Google 搜索合作伙伴"的表现。

### 智能出价下的设备 / 时段调整

如果使用智能出价（tCPA、tROAS 等），**手动的设备和时段出价调整实际上会被忽略**（Google 的 AI 会自己实时管理）。

| 出价策略 | 设备调整 | 时段调整 |
|---------|-------------|-----------|
| 手动 CPC | **生效** | **生效** |
| 争取更多点击 | **生效** | **生效** |
| tCPA / tROAS | **被忽略**（例外：-100% 可完全排除某设备） | **被忽略** |
| 争取更多转化 / 转化价值 | **被忽略**（仅 -100% 例外） | **被忽略** |

**变通方法**：
- 智能出价下要完全排除某设备，设为 -100%（例如排除平板）
- 要控制投放时段，用广告投放时间设置"不投放"的时段（用开/关控制，不用出价调整）
- 按设备优化落地页，通过质量得分间接改善表现

### 搜索字词质量（尤其是 B2B）

除了加否定关键词，还需要评估所获潜在客户的**质量**。

**维度：**

| 维度 | 检查方法 |
|----|---------|
| 意图质量 | 搜索字词是信息型还是购买意图 |
| 商机质量 | 与 CRM 交叉，看各搜索字词的商机率 |
| 成交率 | 用离线转化数据跟踪各搜索字词的成交率 |
| LTV | 跟踪各搜索字词的客户 LTV（长期工作） |

**实现方法：**
1. 在隐藏表单字段中捕获 Google Ads 的 GCLID（点击 ID）
2. 在 CRM 中把 GCLID 与每条商机 / 赢单记录一起存储
3. 作为离线转化上传回 Google Ads
4. 用搜索字词报告识别"带来高质量潜在客户的关键词"

### 品牌防守标准

竞品竞价你的品牌名时的应对政策。

**决策标准：**

| 条件 | 决策 |
|------|------|
| 竞品竞价你的品牌名 | 建防守系列 |
| 你独占自然排名第一且没有竞品竞价你 | 不防守（预算转给非品牌） |
| 品牌名搜索量大 | 防守 ROI 高 |

**防守系列设置：**

| 项目 | 建议 |
|------|------|
| 出价策略 | 目标展示份额（页面顶部 90–95%） |
| 匹配类型 | 精确匹配 + 短语匹配 |
| 日预算 | 通常较小（品牌关键词 CPC 低） |
| 监控 | 用竞价洞察跟踪竞品进入 / 退出 |

### "包含展示广告网络"扩展

搜索系列创建流程有时会提供"包含展示广告网络"开关。

> **建议：在搜索系列中关闭。** 需要展示广告时，单独跑展示系列。把搜索和展示数据混在一起会污染智能出价的学习信号。

## 11. 分析与改进

### KPI 基线

以账户历史、单位经济性、关键词规划师预估和当前竞价环境为主要基线。泛泛的行业平均值太粗，不足以支撑决策。

| KPI | 主要基线 | 用法 |
|-----|--------|-----------|
| CTR | 按品牌 / 非品牌 / 竞品 / 品类的账户历史 | 诊断相关性和广告强度，不单独用来判断业务盈利性 |
| CVR | 按意图细分的落地页和报价历史 | 区分查询质量问题和落地页 / 报价问题 |
| CPA | 来自利润、成交率和 LTV 的目标经济性 | 把 tCPA 锚定在实际表现上，再逐步收紧 |
| ROAS | 毛利率或边际贡献的盈亏平衡点 | 只看收入 ROAS 可能在低毛利产品上过度投入 |

### 使用搜索字词报告

| 步骤 | 详情 |
|---------|------|
| 1. 找否定词 | 把不相关的查询加入否定词 |
| 2. 发现新关键词 | 把高表现的查询提升为关键词 |
| 3. 优化匹配类型 | 检查扩展是否去了你想去的方向 |
| 4. 改进广告文案 / 落地页 | 从查询中读出用户意图，优化文案 / 落地页 |

> 开启 AI Max 时，搜索字词报告会显示 AI Max 专属报告，包括 AI Max 流量的视图和匹配贡献（[Google Ads 帮助](https://support.google.com/google-ads/answer/16470459?hl=en)）。检查 AI 扩展的查询，排除不需要的。

### 使用竞价洞察

| 指标 | 解读 |
|------|------|
| 展示份额（IS, Impression Share） | 你的展示次数 ÷ 符合条件的展示次数 |
| 重叠率 | 竞品也出现的竞价占比 |
| 超出排名份额 | 你排名超过某竞品的频率 |
| 页面顶部率 | 出现在页面顶部的频率 |
| 绝对顶部率 | 出现在绝对顶部的频率 |
| 排名高于率 | 竞品广告出现在你之上的频率 |

**用法：**
- 发现新竞品进入
- 跟踪特定竞品的竞价压力
- 定位展示份额下降的原因（因预算损失展示份额 → 预算不足；因评级损失 → 质量得分 / 出价不足）

### 细分分析

| 细分 | 分析 |
|-----------|-------------|
| 设备 | 移动 / 桌面 / 平板的 CVR 差异 → 出价调整（手动 CPC）或修落地页（智能出价） |
| 时段 | 转化集中的时段 → 投放时间设置（手动 CPC）或仅作参考（智能出价） |
| 星期 | 星期几的差异 → 同上 |
| 区域 | 按州 / 城市的 CVR → 区域出价调整，或拆成区域系列 |
| 受众 | 再营销名单的 CVR → 以观察模式加入，按数据给出价调整 |

### 归因

Google Ads 支持的归因模型只有 **DDA 和最终点击**；首次点击、线性、时间衰减和基于位置的模型已不再支持（[Google Ads 帮助](https://support.google.com/google-ads/answer/6259715?hl=en)）。

| 模型 | 适用条件 | 说明 |
|--------|---------|------|
| **DDA（推荐）** | 大多数网页 / GA4 转化操作的默认 | ML 把功劳分配给每个触点；上层漏斗触点也能分到功劳 |
| 最终点击 | 无 | 100% 功劳给最后一次点击的广告 |

- 只有当你刻意需要保守参照，或 DDA 对业务问题不可信时，才用最终点击。

## 12. 预算管理与优化

### 预算设置

| 项目 | 建议 |
|------|------|
| 日预算 | 窄测试：目标 CPA 的 1–3 倍/天；健康学习：3–5 倍+；经济上可接受快速放量：10 倍+ |
| 月预算 | Google Ads 某天最多可花掉日预算的 2 倍（按月平均） |
| 预算不足的信号 | 如果因预算损失的展示份额 ≥ 20%，考虑增加 |

### 盈亏平衡计算

```
[基础]
边际 CPA = 价格 - 成本
目标 CPA = 边际 CPA - 期望利润

[考虑 LTV（订阅 / 复购）]
边际 CPA = 客户 LTV × 毛利率 %
目标 CPA = 边际 CPA × (1 - 利润率)

[B2B 潜在客户开发]
边际 CPA = 平均客单价 × 毛利率 × 商机率 × 成交率
目标 CPA = 边际 CPA × (1 - 利润率)
```

### 应对预算约束

| 手段 | 详情 |
|--------|------|
| 收紧关键词集 | 暂停低表现词，集中获胜词 |
| 投放时间 | 暂停低转化时段（手动 CPC 下降低出价） |
| 地理 | 降低低表现区域的出价 |
| 设备 | 降低低 CVR 设备的出价（手动 CPC） |
| 增加预算 | ROAS 健康时，考虑提高预算 |

### 创意刷新节奏

| 素材类型 | 节奏 |
|-----------|----------|
| RSA 文案 | 表现一下滑就刷新 |
| 图片素材 | 每 4–6 周 |
| 站内链接等 | 每月检查，轮换低表现者 |

### 2026 新功能：系列总预算

为一个明确的周期设置总预算，让 Google 的 AI 优化每日分配。适用于搜索、P-MAX 和购物。适合高峰和特定促销窗口。

## 13. 常见失败模式

### 新手十大错误

| # | 错误 | 避免方法 |
|---|------|--------|
| 1 | 转化跟踪缺失或损坏 | 上线前在 GTM 预览中验证所有代码触发。设置增强型转化 |
| 2 | 没有否定关键词 | 从第一天就应用通用否定词列表（见 [附录 A](#appendix-a-starter-negative-keyword-set)）。每周检查搜索字词 |
| 3 | 一上来全用宽泛匹配 | 从精确匹配 / 短语匹配开始，分阶段扩展 |
| 4 | 把不相关的关键词塞进一个广告组 | 围绕单一意图、落地页和信息分组关键词 |
| 5 | 只有一个广告变体 | 每个广告组 2–3 条信息不同的 RSA（账户硬性上限是 3 条启用的 RSA） |
| 6 | 落地页就是首页 | 每个广告组主题建专属落地页 |
| 7 | 照单全收平台建议 | 把它们当输入，用自己的数据和目标做决定 |
| 8 | 转化数据不足就用智能出价 | 先积累更多真实转化量。除非代理指标经验证能预测质量，否则微转化只做观察 |
| 9 | 一个月才看一次 | 至少每周检查搜索字词和表现 |
| 10 | 落地页不适合移动端 | 响应式设计、页面速度、表单优化是必须的 |

### 智能出价的六个坑

| # | 坑 | 避免方法 |
|---|---------|--------|
| 1 | 转化数据不足（月转化 <30）就迁移 | 数据积累够之前留在手动或争取更多点击 |
| 2 | 目标不切实际 | 从实际数据出发，逐步收紧 |
| 3 | 学习期内频繁改动 | 2–3 周内避免大幅改动 |
| 4 | 预算与 tCPA 不匹配 | 避免预算低于 1 倍 tCPA；期望稳定学习时用 3–5 倍+ tCPA/天 |
| 5 | 转化数据污染 | 准确跟踪；注意微转化被意外计入 |
| 6 | 照单全收平台建议 | 建议只是假设——用自己的数据判断 |

## 14. 搜索系列的 AI Max

一个普遍可用的层，为搜索系列增加 AI 辅助匹配、广告文案生成和落地页选择（[Google Ads 帮助](https://support.google.com/google-ads/answer/15910187?hl=en)）。界面入口已广泛可用，但 API / Editor 支持和具体控件可能仍有差异，依赖批量工作流前先验证操作支持。

### 三大核心功能

| 功能 | 详情 |
|------|------|
| 关键词匹配扩展 | 宽泛匹配 + 无关键词技术，按意图匹配 |
| 广告文案自动生成 | AI 生成标题 / 描述，与你的素材组合 |
| 落地页自动选择 | 根据搜索意图从你的网站中选最匹配的落地页 |

### 表现预期

- 把 AI Max 当作扩展和自动化层，而不是保证提升。
- 精确 / 短语覆盖狭窄的账户，相比已经很宽泛的账户，可能看到更多发现收益。
- 学习期后，按查询质量、CPA / ROAS、落地页路由和生成文本质量评判它。

### 文本指南

可以在 AI Max / 素材优化控件中控制 AI 生成的文案和其他 AI Max 设置（[设置帮助](https://support.google.com/google-ads/answer/15909989?hl=en)）。例如："不要提价格"、"不要用竞品名"。

### 建议的上线步骤

```
1. 先在一个系列上做 A/B 测试（4 周以上）
2. 分析结果（转化数、CPA、搜索字词质量）
3. 有效再逐步推广
4. 品牌关键词系列保持 AI Max 关闭
```

### 运营护栏

AI Max 需要被控制——设置以下护栏。

#### 保持 AI Max 关闭的情况

| 情况 | 原因 |
|--------|------|
| 品牌关键词系列 | AI 会扩展到非品牌查询，侵蚀品牌低 CPC / 高 CVR 的优势 |
| 高度监管行业（医疗、金融、法律等） | AI 生成的文案可能违反行业广告法规 |
| 必须严格避免竞价竞品名 | AI Max 可能扩展到竞品查询 |
| 月转化低于 30 的系列 | 学习数据不足会让优化不稳定 |

#### 广告文案生成护栏

在文本指南中设置以下内容：

| 设置 | 原因 |
|------|------|
| 禁止虚假价格声明 | AI 可能生成与实际不符的价格 |
| 禁止竞品名 | 商标风险 |
| 禁止夸张 | 没有依据的"行业最佳"、"#1" |
| 禁止违反行业规定的声明 | "治愈"、"保证有效"（医疗 / 健康） |
| 指定品牌语调 | 与自有品牌指南对齐 |

#### 落地页自动选择护栏

配置网址排除，防止 AI Max 路由到非预期的页面。

**要排除的网址：**
- 感谢页（转化后）
- 登录页
- 招聘页
- 管理 / 账户设置页
- 老旧 / 即将下线的落地页
- 隐私政策 / 条款页

### 搜索字词报告

开启 AI Max 时，AI Max 专属报告会展示搜索字词、标题、落地页和 AI Max 贡献视图（[报告帮助](https://support.google.com/google-ads/answer/16470459?hl=en)）。**开启后的前两周每天检查搜索字词报告**，留意不需要的扩展。

## 附录 B：A/B 测试设计模板

跑测试前，先确定并记录以下内容。

### 测试设计表

| 项目 | 填写 |
|------|------|
| **测试名称** | 例如："标题利益导向 vs. 价格导向" |
| **假设** | 例如："标题放具体价格比利益框架 CVR 更高" |
| **变更的变量（只改一个）** | 例如：RSA 标题 2–4（切换为价格导向） |
| **保持不变的变量** | 关键词、落地页、出价策略、预算、受众、其他所有广告文案 |
| **主要指标** | 例如：CPA |
| **次要指标** | 例如：CTR、CVR |
| **成功标准** | 例如：CPA 改善 10%+ 且统计显著（p < 0.05） |
| **停止标准** | 例如：CPA 恶化 30%+ 立即中止 |
| **测试时长** | 至少 2–4 周（或每个变体 100+ 转化） |
| **测试方法** | 广告变体或系列实验 |

### 样本不足时

| 情况 | 变通方法 |
|------|--------|
| 转化不够 | 延长到 4–6 周 |
| 还是不够 | 只有当代理指标已知与业务结果相关时，才用合格的代理指标 |
| 关键词搜索量低 | 合并目标广告组 |
| 没有统计显著性 | 变化可能太微妙——测试更大胆的改动 |
