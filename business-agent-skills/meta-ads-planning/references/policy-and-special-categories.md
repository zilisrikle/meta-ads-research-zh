# 政策与特殊广告类别

在为受管或受限类别推荐 Meta 广告的定向、结构、创意或优化前，先用本参考。在 Meta 上政策不是事后补救：它可能决定哪些目标、定向控制、受众、排除、文案声明、表单和创意可用。

## 运营规则

- 先查政策类别再做受众设计。再漂亮的定向方案，如果特殊广告类别（Special Ad Category）规则拿掉了控制项，也没用。
- 把政策和准入视为账户/地域/时间敏感的事项。给出硬性操作指令前，先核实当前 Ads Manager 界面与 Meta 政策。
- 区分**平台政策合规**与**业务/法律合规**。Meta 审核通过不代表广告主满足了当地法律。
- 不要设计依赖受限或已下线控制项的策略，比如用于敏感筛选的详细定向排除。
- 受管类别优先用合规的宽泛结构、强创意资格筛选、干净的落地页/表单披露，以及第一方/CRM 质量闭环。
- 涉及金钱、就业、住房、健康、安全、身份或政治的声明，要求有依据、用词保守。

---

## 1. 特殊广告类别分诊

先问广告系列是否推广以下任一类别。如果是，先走政策检查再做媒体设计。

| 类别 | 示例 | 规划影响 |
|---|---|---|
| 信贷 / 金融产品与服务 | 信用卡、贷款、房贷、融资、BNPL、债务减免、保险、银行、投资、支付或其他金融服务 | 定向限制、文案/披露审查、可能的受众限制 |
| 就业 | 招聘、猎头、实习、就业服务、职业机会 | 定向限制、反歧视约束 |
| 住房 | 房屋买卖/租赁、房贷、房源、住房服务 | 定向限制、反歧视约束 |
| 社会议题 / 选举 / 政治 | 选举、候选人、立法、社会议题倡导、政治筹款 | 授权、免责声明、地域/账户控制、广告资料库透明 |

不确定时，说明不确定性，并要求提供卖点、落地页、目标国家和声明用语。

---

## 2. 各层的规划影响

| 层级 | 受约束时可能的变化 |
|---|---|
| 广告目标 | 政策审核风险高时，某些目标或转化位置可能不现实 |
| 受众 | 年龄、性别、邮编、详细定向、类似受众、排除或已保存受众可能受限 |
| 自定义受众 | 客户名单可能可用，但其使用、扩展或排除受政策与隐私规则约束 |
| 版位 | 某些版面可能因声明可见性、线索质量或披露空间不足而不合适 |
| 创意 | 声明、前后对比框架、个人属性、耸动内容、金融/健康承诺需要保守措辞 |
| 表单 | 需要隐私政策、免责声明、同意用语、资格筛选问题，并谨慎处理敏感数据 |
| 衡量 | CRM/线下回传必须遵守同意、数据处理与敏感数据限制 |
| 报告 | 避免歧视性分群或优化解读 |

---

## 3. 受约束下的受众设计

### 默认合规姿态

- 以地域、语言和宽泛投放为基础。
- 用创意、卖点、落地页和表单问题做资格筛选，而不是用敏感定向。
- 在允许范围内用 CRM/线下质量反馈。
- 只在政策和当前界面允许时保留客户排除。
- 明确记录什么是硬性控制、什么是受众建议。

### 避免

- 推断或定向敏感个人属性。
- 暗示观看者具有受保护特征、财务困境、健康状况、就业状态或个人处境的文案。
- 把已下线/不稳定的控制项作为计划核心，尤其是详细定向排除。
- 可能在住房、信贷、就业领域造成歧视风险的过窄地域/年龄结构。
- 把类似受众或扩展逻辑当作政策审查的替代品。

## 4. 信贷 / 金融产品与服务

用于信用卡、贷款、房贷、融资、债务服务、银行、保险、投资、支付及类似金融产品。Meta 的 API 与界面可能仍同时显示 `CREDIT` 和 `FINANCIAL_PRODUCTS_SERVICES` 两个选项；选择类别前先核实当前账户流程。

### 规划立场

- 优先合规的线索质量，不追便宜的线索量。
- 转化是申请、报价、咨询还是购买，决定用 Leads 还是 Sales。
- 优先用合格线索阶段和后端审批结果，而不是原始表单提交。
- 在要求处对资格、利率、费用与限制做清晰披露。
- 用审批率、放款账户数、违约风险和贡献毛利对平台线索做对账。

### 创意与文案注意事项

| 风险 | 更安全的做法 |
|---|---|
| "Are you in debt?" 或类似个人属性点名 | "Debt consolidation options for eligible applicants" |
| 保证审批 | 如实说明资格/审批条件 |
| 缺少费用/利率细节 | 链接到清晰的条款与披露 |
| 基于财务困境的定向 | 用合规的宽泛定向 + 表单资格筛选 |

---

## 5. 就业

用于招聘、猎头、招聘平台、实习和职业机会类广告系列。

### 规划立场

- 量允许时优化完成申请或合格申请人。
- 只有在招聘团队能快速跟进、且表单不收集不必要的敏感数据时才用线索表单。
- 避免暗示对受保护群体有偏好的人口属性定向或文案。
- 按合格申请人、面试、入职和留存衡量质量，不只看原始 CPL。

### 创意与文案注意事项

| 风险 | 更安全的做法 |
|---|---|
| 年龄/性别编码的语言 | 岗位、福利、要求、排班、地点 |
| "Moms wanted" / "young professionals" | 中性的岗位与资格表述 |
| 薪酬或工作条件不明 | 尽量加上薪资范围、地点、远程/到岗、要求 |

---

## 6. 住房与房产

用于房屋租赁/买卖、房产中介、与房贷相关的住房产品和住房服务。

### 规划立场

- 检查住房和信贷两个类别是否同时适用。
- 用合规的地域和宽泛投放；不用可能排除受保护群体的定向。
- 用创意和落地页按房型、价格区间、位置、可租售状态做资格筛选，避免歧视性表述。
- 按合格咨询、看房、申请、签约或成交衡量。

### 创意与文案注意事项

| 风险 | 更安全的做法 |
|---|---|
| "Perfect for young families" | "3-bedroom homes near transit and parks" |
| 暗示按受保护群体筛选的社区定向 | 房产/位置事实 + 合规的宽泛触达 |
| 误导性的可租售状态或价格 | 保持商品流/房源的上架状态为最新 |

---

## 7. 社会议题、选举与政治

当广告系列涉及选举、候选人、公投议题、立法、政治组织或社会议题倡导时使用。

### 规划立场

- 启动规划前先确认广告主授权、国家准入、免责声明以及主页/账户要求。
- 预期审核延迟以及透明度/广告资料库的影响。
- 用保守声明和有出处的表述。
- 避免无法消化政策审核或授权延迟的临门一脚式上线计划。

### 衡量立场

- 把互动和触达视为方向性信号，不是说服力的证明。
- 适用时用提升度（lift）、调研、网站行为、捐款、志愿者报名或名单增长。
- 谨慎做敏感分群和报告解读。

---

## 8. 健康、养生、个人属性与敏感声明

健康养生类广告系列不一定属于特殊广告类别，但政策风险很高。

### 规划立场

- 避免暗示观看者有疾病、身体特征、成瘾、心理健康状态或敏感个人身份的文案。
- 用教育、服务或收益框架，而不是个人属性点名。
- 对功效声明、前后对比图、证言和效果声明要求有依据。
- 适用时在落地页加上适当的免责声明和专业资质。

| 风险 | 更安全的做法 |
|---|---|
| "Struggling with anxiety?" | "Mental wellness support options" |
| "Lose 20 lbs fast" | "Personalized fitness coaching" 并用现实的声明 |
| 前后对比的身体图像 | 展示产品/服务本身，不羞辱、不给不现实的效果 |

## 9. 青少年与年龄敏感定向

Meta 的青少年定向与数据使用规则随时间变化，且因地区而异。当前 Meta 帮助文档说明，广告主只能按年龄和位置纳入青少年，不能按兴趣、行为、性别或站外行为定向；部分国家（如泰国、印尼）适用更高的年龄门槛。

规划立场：

- 推荐青少年广告系列前，先核实当前的年龄、位置颗粒度、版位和数据使用限制。
- 避免敏感话题、身材焦虑、财务承诺或操纵性紧迫感。
- 用宽泛、适龄的创意和落地体验。
- 没有当前界面核实前，不要依赖精细定向或再营销假设。

---

## 10. 线索表单与隐私

任何收集个人数据的广告系列：

- 附上有效的隐私政策 URL。
- 在卖点需要同意、金融/健康披露或跟进许可时加自定义免责声明。
- 只收集业务流程必需的字段。
- 除非有明确法律依据和平台许可，不要在 Meta 表单内收集敏感数据。
- 明确线索如何进入 CRM、谁能访问、多快跟进。
- 做转化线索（Conversion Leads）或线下事件时，确认服务器/CRM 上传的同意与数据处理安排。

## 11. 审核风险检查清单

上线前逐项核实：

| 检查项 | 原因 |
|---|---|
| 类别选对了 | 类别选错会导致拒审、投放受限或合规风险 |
| 落地页与广告声明一致 | 审核常看落地页，不只看广告文案 |
| 披露可见 | 金融、健康、就业、住房、线索类声明需要清晰 |
| 无个人属性点名 | Meta 拒审的常见原因 |
| 无误导性紧迫感/稀缺性 | 金融、健康、住房、政治尤其高风险 |
| 受众控制项是当前可用的 | Meta 经常调整可用定向控制 |
| CRM/线下上传已获同意 | 衡量设计可能带来隐私/合规风险 |
| 所有创意变体都合规 | 动态/灵活/Advantage+ 变体同样需要审核 |

---

## 12. 输出指引

当政策重要时，在计划中加一段简短的政策章节：

1. 类别假设与置信度。
2. 目标国家/地区。
3. 定向约束。
4. 文案/创意约束。
5. 表单/落地页披露要求。
6. 衡量/数据处理约束。
7. 需在当前 Ads Manager 或与法务/合规负责人处核实的事项。

在类别和目标地域明确之前，不要把政策敏感的媒体建议当作最终结论呈现。
