## 1. 通用原则

### 1-1. 创意驱动效果

在现代 Meta 广告中，创意质量与多样性往往比小的定向或出价调整更重要。创意告诉 Meta：优惠是什么、给谁、以及用户为什么要在乎。

### 1-2. 文案长度

| 要素 | 建议长度 | 过长会怎样 |
|---|---:|---|
| **正文（Primary text）** | 125 个字符以内，否则有被截断风险 | 可能被折叠在"查看更多"后面 |
| **标题（Headline）** | 27 个字符以内，否则有被截断风险 | 可能被截断 |
| **描述（Description）** | 通常 25-30 个字符；Facebook 动态消息常用约 27 个 | 常因版位被隐藏 |

注意：描述经常不在 Instagram 版位展示，可能只出现在 Marketplace、Audience Network、Facebook 搜索结果或信息流内视频等部分场景。把核心信息集中在正文、标题和视觉上。

### 1-3. 文案测试

预算允许时，每个创意概念至少准备**三个文案变体**。

| 长度 | 作用 | 适合 |
|---|---|---|
| **极短** | 一两行让人停下滑动 | 已知产品、简单优惠 |
| **中等** | 问题 -> 解决方案讲解 | 中价位优惠、已知品类 |
| **长** | 故事或详细讲解 | 高客单价、未知品类、B2B |
| **长篇教育型** | 以教育为先的说服 | 复杂服务和教育类优惠 |

### 1-4. 钩子设计

钩子是文案的第一行，或视频的前 3 秒。

#### 钩子类型

| 序号 | 类型 | 描述 | 示例方向 |
|---|---|---|---|
| 1 | **提问** | 引发用户思考 | "还在为……苦恼吗？" |
| 2 | **数字/统计** | 用数据建立可信度 | "92% 的用户注意到……" |
| 3 | **收益** | 直接说出结果 | "3 天改变 X" |
| 4 | **痛点** | 说出一个烦恼 | "受够了……？" |
| 5 | **故事** | 打开一个叙事 | "去年我……" |
| 6 | **FOMO** | 增加紧迫感或稀缺感 | "只剩 24 小时" |
| 7 | **反常识** | 挑战一个固有认知 | "X 不是答案" |
| 8 | **前后对比** | 展示转变 | 前后对比视觉 |
| 9 | **好奇心缺口** | 制造信息差 | "高手都在避免的三个错误" |
| 10 | **惊喜** | 用意想不到的结果 | 不同寻常的用例 |
| 11 | **社会证明** | 用第三方背书 | 评分、评价、用户数 |
| 12 | **直接点名** | 点出目标受众 | "给运营团队的……" |
| 13 | **悬念** | 推迟揭晓结果 | "等看结果……" |
| 14 | **挑衅** | 抛出值得争论的观点 | "X 已经过时了" |
| 15 | **互动** | 引导投票或小测 | "A 还是 B？" |
| 16 | **视觉爽感** | 用令人着迷的画面 | 开箱、烹饪、制作过程 |

#### 钩子率规划

用 3 秒播放量或早期留存作为方向性信号。基准值因形式、受众和版位差异很大。

### 1-5. 行动号召（CTA）设计

#### 行动号召按钮选择

| 行动号召按钮 | 最佳目标 | 最适合的业务类型 |
|---|---|---|
| **Shop Now** | 购买 | 电商/D2C |
| **Learn More** | 教育与种草 | 适用面广 |
| **Sign Up** | 潜客获取或账号注册 | SaaS、newsletter、webinar |
| **Book Now** | 预约 | 沙龙、诊所、酒店、服务业 |
| **Contact Us** | 咨询 | B2B 与服务业 |
| **Download** | 应用或内容下载 | 应用、白皮书 |
| **Apply Now** | 申请 | 招聘、金融、教育 |
| **Get Quote** | 获取报价 | 保险、装修、B2B |
| **Buy Tickets** | 购票 | 活动与娱乐 |

规则：

- 行动号召按钮要与文案中的承诺一致。
- 把用户送到与行动号召预期一致的页面。
- 下一步行动明确时，用具体的行动号召。

### 1-6. 广告角度设计

| 角度 | 内容 | 文案方向 |
|---|---|---|
| **痛点** | 对问题的共情 | "花了太多时间在……" |
| **收益/独特卖点（USP, Unique Selling Proposition）** | 直接价值 | "Y 分钟搞定 X" |
| **社会证明** | 评价、效果、体量 | "深受……信赖" |
| **对比** | 与替代方案的差异 | "比……长 3 倍" |
| **稀缺/紧迫** | 现在行动的理由 | "今晚截止" |
| **好奇心** | 开放式悬念 | "为什么专家都避开……" |
| **奢华/高端** | 品质与身份 | "主厨推荐……" |
| **速度/便捷** | 便利 | "明天送达" |

## 2. 图片广告

### 2-1. 规格

| 项目 | 规格 |
|---|---|
| 建议尺寸 | 动态消息：1440x1800（4:5）、1440x1440（1:1）；Stories/Reels：1440x2560 或 1080x1920（9:16） |
| 最小尺寸 | 动态消息：600x750（4:5）、600x600（1:1） |
| 文件类型 | JPG、PNG |
| 文件大小 | 30 MB 以内；文件越小加载越快 |
| 图片文字 | 尽量少；旧的 20% 文字规则已不再是硬性规则，但更干净的图片通常效果更好 |

### 2-2. 设计实践

布局原则：

- **一条广告 = 一个信息。**不要把多个宣称塞进一张图。
- 动态消息尽量**用 4:5**。
- **9:16 用于 Stories/Reels**，不要把它当作动态消息图片的默认尺寸。
- **用高对比度**让人停下滑动。
- 有原创产品、客户或品牌摄影可用时，**避免用通用图库素材**。

有效的设计模式：

| 模式 | 描述 | 适合 |
|---|---|---|
| **产品主角** | 大产品图 + 收益文案 | 电商、D2C |
| **文字叠加** | 图片上的醒目宣称 | 优惠、促销、公告 |
| **前后对比** | 分屏展示转变 | 美妆、健身、家居改善 |
| **客户证言** | 客户面孔 + 引言 | 信任与社会证明 |
| **信息图** | 数据或流程可视化 | 教育、B2B |
| **生活方式** | 使用中的产品 | 品牌认知、服装、消费品 |
| **PNG 叠加** | 抠图产品 + 背景 + 配文 | 静态创意做出动态感 |

品牌元素：

- 谨慎使用 logo。
- 保持设计系统一致：字体、颜色、布局、图片风格。

### 2-3. 文案

正文：

```
Hook: First line earns attention.
Body: Explain 2-3 benefits or proof points.
CTA: Tell the user what to do next.
```

标题：

- 保持简短。
- 直接说出收益或优惠。

排版：

- 用换行提高可读性。
- 只有符合品牌和市场调性时才用 emoji。
- 收益需要扫读时用列表。

## 3. 视频广告

### 3-1. 规格

| 项目 | 规格 |
|---|---|
| 建议尺寸 | Reels/Stories：1440x2560 或 1080x1920（9:16）；动态消息：1440x1800（4:5）或 1440x1440（1:1） |
| 最小尺寸 | 120x120；制作时用高分辨率源文件 |
| 建议时长 | 动态消息：15-60 秒；Reels：15-30 秒（经验性参考）；快拍：短而直接 |
| 文件类型 | MP4、MOV；部分视频版位可能接受 GIF |
| 文件大小 | 最大 4 GB |
| 编解码器 | H.264 视频、AAC 音频 |
| 音视频技术参数 | 建议方形像素、固定帧率、逐行扫描、立体声 AAC 128 kbps+ |
| 帧率 | 除非源文件和版位另有要求，30 fps 以内是实用的默认值 |
| 最长时长 | 取决于版位；Instagram Reels 广告最长可达 15 分钟，但简洁的广告通常跑得比理论上限更好 |

### 3-2. 结构框架

核心结构：钩子 -> 正文 -> 行动号召

```
[0-3s] Hook          -> Stop the scroll
   ↓
[3-15s] Body         -> Show value: benefit, demo, story, proof
   ↓
[Middle] Soft CTA    -> First action cue
   ↓
[Remaining] Detail   -> More proof, testimonial, FAQ, offer
   ↓
[End] Final CTA      -> Repeat the action
```

#### 9:16 安全区

| 版位 | 顶部边距 | 底部边距 | 两侧边距 |
|---|---:|---:|---:|
| Stories/Reels 9:16 | 14% | 20-35% | 每侧 6% |

规则：用统一的 9:16 安全区设计。如果广告可能跑在 Reels 上，用保守的 35% 底部边距。因为字幕、行动号召和设备 UI 会改变遮挡区域，每份最终素材都要在 Ads Manager 的版位预览中核验。

### 3-3. 设计实践

音频：

- 默认加字幕。
- 字幕要大、对比度要高。
- 仍然要为开声音观看的用户配音乐、旁白或音效设计。

视觉：

- 从第一帧就加入动效。
- 合适时用醒目的字幕和图形化行动号召。
- 产品抠图叠加在能讲清优惠时效果不错。
- 根据优惠选调性：证言、访谈、演示、纪录片、精制作或低成本粗糙风。

创意类型：

| 类型 | 描述 | 最佳用途 |
|---|---|---|
| **UGC 风格/低成本粗糙风** | 自然的手机拍摄画面 | 亲近感与真实感 |
| **证言** | 客户讲述体验 | 信任、漏斗中部/底部 |
| **创始人/员工出镜** | 对镜讲述 | 品牌人情味与信任 |
| **演示/教程** | 展示产品使用 | 产品教育 |
| **动态图形** | 动画或数据可视化 | B2B、SaaS、复杂服务 |
| **电影感** | 品牌大片风格 | 认知与情感叙事 |

### 3-4. 文案

正文：

- 给出观看或行动的理由。
- 补充视频讲不到的细节。
- 以明确的行动号召结尾。

标题：

- 浓缩核心信息。
- 即使用户不看视频也能看懂。

## 4. 轮播广告

### 4-1. 规格

| 项目 | 规格 |
|---|---|
| 卡片数 | 2-10 张；从 3-5 张开始 |
| 图片尺寸 | 最小 1080x1080；有条件用 1440x1440 |
| 视频尺寸 | 最小 1080x1080；有条件用 1440x1440 |
| 视频时长 | 通常越短越好；每张卡片聚焦一点 |
| 文件大小 | 保持轻量以加快加载 |
| 正文 | 保持简洁 |
| 卡片标题 | 45 个字符以内，否则有被截断风险 |
| 卡片描述 | 可选；保持约 18 个字符，或不需要就省略 |
| 宽高比 | 所有卡片保持一致 |

### 4-2. 卡片结构

五拍结构：

```
Card 1: Hook        -> Earn attention and encourage swipe
Card 2: Context     -> State the situation or problem
Card 3: Discovery   -> Introduce the solution or product
Card 4: Reward      -> Proof, testimonial, detail
Card 5: CTA         -> Final action card
```

有效的轮播模式：

| 模式 | 卡片结构 | 适合 |
|---|---|---|
| **产品目录** | 产品 A -> 产品 B -> 产品 C | 电商与产品线 |
| **收益叠加** | 卖点 1 -> 卖点 2 -> 证明 -> 优惠 | SaaS 与服务 |
| **步骤讲解** | 步骤 1 -> 步骤 2 -> 步骤 3 -> 结果 | 教程与流程 |
| **前后对比** | 使用前 -> 使用中 -> 使用后 -> 行动号召 | 美妆、健身、家居改善 |
| **讲故事** | 问题 -> 发现 -> 改变 -> 结果 -> 行动号召 | 品牌故事 |
| **FAQ/异议处理** | 提问 -> 回答 -> 提问 -> 回答 -> 行动号召 | 考虑阶段用户 |

### 4-3. 设计实践

第一张卡是守门员：

- 用强收益、好奇心缺口、统计数据或转变预告。
- 用箭头或视觉连续性暗示还有更多可滑。

一致性：

- 背景、字体、照片风格保持一致。
- 用高对比度，移动端可读的文字尽量少。
- 用鼓励滑动的视觉提示。

排序：

- 讲故事时，如果自动排序会破坏叙事，就关掉它。
- 产品目录用自动排序可能有用。

### 4-4. 文案

正文：

- 总结轮播的主题或价值。
- 给出滑动的理由。

卡片标题：

- 每张卡片讲一个不同的点。
- 避免每张卡片重复同一信息。

### 4-5. 要避免的错误

- 卡片之间混用宽高比。
- 用拖慢加载的重文件。
- 给叙事型轮播开自动排序。
- 把动态消息设计直接复用到 Stories，不做安全区适配。
- 重复几乎相同的卡片。

## 5. 精品栏广告（Collection Ads）

### 5-1. 规格

| 项目 | 规格 |
|---|---|
| 封面 | 图片或视频 |
| 产品图 | 从商品目录拉取，以网格状布局展示 |
| 标题 | 保持简短 |
| 正文 | 保持简洁 |
| 点击行为 | 打开即刻体验（Instant Experience） |
| 前提 | 已连接商品目录 |

### 5-2. 设计实践

封面图/视频：

- 用最强的主视觉。
- 用视频时，在前几秒讲清品牌和产品品类。
- 当场景重要时，生活方式场景可能比孤立的产品图更好。

产品图：

- 用高分辨率、风格一致的产品图。
- 产品拍摄风格保持统一。
- 根据选品策略选择自动或手动选品。

### 5-3. 即刻体验模板选择

| 模板 | 简介 | 适合 |
|---|---|---|
| **Instant Storefront** | 目录式产品浏览 | 电商与多产品销售 |
| **Instant Lookbook** | 带产品的生活方式影像 | 服装、家居、美妆 |
| **Instant Customer Acquisition** | 以潜客或行动为导向的体验 | B2B、服务、注册 |
| **Instant Storytelling** | 沉浸式品牌叙事 | 认知与新品发布 |

### 5-4. 文案

- **标题：**用直白的语言写品类或优惠。
- **正文：**收益加行动。
- 因为字符空间紧张，只聚焦一个信息。

## 6. 潜客广告（Lead Ads）/即时表单（Instant Forms）

### 6-1. 规格

| 项目 | 规格 |
|---|---|
| 形式 | 图片或视频 + 即时表单 |
| 问题 | 自定义问题尽量少，除非筛选需要更多 |
| 表单类型 | 更多量（More volume）/更高意向（Higher intent）/丰富创意（Rich creative） |
| 自动填充 | 在允许的情况下使用 Facebook 个人资料信息自动填充 |

### 6-2. 表单设计

表单类型选择：

| 类型 | 特点 | 适合 |
|---|---|---|
| **更多量** | 更容易完成、量更大 | newsletter、内容下载、早期潜客获取 |
| **更高意向** | 提交前增加复核步骤 | 演示申请、高客单价咨询 |
| **丰富创意** | 增加影像、品牌与产品细节 | 品牌主导的潜客体验 |

问题流程：

```
[Basic information] Name and email with autofill where possible
    ↓
[Segment questions] 1-2 multiple-choice questions to qualify
    ↓
[Thank-you screen] Message plus next-step CTA
```

潜客质量打法：

- 加自定义问题过滤不匹配的潜客。
- 在可用且合适时用电话或邮箱验证。
- 尽早对接 CRM，让潜客质量能反哺跟进与优化。

### 6-3. 广告创意

图片/视频：

- 把优惠讲清楚：指南、咨询、报价、演示、webinar 等。
- 把价值可视化：封面图、webinar 场景、产品/服务效果。
- 图片广告通常就够了；视频有用，但不总是必需。

文案：

- **正文：**讲清用户能得到什么、为什么是现在。
- **标题：**直接点名优惠。
- **行动号召：**与行动匹配：Sign Up、Download、Get Quote、Learn More 等。

### 6-4. 即时表单开场白

在问题之前，说明：

- 提交后会发生什么。
- 用户能得到什么好处。
- 需要多长时间。

## 7. 即刻体验（Instant Experience）

### 7-1. 概述

即刻体验（Instant Experience）是广告点击后打开的全屏移动端体验。它可以用作精品栏广告的落地页，也可以作为独立的沉浸式落地页。

### 7-2. 设计实践

速度：

- 它比典型的移动端网页加载更快。
- 当外部站点慢或太泛时，它可以替代移动端落地页。

推荐结构：

```
[Header] Brand logo + key message
  ↓
[Hero] Video or image impact
  ↓
[Benefits] 3-4 visual benefit blocks
  ↓
[Social proof] Testimonial or result metric
  ↓
[Product/service] Carousel or grid
  ↓
[CTA] Action button
```

## 8. 创意测试与运营周期

### 8-1. 测试原则

- 预算允许时，每个主要创意概念至少测试三个文案变体。
- 让测试积累足够的数据再下结论。
- 当目标是干净的学习结论时，一次只改一个有意义的变量。

### 8-2. 每周创意周期

```
Week 1: Launch 5-10 new creative assets or concepts
  ↓
Week 2: Let them run without unnecessary edits
  ↓
End of Week 2: Judge winners and losers
  - Winners -> Move or adapt into scaling campaign
  - Losers -> Pause or learn from them
  ↓
Week 3: Extract performance insights
  ↓
Week 3: Produce the next creative batch from the insights
  ↓
Repeat
```

### 8-3. 胜出标准

| 指标 | 解读 |
|---|---|
| 点击率（CTR） | 创意的吸引力与相关性 |
| 每次转化费用/广告投入回报率（CPA/ROAS） | 业务效率；转化类广告的最终决策 |
| 钩子率/3 秒播放量 | 开头强度 |
| 频次 | 疲劳信号 |
| 千人触达成本（CPM） | 受众疲劳或竞价压力信号 |

### 8-4. 创意生命周期

- 获胜创意跑 30-60 天后或出现疲劳时更新。
- 频次上升 + 点击率下降，基本可以判定疲劳。
- 先用创意更新应对疲劳，再动出价。
- 放量时定期补充新创意。

### 8-5. 放量技巧

- **帖子 ID 复用（Post ID reuse）：**把获胜创意放大到另一个广告系列时，复用帖子 ID 可以保留点赞、评论、分享等社会证明。
- **按概念放量：**放大的是获胜的角度和形式逻辑，而不只是一个广告文件。
- **预算增加：**避免突然大幅加预算；渐进增加能减少对学习的干扰。
