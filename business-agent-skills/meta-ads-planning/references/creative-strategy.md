## 1. 为什么创意重要

创意质量是 Meta 广告中最重要的杠杆之一。预算、定向和出价设置都很重要，但它们救不了弱创意。

- 创意是投放质量与转化率（CVR, Conversion Rate）的主要驱动因素。
- Meta 的投放系统利用创意信号来推断哪些人更可能产生响应。
- 创意策略应在素材制作开始前就明确受众、信息、证明、形式与测试计划。
- Andromeda/GEM 这类 AI 检索/排序系统让创意输入变得更加重要，但要避免没有依据的说法，例如"固定比例的效果是由创意带来的"。

## 2. 创意多样性 vs 创意数量

### 原则：多样性胜过重复

不要为一个素材制作几十个几乎相同的变体。要构建真正不同的创意概念。

不好的做法：

- 在同一张获胜图片上加 20 个钩子或标题，然后指望算法把它们当作不同的概念。

更好的做法：

- 把获胜的信息用在真正不同的形式上。
- 测试不同的角度、语气、证明类型、视觉风格和内容结构。
- 让在投素材库的规模与预算成比例。预算大的账户可以测试更广的创意面；预算小的账户通常需要更少、更清晰的概念。

### 创意类别

有效的广告素材库应包含多种创意类型。

| 类别 | 示例 |
|---|---|
| 静态图片 | 产品摄影、文字叠加图、信息图 |
| 短视频（低成本粗糙风格） | 手机拍摄视频、UGC 风格、客户证言 |
| 精制作视频 | 电影感、动态图形 |
| 创始人/员工出镜内容 | 自拍视频、访谈 |
| GIF/梗图风格创意 | 轻松、有本土文化感的信息表达 |
| 轮播广告 | 多产品、步骤讲解、前后对比 |

### 创意概念示例

- **电影感品牌故事：**传达品牌世界观与价值观。
- **梗图风格对比：**用通俗的幽默制造反差。
- **低成本粗糙证言：**用真实客户或创作者的证明。
- **动态图形：**解释数据、流程或抽象价值。
- **怀旧角度：**用记忆与情感建立亲近感。

## 3. 创意设计规则

### 按版位设计创意

设计规则：当 Reels 和 Stories 重要时，以 9:16 竖版作为主设计，并把重要元素放在 Reels 底部 UI 区域之外。再按需适配到 4:5 和 1:1。

| 版位 | 宽高比 | 安全区指引 | 设计说明 |
|---|---|---|---|
| **动态消息（Feed）** | 首选 4:5，可接受 1:1 | 关键内容居中 | 4:5 比 1:1 占据更多屏幕空间 |
| **快拍（Stories）** | 9:16 | 避开顶部和底部 UI 区域 | 把行动号召（CTA, Call To Action）/logo 放在中间区域 |
| **Reels** | 9:16 | 底部 UI 区域是最大限制 | 先围绕底部安全区设计 |
| **信息流内视频（In-stream）** | 16:9 | 关键内容居中 | 横屏视频场景 |
| **Marketplace/搜索** | 1:1 | 关键内容居中 | 以产品为先，布局简洁 |

### 视频设计

| 要素 | 建议 |
|---|---|
| 前 1-3 秒 | 使用强钩子；这是最重要的部分 |
| 时长 | 动态消息：15-60 秒；Reels：15-30 秒（经验性参考）；快拍：短而直接 |
| 宽高比 | 竖版优先投放用 9:16；动态消息适配用 4:5 |
| 字幕 | 默认添加字幕 |
| 语气 | 匹配买家与优惠；证言、访谈、演示和问题导向的钩子通常效果不错 |
| 行动号召 | 包含明确的行动指令 |
| UGC 风格 | 在真实感和亲近感重要时有用；对高端、信任敏感或受监管的优惠并非万能 |

### 静态图片设计

| 要素 | 建议 |
|---|---|
| 宽高比 | 动态消息用 4:5，1:1 兼容性最广，Stories/Reels 用 9:16 |
| 分辨率 | 动态消息：1440x1800 或 1440x1440（如有）；Stories/Reels：1440x2560 或 1080x1920 |
| 信息 | 一个清晰的优惠或观点 |
| 图片文字量 | 尽量少，即使旧的"20% 文字规则"已不再是硬性规则 |
| 质量 | 使用高质量的产品、生活方式或平面设计素材 |
| 作用 | 不要忽视静态图片；它们依然是快速、好用的测试手段 |
### 文案设计

准备不同长度、不同分工的文案变体。

| 长度 | 作用 |
|---|---|
| 极短 | 一两行就能让人停下滑动 |
| 中等 | 三到五行讲清痛点与解决方案 |
| 长 | 段落式故事或讲解 |
| 长篇教育型 | 以教育为先的说服，适合复杂优惠 |

### 广告角度变体

| 角度 | 内容 |
|---|---|
| 痛点 | "你是否还在为……苦恼？" |
| 愉悦/收益 | "获得……"或"实现……" |
| 证言/社会证明 | 评价、效果、客户故事 |
| 好奇心 | "为什么……？"或"原因是……" |
| 直接提问 | "在找……？" |
| 稀缺/紧迫 | 限时、限量、截止日期 |
| 对比 | 旧方式 vs 新方式、竞品替代方案 |

## 4. 创意测试

### 3-3-3 漏斗框架

| 阶段 | 信息姿态 | 假设 |
|---|---|---|
| **漏斗顶部/认知（ToF/Awareness）** | 问题 framing 与教育 | 用户可能不了解品牌或产品 |
| **漏斗中部/考虑（MoF/Consideration）** | 帮助评估解决方案 | 用户已知问题，正在比较选项 |
| **漏斗底部/转化（BoF/Conversion）** | 优惠、证明、保障、对比 | 用户接近购买或咨询 |

### 运营周期

推荐的每周循环：

1. 在预算允许时，上线一小批真正不同的概念。
2. 让它们跑大约 7 天，不要做不必要的修改。
3. 暂停明显失败的，放大获胜的。
4. 从效果数据中提炼洞察。
5. 基于洞察产出下一批创意。
6. 重复。

### 胜出标准

| 指标 | 解读方式 |
|---|---|
| 点击率（CTR, Click-Through Rate） | 创意的吸引力与相关性 |
| 每次转化费用（CPA, Cost Per Action）/广告投入回报率（ROAS, Return on Ad Spend） | 业务效率；转化类广告的最终决策指标 |
| 频次（Frequency） | 高频次可能意味着创意疲劳 |
| 千人触达成本（CPM, Cost Per Mille） | 上升可能预示疲劳或竞价压力 |
| 钩子率/3 秒视频播放量 | 开头的强度；按形式/账户建立基准，没有通用值 |
| 完播留存率（Hold rate） | 钩子与正文是否匹配；钩子率高但留存弱，可能意味着只有好奇、没有购买意向 |
| 合格结果率 | 潜在客户或客户质量；防止优化到便宜但不匹配的用户 |

### 创意生命周期

- 获胜创意跑 30-60 天后，或出现疲劳信号时，考虑更新。
- 频次上升 + 点击率下降、每次转化费用上升，或钩子/留存指标下滑，都是疲劳信号。
- 出现疲劳时，先更新创意，再调出价。
- 如果广告系列依赖持续放量，定期补充新创意。

### 概念 vs 变体

| 类型 | 含义 | 用途 |
|---|---|---|
| 概念 | 不同的论点、买家洞察、证明类型、形式或优惠 | 主要测试单元 |
| 变体 | 同一创意下的不同标题、裁剪、颜色、开头或行动号召 | 概念有潜力后的精细打磨 |

不要把 20 个表面变体当成 20 次测试。Meta 可能仍会把它们当作同一个实际创意来投放，账户也学不到什么。

## 5. 按漏斗阶段的创意策略

### 漏斗顶部/认知（ToF/Awareness）

- **目标：**教育新受众，连接其痛点或欲望。
- **形式：**视频/Reels、图片、轮播。
- **内容：**品牌故事、问题 framing、教育内容。
- **语气：**信息型、情感型、共情型。

### 漏斗中部/考虑（MoF/Consideration）

- **目标：**推动已认知用户进入评估与信任阶段。
- **形式：**轮播、视频、证言。
- **内容：**案例研究、对比、产品细节、常见问题。
- **语气：**可信、具体、逻辑。

### 漏斗底部/转化（BoF/Conversion）

- **目标：**转化接近行动的用户。
- **形式：**动态广告、精品栏广告（Collection Ads）、图片。
- **内容：**限时优惠、优惠券、证言、保障、免费试用。
- **语气：**清晰、自信、行动导向。

## 6. 品牌内容合作广告（Partnership Ads）

### 概述

品牌内容合作广告（Partnership Ads）允许品牌在获得必要权限并完成设置后，以创作者或合作伙伴的身份投放广告。

### 优势

- 复用创作者已有的受众语境与内容风格。
- 广告看起来比品牌官方号广告更原生，更容易建立信任。
- 有助于发现新受众。
- 当 UGC 或创作者公信力重要时，往往效果不错。

### 推荐使用场景

- 强化 UGC 策略。
- 触达新市场或新受众。
- 品牌官方号广告效果见顶时，用它来刷新效果。

## 7. 创意简报（Brief）模板

用这份简报作为从创意策略到素材生产的交接文档。一份简报 = 一个**概念**（不是一个变体）。在委托拍摄、脚本或设计工作之前填写，并在测试日志中把它和广告放在一起。

一个定义清晰的概念需要满足：(a) 角度、证明、异议处理都明确；(b) 竞争对手不换品牌就跑不了同一条广告；(c) 假设中指明了指标和漏斗阶段。

### 简报字段

| 字段 | 填写内容 | 说明 |
|---|---|---|
| 概念名称 | 短标识（`UGC_BeforeAfter_Skin_v1`） | 用于广告名称和测试日志 |
| 广告系列 | 目标 + 转化位置 + 效果目标 | 例如 `Sales / Website / Purchase` |
| 漏斗阶段 | ToF / MoF / BoF | 决定语气、时长和 KPI |
| 受众洞察 | 一句话说明这个概念为谁而做 | 买家状态，而非人口属性 |
| 优惠 | 这条广告中的具体承诺或产品 framing | 不是品牌标语 |
| 角度 | 以下选其一：痛点、收益、社会证明、好奇心、对比、稀缺、演示、反常识、创始人、品类切入点 | 只选一个，不要混搭 |
| 钩子 | 视频前 1–3 秒，或静态/文案的第一行 | 必须筛选意向，而不只是吸引眼球 |
| 证明 | 证言、前后对比、数据、资质、演示、UGC | 具体、有出处 |
| 处理的异议 | 这个概念要消除的单个买家顾虑 | 价格、信任、适配、转换成本、时间 |
| 形式 | 图片/短视频/精制作视频/轮播/精品栏/Reels 原生/品牌内容合作广告 | 每份简报一种 |
| 宽高比 + 时长 | 9:16 / 4:5 / 1:1；视频注明秒数 | 匹配版位优先级 |
| 行动号召按钮 | Meta 预设按钮 | 必须与转化位置一致 |
| 文案变体 | 正文和标题的短/中/长版本 | 每种至少 3–5 个 |
| 假设 | "我们预计这个概念会在{指标}上{胜出/失败/改变}，因为{原因}" | 一句话，可证伪 |
| 读数 KPI | 继续/叫停的主要指标 | 每次转化费用、每次潜在客户费用（CPL, Cost Per Lead）、广告投入回报率、合格潜在客户率、钩子率、留存率 |
| 更新触发器 | 标记疲劳的频次/点击率/每次转化费用阈值 | 尽量跨概念复用 |
| 制作负责人 | 负责的人或供应商 | 避免无人负责的停滞 |
| 合规标记 | 特殊广告类别（Special Ad Category）、受监管的宣称、青少年/敏感定向、音乐授权、品牌内容合作广告权限 | 制作前检查，而不是制作后 |

### 填写示例

| 字段 | 值 |
|---|---|
| 概念名称 | `UGC_BeforeAfter_Skin_v1` |
| 广告系列 | Sales / Website / Purchase |
| 漏斗阶段 | MoF |
| 受众洞察 | 28–45 岁女性，试过 2 个以上护肤品牌，不再相信广告宣称 |
| 优惠 | 晚间精华 30 天无理由退款试用 |
| 角度 | 社会证明（创作者本人的前后对比） |
| 钩子 | "我不再买护肤品广告了。然后 4 周后发生了这个。" |
| 证明 | 真实创作者、有日期的照片、文案中的皮肤科医生引言 |
| 处理的异议 | "又是一款过度承诺、买了会后悔的精华" |
| 形式 | 短视频（UGC 风格，创作者拍摄） |
| 宽高比 + 时长 | 9:16，22 秒 |
| 行动号召按钮 | Shop Now |
| 文案变体 | 短（1 行怀疑型钩子）、中（3 行心路历程）、长（带退款政策的段落） |
| 假设 | "我们预计这个概念在钩子率上会胜过棚拍视频，因为怀疑型 framing 更早筛选了意向" |
| 读数 KPI | 购买的每次转化费用；次要：钩子率、留存率 |
| 更新触发器 | 频次 > 3.5 且点击率周环比下降 > 25% |
| 制作负责人 | 创作者合作负责人 |
| 合规标记 | 需要审核健康宣称；需要品牌内容合作广告权限；禁用"保证效果"类措辞 |

### 如何在测试中使用简报

- 一份简报对应一个概念；多个变体（标题、开头、裁剪）挂在同一份简报下。
- 一轮测试是 3–5 份简报互相对打，而不是同一份简报的 3–5 个变体。
- 用读数 KPI 决定简报的去留，而不是只看钩子率。
- 只有当一份简报至少在该广告系列量级对应的标准学习窗口内达成了漏斗阶段 KPI，才能晋升为"胜出者"。
- 把胜出者的**角度/证明/异议处理**复用到新简报中，换上不同的形式和钩子；不要把同一份简报渲染成 20 个变体。
