# 预算规划与可行性

本参考用于判断现有预算能否支撑拟定的 Meta 广告系列组合完成学习、产生转化并被正确判读。预算规划应从经济效益和预期信号量出发，而不是从通用的漏斗拆分出发。

## 核心公式

| 问题 | 公式 | 用途 |
|---|---|---|
| 可承受 CPA（Allowable CPA） | 平均订单/客单价 × 毛利率 × 成交率 | 盈利前的最高获客成本 |
| 所需展示量 | 目标点击量 ÷ 预期 CTR × 100 | 触达能否支撑计划 |
| 所需点击量 | 目标转化量 ÷ 预期 CVR | 流量是否充足 |
| 所需花费 | 所需转化量 × 预期 CPA | 计划能否产生信号 |
| 预期转化量 | 预算 ÷ 预期 CPA | 优化事件是否有足够量 |
| 盈亏平衡 ROAS | 1 ÷ 毛利率 | 电商的营收 ROAS 下限 |
| 贡献 ROAS | 贡献毛利 ÷ 广告花费 | 当运费、折扣、销货成本、退货影响大时更适用 |

线索型业务：

```
Allowable CPL = 平均客单价 × 毛利率 × 商机率 × 成交率
```

电商：

```
Break-even ROAS = 1 / gross margin
目标 ROAS 应在扣除退货、运费、折扣和运营成本后，高于盈亏平衡线。
```

## 可行性检查

在推荐广告目标或结构之前，按顺序回答这些问题。

| 步骤 | 问题 | 决策 |
|---|---|---|
| 1 | 真正的业务结果是什么？ | 购买、合格线索、预约工单、留存 App 用户、门店销售 |
| 2 | 可承受的 CPA / 要求的 ROAS 是多少？ | 未知就从单位经济效益算出一个区间 |
| 3 | 合理的 CPA/CPL/CPI 区间是多少？ | 用账户历史或保守的规划假设 |
| 4 | 落地页可能的转化率是多少？ | 有历史用历史，没有就保守 |
| 5 | 预算能买到多少真实结果？ | 决定结构与出价 |
| 6 | 转化延迟是否可接受？ | 延迟长意味着判读窗口更长 |
| 7 | 能以什么事件作为主优化目标？ | 用量充足的最深层可靠事件 |

## 预算-结构决策

| 预期每月真实转化量 | 结构姿态 | 出价/优化姿态 |
|---|---|---|
| 0–10 | 非常收敛。一个主广告系列/广告组和一个干净事件 | 最高量（Highest volume）；不用成本控制、不做复杂测试 |
| 10–30 | 依然合并。避免太多广告组和独立测试广告系列 | 最高量；若真实转化太稀疏，考虑用已验证的代理事件 |
| 30–50 | 每个目标一个主广告系列可以成立 | 仅在 CPA 稳定时用成本控制 |
| 50–100 | 有受控创意测试或漏斗分层的空间 | Advantage+ / 宽泛投放测试变得更合理 |
| 100+ | 更宽的结构和实验变得现实 | 可用单次转化费用目标（Cost per result goal）、ROAS 目标、最高价值（highest value），条件合适时可做对照组 |

这些是运营阈值，不是平台硬性要求。如果转化动作本身质量低，再多量也没用。

## 预算分配原则

| 原则 | 做法 |
|---|---|
| 先给主学习闭环吃饱 | 把足够预算放到信号最干净的广告系列 |
| 别太早拆分测试 | 两边都拿不到量，创意测试就是白做 |
| 测试预算保持成比例 | 总预算允许时，创意测试 10–20% 是常见起点 |
| 再营销要有上限 | 温受众看起来高效却可能毫无增量，会吸走花费 |
| 放量需要创意深度 | 加预算会更快暴露创意疲劳 |
| 预算逐步加 | 20–30% 的步长是保守经验，不是平台通用定律 |
| 留维修预算 | 追踪、目录、表单、落地页、CRM、创意工作的价值可能超过媒体花费本身 |

## 按预算充足度的广告系列组合

| 预算状况 | 建议姿态 |
|---|---|
| 预算买不起每月几个有意义的结果 | 只保留一个收敛的转化闭环；只有在有明确质量声明的前提下才用上层漏斗代理事件 |
| 预算能买流量但买不到 15+ 个真实结果/月 | 只用一个合并广告系列；不拆拓客、再营销、测试三个广告系列 |
| 预算能产生 30+ 个真实结果/月 | 有限自动化和创意测试变得现实 |
| 预算能产生 50+ 个真实结果/月 | 宽泛投放/Advantage+、价值优化测试、有控制的扩张变得更合理 |
| 预算能让多个目标各自都有量 | 按经济效益、客户类型、地域、漏斗角色或衡量需求拆分 |

## 红旗信号

| 症状 | 含义 | 行动 |
|---|---|---|
| 日预算低于预期 CPA | 投放可能花几天都出不了一个结果 | 合并，或用更高频的已验证事件 |
| 很多广告组每个都只花一点 | 信号碎片化 | 围绕最干净的信号合并 |
| CPL 便宜但 SQL 率弱 | 系统在学习低质量线索 | 加资格筛选并回传质量事件 |
| ROAS 好看但利润不行 | 毛利率或新老客组合错了 | 按贡献毛利和新客占比报告 |
| 频次上升、CTR 下降 | 创意或受众疲劳 | 先刷新创意再调出价 |
| 测试预算小到无法下结论 | 赢家和输家都是假的 | 少测、测差异更大的概念 |

## 最低回答格式

回答预算可行性时，包含：

1. 经济目标：可承受 CPA/CPL/CPI 或要求的 ROAS。
2. 预期信号量：可能的真实结果/月。
3. 学习可行性：事件和广告系列组合能否学习。
4. 结构含义：能支撑几个广告系列/广告组。
5. 暂时别上的：预算不足或无法衡量的结构。
