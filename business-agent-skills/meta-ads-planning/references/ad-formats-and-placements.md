## 1. 广告格式

### 1-1. 图片广告

概述：一张静态图片 + 文案 + CTA。最基础、最快的格式。

| 项目 | 规格 |
|---|---|
| 推荐分辨率 | 信息流：1440x1440（1:1）或 1440x1800（4:5）；Stories/Reels：1440x2560 或 1080x1920（9:16） |
| 最低分辨率 | 信息流：600x600（1:1）或 600x750（4:5） |
| 文件类型 | JPG、PNG |
| 文件大小上限 | 30 MB |

表现特征：

- 静态图片仍能带来相当大比例的转化。
- 4:5 在信息流中常比 1:1 表现更好，因为占据更多纵向空间。
- 不要把 9:16 当作 Facebook 信息流图片规格；9:16 用于 Stories/Reels 或版位专属的全屏流量。
- 制作快，适合快速概念测试。

适用场景：推广单一产品或卖点、制作资源有限、快速 A/B 测试、再营销。

### 1-2. 视频广告

概述：用于信息流、Stories、Reels 及其他视频版位的视频创意。

| 项目 | 规格 |
|---|---|
| 推荐分辨率 | 信息流：1440x1440（1:1）或 1440x1800（4:5）；Reels/Stories：1440x2560 或 1080x1920（9:16） |
| 最低分辨率 | 120x120；尽量用更高质量的源文件 |
| 推荐时长 | 信息流：15–60 秒；Reels：15–30 秒（经验法则）；Stories：每个故事单元最长 15 秒 |
| 文件类型 | MP4、MOV；部分视频版位也接受 GIF |
| 文件大小上限 | 4 GB |
| 编解码 | H.264 视频、AAC 音频；建议方形像素、固定帧率、逐行扫描、立体声 AAC 128 kbps+ |
| 最长时长 | 因版位而异；Instagram Reels 广告最长可达 15 分钟，Facebook Reels 上限有过调整；通常短而精表现更好 |

表现特征：

- 适合产品演示、讲故事、证明和情感表达。
- 默认加字幕，因为很多用户静音观看。

适用场景：产品演示、品牌故事、客户证言、创始人故事、情感钩子。

### 1-3. 轮播广告

概述：2–10 张可滑动的图片或视频，每张卡片可配独立链接。

| 项目 | 规格 |
|---|---|
| 卡片数 | 2–10；建议从 3–5 开始 |
| 推荐分辨率 | 方形卡片最低 1080x1080；有条件用 1440x1440 |
| 宽高比 | 卡片保持一致，通常 1:1 或 4:5 |
| 视频卡片 | 保持短；15 秒以内通常更实用 |
| 卡片描述 | 可选；尽量极短，可能被隐藏或截断 |

适用场景：多产品、分步讲解、前后对比、卖点序列、对比。

### 1-4. 精品栏广告（Collection Ads）

概述：移动优先格式，封面图/视频 + 商品网格。点击打开全屏快应用（Instant Experience）。

| 项目 | 规格 |
|---|---|
| 封面 | 一张图片或一条视频 |
| 商品图 | 来自目录展示，通常为方形 |
| 前提 | 在 Commerce Manager / Meta 商户管理平台中已连接商品目录 |

适用场景：电商目录强、希望用户浏览多款商品。

### 1-5. 线索广告 / 即时表单（Lead Ads / Instant Forms）

概述：线索获取在 Facebook 或 Instagram 内完成。

表现特征：

- 比跳转外部表单摩擦更小。
- 自动填充可提高完成率。
- 除非问题设计和跟进做得好，线索质量可能低于网站表单。

提质量的做法：

- 加自定义资格筛选问题。
- 高价值线索用**高意向（Higher intent）**表单类型。
- 在感谢页设清晰的 CTA。

适用场景：订阅、资料下载、咨询、演示预约、移动端表单流失严重。

### 1-6. 全屏快应用（Instant Experience）

概述：广告点击后打开的快速加载全屏移动体验。

适用场景：沉浸式品牌体验、目录浏览、移动端落地页替代、精品栏广告落地。

### 1-7. 格式选择矩阵

| 广告目标 | 首选 | 次选 | 第三选择 | 原因 |
|---|---|---|---|---|
| **认知（Awareness）** | 视频/Reels | 轮播 | 图片 | 视频更能抓注意力 |
| **流量（Traffic）** | 图片 | 轮播 | 视频 | CTA 清晰、制作快 |
| **互动（Engagement）** | 视频/Reels | 轮播 | 图片 | 利于互动 |
| **线索（Leads）** | 线索广告 / 即时表单 | 视频 | 图片 | 表单完成摩擦低 |
| **销售：电商** | 精品栏广告 | 轮播 | 动态广告 | 商品浏览与购买路径 |
| **销售：非电商** | 视频 | 图片 | 轮播 | 说服力 + CTA |
| **App 推广** | 视频 | 可玩广告（Playable ads） | 图片 | 展示 App 体验 |

## 2. 版位

### 2-1. 版位列表

#### Facebook 版位

| 版位 | 说明 | 格式 | 备注 |
|---|---|---|---|
| **信息流（Feed）** | Facebook 主信息流 | 图片、视频、轮播、精品栏 | 触达广 |
| **Marketplace** | 用户浏览 Marketplace 时展示 | 图片、视频、轮播 | 购买场景 |
| **视频信息流（Video Feeds）** | 视频浏览场景，含类 Watch 流量 | 视频 | 用户处于视频模式 |
| **右侧栏（Right Column）** | 桌面端右侧栏 | 图片 | 触达有限；常用于再营销 |
| **Stories** | 全屏故事版位 | 图片、视频 | 沉浸式 |
| **Reels** | Reels 信息流之间 | 视频 | 高互动、竖屏优先 |
| **视频插播（In-Stream Video）** | 视频内容播放中 | 视频 | 用户专注的视频观看场景 |
| **搜索结果（Search Results）** | Facebook 搜索结果 | 图片、视频 | 意图相邻的发现场景 |
| **商业探索（Business Explore）** | 商业内容发现 | 图片、视频 | 商业兴趣场景 |
| **小组信息流（Groups Feed）** | 小组信息流版面 | 图片、视频 | 社群触达 |

#### Instagram 版位

| 版位 | 说明 | 格式 | 备注 |
|---|---|---|---|
| **信息流（Feed）** | Instagram 主信息流 | 图片、视频、轮播、精品栏 | 视觉互动强 |
| **Stories** | 全屏故事 | 图片、视频 | 沉浸式、行动导向 |
| **Reels** | Reels 信息流之间 | 视频 | 竖屏优先、高注意力 |
| **探索信息流（Explore Feed）** | 点击探索内容后 | 图片、视频 | 发现型用户 |
| **探索首页（Explore Home）** | 探索页网格位 | 图片、视频 | 发现场景 |
| **购物（Shop）** | Instagram 购物场景（如可用） | 图片 | 购物场景 |
| **搜索结果（Search Results）** | Instagram 搜索结果 | 图片、视频 | 搜索/发现场景 |

#### Messenger 版位

| 版位 | 说明 | 格式 | 备注 |
|---|---|---|---|
| ~~首页（收件箱）~~ | ~~聊天列表之间~~ | — | **2025-11-11 已下线**（`messenger_home`）。该版位已移除；新计划中不要包含。 |
| **赞助消息（Sponsored Messages）** | 聊天内送达的消息 | 文字 + 图片 | 用途有限/基于关系；一键私信广告是主流获客路径 |

#### Audience Network / Threads

| 版位 | 说明 | 格式 | 备注 |
|---|---|---|---|
| **原生、横幅、插屏** | 第三方 App 与网站 | 图片、视频 | CPM 低；质量差异大 |
| **激励视频（Rewarded Video）** | 激励类 App 视频流量 | 视频 | 完播率高，多为 App/游戏场景 |
| **Threads 信息流** | Threads 信息流流量（如可用） | 图片、视频 | 扩大触达；可用性因时而异 |

### 2-2. 版位质量分层

| 层级 | 版位 | 特征 | 建议用途 |
|---|---|---|---|
| **高质量** | Facebook/Instagram 信息流、Reels、Stories | 互动与转化潜力强 | 多数目标，尤其 Sales/Leads |
| **中等质量** | Instagram 探索、Facebook Marketplace、视频插播 | 触达更广、有场景价值；插播流量存在，但对多数账户不如信息流/Reels/Stories 核心 | 认知、流量、销售测试 |
| **较低质量 / 波动大** | Audience Network、Messenger、右侧栏 | 展示便宜但意愿差异大 | 认知、触达扩量或受控测试 |

### 2-3. Advantage+ 版位 vs 手动版位

| 项目 | Advantage+ 版位 | 手动版位 |
|---|---|---|
| 机制 | Meta 在合格版位间自动分配投放 | 广告主自选版位 |
| 触达 | 合格触达更广 | 仅所选版位 |
| CPM | 因流量灵活，整体常更低 | 因版位而异 |
| CPA | 创意适配各主要版位时常更好 | 控制更多，限制风险也更大 |
| 适用 | 默认用于转化目标 | 特定版位测试、品牌要求或质量控制 |

默认：Sales、Leads、App 推广用 **Advantage+ 版位**，除非有明确的控制或质量理由不用。

### 2-4. 版位创意规格

#### 宽高比

| 版位 | 推荐宽高比 | 分辨率 |
|---|---|---|
| 信息流图片 | 4:5 优先，1:1 可接受 | 1440x1800、1440x1440 |
| 信息流视频 | 信息流用 4:5 或 1:1；符合条件的竖屏优先视频投放可用 9:16 | 1440x1800、1440x1440 或 1080x1920 |
| Stories | 9:16 | 1440x2560 或 1080x1920 |
| Reels | 9:16 | 1440x2560 或 1080x1920 |
| 视频插播 | 16:9 | 1920x1080 |
| 右侧栏 | 1:1 | 1080x1080 |
| Marketplace | 1:1 | 1080x1080 |
| Messenger | 1:1 或版位专属的消息创意 | 以当前 Ads Manager 预览为准 |

#### 安全区

| 版位 | 顶部边距 | 底部边距 | 侧边距 | 安全区域 |
|---|---:|---:|---:|---|
| **信息流 1:1** | 10% | 10% | 10% | 中央 80% |
| **信息流 4:5** | 8–12% | 15–20% | 关键内容居中 | 中央区域 |
| **Stories/Reels 9:16** | 14% | 20–35% | 每侧 6% | 统一竖屏安全区；若可能跑 Reels，底部按 35% 留 |

设计原则：用比例安全区，不要用固定像素。对 9:16 素材，关键文字、Logo、产品细节和 CTA 避开顶部 14%、底部 20–35%、两侧各 6% 的区域。务必用 Ads Manager 的版位预览核实，因为界面遮挡随设备、版位、文案长度和产品更新而变化。

### 2-5. 按业务类型的版位策略

| 业务类型 | 推荐版位 | 原因 |
|---|---|---|
| **电商 / D2C** | Advantage+ 版位；确保 Instagram 信息流和 Reels 素材够强 | 视觉化商品发现与放量 |
| **B2B 线索型** | Facebook 信息流 + Instagram 信息流；考虑排除 Audience Network | 线索质量控制 |
| **App** | Advantage+ 版位 | Meta 可按安装或事件概率优化 |
| **本地商户** | Facebook 信息流 + Marketplace + Instagram 信息流 | 本地定向与本地发现 |
| **品牌认知** | Advantage+ 版位；备好 Reels + Stories 视频 | 广触达与沉浸式观看 |
| **内容营销** | Facebook 信息流 + Instagram 信息流 + 探索 | 发现与内容分发 |

## 3. 基准参考

基准因国家、行业、季节、产品价格、卖点、漏斗和衡量搭建差异极大。任何基准都只作初期规划参考，不作成功标准。

| 指标 | 规划说明 |
|---|---|
| CPC | 对照账户历史和渠道角色比较 |
| CPM | 受众越窄、竞争越强、疲劳越重，CPM 可能越高 |
| CTR | 适合创意诊断，但单独看不够 |
| CPL / CPA | 必须挂钩线索质量、利润率、成交率或 LTV |
| ROAS | 必须结合利润率、退货、折扣和增量来解读 |
