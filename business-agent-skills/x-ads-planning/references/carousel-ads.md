# 轮播广告（Carousel Ads）

轮播广告（Carousel Ads）是带有多个可横向滑动图片或视频的推广广告（Promoted Ads）。用它们展示多个产品、解释步骤序列或构建叙事。

规格来源：X 创意广告规范（https://business.x.com/en/help/campaign-setup/creative-ad-specifications）及 2026 年宽高比公告（https://business.x.com/en/blog/x-expands-aspect-ratio-support-for-ad-creatives.html）。最后核实：2026-04。

## 规格

| 项目 | 指南 |
|---|---|
| 卡片数 | 2-6 张图片或视频 |
| 图片轮播尺寸 | 常见规格包括 800x418、800x800，以及扩展比例如 1440x1800、1080x1620、1080x1080、2064x1080、1920x1080、1080x1920 |
| 视频轮播尺寸 | 常见规格包括 800x450、800x800，以及受支持处的扩展比例 |
| 宽高比 | 一个轮播内保持同一宽高比 |
| 混合媒体 | 图片与视频的宽高比保持一致；1:1 是最安全的混合媒体选择 |
| 落地页 | 单落地页轮播用一个落地页；多落地页网站轮播（multi-destination Website Carousels）最多六个独立网页落地页 |
| 网站标题 | 最多 70 个字符；50 个以内更不易被截断 |

X 在 2026 年扩展了 4:5 和 2:3 支持，以提高来自 Meta、TikTok、Instagram 和其他社交平台的创意可移植性。投放前请在 X Ads Manager 中核实当前创意规格。

## 适用场景

- 多个产品或功能。
- 分步讲解。
- 前后对比序列。
- 利益点堆叠。
- 应用或 SaaS 上手流程。
- 活动议程或嘉宾阵容。

## 叙事结构

| 模式 | 卡片 |
|---|---|
| 产品集 | 产品 A -> 产品 B -> 产品 C -> CTA |
| 故事 | 问题 -> 洞察 -> 解决方案 -> 证据 -> CTA |
| 功能序列 | 功能 1 -> 功能 2 -> 功能 3 -> 价值 -> CTA |
| 异议处理 | 异议 -> 回答 -> 证据 -> 下一步 |
| 前后对比 | 前 -> 过程 -> 后 -> 优惠 |

## 创意实践

- 让卡片 1 成为强钩子。
- 卡片设计保持一致。
- 使用简短、易读的文字。
- 每张卡片聚焦一个想法。
- 用视觉连续性鼓励滑动。
- 每张落地页匹配卡片承诺。

## 常见错误

- 把轮播当作随机图片堆放。
- 混用不相关的宽高比。
- 使用极小文字。
- 所有卡片重复同一个想法。
- 明明可以用特定落地页，却把所有卡片都送到通用落地页。

## 诊断

| 症状 | 可能原因 | 应对 |
|---|---|---|
| 卡片 1 有展示但互动少 | 首卡弱 | 把卡片 1 做成清晰的问题、主打产品或承诺 |
| 后续卡片被忽略 | 没有滑动理由 | 加入序列逻辑：问题 -> 证据 -> 优惠 |
| 点击质量弱 | 落地页通用 | 在可用处使用卡片专属 URL |

## 运营节奏

- 复盘卡片层级表现，而不只看整条广告的 CTR。
- 当叙事仍成立时，替换弱卡片而不丢弃整个结构。
- 上传前先统一宽高比。
