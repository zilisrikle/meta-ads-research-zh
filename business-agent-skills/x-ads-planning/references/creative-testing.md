# 创意测试（Creative Testing）

在规划 X Ads 创意测试、刷新节奏或消息实验时，使用本参考文档。

## 测试原则

- 一次测试一个主要学习点：信息、受众假设、格式、offer、视觉或落地页。
- 先做好 X 原生帖子功课，再测微观变体。
- 保持广告组可读。如果多个受众和创意混在一起，结果无法解释是什么起了作用。
- 把回复（而不只是指标）当作创意研究。
- 不要因为一天的噪音就暂停或重建。

## 帖子数量

X 官方优化指南建议每个广告系列放多条帖子，并称排名更高的帖子会获得更多投放。建议每个广告系列至少 **3 条帖子**，一个广告系列不超过 **7-10 条**。

实用姿态：

| 情形 | 创意数量 |
|---|---|
| 小测试 | 3 条有实质差异的帖子 |
| 常规发布 | 3-5 条帖子，钩子/角度各异 |
| 更大测试 | 仅在预算和受众规模能让每条都有读数时，才用 7-10 条 |
| 再营销 | 帖子更少、刷新更勤；关注频次和回复 |

避免用近乎相同的帖子塞满广告系列。

## 测试类型

| 测试 | 好的设计 | 坏的设计 |
|---|---|---|
| 信息角度 | 同一受众，不同主张/证据 | 受众、出价、创意、落地页全不同 |
| 钩子行 | 同一 offer/视觉，不同第一行 | 只改标点的微调 |
| 格式 | 文字 vs 图片 vs 视频 vs 竖视频 | 换格式的同时换 offer 和受众 |
| 受众假设 | 关键词 vs 粉丝相似 vs 对话 | 把所有定向类型叠在一起 |
| 创作者/账号 | 在工作流允许处用创始人/创作者/品牌账号 | 假定某一种身份永远赢 |
| 落地页 | 同一帖子到页面 vs 卡片/落地页变体 | 同时改定向和创意 |

## 刷新信号

使用账号本地基线。实用的排查触发点：

- CTR 相对帖子早期稳定期明显下跌。
- 落地页或应用转化率不变，但 CPA/CPL/CPI 上升。
- 回复情感转负或重复。
- 小再营销或自定义受众（Custom Audience）池中频次上升。
- 一条帖子吃掉大部分展示，其余帖子从未获得有意义读数。
- CPM 在没有预算或市场解释的情况下跳升；审计创意质量、品牌安全和美学分（Aesthetic Score）指南。

## 概念 vs 变体

| 层级 | 示例 |
|---|---|
| 概念（Concept） | 创始人观点 vs 客户证据 vs 竞品替代 |
| 钩子（Hook） | 第一行或第一帧 |
| 证据（Proof） | 引用、数据、演示、截图、评价、案例结果 |
| 变体（Variant） | 裁剪、标题、CTA、结尾卡、文案微调 |

在 X 上，文案变体可能比在更视觉化的平台上更重要，但仍需要真实的信息差异。

## 决策规则

- 转化广告系列用 3-7 天滚动读数，除非投放出问题。
- 追踪、拒审或落地页问题立即修。
- 在投放量和搜索/关键词数据足够之前，不要评判关键词广告系列。
- CTR 弱，先诊断第一行、视觉和受众语境。
- CTR 健康但 CVR 弱，诊断落地页、offer、事件和线索/订单质量。
- 互动强但业务结果弱，广告可能只引发了对话而没有创造需求。
