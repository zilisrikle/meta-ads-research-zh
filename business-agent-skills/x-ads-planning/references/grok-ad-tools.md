# Grok 与 xAI 广告工具

本参考用于规划 AI 辅助的 X 创意或账户运营。将这些工具视为持续演进的界面，并在账户中核验当前可用性。

## 当前用途

| 工具 / 能力 | 用途 | 规划注意事项 |
|---|---|---|
| Prefill with Grok | 根据 URL 生成广告文案、图片和 CTA 创意 | 已报道上线；核验账户权限 |
| Analyze Campaign with Grok | 获取 AI 辅助的系列表现总结 | 仅作分析辅助，不作权威报告来源 |
| xAI Imagine API 广告生成 | 从产品照片和提示词生成可投放的图片或视频 | xAI 官方 API 界面；需要单独的接入/实现 |
| 生成式受众定向 | 用自然语言描述理想客户 | 视为测试/演进中功能；核验可用性 |
| Grok 回答中的广告 | 新兴或已公布的广告位概念 | 除非账户权限确认，否则不要作为标准库存规划 |

## 创意工作流

用 AI 工具基于人工策略产出变体：

1. 定义受众、痛点、权益、证据和期望动作。
2. 生成多个概念方向，而不只是文案变体。
3. 检查每份产出的政策合规、事实主张、品牌语气和视觉质量。
4. 适配 X 规范与美学评分（Aesthetic Score）指引。
5. 上线前在 X Ads Manager 预览中验证。

不要让 AI 生成的创意取代定位。通用 AI 产出会加剧同质化和疲劳。

## 适用场景

- 产品背景变体。
- 钩子（Hook）探索。
- CTA/标题选项。
- 用于利益相关方评审的快速概念看板。
- 经母语者审校的本地化初稿。
- 人工诊断前的系列表现总结。

## 风险

- 无依据或夸大的主张。
- 视觉风格同质化。
- 生成图片中的文字伪影。
- 受管类目的政策问题。
- 生成广告与落地页、实际产品不一致。
