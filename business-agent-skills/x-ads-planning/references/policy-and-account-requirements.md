# 政策与账户要求（Policy and Account Requirements）

在为受管类目、高端产品或资格不明的账户推荐 X Ads 前使用本参考。

政策来源：X 广告政策（https://business.x.com/en/help/ads-policies）、议题导向广告政策（https://business.x.com/en/help/ads-policies/ads-content-policies/cause-based-advertising.html）、住房/借贷/信贷机会政策（https://business.x.com/en/help/ads-policies/campaign-considerations/housing-lending-and-employment-opportunities）、医疗健康政策（https://business.x.com/en/help/ads-policies/ads-content-policies/healthcare）与系列定向文档（https://business.x.com/en/help/campaign-setup/campaign-targeting）。最后核验：2026-04。

## 账户资格

X 账户和广告在推广前及推广期间都需接受审核。上线前确认：

- 广告账户具备资格、有资金，且未处于审核/清退状态。
- 品牌账号适合该系列，并有足够的资料可信度。
- 若账户、产品或托管工作流要求，需具备 Verified Organizations 或 X Premium 状态。
- 域名、落地页、应用商店页面、产品目录和披露信息与推广主张一致。
- 托管产品在纳入计划前已确认具备 X 客户团队、X Next 或支持渠道。

不要将 Verified Organizations 或 X Premium 表述为所有 X Ads 的普遍要求。将其视为可信度/资格输入，在托管、品牌或敏感工作流中可能更重要。

## 受限与敏感类目

X 的受限类目可能要求遵守各国规则、强制警告、预先授权或系列限制。

| 类目 | 规划规则 |
|---|---|
| 住房、借贷与信贷机会 | 美国/加拿大广告主必须获得认证，且不得使用年龄、语言、性别、受保护特征或邮编级精确定位等被禁止的定向 |
| 议题导向广告（Cause-Based Advertising） | 要求广告主认证和定向限制；美国以外地区，地理仅限州/省/地区级及以上，且只允许地理、关键词和兴趣定向 |
| 医疗健康与药品 | 按国家逐一确认资格；除非明确允许，许多产品需要预先授权或被禁止 |
| 金融产品与服务 | 规划前先核验各国规则、披露要求、定向限制和预先授权 |
| 酒精、博彩、成人、烟草、药品、政治内容 | 在当前 X 政策和当地法律确认资格前，一律视为受限或禁止 |
| 敏感类目定向 | 不得超出 X 政策允许范围定向或推断敏感属性 |

若系列涉及上述类目，在选择目标、定向、创意或主张前，先核对当前确切的 X 政策页面和当地法律。

## 政策规划清单

| 检查项 | 重要性 |
|---|---|
| 类目分类 | 决定系列是被禁止、受限还是需要预先授权 |
| 市场与语言 | X 政策可能因国家和当地法律而异 |
| 定向限制 | 某些类目会移除或限制受众功能 |
| 主张与证据 | 医疗、金融、就业和议题导向主张需要证据和披露 |
| 落地页合规 | X 审核目标页面，而不仅是广告 |
| 审批时间 | 预先授权和托管审批可能打乱上线排期 |

## 安全撰写计划的方法

- 明确写出政策假设。
- 对受限类目使用"上线前核验当前 X 政策/账户资格"。
- 避免为敏感或受管类目推荐微观定向。
- 不要建议绕过政策限制的变通方法。
- 紧急上线时，将政策审核作为时间线中的前置任务。
