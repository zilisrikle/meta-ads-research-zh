# 创意策略（Creative Strategy）

当用户需要实用的 X Ads 创意方向（而不只是规格）时，使用本参考文档。X 创意应该像一条有明确商业任务的强原生帖子，而不是把展示横幅或 Meta/TikTok 素材直接丢进 X。

## 第一性原理

- X 以文字为先、对话驱动。第一行往往和图片或视频同样重要。
- 做 **X 帖子，而不是广告**：简洁、有人味、直接、及时、清晰。
- 一条帖子讲一个信息。不要把多个 offer、受众和 CTA 堆进一条广告。
- 避免普通广告文案的跳出点：话题标签、裸 URL、@提及、emoji 堆砌和多个 CTA。
- 在可用时用卡片（Cards）做直接回应，让落地页活在卡片里，而不是以裸 URL 出现在正文。
- 把回复当作广告体验的一部分。回复能揭示异议、情感、品牌安全风险和下一轮钩子。

## 原生文案模式

| 模式 | 适用 | 说明 |
|---|---|---|
| 单行钩子 | 快速抓住信息流注意力 | 钩子放在第 1 行；不要把重点埋在截断线以下 |
| 钩子 / 空行 / 落点 | B2B、SaaS、线索生成 | 呼应强原生 X 帖子的结构 |
| 反共识观点 | 创始人、创作者、B2B、金融、科技 | 需要证据；避免空洞的噱头观点 |
| 引用/证言视觉 | 证据和信任 | 用作静态图或视觉装置；核实版权 |
| 回复式异议 | 再营销和教育 | 回答来自回复、客服、销售或评价的真实异议 |
| 帖串式教育 | 复杂 SaaS/B2B 或报告 | 当 offer 需要解释且账号有权威感时使用 |

## 格式姿态

| 格式 | 创意姿态 |
|---|---|
| Text Ads | 最适合 B2B、创始人/创作者观点、思想领导力和快速消息测试 |
| Image Ads | 适合一个想法、一个 offer、一个视觉证据点 |
| Video Ads | 产品演示、讲解、证言、发布故事 |
| Vertical Video Ads | 全屏、开声、9:16 优先的叙事；不只是裁剪过的信息流广告 |
| Carousel / Collection | 产品集、对比、序列、多步讲解 |
| DPA | 目录个性化的产品提醒或发现 |
| 优质 / 托管式 | 一条锐利的发布或文化信息，配后续漏斗 |

## 美学与质量姿态

把美学分（Aesthetic Score）指南当作 QA 过滤器，而不是保证可见的 KPI：

- 当卡片能承载落地页时，正文不要放裸 URL。
- 普通付费文案中不要用话题标签，除非托管式产品要求。
- emoji 极简；默认一个或零个。
- 语法、大小写、裁剪和视觉清晰度干净。
- 全幅、易读、高质量媒体。
- 避免在信息流中难读的截图或密集叠加。

## 视频与竖视频

- 标准信息流视频，15 秒或更短是实用默认，除非 offer 真的需要更长讲解。
- 竖视频广告（Vertical Video Ads）按 9:16 构建，开声、前三秒冲击、字幕和安全框构图。
- CTA 按钮的行为和位置因版位而异；不要只依赖原生按钮。在文案或结尾帧中强化 CTA。
- 在 X 上使用前，先重剪 TikTok/Reels/Shorts 素材。去掉平台水印和趋势特定的语境。

## 创作者、创始人与品牌账号

账号本身是创意的一部分。对 X 而言，品牌账号 vs 创作者/创始人账号是战略选择：

| 账号类型 | 好的用法 | 注意点 |
|---|---|---|
| 品牌账号 | 官方发布、产品公告、受监管声明、品牌资产 | 没有强原生历史时会感觉像广告 |
| 创始人/运营者账号 | B2B、SaaS、专家观点、思想领导力 | 需要可信度和持续的原生存在 |
| 创作者/发布者账号 | 文化、媒体、创作者主导的证据、Amplify 工作流 | 需要版权、披露和账号/工作流资格 |

从业者共识倾向于在可信时使用创作者/创始人式证据，但对受监管或官方声明不要硬套。

## 回复挖掘

每周阅读推广帖的回复：

- 正面回复变成证据语言。
- 异议变成下一轮钩子。
- 困惑揭示信息错配。
- 敌意或政治化回复可能预示品牌安全或版位风险。
- 反复出现的"看太多次了"类回复，可能在 CPA 完全走坏之前就预示疲劳。

## 应避免的做法

- 把 X 当 Meta 或 TikTok，用同样的创意和文案。
- 在业务需要线索、安装、销售或合格流量时，却优化向互动。
- 因为旧 Twitter 指南推荐过就用话题标签。
- 写得像新闻稿的广告文案。
- 只用互动量评判创意；回复质量和下游行为同样重要。
