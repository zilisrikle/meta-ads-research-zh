# 品牌话题标签与品牌化功能（Branded Hashtags and Branded Features）

Branded Hashtags 让广告主能够为话题标签在 X 上添加视觉上独特的品牌化元素。当前官方 X 广告格式页面仍列有 Branded Hashtags，而公开报道表明付费广告文案中的普通话题标签已受限制。请将托管式 Branded Hashtags 视为经 X 批准的独立产品，而不是在标准推广帖中添加话题标签的许可。

规格来源：X 创意广告规范（https://business.x.com/en/help/campaign-setup/creative-ad-specifications）。最后核实：2026-04。

## 可用性

Branded Hashtags 通常是托管式服务产品，可能需要 X 批准。请与 X 确认当前资格、市场、日期、创意要求和定价。

相关的托管式品牌化功能可能包括 Hashmoji、Hashfetti、Custom Likes / Branded Likes 或其他经 X 批准的视觉元素。在将其作为可用产品呈现之前，请先与 X 核实现品名称和市场。

## 适用场景

- 品牌发布。
- 娱乐和体育时刻。
- 粉丝参与活动。
- 产品投放。
- 社交挑战或社群活动。
- 事件对话中心。

## 话题标签设计

| 原则 | 指南 |
|---|---|
| 简短 | 易于输入和记忆 |
| 清晰 | 含义一目了然 |
| 品牌关联 | 与品牌、广告系列或时刻相关联 |
| 安全 | 避免歧义、负面解读或被劫持风险 |
| 全球适用 | 如跨市场投放，需检查语言和文化含义 |

当前已收录的 X 官方 Branded Hashtags 规格包括：

- 一个表情符号最多可关联 5 个话题标签。
- 理想话题标签在过去 30 天内于 X 上的提及数不应超过 250 次，除非与品牌对话直接相关；当前已收录的 X 规格采用 >70% 品牌对话占比阈值。
- 表情设计为 72x72 像素，在 16x16 下仍清晰可见。
- 必须在浅色和深色背景下都可用。
- 设计简洁；避免多个缩小后无法分辨的面孔/Logo。

## 创意实践

- 将话题标签作为广告系列的对话锚点。
- 搭配推广广告（Promoted Ads）解释参与理由。
- 普通推广广告文案中不要使用话题标签，除非托管式品牌化功能的工作流程要求如此。
- 在相关时借助创作者、发布者、事件或社群支持。
- 准备社群管理与回复指南。

## 衡量

| 指标 | 用途 |
|---|---|
| 话题标签使用量 | 参与量 |
| 触达和展示 | 对话规模 |
| 互动 | 参与质量 |
| 情感 / 内容审查 | 品牌安全与共鸣 |
| 下游流量或转化 | 业务效果 |

## 常见错误

- 话题标签太长。
- 话题标签巧妙但含义不清。
- 没有参与引导。
- 没有审核计划。
- 在没有下游衡量的情况下，把话题标签量等同于业务影响。
