# 时间线接管（Timeline Takeover）

Timeline Takeover 是高端 X 接管（Takeover）产品，当用户打开 X 时，将品牌广告作为当日第一条广告置于对话顶部。

规范来源：X 广告形式（https://business.x.com/en/advertising/formats）与 X 接管指引。最后核验：2026-04。

## 可用性

Timeline Takeover 是托管式高端广告位。在将其作为最终方案推荐前，先与 X 确认可用性、市场、日期、资格、定价、创意规范和审批时间线。

## 最佳用途

- 重大发布。
- 大型事件。
- 娱乐内容上线。
- 国家或全球级品牌时刻。
- 单日触达最大化至关重要的系列。

## 规划输入

| 输入 | 重要性 |
|---|---|
| 发布日期 / 投放日期 | 库存具有时效性 |
| 市场 | 可用性与成本因市场而异 |
| 创意素材 | 必须提前准备并获批 |
| 落地目标页 | 高触达会迅速暴露薄弱的目标页 |
| 度量 | 需要触达、品牌和下游成功标准 |

## 创意指引

- 使用简单、高冲击的信息。
- 品牌线索和权益/事件必须即刻清晰。
- 避免密集文案。
- 接管创意与系列其余部分匹配，让后续广告感觉连贯。

## 度量

| KPI | 用途 |
|---|---|
| 触达与频次 | 主要投放读数 |
| CPM | 成本效率 |
| 互动与视频指标 | 创意共鸣 |
| 搜索/直接访问/网站提升 | 需求信号 |
| 转化或收入 | 除非系列明确为效果导向，否则为次要 |

## 规划与成本核查

接管定价和最低消费因市场、日期、库存和打包方案而异。不要写死价格。向 X 索取：

- 最低花费、预订规则和市场/日期可用性。
- 购买是否包含配套推广广告或其他广告位。
- 创意审批时间线与备用创意要求。
- 报告粒度和提升研究可用性。

## 诊断

| 症状 | 可能原因 | 应对 |
|---|---|---|
| 触达达标但提升弱 | 创意缺少令人记住的权益或由头 | 强化发布信息与配套媒体 |
| 利益相关方用 CPA 评判 | KPI 框架错误 | 前置设定触达/提升/直接访问/搜索 KPI |
| 审批延迟 | 高端创意提交不够早 | 在时间线中预留审批缓冲 |
