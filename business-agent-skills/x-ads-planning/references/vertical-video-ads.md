# 竖屏视频广告（Vertical Video Ads）

竖屏视频广告（Vertical Video Ads）是 X 沉浸式媒体查看器（Immersive Media Viewer）及相关竖屏视频场景中的全屏、有声视频广告。

规范来源：X 竖屏视频广告产品页（https://business.x.com/en/products/vertical-video-ads）与创意广告规范（https://business.x.com/en/help/campaign-setup/creative-ad-specifications）。最后核验：2026-04。

## 规范

| 项目 | 指引 |
|---|---|
| 推荐宽高比 | 9:16 |
| 最大分辨率 | 1080x1920 |
| 最小分辨率 | 720x1280 |
| 推荐时长 | 15 秒以内 |
| 支持时长 | 视可用情况最长 2:20 |
| 最大帧率 | 60 fps |
| 视频编码 | H.264，Baseline/Main/High Profile，4:2:0 色彩空间 |
| 音频编码 | AAC LC |
| 音频行为 | 有声环境；仍应让广告在无声时也能看懂 |

在 X Ads Manager 中核验当前可用性、规范和广告位预览。

## 最佳用途

- 移动优先的认知。
- 快节奏的产品演示。
- 创作者风格叙事。
- 应用导览。
- 发布、事件与文化时刻。

X 将竖屏视频广告定位在沉浸式媒体查看器周边，并称用户每日有可观时长停留于此。将其作为移动优先的注意力形式，而不只是信息流视频的裁剪版。

## 创意实践

- 有意图地填满竖屏画面。
- 第一秒即出钩子。
- 使用大字幕和高对比文字。
- 尽早露出产品或品牌线索。
- 有意图地使用声音，但保证无声也能看懂。
- 把 CTA 放在安全的中央区域。
- 如使用网站/应用 CTA 按钮，按观看 1 秒后自动出现的逻辑规划。
- 不要直接复用横屏或方形信息流版本而不为沉浸式媒体查看器重做开头、安全区和有声节奏。
- 预算允许时将 X 竖屏场景作为独立测试；否则混合的信息流/视频结果会掩盖广告位特定学习。

## 结构

```text
0-1 秒：钩子
1-5 秒：产品或故事铺垫
5-12 秒：证明、演示或高潮
最后几秒：CTA
```

## 度量

| 目标 | 读数 |
|---|---|
| 认知 | 触达、CPM、观看率 |
| 互动 | 互动率、关注、转发、点赞 |
| 流量 | CTR、CPC、落地页行为 |
| 转化 | CPA、ROAS、点击后质量 |

## 常见错误

- 横屏视频直接裁剪而不重新设计。
- 文字离 UI 区域太近。
- 首帧节奏慢。
- 前几秒后没有明确 CTA。

## 诊断

| 症状 | 可能原因 | 应对 |
|---|---|---|
| 留存低 | 钩子不即时或非竖屏原生 | 为 0-1 秒注意力和全屏构图重剪 |
| 无点击 | CTA/产品出现太晚 | 在 1 秒 CTA 按钮出现前引入产品与 CTA 逻辑 |
| 看起来被裁剪或杂乱 | 复用横屏素材未重新设计 | 为 9:16 重建安全区布局 |

## 运营节奏

- 上线前检查手机预览。
- 将首帧概念与权益/CTA 概念分开测试。
- 留存下降时快速刷新；竖屏库存对陈旧开头惩罚严重。
