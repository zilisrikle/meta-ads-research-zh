# 预算规划（Budget Planning）

使用本参考文档核查拟定的 X Ads 结构是否能产生足够可用的信号。

## 预算原则

- 预算应跟着业务结果走，而不是跟着可用格式的数量走。
- 预算小时，保持初始结构窄。
- 除非每个切分都能分到足够学习的预算，否则不要按受众、关键词、地域、版位、创意做大量切分。
- 用目标行为衡量预算是否充足：CPA、CPL（线索成本）、购买量、合格线索量或观看质量。
- 优质版位和托管式产品需要与 X 单独确认可用性和最低花费。
- 不要把通用的 CPM/CPC/CPA/CPV/CPI 基准写死。用近期账号数据、当前 X 预测和特定市场的外部基准作为规划输入。

## 信号可行性

| 目标 | 最低可行性检查 |
|---|---|
| 网站转化 / 销售 | 在复盘窗口内，预算能否产生足够的转化事件来判断 CPA/ROAS？ |
| 线索生成 | 预算能否产生足够的合格线索，而不只是表单填写？ |
| 应用安装 | MMP 追踪是否已配置，CPI 能否支撑有意义的安装量？ |
| 应用再互动 | 可再营销的应用受众是否够大，下游事件是否已追踪？ |
| DPA（动态产品广告） | 目录事件与产品 ID 是否可靠匹配？ |
| 认知/视频 | 触达/频次是否大到足以给出有意义的结论？ |

如果答案是否定的，就收窄结构，或暂时优化向更高量的过渡信号（interim signal）。

从业者的经验法则是：每个广告组每周大约 15-25 个有意义事件，作为转化学习的下限。把它当作规划检查项，而不是平台定律。如果预算达不到这个量级，就合并结构，或暂时优化向更高量的代理指标（proxy）。

## 规划计算

在提出结构之前先做这些计算：

| 问题 | 计算 |
|---|---|
| 转化优化能学起来吗？ | 月预算 / 目标 CPA = 预期转化数 |
| 广告系列切分太碎吗？ | 预期转化数 / 广告组数 = 每个广告组的信号 |
| 流量够吗？ | 预算 / 预期 CPC = 点击数；点击数 x 落地页 CVR = 转化数 |
| 应用预算可行吗？ | 预算 / 预期 CPI = 安装数；安装数 x 激活率 = 有意义事件数 |
| 视频预算可行吗？ | 预算 / 预期 CPV = 观看数；观看数 x 合格观看率 = 可用注意力 |

如果预期转化或合格事件太少，就合并广告组、暂时使用更高量的过渡事件，或缩小测试范围。

## 基准的使用

基准只适合做粗略的量级检查。

| 指标 | 用法 |
|---|---|
| CPM | 估算触达和认知可行性；根据市场、季节、品牌安全和优质库存调整 |
| CPC | 估算流量规模；根据目标、创意、受众和落地页相关性调整 |
| CPV | 估算视频规模；根据视频时长、版位和观看定义调整 |
| CPI | 估算应用安装量；与 MMP 和下游激活对账 |
| CPA / ROAS | 只有在明确事件质量、归因窗口、利润和新老客拆分之后再用 |

当用户问预算是否可行时，请索取或估算本地基准区间，展示计算过程，并标明假设。不要把基准区间当作承诺呈现。

## 按月预算的结构

这些是规划区间，不是平台规则。根据市场 CPM/CPC/CPA 和品类经济性调整。

| 月预算 | 可行结构 |
|---|---|
| 小 | 1 个广告系列，1-2 个广告组，2-4 个差异化创意。聚焦一个目标。 |
| 中 | 2-3 个广告系列或角色：拉新、再营销、创意/关键词测试。 |
| 大 | 全漏斗结构，受控测试，DPA/目录，在合理处使用应用或优质版位。 |
| 托管 / 发布爆发 | 为 Takeover、Amplify Sponsorship、X Live、Branded Notifications 或 Branded Hashtags 单独做媒体计划。 |

预算非常小时，不要同时测试关键词、粉丝相似（follower look-alike）、对话定向、DPA、再营销和多种格式。选定一个受众假设和几条强帖子。

## 优质与托管产品的成本核查

Timeline Takeover、Spotlight Takeover、Amplify Sponsorship、X Live、Branded Notifications 和 Branded Hashtags 可能有特定市场的最低花费、预订规则、第三方工具成本或捆绑媒体要求。除非 X 针对确切市场和日期给出当前报价，否则不要写死最低花费金额。

请向 X 或托管式服务合作伙伴索取：

- 最低花费、套餐组成，以及是否需要配套媒体。
- 预订窗口、取消条款和补偿政策（makegood policy）。
- 创意审批截止日期和备用素材要求。
- 报告字段、提升研究（lift-study）可用性和投放后交付时间。
- 第三方设置成本，如 Branded Notifications 的 Arrow。

## 预算分配起点

| 业务模式 | 起始分配 |
|---|---|
| 电商 | 60-80% 拉新/转化，10-25% 再营销/DPA，10-20% 创意测试 |
| 线索生成 | 50-70% 拉新/意图，15-30% 再营销，10-20% 测试 |
| 应用 | 70-90% 安装或事件获客，10-30% 再互动（如受众存在） |
| 品牌 | 70-90% 触达/视频/优质版位，10-30% 互动或再营销跟进 |
| 事件 | 40-60% 事件前，20-40% 直播中，10-30% 事件后跟进 |

根据实际转化质量调整，而不是只看便宜的平台结果。

## 变更纪律

- 在转化延迟充分过去之前，不要评判一个转化广告系列。
- 批量进行预算和出价变更；避免同时改预算、定向、创意和事件定义。
- 逐步加预算，除非广告系列明显预算不足或绑定了固定事件日期。一个保守的从业者做法是每隔几天 +15-20%，然后观察投放、 CPA/ROAS、频次和创意疲劳。
- 保留变更日志：日期、广告系列/广告组、变更内容、原因和预期观察窗口。

在 X 上，横向扩量通常比激进的纵向加预算更安全：复制一条已验证的广告组，只改一个真实输入，如受众主题、地域、创意概念或设备/操作系统，而不是大幅提高一个预算。
