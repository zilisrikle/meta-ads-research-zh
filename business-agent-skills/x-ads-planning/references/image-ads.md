# 图片广告（Image Ads）

图片广告（Image Ads）是推广广告（Promoted Ads），将一张图片与帖子文案结合，并可搭配可选的 X 广告功能，如网站卡片（Website Cards）、应用卡片（App Cards）、对话按钮（Conversation Buttons）或投票（Polls）。

规范来源：X 创意广告规范（https://business.x.com/en/help/campaign-setup/creative-ad-specifications）与 2026 年宽高比公告（https://business.x.com/en/blog/x-expands-aspect-ratio-support-for-ad-creatives.html）。最后核验：2026-04。

## 规范

| 项目 | 指引 |
|---|---|
| 推荐格式 | PNG 或 JPEG。除非当前账户规范明确列出，否则不要默认支持 WebP。 |
| 文件大小 | 最大 5 MB |
| GIF 行为 | 在当前官方规范中，上传到图片广告的 GIF 渲染为静态图片 |
| 常见宽高比 | 1:1、1.91:1、4:5、2:3、16:9、9:16（视支持情况） |
| 常用尺寸 | 1080x1080、2064x1080、1440x1800、1080x1620、1920x1080、1080x1920 |
| 文案 | 最多 280 字符；链接会占用文案长度 |

2026 年 X 扩展了宽高比支持，广告主可免重新制作直接复用其他社交平台的创意。将 4:5 和 2:3 视为实用的跨平台选项，但上线前先核验所选广告位和创意预览。

## 功能变体

| 变体 | 用途 |
|---|---|
| 独立图片广告 | 品牌信息、产品证明、公告 |
| 网站卡片（Website Card） | 引流至落地页 |
| 应用卡片（App Card） | 推动应用安装或打开 |
| 对话按钮（Conversation Button） | 鼓励用户发布带预填文本或话题标签的帖子 |
| 投票（Poll） | 轻量互动与受众反馈 |

对话按钮和投票可能需要使用当前支持的创作器/工作流，而非普通帖子创作器。在将其作为自助功能推荐前先核验可用性。

## 创意实践

- 让一个视觉焦点显而易见。
- 图片文字叠加尽量少，且在手机上清晰可读。
- 使用高对比度图片，在信息流中脱颖而出。
- 快速展示产品、效果、证明或使用场景。
- 重要内容远离边缘，因为裁剪可能各不相同。
- 图片、文案、卡片标题与落地页保持一致。
- 普通推广文案中不要加话题标签，除非所选 X 功能明确要求。

## 文案实践

用文案解释视觉为何重要。

```text
钩子：为什么用户应该在意
利益/证明：改变了什么、为什么可信
CTA：下一步做什么
```

## 漏斗应用

| 漏斗阶段 | 作用 |
|---|---|
| 认知（Awareness） | 品牌/产品介绍 |
| 考虑（Consideration） | 证明、对比、功能教育 |
| 转化（Conversion） | 权益、产品细节、落地页点击 |
| 再营销（Retargeting） | 提醒、异议处理、激励 |

## 常见错误

- 图片中文字过多。
- 多个产品或信息争夺注意力。
- 通用的图库照片。
- 广告与落地页的信息匹配弱。
- 素材分辨率低或压缩过度。

## 诊断

| 症状 | 可能原因 | 应对 |
|---|---|---|
| CTR 低 | 视觉焦点弱或第一眼信息不清 | 围绕一个产品、证明点或效果重做 |
| CTR 高、CVR 低 | 图片承诺与落地页不符 | 对齐图片、文案、卡片标题和目标页面 |
| 投放受限 | 政策问题、低质量或受限类目 | 检查政策/账户要求与创意质检 |

## 运营节奏

- 上线前及每次调整宽高比后检查预览/裁剪。
- 当 CTR 或 CPE 相对系列近期基线恶化时刷新。
- 保留胜出概念并轮换新视觉；不要只改颜色或微调文案。
