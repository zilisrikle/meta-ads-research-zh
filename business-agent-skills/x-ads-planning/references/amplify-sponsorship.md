# Amplify 赞助（Amplify Sponsorship）

Amplify Sponsorship 提供在指定时刻与发布者的一对一配对，在广告系列投放期间拥有帖子层级的控制。

规格来源：X 创意广告规范（https://business.x.com/en/help/campaign-setup/creative-ad-specifications）及托管式产品文档。最后核实：2026-04。

## 可用性

Amplify Sponsorship 通常是托管式服务（managed-service）产品，自助投放的广告主可能无法使用。请与 X 确认可用性、库存、日期、发布者匹配度和最低花费。

## 适用场景

- 体育、娱乐、新闻、文化事件和重要时刻。
- 品牌认知，以及与优质内容建立关联。
- 需要高信任媒体语境的产品发布。
- 独家性和一致性比廉价触达更重要的广告系列。

## 规划输入

| 输入 | 为什么重要 |
|---|---|
| 发布者 / 内容合作伙伴 | 决定语境匹配度和品牌安全 |
| 时刻或投放日期 | 赞助价值取决于时机 |
| 创意素材 | 必须适配视频语境和品牌关联 |
| 衡量计划 | 品牌提升（lift）、触达、频次、观看质量和下游影响 |
| 审批流程 | 发布者和 X 的审批可能影响时间安排 |

## 创意指南

| 要素 | 指南 |
|---|---|
| 文件类型 | MP4 或 MOV |
| 文件大小 | 最大 1 GB |
| 时长 | 建议 6 秒或更短；最长 2:20 |
| 宽高比 | 建议 16:9 或 1:1，取决于发布者内容 |
| 尺寸 | 建议 1200x1200；1:1 最低 600x600 |
| 裁剪 | 若高度超过宽度，视频在信息流中可裁剪为 1:1 |

- 品牌线索（brand cue）要尽早明确。
- 语气与发布者及内容时刻保持一致。
- 避免通用型广告片，避免到哪里都能播的素材。
- 使用简单信息，确保在视频内容前后能被快速理解。

## 衡量

使用触达、频次、视频观看质量、可用时的品牌提升、搜索/直接访问提升，以及下游的网站或转化信号。不要仅凭末次点击 CPA 来评判赞助。

## 规划与成本核查

除非 X 针对具体市场和日期给出当前报价，否则不要在计划中写死最低花费金额。请向 X 索取：

- 最低花费、预订窗口、取消条款和补偿政策（makegood policy）。
- 发布者/内容包、独家性和品牌安全控制。
- 审批截止日期和素材交付要求。
- 投放期间及投放后可用的报告字段。

## 诊断

| 症状 | 可能原因 | 应对 |
|---|---|---|
| 触达强但回忆弱 | 创意通用或品牌线索弱 | 把品牌/产品的作用提前 |
| 互动波动 | 发布者时刻错配 | 重新核查内容一致性和受众预期 |
| 利益相关方期望 CPA | 赞助目标被误框定 | 购买前先设定触达/提升/语境类 KPI |
