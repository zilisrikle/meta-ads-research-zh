# 视频广告（Video Ads）

视频广告（Video Ads）是推广广告（Promoted Ads），用视频演示、讲解、娱乐或建立信任。

规范来源：X 创意广告规范（https://business.x.com/en/help/campaign-setup/creative-ad-specifications）与 2026 年宽高比公告（https://business.x.com/en/blog/x-expands-aspect-ratio-support-for-ad-creatives.html）。最后核验：2026-04。

## 规范

| 项目 | 指引 |
|---|---|
| 文件类型 | MP4 或 MOV |
| 常见宽高比 | 1:1、16:9、9:16、4:5、2:3（视支持情况） |
| 文件大小 | 最大 1 GB；强烈建议 30 MB 以内 |
| 推荐短视频时长 | 信息流视频广告 15 秒或更短 |
| 最长时长 | 支持最长 2:20；部分广告主可申请最长 10 分钟 |
| 帧率 | 推荐 29.97 或 30 FPS；支持最高 60 FPS |
| 码率 | 1080p 用 6,000-10,000k；720p 用 5,000-8,000k |
| 视频编码 | H.264 Baseline/Main/High Profile，4:2:0 色彩空间 |
| 音频编码 | AAC LC |
| 循环 | 60 秒以内的视频可循环 |
| 音频 | 使用字幕或文字叠加，因为用户可能静音观看 |

2026 年 X 扩展了 4:5 和 2:3 支持以便跨平台创意复用。按广告位和购买路径核验当前 X 创意规范的确切上限。

## 最佳用途

- 产品演示。
- 创始人或客户故事。
- 前后对比或流程讲解。
- 事件推广。
- 应用导览。
- B2B 或 SaaS 教育。

## 结构

```text
0-2 秒：钩子或视觉打断
2-8 秒：产品、问题或证明
8-15 秒：利益点与 CTA
```

长视频可用于教育或高端广告位，但前几秒仍承担重任。

## 创意实践

- 尽早展示产品或效果。
- 默认使用字幕。
- 品牌露出可见但不突兀。
- 移动优先设计。
- CTA 与卡片或目标页面对齐。
- 避免缓慢的品牌片头。

## 指标

| 目标 | 主要读数 |
|---|---|
| 触达 | CPM、触达、频次 |
| 视频观看 | 观看率、CPV、完播率 |
| 网站流量 | CTR、CPC、落地页行为 |
| 网站转化 / 销售 | CPA、ROAS、转化质量 |

## 常见错误

- 以冗长的品牌动画开场。
- 只有开声音才能看懂。
- 业务需要转化却优化观看。
- 电视式剪辑未适配 X 时间线直接复用。

## 诊断

| 症状 | 可能原因 | 应对 |
|---|---|---|
| 观看率低 | 首帧慢或钩子弱 | 以产品、效果、冲突或动感开场 |
| 观看强、点击弱 | CTA 出现晚或信息只有认知价值 | 前置价值/权益提示并对齐卡片 CTA |
| CPV 高 | 受众/上下文不匹配或缩略图/开头弱 | 测试不同的前 2 秒与定向信号 |

## 运营节奏

- 首日投放读数可发现明显的钩子失败，但评判 CPA/ROAS 前要等足够花费。
- 疲劳的开头先换，整体概念后重建。
- 为每次测试记录钩子、证明、CTA、时长和宽高比。
