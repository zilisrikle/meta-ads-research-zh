# 业务模式打法手册（Business Model Playbooks）

在选择 X 广告目标或广告格式之前，先参考本文档。从业务模式出发，再选择支撑它的广告系列菜单项。

## 电商 / 零售

默认策略：

- 在购买追踪就绪时使用**网站转化 / 销售（Website conversions / Sales）**。
- 仅在 X Shopping Manager、feed 质量和产品事件就绪时使用**动态产品广告（Dynamic Product Ads，DPA）**。
- 当预算、报告或受众意图不同时，拆分拉新和再营销。
- 追踪购买价值、边际贡献、新老客户拆分和产品层级表现。
- 与没有 X 受众的通用常青 DTC（direct-to-consumer）相比，X 更适合利基/社群驱动的商业、再营销、产品投放和对话时机的优惠。

推荐结构：

| 角色 | 目标 / 格式 | 说明 |
|---|---|---|
| 拉新 | Website conversions / Sales，配合 Image、Video、Carousel 或 DPA Prospecting | 使用足够宽的受众和强有力的产品/品类钩子 |
| 再营销 | DPA Retargeting 或产品向 Carousel | 在可用处使用目录行为和网站受众 |
| 创意测试 | Image/Video/Carousel | 测试优惠、产品品类、证据和问题框定 |

不要只看平台 ROAS 来评判。当其他付费社交/搜索渠道也在投放时，X 可能过度归因品牌或再营销需求。

### 转化设计

| 层级 | 推荐设置 | 注意点 |
|---|---|---|
| 主事件 | 带价值的 Purchase（购买） | 收入 ROAS 可能掩盖利润、退货、折扣和存量客户偏差 |
| 目录信号 | Page View、Content View、Add to Cart、带产品 ID 的 Purchase | 产品 ID 必须与 X Shopping Manager 目录 ID 一致 |
| 业务读数 | 边际贡献、新客户占比、复购 | 只看平台 ROAS 会偏向再营销和低利润产品 |
| Feed 健康度 | 可用性、价格、促销价、图片 URL、产品集过滤器 | 坏的 feed 数据会破坏个性化和报告 |

设计说明：

- 当品类、利润、季节、库存或客户类型影响经济性时，按这些维度切分产品集。
- 把新老客户组合与整体 ROAS 分开监控。
- 只有在产品 feed 和事件质量可信之后，再用 DPA Prospecting。
- 如果品类在 X 上没有自然讨论，先小规模起步，与 Meta、Google、TikTok、邮件和搜索提升对比后再扩量。

## 线索生成

X 目前没有与 Meta Lead Ads 或 LinkedIn Lead Gen Forms 对等的原生线索表单目标。把线索生成当作网站转化问题来处理。

默认策略：

- 如果表单填写、合格线索或 CRM 阶段事件已埋点，使用**网站转化 / 销售（Website conversions / Sales）**。
- 仅在转化追踪未就绪或目标是内容消费时使用**网站流量（Website traffic）**。
- 使用**关键词广告（Keyword Ads）**、粉丝相似（follower look-alikes）、对话定向和再营销来塑造意图。
- 尽可能在 X Ads Manager 之外导入或对账合格线索质量。

推荐结构：

| 角色 | 目标 / 格式 | 说明 |
|---|---|---|
| 意图捕获 | Keywords 广告系列 / Search Ads | 文案匹配搜索或问题意图 |
| 拉新 | Image/Video/Carousel 到落地页 | 使用证据、痛点、结果和异议处理 |
| 再营销 | Image/Video/Carousel | 处理异议并推向转化 |

看线索质量，而不只看 CPL。便宜的线索会把投放训练向低意图的表单填写。

### 转化设计

| 层级 | 推荐设置 | 注意点 |
|---|---|---|
| 主事件 | 合格线索、已预约通话、申请或 CRM 阶段 | 原始表单提交会优化向低质量量级 |
| 过渡事件 | 表单提交或高意图落地页行为 | 仅在质量反馈可用前使用 |
| 业务读数 | 合格线索率、每合格线索成本、管道价值 | 只看 CPL 不够 |
| 落地页 | 快速移动端表单，带证据、筛选和明确下一步 | 摩擦太多杀量级；筛选太少伤质量 |

设计说明：

- 写能筛选用户的文案，而不只是吸引点击的文案。
- 用 CRM 阶段、销售接受率或通话结果来评判受众/创意质量。
- 保持线索磁石、表单和跟进速度一致。

## SaaS / B2B

默认策略：

- 把 X 用于品类对话、竞品/替代方案发现、创始人/思想领导力放大和再营销。
- 当量级支撑时，用**网站转化 / 销售（Website conversions / Sales）**投 demo、试用、注册或合格注册事件。
- 仅在下游追踪清晰时，用**网站流量（Website traffic）**投内容offer和教育。
- 谨慎使用关键词广告和粉丝相似；每个广告组匹配一个清晰的受众假设。

推荐结构：

| 角色 | 目标 / 格式 | 说明 |
|---|---|---|
| 品类意图 | Keywords 广告系列 / Search Ads | 问题、品类、竞品和对比词 |
| 教育 | Video、Image、Carousel | 展示问题、证据、工作流或差异化观点 |
| 再营销 | Image/Video/Carousel | 把网站访客或内容互动者推向试用/demo |

追踪管道质量和激活，而不只看试用/注册量。

### 转化设计

| 层级 | 推荐设置 | 注意点 |
|---|---|---|
| 主事件 | 合格 demo、已激活试用、销售合格注册 | 激活低时注册量可能很虚 |
| 过渡事件 | 定价页、内容下载、webinar 注册 | 这些是意图信号，不是收入 |
| 业务读数 | 管道、激活率、销售周期、ACV/LTV | X 可能助力了在别处成交的需求 |
| 定向读数 | 关键词簇、粉丝相似主题、再营销阶段 | 把所有 B2B 受众混在一起会掩盖信号 |

设计说明：

- 在产品搜索需求有限时，使用创始人/观点和品类对话角度。
- 把高意图关键词广告系列与宽泛的思想领导力放大分开。
- 用证据和异议处理再营销网站/内容互动者。
- 不要试图复刻 LinkedIn 的公司画像定向。X 更适合做关键词、粉丝相似、创始人/创作者分发和对话语境。

## 应用

默认策略：

- 在规划应用安装出价之前，先配置经批准的移动衡量合作伙伴（Mobile Measurement Partner，MMP）。
- 用**应用安装（App installs）**做获客，用**应用再互动（App re-engagements）**做存量用户。
- 仅在预算和衡量支持时，才拆分 iOS/Android 或主要地域。
- 一旦有意义的应用内事件量可用，就优化到安装之外。

推荐结构：

| 角色 | 目标 / 格式 | 说明 |
|---|---|---|
| 获客 | App installs，配合 Video、Vertical Video、Carousel、App Card | 前几秒展示应用 |
| 再互动 | App re-engagements，配合深链 | 使用功能、优惠或生命周期特定的消息 |
| 品牌光环 | Reach 或 Video views，并开启应用转化衡量 | 仅在上层漏斗价值可信时使用 |

### 转化设计

| 层级 | 推荐设置 | 注意点 |
|---|---|---|
| 主事件 | 应用内事件、订阅、购买、留存用户、LTV | 只看安装会优化向低价值用户 |
| 衡量 | 经批准的 MMP 加应用分析对账 | X 与 MMP 的归因可能不一致 |
| 业务读数 | CPI -> 激活 -> 留存 -> LTV | 便宜的 CPI 不等于增长 |
| 创意读数 | 前 1-3 秒、应用演示清晰度、CTA | 应用广告需要立即展示效用 |

## 品牌 / 发布

默认策略：

- 用**触达（Reach）**和**视频观看（Video views）**做广泛曝光。
- 以 Vertical Video Ads 和 Video Ads 为核心创意格式。
- 仅在广告系列有足够预算、时机和运营支持时，才考虑 Timeline Takeover、Spotlight Takeover、Amplify、Branded Hashtags 或 Branded Notifications。

推荐结构：

| 角色 | 目标 / 格式 | 说明 |
|---|---|---|
| 触达爆发 | Reach + Vertical Video / Takeover | 用于发布和文化时刻 |
| 叙事 | Video views + Video/Vertical Video | 优化观看质量，不只看便宜观看 |
| 对话 | Engagement + 符合资格的品牌化功能 | 需要社群管理和审核 |

尽可能使用提升（lift）、搜索/直接流量、品牌搜索、网站访问和定性对话复盘。

### 衡量设计

| 层级 | 推荐设置 | 注意点 |
|---|---|---|
| 主读数 | 触达、频次、视频观看质量、提升/代理需求指标 | 末次点击 CPA 会低估认知价值 |
| 次读数 | 搜索/直接访问提升、主页访问、网站访问、关注 | 这些是方向性指标，单独不能作为证明 |
| 质量读数 | 情感、回复质量、创作者/社群反馈 | 高互动可能是负面的 |
| 跟进 | 再营销、网站/应用 CTA、邮件/搜索捕获 | 发布爆发需要转化路径 |

## 直播 / 事件

默认策略：

- 按三个阶段规划：事件前、直播中、事件后。
- 仅在有托管式接入、Arrow 设置和真实提醒价值时使用 Branded Notifications。
- 当事件有值得直播观看的理由时，使用 X Live 和剪辑。

推荐结构：

| 阶段 | 格式 | 衡量 |
|---|---|---|
| 事件前 | Video、Image、Branded Notifications、Takeover | 触达、提醒、注册 |
| 直播中 | X Live、推广剪辑、互动广告 | 观看人数、观看时长、互动 |
| 事件后 | 精彩剪辑、再营销、转化广告 | 剪辑观看、网站行为、线索、销售 |

当品牌有真实理由参与对话时，X 最适合直播/事件计划：体育、娱乐、金融、游戏、科技发布、会议、新闻、音乐、时尚或粉丝圈。如果品牌没有文化许可，在推荐托管式 takeover 之前先用轻量竞价支持。

### 转化设计

| 层级 | 推荐设置 | 注意点 |
|---|---|---|
| 事件前 | 注册、提醒订阅、落地页访问 | 提醒订阅不等于到场 |
| 直播中 | 观看人数、观看时长、互动、提问 | 互动质量比量级更重要 |
| 事件后 | 剪辑观看、再营销行为、购买/线索 | 没有事件后计划会浪费直播注意力 |
| 业务读数 | 票务销售、产品行为、管道、媒体价值 | 时机和跟进驱动价值 |

## 多格式组合模式

当每种格式有不同分工时使用多种格式：

| 模式 | 适用场景 | 组合 |
|---|---|---|
| 效果发布 | 转化追踪已就绪 | Website conversions / Sales + Image/Video + 再营销 |
| 目录电商 | Feed 和事件已就绪 | DPA Prospecting + DPA Retargeting + Collection |
| 意图加教育 | 搜索意图存在但需要解释 | Keywords 广告系列 + Video/Carousel + 再营销 |
| 文化时刻 | 时机和对话语境重要 | Vertical Video + Takeover/Amplify + 互动跟进 |
| 应用增长 | MMP 和应用内事件已就绪 | App installs + Vertical Video + 再互动 |
