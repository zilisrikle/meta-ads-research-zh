# X Live

X Live 支持产品发布、会议、观影派对、访谈、娱乐、体育及其他直播时刻的实时直播。

X Live 是高接触形式。在将其作为标准自助广告位呈现前，先与 X 核验当前可用性、技术支持和推广选项。

规范来源：X 创意广告规范（https://business.x.com/en/help/campaign-setup/creative-ad-specifications）。最后核验：2026-04。

## 直播规范

| 项目 | 指引 |
|---|---|
| 协议 | RTMP |
| 视频编码 | H.264/AVC |
| 视频码率 | 推荐 9 Mbps；最大 12 Mbps |
| 音频编码 | AAC-LC |
| 音频码率 | 最大 128 kbps |
| 分辨率 | 推荐 1280x720；最大 1920x1080 |
| 帧率 | 推荐 30 FPS；最大 60 FPS |

## 最佳用途

- 产品公告。
- 直播事件与会议。
- 体育或娱乐陪伴内容。
- 高管/创始人问答。
- 创作者或出版商合作。

## 规划输入

| 输入 | 重要性 |
|---|---|
| 事件日期与流程表 | 直播系列需要精确时间 |
| 主持人与嘉宾 | 决定可信度与出席率 |
| 推广窗口 | 在直播时刻前建立提醒 |
| 直播后计划 | 精彩片段与再营销可延长价值 |
| 审核 | 直播对话需要运营覆盖 |

## 系列结构

```text
活动前：认知、提醒，视可用情况用 Branded Notifications
直播中：X Live 推广与实时互动
活动后：高光片段、再营销、转化跟进
```

## 创意指引

- 明确主题与时间。
- 使用短预告片。
- 宣传为什么值得直播观看。
- 准备活动后放大的精彩片段。

## 度量

| 阶段 | 指标 |
|---|---|
| 活动前 | 触达、提醒订阅、网站注册 |
| 直播中 | 观看人数、观看时长、互动、话题量 |
| 活动后 | 片段观看、流量、线索、转化 |

## 常见错误

- 只在活动当天推广。
- 没有明确的直播观看理由。
- 没有活动后内容计划。
- 没有审核或响应计划。

## 规划与成本核查

不要将 X Live 视为标准自助库存。向 X 索取：

- 技术支持要求与推流测试时间线。
- 直播前、中、后的推广选项。
- 审核、升级与品牌安全责任分工。
- 直播与回放观看的报告字段。

## 诊断

| 症状 | 可能原因 | 应对 |
|---|---|---|
| 出席率低 | 活动前推广弱或直播价值不清 | 更早开始推广，强化直播专属理由 |
| 直播中流失 | 流程慢或制作差 | 收紧议程、主持人与环节节奏 |
| 无业务影响 | 无活动后跟进 | 剪辑高光片段并再营销观看者/报名者 |
