# 创意基础（Creative Fundamentals）

在撰写 X Ads 文案或指定创意素材之前，先使用本参考文档。

Conversation Buttons 和 Polls 的规格来源：X 创意广告规范（https://business.x.com/en/help/campaign-setup/creative-ad-specifications）及 Conversation Buttons 文档（https://business.x.com/en/help/campaign-setup/conversation-buttons）。最后核实：2026-04。

## 核心原则

- 让第一行或第一帧快速赢得注意力。
- 一条广告讲一个信息。
- 创意匹配落地页、卡片、应用行为、关键词或对话语境。
- 使用原生 X 行为：简洁语言、时效相关性、对话语境和清晰观点。
- 普通付费广告文案中不要带话题标签、裸 URL、emoji 堆砌和视觉杂乱，除非所选广告功能明确要求。
- 移动优先设计，并在 X Ads Manager 中核实创意预览。
- 把跨平台创意可移植性当作加分项，而非自动成立。X 支持更多宽高比，但信息仍需感觉原生于 X。

## 美学分指南

X 已公开走向更强的广告质量和美学管控。把美学分（Aesthetic Score）指南当作运营质量过滤器，而不是保证可见的指标或固定折扣。

使用以下检查清单：

- 普通推广广告文案中不要使用话题标签。2025 年 6 月 27 日的公开限制被广泛报道；仅在所选 X 托管式功能（如 Conversation Buttons 或 Branded Hashtags）当前工作流程明确要求话题标签时保留例外。
- 文案中避免裸 URL；需要点击落地页时使用 Website Cards 或 App Cards。
- emoji 尽量少且符合品牌调性。
- 语法、标点和大小写干净。
- 使用精美的高分辨率素材。
- 避免低质量截图、杂乱的文字叠加、噱头式裁剪和无法辨认的视觉。
- 广告、卡片、CTA 和落地页保持一致。
- 出现疲劳时刷新创意。

除非当前账号能看到该指标，否则不要把"美学分"当作常规 KPI 报告。把它当作投放检查清单和创意 QA 标准。

## Conversation Buttons 和 Polls

在当前 X 规格中，Conversation Buttons 和 Media Polls 不是普通帖子编辑器功能；X 指引广告主使用受支持的编辑器/工作流选项，如 Brand Networks（`https://composer.bn.co/`）。在将其作为自助功能推荐之前，请先核实可用性。

| 功能 | 关键规格 |
|---|---|
| Conversation Button 话题标签 | 21 个字符（含 `#`） |
| 预填用户帖子 | 256 个字符 |
| Conversation Button 标题 | 23 个字符 |
| 感谢语 / 可选 URL | 23 个字符 |
| Conversation Button 媒体 | 必须搭配图片或视频媒体 |
| 投票选项 | 2-4 个选项 |
| 投票选项文案 | 25 个字符 |
| 投票时长 | 5 分钟到 7 天 |

投票时长从帖子创建时开始计算，而不是从帖子被推广时开始。在付费投放开始前创建投票时，这一点很重要。

## 文案框架

```text
Hook: earn attention in the first line
Value: explain the benefit, proof, or reason to care
Action: tell the user what to do next
```

## 钩子类型

| 钩子类型 | 用途 |
|---|---|
| 痛点（Problem） | 点出痛点或摩擦 |
| 结果（Outcome） | 以期望结果开头 |
| 证据（Proof） | 用数据、评价、可信度或社会证明 |
| 对比（Contrast） | 旧方式 vs 新方式、前后对比、竞品替代 |
| 时效角度（Timely angle） | 绑定当前事件、季节、发布或对话 |
| 直接点名（Direct callout） | 明确点出受众或场景 |
| 提问（Question） | 引发自我识别或好奇 |

## CTA 选择

| CTA | 适用 |
|---|---|
| Learn More | 教育、种草、B2B、服务 |
| Shop Now | 电商和产品销售 |
| Sign Up | SaaS、webinar、newsletter、试用 |
| Download | 应用、报告、指南 |
| Install | 应用安装 |
| Watch | 视频或事件内容 |
| Apply Now | 申请、招聘、金融、教育 |

## 格式匹配

| 格式 | 创意任务 |
|---|---|
| Text Ads | 原生消息、公告、观点、快速测试 |
| Image Ads | 一个产品、offer、视觉证据或品牌信息 |
| Video Ads | 演示、故事、证言、证据、教育 |
| Vertical Video Ads | 全屏移动端故事、快速钩子、开声冲击 |
| Carousel Ads | 多步叙事、产品集、利益点堆叠 |
| Collection Ads | 产品发现和多落地页购物 |
| Dynamic Product Ads | 目录个性化的再营销或拉新 |
| Keywords campaign / Search Ads | 对主动搜索的意图匹配回应 |

## 测试

先测概念，再测装饰性变体。

| 测试层级 | 示例 |
|---|---|
| Offer | 折扣、试用、捆绑、线索磁石、活动注册 |
| 角度 | 痛点、结果、证据、对比、紧迫 |
| 格式 | 文字、图片、视频、轮播、竖视频 |
| 钩子 | 第一句或前 1-3 秒 |
| 证据 | 证言、评分、创作者、数据、演示 |
| 变体 | 裁剪、标题、CTA、颜色、首帧 |

在预算支持时使用几条有实质差异的创意。避免投放大量近乎相同的变体：它们切分学习却回答不了战略问题。
