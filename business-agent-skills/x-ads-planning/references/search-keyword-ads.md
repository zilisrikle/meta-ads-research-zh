# 关键词系列 / 搜索广告（Keywords Campaign / Search Ads）

关键词系列（Keywords campaigns）基于用户在 X 上的搜索行为触达人群，可在搜索结果中投放推广帖子。注意将其与**关键词定向（keyword targeting）**区分开来——后者是更广泛的系列设置中可用的定向功能。

规范来源：X 创建关键词系列文档（https://business.x.com/en/help/campaign-setup/create-a-keywords-campaign）与关键词定向文档（https://business.x.com/en/help/campaign-setup/campaign-targeting/keyword-targeting）。最后核验：2026-04。

## 产品行为

| 项目 | 指引 |
|---|---|
| 系列设置 | 在可用的系列目标/工作流中选择关键词（Keywords） |
| 支持的系列类型 | 应用安装、应用再互动、网站流量、网站转化 / 销售 |
| 必需广告位 | 搜索结果（Search Results）为强制/默认 |
| 附加广告位 | 主页时间线和回复可在上下文相关时投放 |
| 关键词量 | 关键词系列工作流中一次最多 200 个关键词 |
| 建议下限 | 每个广告组至少 25 个关键词 |
| 匹配行为 | 精确匹配风格；去除多余空格；不区分大小写 |
| 扩展 | 可匹配相关的话题标签（Hashtags）、股票代码标签（Cashtags）和 @账号 |
| 语言 | X 不会自动翻译非英文关键词 |

## 最佳用途

- 捕获产品品类周边的需求。
- 事件、发布或热点驱动的系列。
- 政策允许的竞品或替代品搜索。
- 问题/解决方案类词。
- B2B 品类研究与对比词。

## 关键词策略

| 关键词类型 | 示例 | 用途 |
|---|---|---|
| 品牌 | 品牌、产品、事件名称 | 防御或发布系列 |
| 品类 | 产品或服务品类词 | 拓新 |
| 问题 | 痛点与需求 | 线索收集与教育 |
| 竞品 / 替代 | 竞品名称、对比词 | 谨慎使用并遵守政策 |
| 事件 / 热点 | 会议、体育、文化时刻 | 时效相关性 |

关键词要足够多以保证投放空间，但广告组内保持主题一致。

对于该系列工作流之外的常规关键词定向，当前官方文档列出每个广告组最多 750 个关键词。

实用上线姿态：

- 当关键词定向是主要受众思路时，使用 25–50 个紧凑主题的关键词。
- 除非目标是广泛探索且报告能容忍噪音，避免混合意图的大规模词表。
- 不要为了覆盖量同时添加带话题标签和不带标签的版本；普通关键词定向中 X 会自动包含话题标签变体。
- 尽早添加否定词，覆盖无关含义、求职者、免费党、不安全上下文和竞品冲突。

## 系列设计

- 按意图或信息分组关键词。
- 创意与关键词意图匹配。
- 以流量或转化为目标时使用网站卡片（Website Cards）。
- 对意图差异大的词使用独立广告组。
- 排除或避免带来低质量点击的无关词。
- 不要依赖平台翻译非英文关键词；显式构建本地语言关键词集。
- 让关键词系列积累足够数据再暂停。最初几天表现弱可能反映预热期、搜索量稀疏或关键词/创意不匹配，而非渠道失败。

## 度量

| 目标 | 指标 |
|---|---|
| 流量 | CPC、CTR、落地页行为 |
| 转化 | CPA、CVR、ROAS、合格动作 |
| 认知 | 触达、CPM、互动质量 |

## 常见错误

- 在同一广告组混用宽泛认知词和高意向转化词。
- 把关键词系列与普通关键词定向混淆。
- 使用与搜索意图不匹配的通用文案。
- 只看 CTR 评判。
- 不用 UTM 或落地页分析。

## 诊断

| 症状 | 可能原因 | 应对 |
|---|---|---|
| 投放量低 | 关键词过少或话题搜索量低 | 扩展到相邻词、账号和问题话术 |
| CTR 高、转化低 | 好奇心/搜索不匹配 | 收紧文案贴合用户意图，改善落地页匹配 |
| 流量质量差 | 关键词意图混杂 | 拆分品牌/品类/问题/竞品词 |

## 运营节奏

- 每周审视关键词簇，批量增删词。
- 对意图差异大的词保持独立广告组。
- 手动重建本地语言关键词集；不默认平台会翻译。
- 扩展胜出词：添加相邻问题话术、竞品替代、事件词，以及受众重合的粉丝相似账号。
