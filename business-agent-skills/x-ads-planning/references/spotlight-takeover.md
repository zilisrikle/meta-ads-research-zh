# Spotlight 接管（Spotlight Takeover）

Spotlight Takeover 是 X 接管（Takeover）产品，将品牌创意投放在高注意力的探索（Explore）与趋势上下文附近。一些旧文档、政策页面或案例可能使用 Trend Takeover 或 Trend Takeover+ 的说法。除非 X 客户团队确认为该系列提供独立的 Trend Takeover SKU，否则规划主标签使用 **Spotlight Takeover**。

规范来源：X Spotlight Takeovers 产品页（https://business.x.com/en/products/spotlight-takeovers）与 X 接管指引。最后核验：2026-04。

## 可用性

Spotlight Takeover 是托管式高端广告位。向 X 确认当前命名、可用性、定价、市场、日期、创意规范、独占性和审批流程。

## 最佳用途

- 热点驱动的发布。
- 娱乐、体育与文化时刻。
- 需要话题关联的品牌系列。
- 话题标签或创作者主导的激活。

## 规划输入

| 输入 | 重要性 |
|---|---|
| 时刻 / 趋势上下文 | 只有相关性清晰时该广告位才有效 |
| 创意概念 | 必须在探索/趋势上下文中一眼可懂 |
| 话题标签或话题计划 | 帮助将付费触达连接到自然参与 |
| 品牌安全 | 趋势上下文可能波动剧烈 |
| 度量 | 需要触达、互动、话题/对话量及下游读数 |

## 创意指引

- 信息简短且贴合文化语境。
- 使用品牌的观点，而非泛泛的蹭热点。
- 搭配后续推广广告延续话题。
- 为高曝光准备审核与社群管理。

## 度量

使用触达、互动、话题标签/话题量、可用的情感分析、主页访问、网站流量，以及下游转化或提升指标。

## 规划与成本核查

接管定价和最低消费因市场、日期、库存和打包方案而异。不要写死价格。向 X 索取：

- 市场/日期可用性与独占性。
- 最低花费与捆绑媒体要求。
- 创意尺寸、审批时间线和应急规则。
- 报告、透明度与品牌安全控制。

## 诊断

| 症状 | 可能原因 | 应对 |
|---|---|---|
| 触达高、互动弱 | 信息未绑定话题时刻 | 围绕明确的事件、发布或文化由头重做 |
| 负面或嘈杂回复 | 高曝光上下文缺少审核 | 准备社群管理与升级机制 |
| 无下游提升 | 无后续承接路径 | 搭配再营销、网站/应用 CTA 或接管后内容 |
