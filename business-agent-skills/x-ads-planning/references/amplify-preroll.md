# Amplify Pre-roll

Amplify Pre-roll 让广告主可以在 X 上的优质视频内容品类前投放前贴片视频广告。

规格来源：X Creative Ad Specifications（https://business.x.com/en/help/campaign-setup/creative-ad-specifications）。最后核实：2026-04。

## 最佳适用场景

- 品牌认知。
- 产品发布。
- 活动推广。
- 娱乐、体育、新闻和文化相关的广告系列。
- 需要品牌安全视频场景的广告系列。

## 购买与准入

Amplify Pre-roll 可能通过自助或准入制账户流程投放，取决于市场、账户和库存。请在 X Ads Manager 或联系 X 支持核实当前可用性。

## 素材指引

| 元素 | 指引 |
|---|---|
| 文件类型 | MP4 或 MOV |
| 文件大小 | 最大 1 GB |
| 时长 | 建议 15 秒或更短；最长 2:20 |
| 宽高比 | 推荐 1:1；9:16 可占据相近版面；尽可能与发布者内容宽高比一致 |
| 尺寸 | 推荐 1200x1200；1:1 最小 600x600；非 1:1 最小 640x360 |
| 开头 | 尽早露出品牌或产品 |
| 信息 | 一次只讲一个清晰的想法 |
| 声音 | 按有声设计，但配字幕或文字叠加 |
| CTA | 广告系列有下游行动时使用 |

## 定向与场景

- 选择与品牌和信息契合的内容品类。
- 避免品类选择造成品牌安全或场景错配。
- 素材调性与优质视频环境保持一致。

## 衡量

| 目标 | 指标 |
|---|---|
| 品牌认知 | Reach、CPM、frequency |
| 视频消费 | Views、view rate、CPV、completion rate |
| 下游行动 | 网站访问、转化、辅助影响 |

## 常见错误

- 开头缓慢，像电视广告。
- 把前贴片只当作直接转化版式。
- 忽视场景契合。
- 只看末次点击转化评判。

## 诊断

| 症状 | 可能原因 | 应对 |
|---|---|---|
| 完播率低 | 素材太慢或太长 | 提前露出品牌/产品和核心信息 |
| 品牌效应弱 | 品类/场景错配 | 重新审视内容品类和时机契合 |
| 下游行动差 | 没有浏览后承接计划 | 搭配再营销或后续 Promoted Ads |

## 运营节奏

- 建计划前先确认库存/品类可用性。
- 每周复查观看质量和品牌安全。
- 把下游读数作为辅助证据，而非唯一成功标准。
