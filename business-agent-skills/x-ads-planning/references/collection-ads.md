# 精选广告（Collection Ads）

精选广告（Collection Ads）让广告主展示一张主视觉图，下方配较小的产品缩略图。它们适合发现、浏览和商业导向的广告系列。

规格来源：X 创意广告规范（https://business.x.com/en/help/campaign-setup/creative-ad-specifications）。最后核实：2026-04。

## 使用场景

- 电商产品发现。
- 产品线发布。
- 季节性合集。
- 一条广告单元内的多个落地页。
- 零售、时尚、美妆、消费品、旅行和市场型 offer。

## 结构

| 要素 | 作用 |
|---|---|
| 主图（Hero image） | 主要视觉钩子和品牌/产品框定 |
| 缩略图 | 最多 6 个产品、服务或促销 |
| 落地页 | 产品专属或品类专属的落地页 |
| 文案 | 给出浏览该合集的理由 |

## 创意实践

- 使用能快速讲清合集的强主图。
- 缩略图保持视觉一致。
- 缩略图用清晰的产品图，而不是杂乱的生活场景图。
- 每张缩略图匹配最相关的落地页。
- 用产品品类或利益点组织合集。

## 衡量

| 目标 | 读数 |
|---|---|
| 产品发现 | CTR、互动、产品页浏览 |
| 销售 | CPA、ROAS、产品层级收入 |
| 新品发布 | 触达、CTR、助攻转化 |

## 常见错误

- 主图弱。
- 产品视觉风格不一致。
- 死链或错配的产品 URL。
- 在没有利润可见性的情况下推广低利润产品。
- 把精选广告当作目录/feed 健康的替代品。

## 诊断

| 症状 | 可能原因 | 应对 |
|---|---|---|
| CTR 低 | 主图没有讲清合集 | 围绕一个清晰品类、offer 或用例重做主图 |
| 点击集中在一张缩略图 | 产品集不均衡 | 把头部产品拆成独立广告，或重做合集 |
| 有点击但收入弱 | 产品低利润或不匹配 | 复盘产品层级利润和落地页匹配度 |

## 运营节奏

- 投放前检查产品 URL 和可用性。
- 每周复盘产品层级点击和收入。
- 围绕季节、新品和畅销款刷新主图。
