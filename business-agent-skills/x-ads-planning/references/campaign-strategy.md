# 广告系列策略（Campaign Strategy）

使用本参考文档处理 X Ads 的广告系列结构、目标、定向、出价、预算、衡量和运营节奏。

## 广告系列结构

X Ads Manager 采用三级结构：

```text
Campaign
  -> Ad group
      -> Ad
```

| 层级 | 主要决策 |
|---|---|
| Campaign（广告系列） | 目标、资金来源、名称、广告系列日期、可选花费上限或广告系列预算优化（Campaign Budget Optimization） |
| Ad group（广告组） | 目标、出价、定向、版位、预算控制、投放日期、相关的动态产品广告（Dynamic Product Ads）开关 |
| Ad（广告） | 帖子、创意、卡片、CTA、落地页、追踪 |

一个广告系列可包含多个广告组，每个广告组可包含一条或多条广告。X 可以在广告组内自动优化向表现更好的广告。

## 结构实践

初始结构保持简单：

| 决策 | 默认 |
|---|---|
| 广告系列 | 一个目标和一个主要业务目标 |
| 广告组 | 一个主要受众假设或控制需求 |
| 广告 | 多条帖子，让 X 选择优胜者 |
| 衡量 | 在优化深层事件之前，先准备好 Pixel / CAPI / MMP / 目录 / CRM |

仅在切分改变真实决策时才切分：目标、市场、设备/操作系统、受众假设、拉新 vs 再营销、优质版位 vs 竞价、受监管品类、创意测试或衡量读数。避免受众相似、创意几乎相同的重叠广告系列。

## 目标选择

X 的目标命名在公开文档和账号流程之间并不完全一致。官方公开广告系列页面仍列出**网站转化（Website conversions）**，而其他 X 页面称之为 **Sales** 或 **Conversions**。在需要时使用双重表述，并在投放前核实当前账号界面。

| 漏斗 | 目标 / 流程 | 适用场景 | 典型结果指标 |
|---|---|---|---|
| 认知 | Reach（触达） | 目标是高效曝光 | Reach、impressions、CPM |
| 种草 | Video views（视频观看） | 目标是视频消费 | Views、view rate、CPV |
| 种草 | Website traffic（网站流量） | 目标是网站访问 | Link clicks、CPC、落地页行为 |
| 种草 | Pre-roll views（前贴片观看） | 目标是在优质内容前投放前贴片视频 | Pre-roll views、CPV |
| 种草 | Engagement（互动） | 目标是帖子互动 | Engagements、CPE、engagement rate |
| 种草 | App installs（应用安装） | 目标是新应用用户 | Installs、CPI |
| 转化 | App re-engagements（应用再互动） | 目标是存量用户的应用行为 | App events、CPA |
| 转化 | Website conversions / Sales（网站转化/销售） | 目标是可追踪的网站结果 | Conversions、CPA、ROAS |
| 高级 / 语境 | Keywords campaign / Search Ads（关键词广告系列/搜索广告） | 目标是捕获主动搜索意图 | CPC、CPA、ROAS、合格行为 |

选择与业务结果匹配的目标。除非转化量或追踪未就绪，否则不要在真实目标是可追踪转化时使用网站流量。

X 没有与 Meta Lead Ads 或 LinkedIn Lead Gen Forms 对等的原生线索生成目标。使用带可追踪表单和 CRM 质量反馈的 Website traffic 或 Website conversions / Sales。

## 购买路径

| 购买路径 | 适用 | 说明 |
|---|---|---|
| 自助 | 常态化效果、测试、标准推广广告、多数应用/网站目标 | 在 X Ads Manager 中管理 |
| 符合资格 / 账号相关 | Vertical Video、Amplify Pre-roll、Polls、Conversation Buttons、Keywords campaign、部分测试版或演进中的功能 | 核实当前账号权限 |
| 托管式服务 / 高接触 | Takeover、赞助、品牌化功能、X Live、优质预订库存、大型事件 | 需要 X 销售/支持、X Next 或账号资格 |

## 定向

### 定向输入

| 类型 | 示例 | 用途 |
|---|---|---|
| 人口/设备 | 地域、语言、设备、操作系统、年龄、性别 | 基本资格和市场控制 |
| 兴趣/行为 | 兴趣、对话、事件、电影/电视 | 宽泛的受众塑造 |
| 关键词定向 | 搜索查询、近期帖子、互动过的帖子 | 跨 X 行为的主题和意图信号 |
| Keywords campaign / Search Ads | 在 Keywords 广告系列流程中选择的关键词 | 在搜索结果中捕获主动搜索意图 |
| 粉丝相似（Follower look-alikes） | 与所选账号粉丝相似的用户 | 触达相关账号周围的社群 |
| 相似受众（Lookalike Audiences） | 基于自定义受众（Custom Audience）种子建模 | 从客户、网站、应用或互动种子扩量 |
| 自定义受众（Custom Audiences） | 客户名单、网站访客、应用用户、互动受众 | 再营销、排除、高价值种子 |
| 排除 | 排除的受众、排除的关键词、Do Not Reach 名单 | 护栏和排除 |

### AND / OR 定向逻辑

X 定向使用加法层和减法层。设计广告组时这点容易被忽略。

| 逻辑 | 定向类型 | 效果 |
|---|---|---|
| 加法 / OR | 兴趣、关键词、对话主题、电影/电视、事件、粉丝相似 | 扩大合格受众；用户匹配其中任意一项即可 |
| 减法 / AND | 地理位置、年龄、性别、设备型号、平台、语言 | 收窄合格受众；所有选定约束都必须满足 |

示例：如果一个广告组定向日本女性、25-44 岁，外加 5 个对话主题和 20 个粉丝相似账号，用户必须满足地域/年龄/性别约束，且可匹配任一选定的对话主题或账号。

### 关键词定向 vs Keywords 广告系列

把两者区分开：

| 功能 | 是什么 | 关键限制 / 行为 |
|---|---|---|
| 关键词定向（Keyword targeting） | 基于搜索、近期帖子和互动帖子的定向功能 | 官方文档列出每个广告组最多 750 个关键词 |
| Keywords campaign / Search Ads | 在搜索结果中投放的广告系列工作流/目标，也可在语境相关时出现在首页时间线/回复中 | 搜索结果为强制/默认；一次最多支持 200 个关键词；X 建议每个广告组至少 25 个关键词 |

关键词为精确匹配风格，会去除多余空格，不区分大小写，并可扩展到匹配的话题标签（Hashtags）、股票标签（Cashtags）和 @账号。X 不会自动翻译非英文关键词。

### 优化定向（Optimized Targeting）

Optimized Targeting 是 X 的 AI 驱动受众扩展系统。当 X 预测有更好表现时，它可以触达所选弹性定向输入之外的用户。

| 始终被遵守 | 开启 Optimized Targeting 时被弹性处理 |
|---|---|
| 性别、年龄、地域、语言、操作系统类型、操作系统版本、设备、排除的关键词、排除的受众、Do Not Reach 名单 | 兴趣、关键词、对话主题、粉丝相似和其他受众特征 |

当规模和效果比严格的手动受众边界更重要时使用它。在受监管品类、窄地域、严格受众测试，或报告必须隔离单一输入的场景下要谨慎。

当前 X 指南称，Optimized Targeting 会在使用 Sales 目标的广告系列中自动选中，并在 Simple Ads 流程中自动应用。在 Advanced 广告系列流程中，请核实该开关是否可更改。

### 对话定向（Conversation Targeting）

对话定向覆盖 25+ 类别下的 10,000+ 主题，使用 28 天回溯窗口，覆盖发布、互动或停留于某主题帖子的人群。

英语市场的语言支持最强。X 还为日语、韩语、葡萄牙语、西班牙语和法语提供有限支持；英语之外的覆盖可能不够全面。对于非英文广告系列，请检查每个主题的预测触达，如果触达低或不可用，补充其他定向选项。

### 定向原则

- 先足够宽以保证投放，再仅出于业务、合规或衡量原因收窄。
- 在学习什么有效时，一次测试一个主要受众假设。X 优化指南倾向于每个广告系列使用一种受众定向类型，以使结果可解读。
- 当广告系列依赖实时意图或文化语境时，使用关键词和对话定向。
- 把粉丝相似当作信号，而不是购买者质量的保证。
- 用相似受众和自定义受众做种子扩量、再营销和排除。
- 如果一个广告组混入太多定向想法会让学习或报告不可读，就不要混。
- 对于相关地区的住房、借贷和信贷广告，投放前请核实受限定向和预测模型要求。

### 粉丝相似实践

当所选账号真实描述了买家/社群图谱时，粉丝相似最有用。

好的种子：

- 直接竞品。
- 品类出版物、newsletter、播客、分析师和创作者。
- 同一买家使用的相邻工具或产品。
- 会议、事件或社群账号。

弱的种子：

- 与买家无关的名人或大众市场账号。
- 来自不相关行业的混合账号名单。
- 无法描述有用受众的极小或不活跃账号。
- 拉新中不带排除逻辑使用自己的客户/员工账号。

## 预算与出价

| 情形 | 推荐姿态 |
|---|---|
| 新发布 | 结构简单，预算足够让主要 KPI 产生有意义的信号 |
| 创意测试 | 测试保持小规模，概念差异清晰 |
| 效果扩量 | 把预算转向下游质量稳定的广告组和创意 |
| 优质版位 | 在推荐前确认可用性、最低花费、日期、审批和衡量计划 |

当广告组目标相同、希望系统自动分配花费时，广告系列预算优化（Campaign Budget Optimization）有用。当严格分配、受众测试或消息测试重要时，使用广告组预算。

常见出价姿态：

| 出价姿态 | 适用场景 |
|---|---|
| 自动（Automatic） | 早期学习、历史有限，或在预算内最大化投放 |
| 最高出价（Maximum bid） | 需要对出价经济性设硬上限 |
| 目标成本（Target cost） | 有稳定转化数据且目标基于实际 |

实用出价姿态：

- 在历史有限、转化信号仍在积累，或目标需要最大化投放时，从自动出价开始。
- 仅在账号/目标支持且目标基于历史表现（而非理想 CPA）时使用目标成本。
- 用最高出价做硬上限、受约束的上层漏斗购买或投放控制；出价过低是常见的无投放原因。
- 转化广告系列在做非紧急出价变更前，先看 3-7 天滚动表现。

## 衡量

| 目标 | 所需衡量 |
|---|---|
| 网站流量 | UTM、落地页分析、跳出/CVR 检查 |
| 网站转化 / 销售 | X Pixel 和/或转化 API（Conversion API / Conversions API）、事件定义、相关的去重 |
| 应用安装 / 再互动 | 经批准的移动衡量合作伙伴（MMP）或应用事件追踪 |
| 电商 / DPA | X Shopping Manager、产品目录、pixel/事件、目录 feed 健康度、购买价值 |
| 线索生成 | 表单事件、CRM 阶段、合格线索反馈 |
| 品牌 / 认知 | 触达、频次、视频观看质量、可用时的提升研究或代理品牌指标 |

用平台指标做优化，但要与业务数据对账，如订单、CRM、应用收入或财务报告。

## 运营节奏

| 节奏 | 重点 |
|---|---|
| 每日 | 投放、花费异常、拒审、追踪中断 |
| 每周 | 创意表现、受众质量、KPI 进度、落地页/应用质量 |
| 双周 | 新创意概念、关键词/受众测试、预算调整 |
| 每月 | 结构复盘、衡量健康度、真相来源对账 |

除非设置明显错误，否则避免同时改预算、出价、定向、创意和转化事件。

对于转化广告系列，把第一周当作稳定窗口，除非投放、追踪、政策或落地页质量出问题。X 没有 Meta 式的学习标签，但从业者普遍观察到早期投放和 CPA 波动较大。
