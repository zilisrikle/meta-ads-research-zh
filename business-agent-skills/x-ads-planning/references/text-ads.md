# 文本广告（Text Ads）

文本广告（Text Ads）是推广广告（Promoted Ads），外观和行为与标准帖子一致。当信息本身就是创意时使用。

规范来源：X 创意广告规范（https://business.x.com/en/help/campaign-setup/creative-ad-specifications）。最后核验：2026-04。

## 规范

| 项目 | 指引 |
|---|---|
| 帖子文案 | 最多 280 字符；链接会占用文案长度 |
| 媒体 | 无需媒体 |
| 互动 | 可获得回复、转发、点赞等标准 X 互动 |
| 适用目标 | 信息与目标页面够强时，适用触达、互动、网站流量、网站转化 / 销售 |

上线前在 X Ads Manager 中核验当前字符处理与链接行为。

## 最佳用途

- 公告与发布。
- 创始人或品牌观点。
- 制作视觉素材前的快速信息测试。
- 推广已有强互动的自然帖子。
- 话题串或对话入口。
- B2B/SaaS 权益——当观点、立场或证明比视觉更强时。

## 创意实践

- 以清晰的观点或利益点开头。
- 把钩子放在第一行；不要把重点埋在截断线以下。
- 一条广告只讲一个信息。
- 避免泛泛的企业话术。
- 当网站卡片（Website Card）是更好的点击体验时，避免裸 URL。
- 普通推广文案中避免话题标签，除非所选 X 托管功能明确要求。

## 文案结构

```text
首行：锋利的钩子或受众点名
中段：为什么重要或证据
结尾：明确的下一步动作
```

## 常见错误

| 错误 | 危害 |
|---|---|
| 写得像横幅标题 | 文本广告应感觉原生于 X |
| 主张过多 | 帖子变得难懂 |
| 无行动路径 | 互动可能无法转化为业务结果 |
| 话题标签堆砌 | 显得低质，可能稀释信息，并可能与当前付费文案限制冲突 |

## 度量

按文本广告承担的任务评判：

- 认知：触达、频次、CPM。
- 互动：互动率、CPE、对话质量。
- 流量/转化：CPC、落地页行为、转化率、CPA。

## 诊断

| 症状 | 可能原因 | 应对 |
|---|---|---|
| 互动低 | 信息泛泛或广告味重 | 用更锋利的观点或受众点名重写 |
| 有互动无行动 | 缺少清晰路径或 CTA | 增加目标页面逻辑，或搭配卡片/媒体形式 |
| 负面回复 | 主张、语气或受众不匹配 | 检查政策、评论与品牌安全姿态 |

## 运营节奏

- 用文本广告做快速信息测试，再投入重型创意。
- 只推广互动相关且质量高的自然帖子。
- 即使互动量高，也淘汰带来低质量回复的信息。
