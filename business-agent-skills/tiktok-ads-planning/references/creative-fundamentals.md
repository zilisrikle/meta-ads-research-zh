# 创意基础

写 TikTok Ads 文案或提创意素材需求前，先用这份参考。

## 核心原则

TikTok 经久不变的创意原则是：**Don't Make Ads. Make TikToks.（别拍广告，拍 TikTok。）**

创意要感觉像 TikTok 原生：快、有人味、有用、有趣、具体，为声音打开的移动端观看而设计，同时配字幕也能看懂。

## 创意体系

| 层级 | 要设计什么 |
|---|---|
| 概念（Concept） | 说服逻辑：痛点、结果、证明、对比、演示、达人故事、优惠 |
| 钩子（Hook） | 前 1–3 秒或首帧画面 |
| 主体（Body） | 演示、故事、证明、异议处理、产品使用、社会证明 |
| CTA | 下一步动作：购买、注册、下载、了解、发消息、看直播 |
| 变体（Variant） | 达人、开场白、视觉角度、产品镜头、剪辑节奏、CTA、文案 |

先测概念，再测 cosmetic（表面样式）变体。如果说服逻辑完全一样，换个颜色、缩略图或文案不算有意义的新概念。

## 钩子类型

| 钩子 | 适用场景 |
|---|---|
| 痛点点名 | 受众有明确痛点 |
| 结果先行 | 期望结果在视觉或情绪上够强 |
| 前后对比 | 转变可信且合规 |
| 打破误区 | 类目存在误解 |
| POV / 自白 | 达人主导的信任很重要 |
| 演示先行 | 产品效用能快速展示 |
| 社会证明 | 评价、评论、达人背书或使用量重要 |
| 搜索意图作答 | 创意要承接 Search Ads |

## 推荐视频结构

```text
0-3 秒：钩子 + 背景
3-12 秒：产品、问题、演示或证明
12-20 秒：异议处理、差异点或社会证明
最后几秒：CTA，与落地页呼应
```

卖点简单时可以更短；需要教育、信任或演示深度时可以更长。

## 声音与字幕

- 有目的地用音频；TikTok 是声音感知型平台。
- 广告使用 TikTok 的 Commercial Music Library（商用音乐库）或已获适当授权的音频。
- 制作前先查当前 Commercial Music Library 条款。TikTok 在 2025 年更新了音乐条款，部分 Premium 曲目可能有额外费用或购买限制。
- 加字幕或文字叠加，让静音也能看懂。
- 避免过小的文字和被 UI 遮挡的文字区域。
- 音频氛围与产品、受众、漏斗阶段匹配。

## 达人与 UGC 指引

达人风格广告常有效，因为它们降低抵触、展示产品使用场景。好的达人 brief 包括：

- 受众与使用场景。
- 要戏剧化的问题/洞察。
- 必须的宣称与禁止的宣称。
- 产品证明或演示要求。
- 钩子选项。
- CTA 与落地页。
- 披露与使用权要求。

不要把达人脚本写死到内容不再原生。

## 创意疲劳

TikTok 创意可能快速疲劳，预算越高越明显。关注：

- CTR 下滑。
- 钩子留存下滑。
- CPM/CPC/CPA 上涨。
- 评论质量下滑。
- 频次与受众重复曝光。

通过换钩子、换达人、换证明、换优惠、换剪辑结构或产品角度来翻新。小的文案修改很少能解决真正的疲劳。

## 文案与 CTA

| 元素 | 指引 |
|---|---|
| 标题文案 | 短、具体、与视频呼应 |
| CTA 按钮 | 用与落地页匹配的平台预设 |
| 屏幕文字 | 用于钩子、证明、步骤标签、优惠或关键异议 |
| 话题标签 | 只在能改善发现/语境时用；不要把它当定向依赖 |
| 宣称 | 有依据、合规 |

## 创意 QA

上线前检查：

- 前几秒能看懂产品/卖点。
- 创意与落地页、优化事件匹配。
- 字幕/文字不与 UI 安全区冲突。
- 音频的广告使用权有效。
- AI 生成或 Symphony 辅助的素材已做版权、披露、品牌安全和政策合规审查。
- 需要的地方，达人授权和 Spark Ads 授权已就位。
- 目标市场的受监管宣称与披露已处理。
