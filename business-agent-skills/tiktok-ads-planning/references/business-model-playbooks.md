# 商业模式 Playbook

选形式前先用这份参考。它让 TikTok 规划锚定业务经济模型，而不是广告形式菜单。

## 网站电商 / DTC

| 层级 | 默认推荐 |
|---|---|
| 首个广告系列 | Sales / 网站转化，配 In-Feed 或 Spark；信号和创意供给就绪时用 Smart+ Web |
| 扩张 | 用 Search Ads 捕捉主动的产品/类目意图；商品目录健康时用 Smart+ Catalog Ads |
| 创意 | 演示优先、评价/评论证明、创始人/达人视角、对比、优惠清晰 |
| 衡量 | Pixel + Events API、`event_id` 去重、Shopify/电商真实来源、毛利 |
| 注意点 | TikTok 制造的需求可能通过 Google、Amazon、直接访问或后续再营销转化 |

设计说明：

- 不要只看平台 ROAS 评判。
- 落地页保持移动端高速，并与广告承诺一致。
- 用 Search Ads 捕捉 "best X"、评价、价格和问题/解决方案类搜索。
- 在订单质量被证明前，把便宜点击当作可疑信号。

## TikTok Shop / 直播电商

| 层级 | 默认推荐 |
|---|---|
| 首个广告系列 | Shop 销售用 Product GMV Max；只有直播运营真实存在时才用 LIVE GMV Max |
| 创意 | 达人/联盟视频、产品演示、符合资质的 Spark、Shop 原生证明 |
| 运营 | 商品上架、价格、评价、库存、履约、退货、联盟计划 |
| 衡量 | Seller Center、净收入、退货、贡献毛利、新买家占比 |
| 注意点 | GMV 不是利润；自动化仍然需要产品和创意治理 |

设计说明：

- 商品准备度就是媒体准备度。
- 剔除毛利差、退货风险高或履约有问题的商品。
- 建设达人-联盟供给；GMV Max 优化不了它没有的素材。
- 直播电商需要主播、流程脚本、库存、优惠和足够的场次时长。

## 线索收集

| 层级 | 默认推荐 |
|---|---|
| 首个广告系列 | Lead Generation 配 Instant Form（即时表单）；合规/教育需求复杂时用网站表单 |
| 表单姿态 | 简单卖点用 More Volume（更多量级）；质量敏感的卖点用 Higher Intent（更高意向） |
| 创意 | 自筛选钩子、证明、案例、清晰的后续承诺 |
| 衡量 | CPL、合格线索率、接通率、预约/销售接受率、收入 |
| 注意点 | 如果成交率低，便宜的 CPL 就是失败 |

设计说明：

- 上线前先定义什么是合格线索。
- 放量前先接通 CRM/Leads Center。
- 设定 speed-to-lead（线索响应时效）SLA。
- 响应团队不上班的时段做分时投放。

## App 与游戏

| 层级 | 默认推荐 |
|---|---|
| 首个广告系列 | App Promotion，优化安装或 App 内事件 |
| 扩张 | Smart+ App、Playable Ads、质量撑得住时用 Pangle |
| 创意 | 玩法/价值演示、App 解决的问题、达人 walkthrough、与应用商店一致 |
| 衡量 | MMP 或 TikTok SDK、SKAN/iOS 设置、App 内事件、留存、LTV |
| 注意点 | 便宜安装可能掩盖差留存 |

设计说明：

- 事件量级撑得住时，优化目标要做到安装之后。
- Pangle 单独诊断，不要和 TikTok 信息流混在一起。
- 试玩要真实反映 App 价值才用 playable。

## B2B / SaaS

| 层级 | 默认推荐 |
|---|---|
| 首个广告系列 | Lead Generation 或网站转化；针对问题/类目意图用 Search Ads |
| 创意 | 创始人/专家视角、痛点教育、异议处理、演示片段 |
| 落地页 | 指南、webinar、试用、咨询或演示流程，筛选标准清晰 |
| 衡量 | 合格线索、销售接受线索、pipeline、CAC/回本周期 |
| 注意点 | TikTok 能制造需求，但长周期意向不一定能直接成交 |

设计说明：

- 不要把所有表单填写当作等价。
- 用能教育和筛选的内容。
- 用证明或下一步优惠再营销视频观看者和网站访客。

## 本地 / 服务型商家

| 层级 | 默认推荐 |
|---|---|
| 首个广告系列 | 视响应流程用 Lead Generation、Messaging Ads 或网站转化 |
| 创意 | 本地证明、前后对比、员工/店主视角、服务流程 |
| 定向 | 地理控制很关键；全国通用的 broad 指引可能不适用 |
| 衡量 | 电话/消息/预约/合格到店/收入 |
| 注意点 | 响应速度和接单能力决定盈利 |

设计说明：

- 收件箱有人值守才用 messaging。
- 线索质量比 CPL 更重要时用 Higher Intent。
- 宣称和受监管类目要求收紧。

## 品牌认知 / 发布

| 层级 | 默认推荐 |
|---|---|
| 首个广告系列 | Reach & Frequency、有代管资质时用 TopView/Top Feed/TopReach，In-Feed/Spark 助推 |
| 创意 | 一个锐利的信息、原生节奏、达人冷启动、证明或参与机制 |
| 衡量 | 覆盖、频次、观看质量、品牌提升、搜索/直接流量提升、再营销池增长 |
| 注意点 | 末次点击 CPA 通常是错误的首要 KPI |

设计说明：

- 高级覆盖配竞价后续承接。
- 只有当参与有真实可模仿的行为时，才用 Branded Mission/Effects/Hashtag。
- 上线前先定义代理需求信号。
