# Spark Ads

Spark Ads 是 TikTok 用于加热自然 TikTok 帖子的原生广告形式。帖子可来自广告主自己的 TikTok 账号，或授权的达人。

## 为什么用 Spark Ads

- 保留 TikTok 原生行为和社会证明。
- 付费互动可以累积到原帖。
- 适合达人内容、证言、产品演示和自然爆款。
- 视账户和广告系列配置可支持多个目标。

## 授权与身份

| 来源 | 要求 |
|---|---|
| 广告主自有帖子 | 关联 TikTok 账号或 Business Center 授权 |
| 达人帖子 | 达人授权 / 视频授权码或授权账号流程 |
| TikTok Shop 内容 | 视配置用 Shop、Showcase、联盟或 Spark 授权规则 |

不要默认授权后还能改文案。上线前确认最终文案、披露、商品链接和使用权。

TikTok 正在逐步淘汰广告用的 Custom Identity（自定义身份）。新广告系列围绕关联 TikTok 账号、广告主自有 Business Account 或其他授权账号/帖子规划，除非当前广告系列类型明确豁免。Business Center 和 Ads Manager 的术语可能称之为账号关联而非申请访问。

Spark Ads 授权时长因流程和账户而异。围绕某条帖子做媒介计划前，先确认达人/帖主能授予所需时长。

广告系列需要长期常青窗口时，在当前流程中申请尽量长的授权时长，如账户支持的 365 天。授权太短可能被迫重建或打断放量计划。

## 最佳适用场景

- 加热已表现出强互动或留存的自然帖子。
- 信任和真实感重要的达人广告。
- 符合资质的 TikTok Shop 或 Showcase 推广。
- 再营销与自然或付费内容互动过的用户。
- 大媒体花费前的达人概念测试。

Spark Ads 不自动优于非 Spark 广告。只有当帖子有原生证明、评论、达人信任或自然热度可供付费版借力时，才优先 Spark。

达人关系可信时，达人号 Spark 的信任度可能强于品牌号 Spark。受监管、高端或宣称需严格控制时，品牌号 Spark 可能更好。测试身份选择，不要默认某一方永远更优。

## 创意筛选

优先选：

- 前 1–3 秒强。
- 评论正面、社会证明可信。
- 产品融入自然。
- 受众/问题匹配清晰。
- 付费使用权和目标市场权利已清理。

## 达人评估

不要只看粉丝数：

| 信号 | 为什么重要 |
|---|---|
| 留存 / 完播 | 比粉丝量更好的注意力信号 |
| 评论质量 | 揭示信任、异议和匹配度 |
| 类目熟练度 | 达人说受众的语言 |
| 产品使用自然 | 降低广告识别、提升可信度 |
| 产出速度 | 支撑更新节奏 |
| 权利可靠性 | 避免上线延误 |

## 衡量

追踪：

- 付费效果：CPM、CTR、CPC、CPA、ROAS、CVR。
- 自然影响：主页访问、涨粉、评论、分享。
- 达人/内容学习：钩子、形式、证明风格、受众反应。

## 常见错误

- 只因为帖子精美就加热。
- 用达人内容但使用权不清。
- 忘了披露或受监管宣称审查。
- 把 Spark Ads 当作自动优于非 Spark 创意。
- 把达人当广告牌，而不是让他们讲可信的故事。
