# Messaging Ads（消息广告）

Messaging Ads 用于在支持的消息目的地开启对话。可用性和目的地因市场和账户而异。

当前官方框架区分：

| 类型 | 目的地 |
|---|---|
| Direct Messaging Ads（站内私信广告） | 把用户留在 TikTok 内，打开 TikTok Direct Messages |
| Instant Messaging Ads（即时消息广告） | 有货时把用户导向 WhatsApp、Facebook Messenger、Zalo 等支持的第三方 App |

## 最佳适用场景

- 靠聊天成交的服务型商家。
- 需要咨询的高决策产品。
- 响应能力快的本地商家。
- 预约或购买前的线索筛选。
- 消息电商常见的市场。

## 规划输入

| 输入 | 为什么重要 |
|---|---|
| 消息目的地 | 决定资质和用户体验 |
| 响应团队 | 回复慢浪费需求 |
| 筛选流程 | 把对话变成有效线索 |
| CRM 或收件箱路由 | 防止对话丢失 |
| 政策类目 | 部分行业需要更严审查 |

## 创意指引

- 发消息的理由要明确。
- 用具体提示：报价、空位、推荐、预约、产品匹配。
- 避免 "message us" 这类没有好处的模糊 CTA。
- 设定响应时效和下一步的预期。

## 衡量

追踪对话开启数、单次对话成本、合格对话、预约、购买、响应时长和成交率。

## 常见错误

- 收件箱没人值守就上线。
- 把所有对话当作等价。
- 没定义筛选标准。
- 简单购买也用消息，明明直接落地页更好。
- 没确认政策、市场和收件箱人力就选目的地。
