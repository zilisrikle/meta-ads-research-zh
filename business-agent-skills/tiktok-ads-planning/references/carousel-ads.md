# Carousel Ads（轮播广告）

Carousel Ads 用可滑动的多图形式。当静态图片比单条视频更能讲清产品、流程或优惠时使用。

## 最佳适用场景

- 商品组合与类目浏览。
- 分步骤讲解。
- 前后对比或转变故事。
- 功能对比。
- App 或 SaaS walkthrough。
- 用产品或证明序列做再营销。

## 创意指引

| 元素 | 指引 |
|---|---|
| 首卡 | 必须承担钩子作用 |
| 叙事顺序 | 每张卡都要推进观点 |
| 视觉体系 | 画幅、字体、设计保持一致 |
| 文案 | 图上文字短、可读 |
| CTA | 最终动作要明显 |
| 音乐 | 当前规格要求标准 Carousel Ads 必须配乐；按允许范围用 CML（商用音乐库）或符合资质的上传音频 |

## 叙事模式

| 模式 | 卡片流程 |
|---|---|
| 商品组合 | 主产品 -> 变体 -> 卖点 -> 优惠 |
| 问题/解决方案 | 痛点 -> 为什么会发生 -> 解决方案 -> 证明 -> CTA |
| 教程 | 步骤 1 -> 步骤 2 -> 步骤 3 -> 结果 |
| 对比 | 旧方式 -> 新方式 -> 证明 -> 下一步 |
| 社会证明 | 评价 -> 用例 -> 结果 -> CTA |

## 投放说明

- 视可用性用 Traffic、Sales/Web Conversion、App Promotion 或 Reach。
- 在 TikTok Ads Manager 中核验卡片数、文件大小、画幅、文案、CTA 和音乐限制。当前规格区分 Standard Carousel 和 VSA Carousel 的要求。
- 只有账户/形式支持时，才给每张卡设独立落地页。
- 除非当前账户界面明确命名，否则不要把 "video carousel" 当作独立官方产品。

## 常见错误

- 把轮播当作随机图片堆砌。
- 每张卡文字太多。
- 裁剪或设计不一致。
- 明明具体落地页转化更好，却把所有卡都导向通用落地页。
