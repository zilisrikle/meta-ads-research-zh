# Search Ads（搜索广告）

Search Ads 帮助广告主在用户于 TikTok 搜索时触达他们。关键词意图、产品研究、问题解决或类目发现重要时使用。

## 最佳适用场景

- 高意向的产品/类目搜索。
- 问题/解决方案类搜索。
- 政策允许时的竞品或替代品研究。
- App 发现。
- 回答搜索问题的教育内容。
- 再营销已表现出搜索或内容意图的用户。

## 关键词策略

当前官方 Search Ads Campaign 指引支持 Web Conversion 和 Traffic 目标、Landing Page View 优化、Traffic 目标下的关键词层级出价，以及有货时的关键词/否定关键词控制。可用性因市场和账户而异。

| 关键词类型 | 用途 |
|---|---|
| 品牌词 | 防守或放大品牌需求 |
| 类目词 | 捕捉购物者/研究者 |
| 问题词 | 匹配痛点搜索 |
| 竞品/替代词 | 谨慎使用并遵守政策 |
| How-to 词 | 教育与产品演示 |
| 事件/季节词 | 捕捉时效性需求 |

### 匹配类型

| 匹配类型 | 规划用途 |
|---|---|
| Broad match（宽泛匹配） | 覆盖最高，搜索词精度最低 |
| Phrase match（词组匹配） | 围绕词组含义平衡覆盖与相关性 |
| Exact match（精确匹配） | 相关性最高，覆盖最低；近似变体仍可能适用 |
| Negative keywords（否定关键词） | 屏蔽不相关或不安全的搜索词主题；有货时用宽泛、词组或精确否定匹配 |

上线时广告组主题收紧。TikTok 当前指引建议每个 Search Ads Campaign 广告组至少 20 个关键词。

## 创意指引

- 前几秒回答搜索意图。
- 尽早把关键词概念或解决方案打在屏幕上。
- 用演示、证明或对比，不用泛泛的品牌认知。
- 落地页与关键词组对齐。
- 只有当帖子明显匹配搜索意图时才用 Spark Ads。

## 投放说明

- 在 TikTok Ads Manager 中核验当前 Search Ads 可用性、市场支持、匹配类型、关键词上限和否定关键词选项。
- 广告组主题保持收紧。
- 用 UTM 和落地页分析评估搜索流量质量。
- 合适时先用宽泛匹配给系统覆盖和学习，再把验证过的词移到词组/精确匹配（如需更紧的控制）。
- 把搜索词报告（Search Terms Report）既当否定关键词来源，也当关键词拓展来源。
- 关键词、否定词、出价或创意优化能在现有广告系列里做时，避免暂停/重建。

## 搜索词-创意映射

| 搜索词类型 | 创意任务 |
|---|---|
| Best / top / review | 对比与证明 |
| How to / fix / solve | 教育与演示 |
| 品牌词 | 官方来源、优惠、产品线、信任 |
| 竞品 / 替代 | 政策安全的对比与差异点 |
| 价格 / 折扣 | 价值叠加与优惠清晰 |
| 问题词 | 痛点钩子与解决方案证明 |

如果创意前几秒没回答搜索词，这个关键词对该素材来说可能太宽了。

## 常见错误

- 高意向关键词用宽泛的通用视频。
- 一个广告组混很不同的意图层级。
- 只看 CTR 不看转化质量。
- 有否定关键词却不用。
- 以为否定关键词会自动屏蔽复数、拼写错误和同义词。要主动加变体。
