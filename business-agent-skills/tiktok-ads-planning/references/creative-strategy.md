# 创意策略

当用户需要实战的 TikTok 创意方向（而不只是规格）时，用这份参考。TikTok 创意规划应先定义概念、钩子、证明、达人匹配、CTA 和更新体系，再谈素材尺寸。

## 第一性原理

- TikTok 是创意信号平台。定向和出价重要，但弱创意通常救不回来，账户结构也救不了。
- 把创意供给当作运营约束。如果团队不能定期产出新概念，就规划更小的结构、更慢的放量。
- 优化目标是创造需求，不只是收割需求。强 TikTok 创意常表现为品牌搜索、直接流量、Amazon/搜索提升、Shop 需求和再营销池增长。
- 速度重要，但有质量底线。低精修可以；含糊、误导或低信任的创意不行。

## 概念先于变体

| 层级 | 变化的是什么 | 示例 |
|---|---|---|
| 概念（Concept） | 说服逻辑 | "省时间" vs "专家讲品质" vs "社会证明" |
| 钩子（Hook） | 首帧视觉/台词/动作 | 评论反驳、演示先行、痛点点名 |
| 证明（Proof） | 为什么可信 | 演示、评价、数据、达人体验、对比 |
| 优惠（Offer） | 为什么现在行动 | 组合装、试用、折扣、测试、咨询、Shop 促销 |
| 变体（Variant） | 执行细节 | 文案、裁剪、CTA、音乐、首帧 |

如果做功的是同一个论点，换个文案不算新概念。

## 钩子库

| 钩子类型 | 适用 | 模式 |
|---|---|---|
| 痛点点名 | 痛点清晰 | "如果 [问题] 反复出现，试试这个……" |
| 演示先行 | 可视化产品/App | 先展示使用，再解释 |
| 转变预告 | 可见的前后对比 | 先展示结果，再讲路径 |
| 负面评论反驳 | 异议多的类目 | 把质疑评论打在屏幕上并回答 |
| 搜索意图作答 | Search Ads / 教育 | "如何 [解决问题] 又不用 [妥协]" |
| 社会证明 | 信任敏感的卖点 | 先上评价/评论，再给产品证明 |
| 创始人/员工视角 | 品牌故事、技术产品 | "我们做这个是因为……" |
| 打破预期 | 饱和的信息流 | 出乎意料的视觉动作、构图或场景 |

避免 "你有没有想过……" 这类通用开场，除非下一帧异常具体。

## 时长与节奏

| 时长 | 适用 |
|---|---|
| 6–15 秒 | 简单产品、App 安装、优惠、再营销 |
| 15–30 秒 | 演示、对比、线索钩子、异议处理 |
| 30–60 秒 | 教育、高决策产品、证明序列 |
| 60 秒+ | 只有内容天然值得注意力且需要深度时 |

先定说服任务，再用能完成它的最短视频。当前规格允许更长的非 Spark 视频，但大多数直接响应概念仍需要快速证明。

## UGC、达人与品牌创意

达人风格创意常胜出，是因为它具体、可信，而不是因为低制作价值有魔法。

| 风格 | 适用 | 注意点 |
|---|---|---|
| 达人/UGC | 信任、演示、社会证明、原生节奏 | 达人被写死脚本就读起来像广告 |
| 员工/创始人 | 专业度、故事、品质讲解 | 可能变成自我中心 |
| 品牌原生拍摄 | 高端类目、合规、可控宣称 | 仍要用 TikTok 节奏 |
| 精修品牌大片 | 发布和代管高级形式 | 竞价转化通常偏弱 |
| Symphony/AI 辅助 | 变体、b-roll、本地化、翻新 | 通用 AI 输出可能让创意同质化 |

## 达人 Brief 检查清单

好的达人 brief 包括：

- 受众与使用时刻。
- 要戏剧化的问题、误区或欲望。
- 必需的证明或演示。
- 可用宣称与禁用宣称。
- 钩子选项，而不是死脚本。
- CTA 与落地页。
- 使用权、Spark 授权时长、账号关联需求。
- 披露与受监管类目要求。

宣称和合规由你控制；原生表达交给达人。

## 疲劳诊断

| 症状 | 可能含义 | 动作 |
|---|---|---|
| CTR 下滑 | 钩子或受众匹配走弱 | 加新钩子/首帧 |
| 2 秒或 6 秒观看率下滑 | 开头留不住注意力 | 换掉前 1–3 秒 |
| 留存率掉但 CTR 稳 | 主体兑现不了钩子 | 重写演示/证明段 |
| CPM 上涨且互动走弱 | 竞价质量或受众反应在恶化 | 更新创意、安全拓宽、看评论 |
| 评论重复/负面 | 信息疲劳或宣称问题 | 换角度、回应异议、查政策 |
| CPA 随频次上涨 | 受众饱和 | 加概念或扩受众/版位 |

主体还在转化时，先换钩子。多次换钩子都失败时，换概念。

数字阈值只做账户本地触发器，不是通用规则。可启动诊断的示例：钩子率相对账户胜出者基线大幅下滑、频次涨得比创意更新能力快，或 2 秒/6 秒观看率先于 CPA 下滑。新账户先记录首批胜出者做基准，再定淘汰规则。

## 评论挖掘

把评论当定性研究：

- 异议变成反驳钩子。
- 重复问题变成 Search Ads 和教育脚本。
- 赞美揭示证明话术。
- 投诉揭示产品/落地页问题。
- 困惑揭示信息错位。

除非互动/社群就是目标，否则不要把评论本身当 KPI 追。

## 要避免的做法

- "UGC 永远赢。" 更好的说法：可信、具体、原生的创意通常赢。
- "越短越好。" 更好的说法：在完成说服任务的前提下尽可能短。
- "高 CTR 就是好创意。" 更好的说法：CTR 要配留存率、转化率、评论质量和下游质量一起看。
- "AI 解决疲劳。" 更好的说法：AI 能提产能，但人工钩子和差异化概念仍然重要。
