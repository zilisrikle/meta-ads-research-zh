# Branded Effects（品牌特效）

Branded Effects 是用户可用于自己视频的定制 TikTok 特效、滤镜、贴纸或互动体验。通常为代管产品，需要 TikTok 确认制作/规格。

Effect House 是 TikTok 的特效制作环境。视特效复杂度和代管准入，可选用 Effect House 或 TikTok/合作伙伴制作流程。

## 最佳适用场景

- 产品试用或可视化。
- 与品牌资产的趣味互动。
- Hashtag Challenge 助推。
- 娱乐、美妆、快消、游戏、体育和发布时刻。

## 特效类型

| 类型 | 用途 |
|---|---|
| 2D 特效 | 简单叠加、贴纸、背景 |
| 2D Pro / 面部特效 | 妆容、发型、面部变换、试用 |
| 3D 特效 | 产品物体或更丰富的视觉互动 |
| 游戏化特效 | 小游戏或计分式参与 |

## 制作检查

- 制作前先确认 Effect House / TikTok 关于封面图、图标、赞助标识、安装包大小和设备支持的规格。
- 简单的面具、贴纸或 2D 素材可用 Asset Studio 或其他 Effect House 工具加速。
- 用真机测试；特效可能因人脸追踪、光线、设备性能或说明不清而失效。

## 创意指引

- 好玩到不需要长说明。
- 品牌元素可见但不喧宾夺主。
- 围绕用户参与设计，不只是品牌装饰。
- 搭配达人、Spark Ads、Branded Hashtag Challenge 或 In-Feed 助推。

## 规划输入

| 输入 | 为什么重要 |
|---|---|
| 特效机制 | 决定制作复杂度 |
| 市场与设备支持 | 不同设备上特效表现可能不同 |
| 音乐/声音 | 需要合规的广告版权 |
| 达人冷启动 | 特效需要示范 |
| 审核 | UGC 可能产生意外含义 |

## 衡量

使用特效打开、视频创作、观看、互动、达人采用、话题活动、情感和品牌提升（如有）。

## 常见错误

- 做了技术上惊艳但难用的特效。
- 过度品牌化。
- 没有达人示范。
- 没有付费助推来冷启动。
