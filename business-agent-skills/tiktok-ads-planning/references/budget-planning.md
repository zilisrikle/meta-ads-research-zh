# 预算规划

用这份参考判断 TikTok Ads 方案的预算和信号是否足以学习。数字是规划用的经验法则，不是承诺。

## 预算可行性

TikTok 官方指引建议基于当前 CPA/CPR 和优化深度设定预算。实用的官方量级经验法则：

| 优化目标 | 规划指引 |
|---|---|
| 高漏斗 / 非转化事件 | 通常需要更大的动作量；至少用平台最低预算，并验证质量 |
| 浅层转化事件 | 量大可以学习，但可能优化到低质量行为 |
| 深层转化事件 | 日预算通常需要达到当前 CPA 的 10 倍左右 |
| 安装类广告系列 | 通常需要达到当前 CPA 的 20 倍左右 |
| Search Ads 广告系列 | 日预算与目标 CPA 的比值很关键；给关键词学习留足预算 |

如果没有当前 CPA/CPR，只用本地基准粗估广告系列能否产生足够的有意义动作。不要承诺基准 CPM/CPC/CPA。

## 预算不足诊断

| 症状 | 可能的问题 | 规划对策 |
|---|---|---|
| 无消耗 | 出价/目标太紧、受众太窄、政策/审核问题 | 放宽目标、安全拓宽、检查审核 |
| 有点击无转化 | 事件太深、卖点/落地页弱、追踪坏了 | 检查事件、落地页、创意承诺 |
| 学习期始终不稳定 | 预算/量级太少或修改太频繁 | 合并、减少改动 |
| Cost Cap 花不出去 | 上限太激进或信号弱 | 提高上限、切到 Maximum Delivery、改善信号 |
| VBO 不稳定 | 价值信号太稀疏或太脏 | 在购买价值可靠前先用成本出价 |

## 出价策略选择

| 情况 | 更合适的姿态 |
|---|---|
| 新账户 / 信号稀疏 | Maximum Delivery + 简单结构 |
| CPA 历史稳定 | Cost Cap + 现实的目标 |
| 有硬性出价上限 | 只有能接受量级损失时才用 Bid Cap |
| 购买价值重要 | Highest Value / Minimum ROAS / Target ROAS（视支持情况） |
| TikTok Shop | 稳定的 GMV Max 用 Target ROI，探索量级用 Max Delivery |
| 线索质量弱的线索收集 | 优化/归因到合格线索质量，不只看 CPL |

## 学习与放量

TikTok 学习期的波动通常在约 25 个广告系列结果或 7 天后趋于平稳。学习期间：

- 除非有东西坏了，否则避免改动定向、出价、预算、目标、优化事件和大幅的创意量级。
- 常年在线的广告系列用日预算，除非是固定时长的活动。
- 学习期结束后，避免无理由的大幅跳预算。保守的做法是阶梯式放量，通常一次约 20%，然后观察消耗、CPA/ROAS 和创意疲劳再做下一步。
- 批量改动并保留改动日志。
- 先扩创意供给，再硬推媒体花费。

## 基准值

基准值只做合理性检查：

- CPM 和 CPC 因市场、目标、季节、创意质量和版位而异。
- 如果评论、转化率或线索/订单质量差，便宜的 CPM 并不便宜。
- 低 CPC 可能掩盖弱落地页或低意向受众。
- 平台 ROAS 和 GMV 不是贡献毛利。

放量前先估算：

1. 预算能换来多少展示/点击/转化。
2. 需要多少创意更新量。
3. 真实来源指标：CRM 收入、Shopify/订单、Seller Center 净收入、App LTV 或财务毛利。
4. 广告系列能否拿到足够的事件，而不必优化到更浅但误导的动作。
