# 创意测试

规划创意测试、更新节奏或创意决策规则时，用这份参考。

## 测试原则

- 先测概念，再测 cosmetic（表面样式）变体。
- 一次隔离一个主要学习点。
- 测试差异要大到能改变用户行为。
- 上线前先定指标和决策规则。
- 不要把单日噪音当证据。
- 保留创意日志：概念、钩子、达人、证明、优惠、受众、结果、评论主题。

## 官方基线与实战经验

TikTok 的推荐指引通常建议**每个广告组 3–5 条独立创意**以避免疲劳。把它当作常规上线单元的基线。

大账户的实战经验通常需要更高产能，但每周确切的创意数量按花费而定：

| 花费 / 规模 | 实战姿态 |
|---|---|
| 小规模上线 | 每个广告组 3–5 条差异化创意 |
| 成长账户 | 每周更新钩子和概念 |
| 放量账户 | 计划性创意上新、达人备选池、混剪胜出者 |
| 高花费账户 | 创意 pipeline 成为主要操作系统 |

## 测试类型

| 测试 | 好的设计 | 差的设计 |
|---|---|---|
| 钩子 | 同主体/同优惠，多个差异化开头 | 什么都不同 |
| 概念 | 不同的说服角度 | 同概念换文案 |
| 达人 | 同 brief 跨达人 | 不同达人用不同宣称/优惠 |
| 优惠 | 同结构，不同优惠 | 优惠+受众+落地页一起变 |
| 落地页 | 同广告导网站 vs 即时页面/表单 | 创意和目标都不同 |
| 搜索创意 | 同关键词主题，不同作答/证明 | 高意向搜索词上通用信息流创意 |

## 上线节奏

新上线：

1. 定商业模式和目标。
2. 用简单结构上线，预算要撑得起该事件。
3. 用多个差异化概念，不用大量近似重复。
4. 除非追踪、政策、花费或落地页坏了，让学习期收够结果。
5. 按领先创意信号和下游质量淘汰或更新创意。

现有账户：

1. 加新创意前先识别失败模式。
2. 钩子弱就更新开头。
3. 留存弱就重写主体/证明。
4. 钩子/留存健康但转化率弱，检查优惠、落地页、事件和线索/订单质量。
5. 尽量保留已验证的学习；不要为创意问题重建账户。

## 决策信号

| 信号 | 用途 |
|---|---|
| CTR | 对承诺的兴趣；没有转化率配合时会误导 |
| 2 秒/6 秒观看 | 钩子强度与早期留存 |
| 留存率 / 观看深度 | 主体质量与节奏 |
| CVR / CPA / ROAS | 滞后确认 |
| 评论 | 异议、困惑、证明话术 |
| 频次 | 饱和风险 |
| 落地页或表单质量 | 点击是否有用 |

## 创意更新规则

- 早期观看指标先于转化率下滑时，更新钩子。
- 保留胜出的主体，测试新开头。
- 换钩子不再奏效时，换概念。
- 证明/信任是瓶颈时，用 Spark Ads 和达人变体。
- 不要随手暂停稳定的广告组；有目的地加/换创意。

## 创意研究工作流

1. 按市场、类目、目标、CTR、2 秒/6 秒观看、CVR、点赞和时效，用 TikTok Creative Center / Top Ads。
2. 把案例存进模式桶，而不是 "要抄的广告"。
3. 标注前 3 秒、证明类型、产品露出时机、CTA、文字密度和评论主题。
4. 把模式转成 brief：演示先行、评论反驳、前后对比、对比、创始人视角、达人故事。
5. 产出适配品牌、优惠、使用权和政策限制的版本。
