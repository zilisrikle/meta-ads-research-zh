# NewFronts 2026 高级形式

TikTok 在 NewFronts 2026 上发布了多款高冲击品牌解决方案。在 TikTok 确认账户、市场、价格和购买路径之前，把它们当作代管/高级产品处理。

## 形式

| 形式 | 用途 |
|---|---|
| Logo Takeover | 重大发布或文化时刻的联名开屏曝光 |
| Prime Time | 序列化叙事：短时间内向同一用户展示同一广告主的最多三条广告 |
| TopReach | TopView + Top Feed 打包购买，最大化单日覆盖 |
| Pulse Mentions | 把广告放在围绕品牌或类目的实时讨论旁边 |
| Pulse Tastemakers | 通过 Pulse 套件把广告与精选的符合资质达人对齐 |

## 规划指引

- 用于重大认知、tentpole（大事件）、娱乐、发布或文化时刻广告系列。
- 向 TikTok 确认市场可用性、套餐要求、创意规格、排期、独占性和衡量选项。
- 规划后续的竞价广告系列做再营销、Search Ads、Spark Ads、网站转化、Shop 或线索承接。
- 首要解读用品牌提升、覆盖/频次、观看质量、搜索/直接流量提升和下游池增长，不用末次点击 CPA。

## 常见错误

- 把新发布的高级形式当自助产品。
- 买了高冲击版位却没有后续漏斗。
- 用宽泛的品牌大片创意，而不是为该时刻准备的一个锐利信息。
- 把别市场的价格或可用性写死。
