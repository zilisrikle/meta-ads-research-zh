# In-Feed Ads（信息流广告）

In-Feed Ads 是出现在 For You 信息流及其他符合资质信息流环境中的标准 TikTok 视频广告。它是效果、测试和常年在线投放的默认灵活形式。

## 最佳适用场景

- 网站流量与转化。
- App 安装与 App 事件。
- 产品演示与达人风格广告。
- 线索收集助推。
- 再营销与序列化信息。
- 放量到更广泛广告系列类型前的创意测试。

## 规格与配置

制作前用当前 TikTok Ads Manager 规格。常见的规划假设：

| 项 | 指引 |
|---|---|
| 创意 | 竖屏视频是默认创意姿态 |
| 画幅 | 首选 9:16；视版位可能支持 1:1 和 16:9 |
| 时长 | 当前指引下非 Spark 竞价视频最长可达 10 分钟；9–15 秒仍是常见的效果甜点 |
| 音频 | 用已授权音频；避免未授权的商业音乐 |
| CTA | 从 TikTok Ads Manager 预设中选择 |
| 落地页 | 网站、App、TikTok Shop、线索表单或其他符合资质的目的地 |

## 创意实操

- 前 1–3 秒承担钩子。
- 尽早露出产品、达人或结果。
- 用字幕或文字叠加。
- 避免冗长的品牌开场。
- 让广告感觉像 TikTok，不像 repurposed（挪用）的电视或展示广告。
- 测试多个差异化概念，不只做小改。

## 广告系列设计

| 场景 | 推荐姿态 |
|---|---|
| 新上线 | 宽泛或简单定向、多个创意概念、Maximum Delivery 或合适的自动出价 |
| 转化放量 | 稳定事件、预算充足、有信号后再用 Cost Cap |
| 再营销 | 高意向用更短窗口；报告重要时与拓新分开 |
| 创意测试 | 每个广告组或测试单元一个清晰假设 |

## 衡量

平台指标和业务指标都要看：

- CPM、CTR、CPC、视频观看、留存率、CPA/ROAS。
- 落地页行为、结算/表单质量、App 事件。
- 评论质量与定性匹配度。

## 常见错误

- 拿精修品牌视频不改直接复用。
- 预算太少还测太多小变体。
- 业务要转化却优化点击。
- 忽视评论和定性反馈。
