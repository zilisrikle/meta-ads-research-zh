# Smart+ Catalog Ads（智能+商品目录广告）

Smart+ Catalog Ads 是面向网站或 App 销售落地页的商品目录驱动型产品广告。TikTok 旧的 Dynamic Showcase Ads / 商品目录广告术语可能仍出现在帮助文章或账户中，但当前规划应使用 **Smart+ Catalog Ads** 或有货时的 **Video Shopping Ads with Catalog**。

## 最佳适用场景

- 基于商品目录的再营销。
- 大商品集。
- 个性化商品推荐。
- 符合资质的 TikTok Shop 之外电商广告系列。
- 有可用商品目录但没用 TikTok Shop 的网站或 App 电商。

## 要求

- 商品目录已连接并过审。
- 至少达到当前账户流程要求的最低可行商品集。
- TikTok Pixel 和/或 Events API 已配置。
- 事件与商品目录之间的商品 ID 对齐。
- 商品 feed 标题、价格、库存、图片、URL 准确。
- 商品集反映类目、毛利、库存或广告系列目标。

## 广告系列设计

| 角色 | 用途 |
|---|---|
| 再营销 | 挽回观看者、商品页访客、弃购者 |
| 拓新 | 有货时用商品目录相关性找新客 |
| 交叉销售 / 向上销售 | 向老客推互补商品 |

## 衡量

追踪 CPA、ROAS、商品层级收入、贡献毛利、新客 vs 老客，以及 feed/商品错误。

## 常见错误

- 商品 ID 不匹配。
- feed 里有缺货商品。
- 商品图弱。
- 再营销窗口太宽。
- 只报收入不报毛利和退货。
- 当前账户界面用 Smart+ Catalog Ads，对客方案里却叫 "DPA" 或 "Dynamic Showcase Ads"。
